## 6.1 Formula for preΨ' 7

A direct Mathlib proof should be short:

1. define the Tate Weierstrass curve with a_1=1-c, a_2=a_3=-b, and a_4=a_6=0;

1. evaluate Ψ₂Sq, Ψ₃, and preΨ₄ at X=0;

1. rewrite preΨ'_odd for indices 5 and 7 and preΨ'_even for index 6;

1. finish each scalar polynomial identity with ring.

The key base lemmas to expose are

```javascript
F 2 = 1
F 3 = -b ^ 3
F 4 = -b ^ 4 * c
```

followed by

```javascript
F 5 = b ^ 8 * (b - c)
F 6 = b ^ 11 * (c ^ 2 + c - b)
F 7 = b ^ 16 * (c ^ 3 + b * c - b ^ 2)
```

The first line must use preΨ'_two; substituting -b there would mix the full Ψ₂ convention into Mathlib's auxiliary sequence and give the wrong recurrence.

## 6.2 Modulo 2: avoid expanding the order-49 polynomial

The most economical formal proof is finite and group-theoretic.

1. Move to ZMod 2.

1. From b\ne0, obtain b=1.

1. Split on the two possibilities c=0 and c=1.

1. Enumerate the curve points, or directly compute that P has order 4 in the first case and order 5 in the second.

1. Conclude [49]P\ne O, hence the odd division polynomial at 49 does not vanish.

The project archive already refers to the bridge KeystoneEDS.nsmul_eq_zero_iff_ΨSq_eval; if its hypotheses fit this file, it is the natural final step. Otherwise, proving the two concrete scalar recurrence values F_{49}=1 is also tiny after specializing b,c.

## 6.3 Modulo 3

There are only six pairs with b\ne0. A fin_cases proof can verify that any pair satisfying F_{49}=0 is (1,2), then close by the explicit formula F_7(1,2)=0. Again, recurrence evaluation at six concrete field points is preferable to importing a 2000-term expanded polynomial.

# 7. Reproducible Wolfram Language computation

The following uses precisely the specialized Mathlib recurrence. It computes the exact order-7 formula, the exact factorization shape at order 49, and the finite-field normal forms.

```javascript
ClearAll[b, c, u, q2sq, q7, h49, nf];

q2sq = b^4;  (* (Psi_2^Sq(0))^2 *)

u[0] = 0;
u[1] = 1;
u[2] = 1;
u[3] = -b^3;
u[4] = -b^4 c;

u[n_Integer?Positive] /; n >= 5 := u[n] = Module[{k, m},
  If[EvenQ[n],
    k = n/2;
    Expand[
      u[k - 1]^2 u[k] u[k + 2]
        - u[k - 2] u[k] u[k + 1]^2
    ],
    k = (n - 1)/2;
    m = k - 2;
    Expand[
      u[k + 2] u[k]^3 If[EvenQ[m], q2sq, 1]
        - u[k - 1] u[k + 1]^3 If[EvenQ[m], 1, q2sq]
    ]
  ]
];

Factor[u[7]]
(* b^16 (c^3 + b c - b^2) *)

q7 = c^3 + b c - b^2;
h49 = Cancel[u[49]/(b^800 q7)];

{Exponent[h49, b], Exponent[h49, c],
 Length[CoefficientRules[h49, {b, c}]]}
(* {98, 147, 3526} *)

nf[f_, p_] := PolynomialReduce[
  PolynomialMod[f, p],
  {b^p - b, c^p - c}, {b, c}, Modulus -> p
][[2]];

{nf[u[7], 2], nf[u[49], 2], nf[h49, 2]}
(* {b, b, b + c + b c} *)

{nf[u[7], 3], nf[u[49], 3], nf[h49, 3]}
(* {
  2 b^2 + b c + b^2 c,
  b^2 + b^2 c + 2 b c^2 + b^2 c^2,

} *)
```
