# Why N13 has the highest expected return

N13 is the only endpoint whose remaining work is presently described by a small, named boundary:

- one local algebra obligation, FirstJetDoublingCompatibility;

- one global comparison obligation, class_eq_iff;

- an endpoint theorem, N13RationalPicardEndpoint.affine_x_is_cuspidal, already matching the assembled axiom.

The repository snapshot contains real, nontrivial N13 mathematics rather than empty scaffolding. For example, FLT/Assumptions/MazurProof/N13VerticalGraphJacobian.lean proves explicit curve, derivative, Jacobian-decomposition, and invertibility statements in the N13 integral/Mumford framework. That makes the 283-file body meaningful evidence of reusable infrastructure, even though the file count must not be interpreted as a completion percentage.

The two gaps have very different risk profiles.

## FirstJetDoublingCompatibility is bounded and certificate-friendly

For monic quadratics

```plain text
P.u   = X² + aX + b,
Q.u   = X² + AX + B,
uBase = X² + a₀X + b₀,
```

the adapter conditions reduce exactly to

```plain text
2a - a₀ - A ∈ I²,
2ab - a₀B - b₀A ∈ I².
```

For the natural base uBase = X² + X, they become

```plain text
2a - 1 - A ∈ I²,
2ab - B ∈ I².
```

This is a finite polynomial/ideal-membership problem. A Sage, Magma, or Singular computation can discover a Gröbner or syzygy certificate; Lean need only check the exported polynomial identities and ideal memberships. It may still require careful convention matching, but it is a bounded engineering task with a clear acceptance test.

## class_eq_iff is risky but still fixed and finite in principle

For J(X₁(13))(ℚ) ≅ ℤ/19ℤ, the useful group kernel is not ⊤. If G is already a faithful model of the rational Jacobian, use kernel = ⊥; if there is an explicit class-code homomorphism, use its actual kernel and prove injectivity. Taking the full group would collapse the quotient and make equality reflection circular.

Because 19 is prime, the global classification can potentially be reduced to a finite class table:

1. construct a concrete class code into ZMod 19;

1. prove that it represents the Abel–Jacobi/Picard class used by the endpoint theorem;

1. enumerate the special/cuspidal class codes;

1. prove that a generic mapped-special class equal to one of those codes forces the corresponding affine point to be a cusp.

If the existing 283-file pipeline already supplies the geometric maps and leaves only this explicit 19-class reflection, N13 is markedly closer than any other endpoint. Closing it also validates a large body of existing architecture and turns hundreds of files from isolated infrastructure into a theorem used by the headline result.

# The essential N13 truth audit

The phrase “two gaps remain” is useful only after checking that neither gap restates the theorem. The first N13 milestone should therefore be an exact dependency audit, not more auxiliary infrastructure.

The audit should answer the following questions directly from Lean declarations:

1. What is G? Is it the actual rational Picard group, a presentation, a quotient, or merely an abstract additive group parameter?

1. What homomorphism has kernel as its kernel? Instantiate ⊥ or the kernel of a concrete class-code map; reject ⊤ unless the theorem is deliberately about a trivial quotient.

1. What are the two sides of class_eq_iff? Expand every abbreviation until one side is a concrete equality and the other is a concrete geometric statement.

1. Which direction is missing? Equality preservation is usually formal; equality reflection is the substantive part. Is reflection already implied by an injective class map, or does it assume the desired rational-point classification?

1. Where is J(ℚ) ≅ ZMod 19 proved and connected to this G? A separate computational fact about the Jacobian does not help until a Lean equivalence or injective homomorphism is wired into the endpoint types.

1. Does the generic family cover every affine rational point under consideration? Otherwise the final theorem may close only a chart.

The gate passes only when class_eq_iff can be restated as a finite, noncircular theorem whose inputs are already constructed. A good normal form would look conceptually like:

```plain text
classCode (genericClass P) = classCode (specialClass s)
    ↔ concrete relation identifying P with the special point s,
```

with classCode proved injective on the relevant classes.

The gate fails if proving it requires, from scratch, a general theory of genus-two Jacobians over ℚ, Mordell–Weil finite generation, a full descent calculation, or a new theorem already equivalent to “all rational points are cusps.” In that event, the 283 files are valuable local infrastructure, but N13 is not actually two bounded lemmas from closure.

# Why N49 should not receive the main effort now

The statement “8 of 9 charts are closed” sounds close, but the surviving chart changes the interpretation completely. A genuine Hensel-liftable ℚ₂ point means the p=2 local-obstruction strategy is not missing one technical inequality; its intended conclusion is false on that chart.

Thus the project is not 89% through one proof. It has completed the negative part of a local analysis and discovered that the remaining component needs a qualitatively different global mechanism.

This makes further work of the following kinds low-return:

- more refinement of the same p=2 Newton polygon hoping the genuine branch disappears;

- additional chart bookkeeping that does not constrain the global rational points;

- formalizing all 3526 coefficients before a global theorem using them has been identified.

A bounded N49 reconnaissance is still worthwhile, but it should have a hard output criterion: produce a globally constraining map or invariant. Candidate questions include:

- Does the surviving component map to a lower-genus quotient or to an explicitly rank-zero Jacobian factor?

- Is there an involution, modular quotient, or norm relation that sends every rational point to a finite computable set?

- Can the bihomogeneous curve be decomposed into components or covers whose rational points admit descent, Chabauty, or Mordell–Weil-sieve certificates?

- Is there a second prime that eliminates precisely the rational residue classes compatible with the genuine 2-adic branch, yielding a multi-prime rather than single-prime obstruction?

- Can one connect the Tate-normal-form equation to the known X₀(49) rank-zero route without building an uncontrolled general modular-curve library?

The archived project analysis in zinan/dialogues/claude-code/2026-07-10-4263836a.md already identified the historical global obstacles: the intended X₀(49)/49a1 argument needs an explicit modular map plus rank-zero/descent infrastructure, while the direct Tate-normal-form route lands on a high-genus rational-point problem. The new 2-adic discovery confirms that this global layer can no longer be bypassed by the original local strategy.

N49 should return to a primary lane only after the reconnaissance produces one of:

- an explicit low-genus quotient with a formalizable rational-point theorem;

- a finite descent or Mordell–Weil-sieve certificate;

- a multi-prime obstruction covering the surviving branch;

- a new factorization that reduces the global statement to already formalized arithmetic.

Without such an object, N49 has an open research problem rather than a bounded Lean gap.

# Why the p≥23 endpoint is fourth

no_prime_order_ge_23 has the greatest strategic scope but the lowest near-term return per unit effort. The project’s archived roadmap calls the prime-order layer “the mountain,” and the current status says there is no comparable infrastructure.

A genuine proof requires a chain containing substantial parts of:

- modular curves and cusps as algebraic objects;

- degeneracy/modular maps with their moduli properties;

- Jacobians or generalized Jacobians;

- Hecke operators and q-expansions;

- the Eisenstein ideal and relevant quotient finiteness;

- reduction/specialization at primes;

- formal immersion at the cusp;

- the argument translating a rational torsion point into a forbidden rational modular-curve point.

Starting this stack now creates many new interfaces before any of the three fixed-level endpoints has certified which abstractions the project can actually support. It is therefore rational to maintain only a design seam:

```plain text
axiom replacement theorem type;
minimal definitions needed by callers;
source theorem decomposition;
which finite computations can be certified;
which general Mathlib additions would be reusable.
```

Full implementation should begin when either the fixed-level work has produced reusable modular/Jacobian infrastructure or a separate team can pursue it without displacing the finite endpoints.

# Concrete portfolio decision

The correct portfolio is not “pick exactly one and stop all others.” It is:

1. Make N13 the closure campaign. Its first deliverable is a noncircular, fully expanded class_eq_iff statement; its second is the centered-doubling first-jet certificate.

1. Keep N25 continuously active. Protect its existing momentum, but measure progress by eliminated endpoint obligations rather than commit count.

1. Park N49’s p=2 chart campaign. Permit only global-route experiments with explicit success/failure criteria.

1. Do not yet build the uniform-prime stack on the critical path. Record interfaces and source decomposition so later work starts cleanly.

The most important immediate result is not necessarily a Lean theorem. It is a reliable answer to this binary N13 question:

After instantiating an honest kernel, is class_eq_iff a finite 19-class equality-reflection certificate, or is it a placeholder for the complete Mordell–Weil/Picard classification?

If the answer is the former, N13 is decisively the highest-return target. If the answer is the latter, N25 becomes the highest-return target and N13 should be reclassified from “wiring” to “new global arithmetic.”

# Final recommendation

Prioritize N13 now, but place a strict truth gate in front of further infrastructure work. Close FirstJetDoublingCompatibility in parallel because it is concrete and certificate-friendly. Spend the main analytical effort reducing class_eq_iff to a finite, honest statement over the explicit ZMod 19 class model. Keep N25 as the durable second lane and immediate fallback. Do not interpret N49’s 8/9 chart count as nearness after the genuine ℚ₂ branch, and do not start the p≥23 mountain on the main critical path while three fixed-level endpoints remain.
