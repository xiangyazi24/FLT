# Verdict

There is no direct theorem in the audited N13 infrastructure that consumes

```javascript
z.property : red₂ (z : G) = 0
```

and produces either

```javascript
Ideal.map reduceCoordinate
  (contractIdeal (graphIdeal canonicalRepresentative.toSemi)) =
    specialIdeal
```

or

```javascript
∃ P : DiskPair,
  centeredPic P = subgroupToPic red₂.ker z.
```

The three modules named in the question are noncircular and are useful pieces of the proof, but they are lower-level algebraic infrastructure. None of them connects membership in the kernel of a class-level reduction homomorphism with the special fiber of the canonical Mumford representative.

The closest existing result is

```javascript
N13ConcreteGraphRecovery.exists_diskPair_class_eq
```

which proves the desired disk-pair recovery assuming precisely the missing contraction-to-specialIdeal equality. The current producer of that equality for all kernel elements is in N13RationalPicardEndpoint.lean, and it still passes through class_eq_iff.

Thus the remaining gap is real, but it is narrower than a new formal-group theory:

Prove the zero-fiber specialization compatibility saying that a class killed by the independently defined reduction map has the same special class as the base divisor.

Once that one-fiber theorem is available, the existing contraction, saturation, graph-recovery, and chart-section files complete kernel coverage formally.

# 1. What the three named modules actually prove

## N13IntegralModelContraction.lean

This file defines contraction of a rational ideal back to the integral coordinate ring:

```javascript
def contractIdeal (I : Ideal RationalRing) : Ideal IntegralRing := ...
```

Its important theorems are of the following form:

```javascript
@[simp] theorem mem_contractIdeal_iff ...

theorem map_contractIdeal_localization (I : Ideal RationalRing) :
  Ideal.map algebraMap₂ (contractIdeal I) = I

theorem contractIdeal_eq_of_map_eq_of_scalarSaturated
    (I J : Ideal IntegralRing)
    (hmap : Ideal.map algebraMap₂ I = Ideal.map algebraMap₂ J)
    (hJ : ScalarSaturated J) :
    contractIdeal (Ideal.map algebraMap₂ I) = J
```

These are exactly the right tools for proving that two integral lattices with the same generic fiber coincide once one is vertically/scalar saturated.

What the file does not contain is any of the following:

```javascript
red₂
red₂.ker
specialClass
specialIdeal
DiskPair
```

It cannot infer which special Picard class an ideal represents. It only compares integral and generic ideals after the ideals have already been supplied.

## N13GeneralizedMumfordReduction.lean

This file constructs the actual coefficient-reduction maps

```javascript
def reduceBase : ℤ_[2] →+* ZMod 2
def reducePoly : ℤ_[2][X] →+* (ZMod 2)[X]
def reduceCoordinate : IntegralRing →+* SpecialRing
```

and packages smooth integral generalized Mumford data:

```javascript
structure SmoothMumford₂ where
  u v w : ℤ_[2][X]
  u_monic : u.Monic
  curve_eq : ...
  bezout : ...
```

For an already-given smooth integral representative it proves that reducing its integral ideal gives its reduced Mumford ideal:

```javascript
theorem SmoothMumford₂.map_integralIdeal (D : SmoothMumford₂) :
  Ideal.map reduceCoordinate D.integralIdeal = D.reducedIdeal
```

Again, this is the correct local algebra, but its direction is

```plain text
chosen smooth integral Mumford graph
        → reduced graph/ideal.
```

It does not prove

```plain text
rational Picard class in ker(red₂)
        → chosen integral graph reduces to the base graph.
```

In particular, the file does not select an integral Mumford representative of an arbitrary Picard class, prove that selection is compatible with red₂, or identify the resulting reduced ideal with the fixed N13SpecialQuotientBasis.specialIdeal.

## N13CanonicalContractionQuotient.lean

This file forms the quotient by the canonical contracted graph ideal and maps it to the rational quotient:

```javascript
abbrev IntegralQuotient (D : Mumford ...) :=
  IntegralRing ⧸
    N13IntegralModelContraction.contractIdeal
      (graphIdeal D.toSemi)

abbrev RationalQuotient (D : Mumford ...) :=
  RationalRing ⧸ graphIdeal D.toSemi

def quotientMap (D : Mumford ...) :
  IntegralQuotient D →+* RationalQuotient D
```

and proves

```javascript
theorem quotientMap_injective (D : Mumford ...) :
  Function.Injective (quotientMap D)
```

This says that the canonical integral contraction embeds faithfully into the generic quotient. It contains no special-fiber classification and no kernel-membership theorem.

## Summary of the module audit

So the fact that these theorems take only Mumford/ideal data is not enough by itself. The missing input is the theorem that the Mumford/ideal data attached to a class in ker(red₂) belongs to the identity residue fiber.

# 2. The closest direct recovery theorem

The exact recovery theorem already exists in N13ConcreteGraphRecovery.lean:

```javascript
theorem exists_diskPair_class_eq
    (D : SexticMumford.Mumford Model)
    (hmap :
      Ideal.map
          N13GeneralizedMumfordReduction.reduceCoordinate
          (N13IntegralModelContraction.contractIdeal
            (N13CanonicalContractionQuotient.graphIdeal D.toSemi)) =
        N13SpecialQuotientBasis.specialIdeal) :
    ∃ P : N13TwoAdicAbelChartData.DiskPair,
      SexticMumford.classOf
          Model
          (N13Infinity.positiveInfinityOrder ℚ_[2])
          D =
        N13TwoAdicAbelChartPic.DiskPair.pic P
```

This theorem is exactly what is needed after the contraction equality:

1. hmap forces the canonical integral model into the selected nonspecial quadratic special graph.

1. Graph recovery gives two Hensel roots in the two distinguished disks.

1. The resulting DiskPair represents the original two-adic Picard class.

1. Translating by the base pair gives the centered equality required by RationalKernelDoublingData.

Therefore no new Hensel, coordinate-injectivity, or Mumford-rigidity theorem is needed. The only missing premise is hmap.

# 3. Where the current code becomes circular

The current endpoint first proves an independent comparison between the canonical contraction and the chosen exact spread:

```javascript
theorem exactNormalizedContractionMatchesSpread
    (kernel : AddSubgroup G) :
    ExactNormalizedContractionMatchesSpread kernel
```

Conceptually, for z : kernel this gives

```plain text
reduction of canonical contraction of the normalized class
  = affine special restriction of exactSpreadLine (z + basePic).
```

This theorem is noncircular. It uses the exact spread's vertical saturation and the contraction uniqueness theorem.

The remaining step is to identify that exact spread's special divisor with the fixed base divisor. The current source proves:

```javascript
theorem exactTranslated_specialDivisor_eq_base
    (kernel : AddSubgroup G)
    (class_eq_iff :
      ∀ L M : SpreadLine,
        specialClass L = specialClass M ↔
          genericClass kernel L = genericClass kernel M)
    (z : kernel) :
    (exactSpreadLine ((z : G) + rationalBasePic)).divisor =
      (exactSpreadLine rationalBasePic).divisor
```

and the proof uses

```javascript
(class_eq_iff
  (exactSpreadLine ((z : G) + rationalBasePic))
  (exactSpreadLine rationalBasePic)).mpr
```

with z.property to prove equality in the quotient by kernel.

That theorem is then used by

```javascript
exactTranslated_affineIdeal_eq_base
exactTranslated_affineIdeal_eq_special
canonicalMappedSpecialFamilyOfExactSpread
```

and finally by the graph-recovery adapter.

Thus the exact circular edge is:

```plain text
z.property : z ∈ kernel
    ↓ class_eq_iff
translated exact spread has base special class/divisor
    ↓
translated affine ideal = specialIdeal
    ↓ independent contraction comparison
canonical contraction reduces to specialIdeal
    ↓
DiskPair recovery.
```

There is no hidden alternative producer in the three contraction/reduction modules.

# 4. The genuinely missing theorem

The global pairwise equivalence class_eq_iff is stronger than kernel coverage needs. Kernel coverage requires only the identity fiber.

A clean minimal proposition is:

```javascript
def KernelSpecializesToBase
    (H : AddSubgroup G) : Prop :=
  ∀ z : H,
    N13RationalCurvePointPicardRealization.specialClass
        (N13RationalPicardSpreadExistence.exactSpreadLine
          ((z : G) +
            N13RationalAbelChartBase.rationalBasePic)) =
      N13RationalCurvePointPicardRealization.specialClass
        N13RationalAbelChartBase.baseSpreadLine
```

An equivalent, slightly lower-level formulation is:

```javascript
def KernelSpecialDivisorEqBase
    (H : AddSubgroup G) : Prop :=
  ∀ z : H,
    (N13RationalPicardSpreadExistence.exactSpreadLine
      ((z : G) +
        N13RationalAbelChartBase.rationalBasePic)).divisor =
      (N13RationalPicardSpreadExistence.exactSpreadLine
        N13RationalAbelChartBase.rationalBasePic).divisor
```

The first formulation is preferable when it is to be derived from an independently defined reduction homomorphism. The second is convenient for immediate use by the spread-restriction code.

This is not the full rational-point theorem and not the full pairwise class_eq_iff. It says only:

```plain text
red₂ z = 0
  → specialization of z + base equals specialization of base.
```

That is the standard zero-fiber compatibility of a group reduction map.

# 5. Reusing the existing contraction machinery once zero-fiber specialization is proved

The current source can be refactored with a new constructor that replaces class_eq_iff by KernelSpecializesToBase.

The following is a compile-facing sketch mirroring the declarations already present. Depending on local abbreviation unfolding, one or two simpa/change steps may be needed, but no additional mathematical hypothesis is hidden.

```javascript
namespace MazurProof.N13RationalPicardEndpoint

noncomputable section

/-- The only special-fiber statement required for kernel coverage. -/
def KernelSpecializesToBase
    (kernel : AddSubgroup G) : Prop :=
  ∀ z : kernel,
    N13RationalCurvePointPicardRealization.specialClass
          (N13RationalPicardSpreadExistence.exactSpreadLine
            ((z : G) +
              N13RationalAbelChartBase.rationalBasePic)) =
        N13RationalCurvePointPicardRealization.specialClass
          N13RationalAbelChartBase.baseSpreadLine

/-- Zero-fiber specialization is enough to construct the canonical
mapped-special family; no pairwise `class_eq_iff` is used. -/
def canonicalMappedSpecialFamilyOfKernelSpecializesToBase
    (kernel : AddSubgroup G)
    (hzero : KernelSpecializesToBase kernel) :
    N13RationalKernelDoublingAdapter.CanonicalMappedSpecialFamily
      kernel := by
  refine ⟨?_⟩
  intro z

  -- Independent localization/saturation comparison.
  have hmatched :=
    exactNormalizedContractionMatchesSpread kernel z

  -- Convert zero-fiber equality to literal equality of the selected
  -- special divisors.
  have hdiv :
      (N13RationalPicardSpreadExistence.exactSpreadLine
        ((z : G) +
          N13RationalAbelChartBase.rationalBasePic)).divisor =
        N13RationalAbelChartBase.specialBaseDivisor := by
    apply N13RationalAbelChartBase.divisor_eq_base_of_abel_eq
    simpa only [
      N13RationalAbelChartBase.baseSpreadLine_specialClass]
      using hzero z

  -- The rest is the existing contraction-to-spread comparison and the
  -- already-proved literal base affine-ideal computation.
  rw [
    N13RationalAbelChartBase.
      canonicalMappedSpecialMumford_subgroup_eq_mapMumford]
  rw [hmatched]
  rw [
    (N13RationalPicardSpreadExistence.exactSpreadLine
      ((z : G) +

  rw [hdiv]
  exact N13RationalAbelChartBase.specialBaseDivisor_affineIdeal
```

# 6. Kernel coverage then becomes immediate

Once the canonical mapped-special family has been built, the existing adapter already supplies a near-base family and its exact centered realization.

```javascript
theorem kernel_coverage
    (kernel : AddSubgroup G)
    (hzero : KernelSpecializesToBase kernel)
    (z : kernel) :
    ∃ P : N13TwoAdicAbelChartData.DiskPair,
      N13TwoAdicAbelChartPic.DiskPair.centeredPic P =
        N13TwoAdicAbelChartSection.subgroupToPic kernel z := by
  let R :=
    canonicalMappedSpecialFamilyOfKernelSpecializesToBase
      kernel hzero
  let F := R.toNearBaseFamily
  exact ⟨F.pair z, F.realize z⟩
```

The chain is now entirely noncircular:

```plain text
KernelSpecializesToBase
  → exact translated special divisor is the base divisor
  → exact translated affine ideal = specialIdeal
  → exactNormalizedContractionMatchesSpread
  → canonical contraction reduces to specialIdeal
  → N13ConcreteGraphRecovery.exists_diskPair_class_eq
  → NearBaseFamily.realize
  → required centered DiskPair.
```

SmallMumfordRigidity enters only through injectivity/uniqueness of the recovered Picard chart, as it should.

# 7. How an independent red₂ should prove KernelSpecializesToBase

Suppose there is a genuinely independent homomorphism

```javascript
red₂ : G →+ J₂
```

and an injective encoding of the stored special-class object into its codomain:

```javascript
specialCode : SpecialSet ↪ J₂
```

The needed geometric compatibility theorem is pointwise specialization of a spread:

```javascript
specialization_compat :
  ∀ L : SpreadLine,
    specialCode
        (N13RationalCurvePointPicardRealization.specialClass L) =
      red₂ L.rationalClass
```

Here L.rationalClass denotes the raw generic rational Picard class stored by the spread; use the exact projection name in the local structure. If specialClass already takes values in J₂, specialCode can be omitted.

Then the zero-fiber theorem is a short group calculation:

```javascript
theorem kernelSpecializesToBase_of_red
    (red₂ : G →+ J₂)
    (specialCode : SpecialSet ↪ J₂)
    (specialization_compat :
      ∀ L : SpreadLine,
        specialCode
            (N13RationalCurvePointPicardRealization.specialClass L) =
          red₂ L.rationalClass) :
    KernelSpecializesToBase red₂.ker := by
  intro z
  apply specialCode.injective
  rw [specialization_compat, specialization_compat]
  simp only [
    N13RationalPicardSpreadExistence.exactSpreadLine_rationalClass,
    N13RationalAbelChartBase.baseSpreadLine_rationalClass]
  rw [map_add, z.property, zero_add]
```

This is the exact formal-group/reduction principle required by the argument: reduction is a homomorphism, the exact spread specializes compatibly, and the identity kernel maps to the identity special class.

It is substantially weaker than proving all fibers exactly:

```javascript
specialClass L = specialClass M ↔
  rawGeneric L - rawGeneric M ∈ red₂.ker.
```

Only the implication from red₂ z = 0 to equality with the base special class is needed for coverage.

# 8. Important caveat about the current red

If red₂ is instantiated as

```javascript
N13ReductionClassifier.Data.red
```

then one must inspect how that Data was constructed. In the current relation-first classifier, the field

```javascript
Data.exact :
  classify P = classify Q ↔ P - Q ∈ kernel
```

is precisely supplied from the same spread equality theorem called class_eq_iff at the endpoint. Using that quotient map to derive kernel coverage would merely move the circularity behind Data.exact.

For the route above to be independent, one needs either:

1. an independently defined geometric reduction homomorphism on the rational Picard group, together with specialization_compat; or

1. directly the one-fiber theorem KernelSpecializesToBase, proved from the concrete integral/spread model without using classifier exactness.

The current contraction modules do not themselves define such a class-level reduction homomorphism.

# 9. Why the formal group slogan is not yet a Lean proof

Mathematically, for an abelian scheme with good reduction, the kernel of reduction is the group of points in the formal completion at the identity. That statement immediately gives coverage by a formal coordinate chart.

In the current N13 implementation, however, the two sides have been developed separately:

```plain text
class-level rational Picard/reduction side
```

and

```plain text
explicit two-disk integral Mumford/formal-chart side.
```

The chart files prove:

```plain text
an element already represented in the two-disk chart
  → integral coordinates
  → quadratic doubling estimate
  → NSeparated.
```

They do not prove the reverse coverage statement:

```plain text
class lies in kernel of reduction
  → class has a two-disk representative.
```

That reverse statement is exactly the concrete N13 version of “the reduction kernel equals the formal completion.” It cannot be obtained from Chart.separated, because Chart.separated assumes the chart map is already defined on every kernel element.

# 10. Role of the order-19 and cusp computations

The facts

```plain text
|J(F₂)| = 19
cuspidal Z/19Z ⊂ G
```

are useful for proving that the independently defined target is finite and that reduction is surjective. They do not identify the special fiber of the canonical contraction of an arbitrary kernel class.

They therefore close the finite-target side of the endgame but not kernel coverage. The missing compatibility theorem is geometric, not cardinality-theoretic.

# Exact answer

The audit finds no direct existing theorem of the requested form. The relevant files divide the work as follows:

```plain text
N13IntegralModelContraction
  + N13GeneralizedMumfordReduction
  + N13CanonicalContractionQuotient
      = local contraction/reduction machinery

N13ConcreteGraphRecovery.exists_diskPair_class_eq
      = contraction-to-specialIdeal → DiskPair

N13RationalPicardEndpoint.exactNormalizedContractionMatchesSpread
      = canonical contraction → chosen exact spread, independently

class_eq_iff
      = currently used only to show that a kernel-translated spread
        has the base special divisor.
```

Therefore the smallest noncircular replacement is not another contraction theorem. It is the one-fiber specialization statement

```javascript
z.property : red₂ z = 0
  → specialClass (exactSpreadLine (z + basePic)) =
      specialClass baseSpreadLine.
```

After that lemma, the existing 283-file infrastructure proves map_contract_eq_special, recovers the DiskPair, and establishes

```javascript
centeredPic P = subgroupToPic red₂.ker z
```

without any use of class_eq_iff.

So kernel coverage is the last missing piece provided that an independent red₂ and its spread-specialization compatibility are already available. If the only red₂ is the quotient map constructed from classifier exactness, then the independent class-level reduction map/compatibility theorem is itself the remaining gap.
