# Verdict

The proposed local mod-5 proof cannot be completed. The branch 5 ∣ b does not yield a contradiction; it is locally soluble. More fundamentally, “all points of C(F₅) are reductions of cusps” does not imply that every rational point is a cusp, because reduction on the curve is not injective. It only puts every rational point into one of the six cusp residue disks.

The true p=5 Mordell–Weil argument is still very short after one supplies an injective Jacobian reduction map and Abel–Jacobi compatibility. In the current formalization, however, constructing that p=5 infrastructure is substantially more work than importing and wiring N13MumfordCenteredDoublingAdapter.

# 1. The exact 5 ∣ b calculation

The repository's sextic is

```plain text
f(X) = X^6 + 4 X^5 + 6 X^4 + 2 X^3 + X^2 + 2 X + 1.
```

For X=a/b, its degree-six homogenization is

```plain text
F(a,b) = a^6 + 4 a^5 b + 6 a^4 b^2 + 2 a^3 b^3
       + a^2 b^4 + 2 a b^5 + b^6,
```

and the curve equation gives

```plain text
F(a,b) = (b^3 Y)^2.
```

Assume gcd(a,b)=1.

## Case 5 ∤ b

Reducing x=a/b in F₅, the values of f are

```plain text
x       0  1  2  3  4
f(x)    1  2  3  2  1.
```

Because 2 and 3 are nonsquares, a square value forces

```plain text
x ≡ 0 or -1 mod 5.
```

But this proves only

```plain text
a ≡ 0 mod 5   or   a+b ≡ 0 mod 5,
```

not a=0 or a=-b. Indeed every x ∈ 5 Z₅ and every x ∈ -1+5 Z₅ has f(x) ∈ 1+5 Z₅, hence has a square root in Z₅ by Hensel. These residue disks contain infinitely many local points.

## Case 5 ∣ b

Coprimality gives 5 ∤ a, and immediately

```plain text
F(a,b) ≡ a^6 = (a^3)^2 mod 5.
```

So the leading term is already a nonzero square; there is no mod-5 obstruction.

In fact the stronger p-adic statement goes in the opposite direction. Put t=b/a ∈ 5 Z₅. Then

```plain text
F(a,b) = a^6 u,

u = 1 + 4t + 6t^2 + 2t^3 + t^4 + 2t^5 + t^6 ∈ 1+5 Z₅.
```

Every element of 1+5 Z₅ is a square: apply Hensel to T^2-u at T=1, whose derivative 2 is a unit. Thus u=s^2 and

```plain text
F(a,b) = (a^3 s)^2.
```

Geometrically, 5 ∣ b means that the point reduces to one of the two points at infinity. Both infinity residue disks are locally soluble. Therefore there is no missing contradiction to fill in the 5 ∣ b branch.

# 2. The false step in the proposed shortcut

The problematic statement is:

```plain text
A noncuspidal rational point reduces to a noncuspidal F₅-point.
```

This is false. A rational point different from a cusp may reduce to the same F₅ point as that cusp. The finite-field computation says only:

- four affine points: (0,±1) and (-1,±1);

- two points at infinity;

- all six are reductions of the six known rational cusps.

It does not say that the corresponding six residue disks contain only their cusp centers.

# 3. The correct p=5 Mordell–Weil proof

Let B be a rational cusp and write ι(P)=[P-B] ∈ J(Q). For a rational point P, choose a rational cusp c with the same reduction in C(F₅). Then

```plain text
red_J(ι(P)) = ι₅(red_C(P))
            = ι₅(red_C(c))
            = red_J(ι(c)).
```

Hence

```plain text
red_J(ι(P)-ι(c)) = 0.
```

If red_J : J(Q) → J(F₅) is injective, then ι(P)=ι(c). The Abel–Jacobi map of a positive-genus curve is injective on points, so P=c.

Thus the k-values {0,1,4,5,11,13} are not needed at the final endpoint once the following are available:

1. every point of C(F₅) is the reduction of a rational cusp;

1. reduction commutes with Abel–Jacobi;

1. J(Q) → J(F₅) is injective.

The facts J(Q) ≅ Z/19Z and #J(F₅)=19 are ways to prove item 3, but equal cardinalities alone do not make an arbitrary homomorphism injective. One must additionally use prime-to-5 torsion injectivity at good reduction, prove surjectivity, or show that a generator has nonzero reduction.

# 4. Finite-field part in Lean

The affine enumeration itself is genuinely tiny:

```javascript
import Mathlib

namespace MazurProof.N13ModFive

open scoped BigOperators

def f5 (x : ZMod 5) : ZMod 5 :=
  x ^ 6 + 4 * x ^ 5 + 6 * x ^ 4 + 2 * x ^ 3 +
    x ^ 2 + 2 * x + 1

/-- The only affine F₅-points lie above `x=0,-1`. -/
theorem affine_x_eq_zero_or_neg_one :
    ∀ x y : ZMod 5,
      y ^ 2 = f5 x → x = 0 ∨ x = -1 := by
  native_decide

abbrev AffinePoint5 :=
  {p : ZMod 5 × ZMod 5 // p.2 ^ 2 = f5 p.1}

/-- Four affine points; the smooth even-degree completion adds two infinity points. -/
theorem card_affinePoint5 : Fintype.card AffinePoint5 = 4 := by
  native_decide

end MazurProof.N13ModFive
```

This proves the finite-field classification, but deliberately does not claim that reduction is injective on rational curve points.

# 5. Complete concise endpoint, parameterized by the genuine p=5 inputs

The following is the Lean proof that the MW sieve would reduce to once a concrete p=5 curve reduction, Jacobian reduction, and commutative Abel–Jacobi square have been constructed. It uses the repository's existing injectivity of the rational Abel–Jacobi map and copies the final affine-cusp extraction already used by N13RationalPicardEndpoint.

```javascript
import FLT.Assumptions.MazurProof.N13RationalPicardEndpoint

namespace MazurProof.N13FiveMWSieve

noncomputable section

abbrev Cℚ : Type :=
  N13RationalPointEndgame.RationalCurvePoint

abbrev Jℚ : Type :=
  N13RationalPointEndgame.G

variable
    {C5 J5 : Type*}
    [AddCommGroup J5]
    (redC : Cℚ → C5)
    (redJ : Jℚ →+ J5)
    (abel5 : C5 → J5)
    (red_abel :
      ∀ P : Cℚ,
        redJ (N13RationalPointEndgame.rationalAbel P) =
          abel5 (redC P))
    (redJ_injective : Function.Injective redJ)
    (cusp_cover :
      ∀ P : Cℚ,
        ∃ c : N13Mumford.Cusp13,
          redC P = redC (N13Mumford.cuspPoint c))

/-- Same reduction plus injective Jacobian reduction forces equality with a cusp. -/
theorem curvePoint_eq_cusp (P : Cℚ) :
    ∃ c : N13Mumford.Cusp13,
      P = N13Mumford.cuspPoint c := by
  obtain ⟨c, hc⟩ := cusp_cover P
  refine ⟨c, ?_⟩
  apply N13MumfordAbelJacobi.abelJacobi_injective ℚ
  apply redJ_injective
  calc
    redJ (N13RationalPointEndgame.rationalAbel P) =
        abel5 (redC P) := red_abel P
    _ = abel5 (redC (N13Mumford.cuspPoint c)) :=
      congrArg abel5 hc
    _ = redJ
          (N13RationalPointEndgame.rationalAbel
            (N13Mumford.cuspPoint c)) :=
      (red_abel (N13Mumford.cuspPoint c)).symm

private def affineX? : Cℚ → Option ℚ
  | .infinityPlus => none
  | .infinityMinus => none
  | .affine x _ _ => some x

/-- The exact theorem consumed by the order-13 exclusion. -/
theorem affine_x_is_cuspidal :
    ∀ X Y : ℚ,
      N13CurveModel.C13SexticEq X Y →
        X = 0 ∨ X = -1 := by
  intro X Y hcurve
  let P : Cℚ := N13Mumford.affineCurvePoint X Y hcurve
  obtain ⟨c, hPc⟩ :=
    curvePoint_eq_cusp
      (redC := redC)
      (redJ := redJ)
      (abel5 := abel5)
      (red_abel := red_abel)
      (redJ_injective := redJ_injective)
      (cusp_cover := cusp_cover)
      P
  have hx := congrArg affineX? hPc
  cases c with
  | infinityPlus =>
      simp [P, affineX?, N13Mumford.affineCurvePoint,
        N13Mumford.cuspPoint] at hx
  | infinityMinus =>
      simp [P, affineX?, N13Mumford.affineCurvePoint,
        N13Mumford.cuspPoint] at hx
  | zeroPlus =>
      exact Or.inl (by
        simpa [P, affineX?, N13Mumford.affineCurvePoint,
          N13Mumford.cuspPoint] using hx)
  | zeroMinus =>
      exact Or.inl (by
        simpa [P, affineX?, N13Mumford.affineCurvePoint,
          N13Mumford.cuspPoint] using hx)
  | negOnePlus =>
      exact Or.inr (by
        simpa [P, affineX?, N13Mumford.affineCurvePoint,
          N13Mumford.cuspPoint] using hx)
  | negOneMinus =>
      exact Or.inr (by
        simpa [P, affineX?, N13Mumford.affineCurvePoint,
          N13Mumford.cuspPoint] using hx)

end

end MazurProof.N13FiveMWSieve
```

This is the concise proof. The non-concise work is producing the concrete values of redC, redJ, abel5, red_abel, redJ_injective, and cusp_cover.

# 6. What the p=5 route would still require in this repository

A faithful implementation needs new p=5 versions of machinery that the current N13 development already built at p=2:

- a smooth proper integral model and total reduction map, including both infinity charts;

- the six-point C(F₅) enumeration and the cusp-reduction cover theorem;

- a concrete finite Jacobian/Picard type over F₅;

- specialization of rational divisor classes and the Abel–Jacobi compatibility theorem;

- injectivity of specialization on J(Q), using the 19-torsion theorem and good reduction.

Therefore the endpoint above may be ten lines, but the route is not a ten-line replacement for the 283-file infrastructure unless most of these declarations already exist.
