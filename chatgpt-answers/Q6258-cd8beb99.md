# 3. Why GF(2^d) exact orbits are the right degree-d object

The potential objection is:

```plain text
on GF(2^d), Frobenius^d = id,
so does OrbitClass(..., d) accidentally include all points?
```

No. The current source separates three notions:

```javascript
FixedByIterate σ d     := {x // σ^[d] x = x}
ExactPeriodicPoint σ d := {x // minimalPeriod σ x = d}
OrbitClass σ d hd      := quotient of ExactPeriodicPoint σ d.
```

fixedByIterateEquivSigmaExact proves that a point fixed by σ^[d] decomposes by its minimal positive period, which divides d:

```javascript
fixedByIterateEquivSigmaExact
    (σ : Equiv.Perm Y) (d : ℕ) (hd : 0 < d) :
  FixedByIterate σ d ≃
    Σ e : PositiveDivisor d, ExactPeriodicPoint σ e.1
```

So the exact-period carrier is precisely the source-level restriction needed to discard F_(2^e) points with e < d.

First prove minimal-period preservation under the injective semiconjugacy:

```javascript
private theorem degreeCurvePointEmbeddingToCommon12_minimalPeriod

            exact
              (degreeCurvePointEmbeddingToCommon12_semiconj

    (P Q : ExactPeriodicPoint (degreePointFrobeniusTwo d) d) :
    SameExactOrbit commonPointFrobeniusTwo d

        (exactPeriodicPointEquivDegreeToCommon12 d hd hd12 Q) ↔

    calc
      degreeCurvePointEmbeddingToCommon12 d hd hd12
          (((degreePointFrobeniusTwo d : _ → _)^[i.1]) P.1) =
        ((commonPointFrobeniusTwo : _ → _)^[i.1])
          (degreeCurvePointEmbeddingToCommon12 d hd hd12 P.1) := by
            exact
              (degreeCurvePointEmbeddingToCommon12_semiconj
                d hd hd12).iterate_right i.1 P.1
      _ = degreeCurvePointEmbeddingToCommon12 d hd hd12 Q.1 := hi
  · rintro ⟨i, hi⟩
    refine ⟨i, ?_⟩
    calc
      ((commonPointFrobeniusTwo : _ → _)^[i.1])
          (degreeCurvePointEmbeddingToCommon12 d hd hd12 P.1) =
        degreeCurvePointEmbeddingToCommon12 d hd hd12
          (((degreePointFrobeniusTwo d : _ → _)^[i.1]) P.1) := by
            exact
              ((degreeCurvePointEmbeddingToCommon12_semiconj
                d hd hd12).iterate_right i.1 P.1).symm
      _ = degreeCurvePointEmbeddingToCommon12 d hd hd12 Q.1 := by
        rw [hi]
```

Then define the quotient equivalence. The clean implementation is Equiv.ofBijective on Quotient.map; injectivity uses Quotient.exact plus the reverse implication above, and surjectivity chooses the inverse exact-period representative.

Exact type:

```javascript
private noncomputable def orbitClassEquivDegreeToCommon12
    (d : ℕ) (hd : 0 < d) (hd12 : d ∣ 12) :
    OrbitClass (degreePointFrobeniusTwo d) d hd ≃
      OrbitClass commonPointFrobeniusTwo d hd := by
  let E := exactPeriodicPointEquivDegreeToCommon12 d hd hd12
  let f :
      OrbitClass (degreePointFrobeniusTwo d) d hd →
        OrbitClass commonPointFrobeniusTwo d hd :=
    Quotient.map E (by
      intro P Q hPQ
      exact (sameExactOrbit_degreeToCommon12_iff
        d hd hd12 P Q).2 hPQ)
  refine Equiv.ofBijective f ⟨?_, ?_⟩
  · intro a b hab
    induction a using Quotient.inductionOn with
    | _ P =>
      induction b using Quotient.inductionOn with
      | _ Q =>
        apply Quotient.sound
        exact (sameExactOrbit_degreeToCommon12_iff
          d hd hd12 P Q).1 (Quotient.exact hab)
  · intro q
    induction q using Quotient.inductionOn with
    | _ Q =>
      refine ⟨orbitClassMk (degreePointFrobeniusTwo d) d hd (E.symm Q), ?_⟩
      exact congrArg
        (orbitClassMk commonPointFrobeniusTwo d hd)
        (E.apply_symm_apply Q)
```

This is the entire descent step. No choice of representative is used except the quotient's own induction principle; no point counts occur.
