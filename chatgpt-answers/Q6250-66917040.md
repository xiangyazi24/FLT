# Circularity / satisfiability audit

The following routes should be rejected:

- Principal := divisorDegree.ker: unsound; not every degree-zero divisor is principal.

- Global principal divisors valued in frobeniusOrbitGrading25TwoLE4.Divisor: unsatisfiable as a global statement because that grading comes from one finite field and omits arbitrary residue degrees.

- Degree-2/4 fibre equivalence for arbitrary Principal: false; the fibre is a complete linear system only for actual linear equivalence.

- hyperplaneSectionClass is canonical because its degree is six: false; many degree-six classes exist.

- Constructing a rational differential before local-order/divisor semantics: this merely hides the same missing order-of-vanishing machinery inside the word div(ω).

- Assuming Picard finiteness/cardinality 71 to prove the RR count: circular.

- Replacing actual Picard classes by a finite normal-form surrogate: a weaker endpoint and contrary to the doctrine’s “no structural doppelgänger” policy.

- Demanding an effective map D ↦ K-D: false in general. The existing residualDegreeFourTwo correctly acts on Picard classes; effectiveness is controlled by the RR space/rank, not by a pointwise effective-divisor map.
