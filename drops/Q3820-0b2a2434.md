Deliverables:

1. algebra identities for the Lean convention

```text
shortCubic A B x = x^3 + A*x^2 + B*x,
chordM x y a b = (y-b)/(x-a),
chordX A x y a b = chordM^2 - A - x - a.
```

The key denominator-cleared identity is:

```lean
/- schematic statement; adapt names/namespaces -/
theorem chordX_sub_a_mul_sq_eq
    {A B x y a b : ℝ}
    (hy : y ^ 2 = shortCubic A B x)
    (hb : b ^ 2 = shortCubic A B a) :
    (chordX A x y a b - a) * (x - a) ^ 2
      = shortCubicDeriv A B a * (x - a) - 2 * b * (y - b) := by
  unfold chordX chordM shortCubic shortCubicDeriv
  ring_nf
  -- then rewrite `hy`, `hb`; depending on normalization, use `nlinarith [hy, hb]`
```

Equivalent expanded form:

```text
(chordX A x y a b - a) * (x-a)^2
  = (3*a^2 + 2*A*a + B)*x + (B*a - a^3) - 2*b*y.
```

2. the y-coordinate identity

```lean
theorem chordY_eq_neg_b_sub_m_mul_x3_sub_a
    {A B x y a b : ℝ} :
    chordY A x y a b
      = -b - chordM x y a b * (chordX A x y a b - a) := by
  unfold chordY chordM
  field_simp
  ring
```

This identity is much more useful than expanding `chordY`: it reduces `chordY → b` to

```text
chordM * (chordX-a) → -2*b.
```

3. generic non-root affine atTop asymptotics

Assumptions:

```text
a>e,
b^2=f(a),
b≠0,
y(x)=sqrt(f(x)),
x→∞.
```

Conclusions:

```text
chordX A x (sqrt(f x)) a b → a,
chordM x (sqrt(f x)) a b * (chordX A x (sqrt(f x)) a b - a) → -2*b,
chordY A x (sqrt(f x)) a b → b.
```

The proof route:

```text
sqrt(f(x))/(x-a)^2 → 0,
(y-b)^2/(x-a)^3 → 1,
(chordX-a) identity gives chordX→a,
then multiply the identity by chordM and use
  chordM = (y-b)/(x-a)
```

#### 2.1 Vertical seam

Hypothesis:

```text
U(a) = -Q, so Q=(a,-sqrt(f(a))) and b≠0.
```

Conclusion:

```text
Tendsto F_Q (𝓝[≠] a) (𝓝 0)
```

or, more locally, both one-sided filters if that matches the bridge:

```text
Tendsto F_Q (𝓝[Set.Ioo l a] a) (𝓝 0),
Tendsto F_Q (𝓝[Set.Ioo a r] a) (𝓝 0).
```

Best proof attack:

```text
chordM → ±∞ in magnitude,
chordX = chordM^2 - A - x - a → ∞,
sigma(chordX) → 0,
theta(output) → 0 regardless of output branch sign,
theta(U(x)) → theta(-Q) = -theta(Q),
therefore F_Q → 0.
```

Do **not** try to give a finite coordinate continuation for the output point.  The output tends to `O`, and `chordX→∞`.

#### 2.2 Tangent/doubling seam

Hypothesis:

```text
U(a)=Q, so u(a)=b and b≠0.
```

First prove the slope quotient limit:

Then define the tangent coordinates:

```text

```

```text

```

#### 2.3 Output-root seam

Hypothesis:

```text

x0≠a
```



File:


Keep this file as curve-free as possible.  It should not know about `sigma`, `theta`, `shortW`, or chord formulas.

Target theorem, schematic:

```lean
/-
One workable abstraction.  Adjust to the exact local-constancy API in S8/S9.
-/
theorem isLocallyConstantOn_Ioi_of_finite_bad
    {X : Type*} [TopologicalSpace X] [T2Space X]
    {e : ℝ} {F : ℝ → X} {bad : Finset ℝ}
    (hclean : ∀ x ∈ Set.Ioi e, x ∉ bad →
      ∃ δ > 0,
        IsLocallyConstantOn F (Set.Ioo (x - δ) (x + δ) ∩ Set.Ioi e))
    (hbad : ∀ s ∈ bad, e < s →
      ∃ δ > 0,
        (∀ t ∈ Set.Ioo (s - δ) s, t ∈ Set.Ioi e → F t = F s) ∧
        (∀ t ∈ Set.Ioo s (s + δ), F t = F s)) :
    IsLocallyConstantOn F (Set.Ioi e) := by
  ...
```

A more flexible version can take `Tendsto F (𝓝[Set.Ioo (s-δ) s] s) (𝓝 (F s))` and right-sided analogues instead of explicit equality to `F s`.  But the explicit-equality version is often easier once S8 has already produced local constants and the seam lemmas identify those constants.

Recommended proof strategy:

1. To show local constancy at a clean `x`, use `hclean`.
2. To show local constancy at a bad `s`, use `hbad` and pick `δ` small enough so `s-δ>e` when needed.
3. Prove equality inside the small neighborhood by cases:
   * both points left of `s`: left equality to `F s`;
   * both points right of `s`: right equality to `F s`;
   * one point is `s`: direct;
   * one left and one right: both equal `F s`.

This avoids having the bridge reason about S8 directly.  The curve-specific assembly file can transform S8+seam `Tendsto` into the explicit `hbad` equalities.

If this still stalls, retreat to an even more specialized bridge for at most two bad points:

```text
bad = ∅, {c}, or {c1,c2} with c1<c2.
```

That is less elegant but probably much shorter in Lean.

Definition of done: a checked theorem turning clean-neighborhood local constancy plus bad-point patching into `IsLocallyConstantOn F (Set.Ioi e)`.

## (b) Hardest single lemma and best attack

The single lemma most likely to stall is the **vertical seam**:

```text
U(a)=-Q  ⇒  Tendsto F_Q (𝓝[≠] a) (𝓝 0).
```

Reason: it is not an ordinary rational-continuity point.  The affine output coordinates do not extend to a finite affine point.  Instead,

```text
chordM → ±∞,
chordX → ∞,
U(x)+Q → O,
theta(U(x)+Q) → 0.
```

This mixes punctured filters, atTop behavior, branch reduction, and `AddCircle` limits.  It is more delicate than the tangent seam, where `HasDerivAt.tendsto_slope` gives the missing quotient limit, and more delicate than the output-root seam, where rational continuity works away from `x=a`.

Best attack for the vertical seam:

1. Prove the purely real asymptotic:

```text
if u(a)=-b and b≠0, then
chordM t (u t) a b ^ 2 → ∞ as t→a, t≠a.
```

Here the numerator tends `-2b`, nonzero, and the denominator tends `0`.

2. Deduce:

```text
chordX A t (u t) a b = chordM^2 - A - t - a → ∞.
```

3. Prove a reusable theta lemma:

```text
if R(t) is an identity-component affine output with x-coordinate X(t),
X(t)→∞,
then thetaCandidate(R(t))→0,
regardless of output sign.
```

This lemma should case-split on output branch sign and use `sigma(X(t))→0`; both `mk(σ)` and `mk(-σ)` tend to `0`.

4. Combine with:

```text
U(t)→-Q,
theta(U(t))→theta(-Q)=-theta(Q).
```

Then:

```text
F_Q(t) = theta(U(t)+Q)-theta(U(t))-theta(Q)
       → 0 - (-theta(Q)) - theta(Q) = 0.
```

If you already have a genuine topology on the Weierstrass group and continuity of addition, a much shorter route is:

```text
U(t)→-Q ⇒ U(t)+Q→O ⇒ theta(U(t)+Q)→theta(O)=0.
```

But unless that continuity is already checked, the coordinate/`sigma` route above is the safer Codex spec.

The second most likely staller is the finite bridge only because Mathlib local-constancy APIs can be awkward.  If it stalls, specialize immediately to at most two bad coordinates instead of building a beautiful general finite-set theorem.

## (d) Prerequisite audit: assume or verify?

Verify first.  The audit should be short, but it is worth doing before parallel work.

The listed facts are promising, but they are not automatically sufficient.  The exact theorem shapes and conventions matter more than the mathematical existence of the facts.

### 1. `ComponentKer` as kernel of `componentBitHom`

This is likely sufficient for closure under addition/negation, but verify the wrappers:

```lean
-- schematic probes

#check map_neg
#check sub_eq_add_neg
```

Expected wrappers:

```text
O ∈ ComponentKer,
P∈ComponentKer → -P∈ComponentKer,
P∈ComponentKer → Q∈ComponentKer → P+Q∈ComponentKer.
```

Also verify that branch reduction applies to **sums** after using this closure.

### 2. S4 derivative and sqrt derivative

S4's `HasDerivAt sigma` and `sqrt_shortCubic_hasDerivAt_of_pos` are sufficient only if they can be applied at:

```text
x>e,
a>e,
f(x)>0,
f(a)>0,
b=±sqrt(f(a)), b≠0.
```

For tangent seams, you need exactly:

```text
HasDerivAt (fun x => sqrt (shortCubic A B x))
  (shortCubicDeriv A B a / (2*sqrt(shortCubic A B a))) a.
```

For the lower branch, the derivative is the negation of this; ideally avoid global lower glue by using negation, but S8 may still need lower output cases.

### 3. S7 `shortW_slope_eq_chordM` bridge

Audit this carefully.  The convention must match:

```text
chordM x y a b = (y-b)/(x-a),
chordX = chordM^2 - A - x - a,
chordY = -(y + chordM*(chordX-x)).
```

If an existing mathlib Weierstrass formula uses `(b-y)/(a-x)`, that is equal to `(y-b)/(x-a)`, so the slope is the same.  But if the y-coordinate formula is written as `-(b + m*(x3-a))`, prove the bridge:

```text
-(y + m*(x3-x)) = -(b + m*(x3-a))
```

using the line-through-`Q` identity.  This bridge prevents sign-convention bugs in S8/S10.

### 4. S8 local constancy shape

Check whether S8 gives:

```text
HasDerivAt defect_lift 0 x
```

or directly:

```text
IsLocallyConstantOn defect_addcircle I.
```

If it gives derivative-zero for a real lift, make sure the conversion to AddCircle local constancy is already wrapped.  The finite bridge should consume the AddCircle-valued local-constancy statement, not redo derivative arguments.

### 5. S9 global glue shape

Verify the exact input type:

```text
IsLocallyConstantOn F (Set.Ioi e)
```

versus `IsLocallyConstant F` on a subtype.  If S9 uses a subtype, add a wrapper once in the audit file and make every later task target that wrapper.

### Bottom line

Do the audit first, but keep it small.  If the audit wrappers compile, the three major tasks can proceed in parallel.  If the audit fails, parallel Codex runs will likely produce incompatible theorem statements and burn time.
