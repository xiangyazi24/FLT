# Q3950: denominator clearing and the mod-2 check for F11

Let

```text
F11(b,c) = (c^3 - b*(b-c))*(b-c)^3 - b*c*(b-c-c^2)^3.
```

The short answer is: the mod-2 obstruction only rules out the case where `b` is a 2-adic unit. It does **not** extend to a proof that `F11(b,c)=0` has no rational solutions with `b != 0`. In fact, there are genuine `Q_2`-solutions with `b != 0`.

## 1. Cleared denominators

Write

```text
b = p/q,   c = r/s,
```

with `p,q,r,s` integers and `q*s != 0`. Define

```text
A = p*s - r*q,
U = q^2*r^3 - p*s^2*A,
V = p*s^2 - q*r*s - q*r^2.
```

Then

```text
b - c              = A/(q*s),
c^3 - b*(b-c)      = U/(q^2*s^3),
b - c - c^2        = V/(q*s^2).
```

Therefore

```text
F11(p/q,r/s) = U*A^3/(q^5*s^6) - p*r*V^3/(q^4*s^7),
```

so the useful cleared equation is

```text
q^5*s^7 * F11(p/q,r/s)
 = s*(q^2*r^3 - p*s^2*(p*s-r*q))*(p*s-r*q)^3
   - p*q*r*(p*s^2 - q*r*s - q*r^2)^3.
```

Equivalently,

```text
P(p,q,r,s) := s*U*A^3 - p*q*r*V^3.
```

A check script:

```sage
from sage.all import QQ, PolynomialRing

R = PolynomialRing(QQ, names=("p", "q", "r", "s"))
p, q, r, s = R.gens()

b = p/q
c = r/s
F11 = (c**3 - b*(b-c))*(b-c)**3 - b*c*(b-c-c**2)**3

A = p*s - r*q
U = q**2*r**3 - p*s**2*A
V = p*s**2 - q*r*s - q*r**2
P = s*U*A**3 - p*q*r*V**3

assert (q**5*s**7*F11 - P).numerator().expand() == 0
```

## 2. Mod 2 after clearing denominators

Work with primitive representatives, so `gcd(p,q)=1` and `gcd(r,s)=1`. Modulo `2`, this means `(p,q) != (0,0)` and `(r,s) != (0,0)`.

### Case `v2(b)=0`

Here `p` and `q` are both odd, so `p=q=1` in `F_2`. Checking the three primitive possibilities for `(r,s)` gives:

```text
(r,s) = (0,1)  ->  P = 1 mod 2
(r,s) = (1,0)  ->  P = 1 mod 2
(r,s) = (1,1)  ->  P = 1 mod 2
```

Thus the cleared equation has no mod-2 solution when `b` is a 2-adic unit. This is the correct extension of the user's affine `b=1` computation: it handles all denominators for `c`, but only under `v2(b)=0`.

### Case `v2(b)>0`

Here `p=0`, `q=1` in `F_2`. The reduction is

```text
P = r*s mod 2.
```

This vanishes if `c` is not a 2-adic unit. So the mod-2 obstruction disappears.

### Case `v2(b)<0`

Here `p=1`, `q=0` in `F_2`. The reduction is

```text
P = s mod 2.
```

This vanishes when `s` is even, i.e. when `v2(c)<0`. Again, no contradiction remains.

So the denominator-cleared mod-2 computation proves only a restricted theorem: no solution with `v2(b)=0`.

## 3. Explicit Q_2 solution with b != 0

The failure is real, not just an artifact of the reduction. There are actual `Q_2`-points.

Put `z = c/b`. For `b != 0`,

```text
F11(b,c) = b^5 * H(b,z),
```

where

```text
H(b,z) = (b*z^3 - (1-z))*(1-z)^3 - z*(1-z-b*z^2)^3.
```

For `z != 0,1`, set

```text
lambda = b*z^2/(1-z),   so   b = lambda*(1-z)/z^2.
```

Substitution gives

```text
H(b,z) = (1-z)^3 * ( z*(lambda^3 - 3*lambda^2 + 4*lambda) - lambda*z^2 - 1 ).
```

Choose `lambda = 3`. Then the condition becomes

```text
3*z^2 - 12*z + 1 = 0.
```

Its discriminant is `132 = 4*33`. Since `33 == 1 mod 8`, `33` is a square in `Q_2`. Let `alpha in Q_2` satisfy

```text
alpha^2 = 33.
```

Then

```text
z = (6 + alpha)/3
```

satisfies `3*z^2 - 12*z + 1 = 0`. Define

```text
b = 3*(1-z)/z^2,
c = b*z.
```

Equivalently,

```text
b = -9*(alpha+3)/(alpha+6)^2,
c = -3*(alpha+3)/(alpha+6).
```

Since `alpha^2=33`, we have `alpha != -6` and `alpha != -3`, so `z != 0`, `z != 1`, and `b != 0`. Therefore this gives a genuine `Q_2`-solution of `F11(b,c)=0` with `b != 0`.

A check script:

```sage
from sage.all import Qp

Q2 = Qp(2, prec=40)
alpha = Q2(33).sqrt()

z = (Q2(6) + alpha) / Q2(3)
b = Q2(3) * (1 - z) / z**2
c = b*z

F11 = (c**3 - b*(b-c))*(b-c)**3 - b*c*(b-c-c**2)**3
assert b != 0
assert F11 == 0
```

## Lean 4 proof sketch

The global no-solution target is false as a 2-adic statement, so do not try to prove it from this mod-2 obstruction. The useful Lean lemmas are these.

```lean
import Mathlib

noncomputable section

namespace FLT.Q3950

def F11 {K : Type*} [Field K] (b c : K) : K :=
  (c^3 - b * (b - c)) * (b - c)^3
    - b * c * (b - c - c^2)^3

def A (p q r s : Int) : Int := p*s - r*q

def U (p q r s : Int) : Int :=
  q^2 * r^3 - p * s^2 * A p q r s

def V (p q r s : Int) : Int :=
  p * s^2 - q*r*s - q*r^2

def P (p q r s : Int) : Int :=
  s * U p q r s * (A p q r s)^3
    - p*q*r * (V p q r s)^3

theorem clear_denoms
    (p q r s : Int) (hq : (q : Rat) != 0) (hs : (s : Rat) != 0) :
    (q : Rat)^5 * (s : Rat)^7 *
      F11 ((p : Rat) / q) ((r : Rat) / s)
      = P p q r s := by
  -- unfold F11 P A U V
  -- field_simp [hq, hs]
  -- ring
  sorry

end FLT.Q3950
```

For the mod-2 unit-`b` obstruction, reduce `P` to `ZMod 2`, set `p=q=1`, and use `fin_cases r <;> fin_cases s`. The primitive condition removes `(r,s)=(0,0)`, and the remaining three cases all reduce to `1`.

For the local counterexample, formalize the identity

```text
F11(b,b*z) = b^5*(1-z)^3*(z*(lambda^3 - 3*lambda^2 + 4*lambda) - lambda*z^2 - 1)
```

under `lambda = b*z^2/(1-z)`. Then use the local square lemma `exists alpha : Q_2, alpha^2 = 33`, coming from `33 == 1 mod 8`, and set

```text
z = (6 + alpha)/3,
b = 3*(1-z)/z^2,
c = b*z.
```

The final ring check is `3*z^2 - 12*z + 1 = 0`.

## Final answer

The cleared denominator is `q^5*s^7`, giving

```text
q^5*s^7 * F11(p/q,r/s)
 = s*(q^2*r^3 - p*s^2*(p*s-r*q))*(p*s-r*q)^3
   - p*q*r*(p*s^2 - q*r*s - q*r^2)^3.
```

Modulo `2`, this rules out only `v2(b)=0`. It does not rule out all `b != 0`; indeed the displayed `Q_2` construction gives actual solutions with `b != 0`. Thus the proposed mod-2 obstruction does **not** prove rational nonexistence.
