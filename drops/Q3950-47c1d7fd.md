# Q3950: denominator clearing and the 2-adic obstruction

The mod-2 obstruction is valid only for the case where `b` is a 2-adic unit.  It does **not** extend to a proof that `F11(b,c)=0` has no rational solutions with `b ≠ 0`: after denominator clearing there are surviving parity cases, and in fact there are 2-adic solutions with `b ≠ 0`.

## 1. Cleared denominator form

Let

\[
F_{11}(b,c)=(c^3-b(b-c))(b-c)^3-bc(b-c-c^2)^3.
\]

For rational inputs

\[
b=\frac p q,\qquad c=\frac r s,
\]

with `q s ≠ 0`, the useful denominator clearing is

\[
q^5s^7 F_{11}\!\left(\frac p q,\frac r s\right)=H(p,q,r,s),
\]

where

\[
\boxed{
H(p,q,r,s)=
s\bigl(q^2r^3-p^2s^3+pqrs^2\bigr)(ps-qr)^3
-pqr\bigl(ps^2-qrs-qr^2\bigr)^3.
}
\]

This comes from the three identities

\[
c^3-b(b-c)
 =\frac{q^2r^3-p^2s^3+pqrs^2}{q^2s^3},
\]

\[
b-c=\frac{ps-qr}{qs},
\]

and

\[
b-c-c^2=\frac{ps^2-qrs-qr^2}{qs^2}.
\]

So

\[
(c^3-b(b-c))(b-c)^3
=\frac{(q^2r^3-p^2s^3+pqrs^2)(ps-qr)^3}{q^5s^6},
\]

while

\[
bc(b-c-c^2)^3
=\frac{pr(ps^2-qrs-qr^2)^3}{q^4s^7}.
\]

Taking the common denominator `q^5 s^7` gives the displayed formula for `H`.

## 2. Mod 2 analysis of the cleared equation

Assume `p/q` and `r/s` are in lowest terms, so `(p,q)` are not both even and `(r,s)` are not both even.  Write

\[
P,Q,R,S\in\mathbb F_2
\]

for the reductions of `p,q,r,s`.  Reducing the cleared equation modulo `2` gives

\[
\overline H
=S(QR+PS+PQRS)(PS+QR)+PQR(PS+QRS+QR),
\]

where I used `x^2=x` and `x^3=x` as functions on `\mathbb F_2`.

The parity cases are:

| parity of `(p,q)` | meaning for `b=p/q` | value of `\overline H` on primitive `(R,S)` |
|---|---:|---|
| `(1,1)` | `v₂(b)=0` | always `1` |
| `(1,0)` | `v₂(b)<0` | `S` |
| `(0,1)` | `v₂(b)>0` | `RS` |

Thus the computation **does** prove:

\[
F_{11}(b,c)=0\quad\Longrightarrow\quad v_2(b)\ne 0.
\]

Equivalently, there is no solution with `b` a 2-adic unit.  This is the correct denominator-cleared strengthening of the original `b = 1 mod 2` check.

But it does **not** prove nonexistence for all `b ≠ 0`.  The cases `v₂(b)>0` and `v₂(b)<0` are not eliminated by reduction modulo `2`.  For example, when `(P,Q)=(0,1)` and `(R,S)=(0,1)`, corresponding to both `b` and `c` being 2-adically even, the cleared equation is `0 mod 2`.

So the answer to the proposed extension is already negative at the mod-2-cleared level: `p` odd alone is not the right condition.  If `p` is odd but `q` is even, then `b` is not a 2-adic integer and the original substitution `b=1 mod 2` is not legitimate.

## 3. There are actual 2-adic solutions

The obstruction is not merely incomplete; it genuinely cannot rule out all 2-adic points, because such points exist.

First note that if `b ≠ 0` and `F11(b,c)=0`, then necessarily `c ≠ 0` and `b ≠ c`: `c=0` gives `F11(b,0)=-b^5`, and `b=c` gives `F11(b,b)=b^8`.

For `b,c ≠ 0` and `b ≠ c`, set

\[
z=\frac b c,\qquad y=\frac{bc}{b-c}.
\]

Then

\[
b=y(z-1),\qquad c=\frac{y(z-1)}{z}.
\]

A direct algebraic simplification gives

\[
F_{11}(b,c)=0
\quad\Longleftrightarrow\quad
C(y,z)=0,
\]

where

\[
C(y,z)=y^3-3zy^2+z(4z-1)y-z^4.
\]

Equivalently,

\[
(z-y)^3=z(z-1)(y-z^2).
\]

Now set `z=3`.  Then

\[
f(y)=C(y,3)=y^3-9y^2+33y-81.
\]

At `y=13`,

\[
f(13)=1024=2^{10},
\]

and

\[
f'(13)=3\cdot 13^2-18\cdot 13+33=306=2\cdot 153,
\]

so

\[
v_2(f(13))=10>2v_2(f'(13))=2.
\]

By the standard Hensel criterion, there is a root `y₀ ∈ ℤ₂` with `f(y₀)=0` and `y₀ ≡ 13 mod 2^9`.  In particular `y₀` is a 2-adic unit.  Then

\[
b=2y_0,\qquad c=\frac{2y_0}{3}
\]

satisfy `F11(b,c)=0` in `ℚ₂`, and `b ≠ 0`.  Here `3` is a 2-adic unit, so `c ∈ ℚ₂` is well-defined.

Therefore there is no 2-adic obstruction to rational points with `b ≠ 0`.  There may still be a separate global reason that no rational solution exists, but this mod-2 argument cannot prove it.

## 4. Lean 4 formalization sketch

Since the answer is negative, the Lean target should not be a theorem saying that all rational `b ≠ 0` are impossible.  The Lean-formalizable statement supported by this computation is the weaker but true unit statement:

```lean
import Mathlib

noncomputable section

-- Rational polynomial.
def F11Q (b c : ℚ) : ℚ :=
  (c ^ 3 - b * (b - c)) * (b - c) ^ 3
    - b * c * (b - c - c ^ 2) ^ 3

-- Cleared numerator for b = p/q and c = r/s.
def H11 (p q r s : ℤ) : ℤ :=
  s * (q ^ 2 * r ^ 3 - p ^ 2 * s ^ 3 + p * q * r * s ^ 2) * (p * s - q * r) ^ 3
    - p * q * r * (p * s ^ 2 - q * r * s - q * r ^ 2) ^ 3

/-
The denominator-clearing lemma should be proved over ℚ by `field_simp` followed by `ring`:

lemma cleared_F11
    (p q r s : ℤ)
    (hq : (q : ℚ) ≠ 0)
    (hs : (s : ℚ) ≠ 0) :
    (q : ℚ) ^ 5 * (s : ℚ) ^ 7 * F11Q ((p : ℚ) / q) ((r : ℚ) / s)
      = (H11 p q r s : ℚ) := by
  field_simp [F11Q, H11, hq, hs]
  ring

Then reduce `H11` modulo `2`.  The useful parity lemma is:

* if `p` and `q` are odd, and `r,s` are not both even, then
  `(H11 p q r s : ZMod 2) = 1`.

This is a finite proof by reducing the four residues to `ZMod 2` and using `fin_cases`
on the three primitive possibilities for `(r mod 2, s mod 2)`:

* `(0,1)`;
* `(1,0)`;
* `(1,1)`.

Combined with `cleared_F11`, this proves:

* no rational solution with `v₂(b)=0`.

It does not prove, and cannot prove, no rational solution with merely `b ≠ 0`, because the
2-adic Hensel construction above gives an actual `ℚ₂` solution with `v₂(b)=1`.
-/

end
```

A compact Lean proof plan for the true unit obstruction is:

1. Normalize `b=p/q`, `c=r/s` with integer numerators and nonzero denominators, and with each pair coprime.
2. Use `cleared_F11` to turn `F11Q (p/q) (r/s)=0` into `H11 p q r s = 0`.
3. Reduce the integer equality modulo `2`.
4. From `v₂(b)=0`, get `p` odd and `q` odd, hence `(p : ZMod 2)=1` and `(q : ZMod 2)=1`.
5. From coprimality of `r,s`, get that `(r,s)` is one of `(0,1)`, `(1,0)`, `(1,1)` modulo `2`.
6. In all three cases, `norm_num [H11]` gives `(H11 p q r s : ZMod 2)=1`, contradicting the reduction of `H11 p q r s = 0`.

The attempted stronger theorem should be avoided: the 2-adic counterexample above shows that the local statement is false.
