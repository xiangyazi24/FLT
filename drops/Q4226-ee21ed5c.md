# X_1(21): explicit quotient to X_0(21), elementary descent, and the stronger G21 = 0 exclusion

## Executive verdict

Two premises in the proposed route need correction.

1. The natural map X_1(21) → X_0(21) has degree φ(21)/2 = 6, not degree 2. On the affine chart in the question it factors as

```text
X_1(21)  -- degree 2 -->  C : G21(t,X)=0  -- degree 3 -->  X_0(21).
```

Here C is the normalization of the plane quartic G21 = 0. The first map forgets the choice of generator of the order-3 subgroup. The second forgets the chosen generator of the order-7 subgroup and is the quotient by the order-3 diamond action P_7 ↦ 2P_7. It is not an Atkin–Lehner quotient.

2. The optimal curve 21a1 is

```text
E0 : y^2 + x*y = x^3 - 4*x - 1,
```

but

```text
E0(Q) ≅ Z/2Z × Z/4Z,
```

not Z/8Z. It has three nonzero rational 2-torsion points. The Cremona data in `JohnCremona/ecdata`, file `docs/curves.1-1000.html`, conductor 21 row A1, confirms the model `[1,0,0,-4,-1]`, rank 0, and torsion order 8. The argument below proves the point list without using the database rank assertion.

The useful conclusion is stronger than the original target:

> For all rational t and X, if t ≠ 0 and t ≠ 1, then G21(t,X) ≠ 0.

Therefore the square condition Z^2 = D21(t,X) is unnecessary. The proof is completely explicit:

* construct the degree-3 quotient map C → E0;
* prove E0(Q) is exactly the displayed eight-point subgroup by a 2-isogeny descent and 2-adic separatedness;
* evaluate the finitely many fibers and apply the rational-root theorem.

## 1. The Tate family, D21, and G21

Put

```text
a1 = 1 + t - t^2,
a2 = a3 = t^2*(1-t),
a4 = a6 = 0.
```

The Tate-normal-form family is

```text
E_t : y^2 + (1+t-t^2)*x*y + t^2*(1-t)*y
      = x^3 + t^2*(1-t)*x^2.
```

Equivalently, in the usual Tate notation,

```text
b = t^2*(t-1),
c = t*(t-1),
```

and the equation is

```text
y^2 + (1-c)*x*y - b*y = x^3 - b*x^2.
```

The point P = (0,0) has order 7 on every nonsingular fiber.

With the completed-square coordinate

```text
Z = 2*y + a1*X + a3,
```

one gets

```text
Z^2 = D21(t,X),
```

where

```text
D21(t,X) =
    4*X^3
  + (t^4 - 6*t^3 + 3*t^2 + 2*t + 1)*X^2
  + (2*t^5 - 4*t^4 + 2*t^2)*X
  + t^6 - 2*t^5 + t^4.
```

The standard Weierstrass invariants are

```text
b2 = t^4 - 6*t^3 + 3*t^2 + 2*t + 1,
b4 = t^5 - 2*t^4 + t^2,
b6 = t^6 - 2*t^5 + t^4,
b8 = t^6*(1-t)^3.
```

Consequently the 3-division polynomial

```text
psi3(X) = 3*X^4 + b2*X^3 + 3*b4*X^2 + 3*b6*X + b8
```

is exactly

```text
G21(t,X) =
    3*X^4
  + (t^4 - 6*t^3 + 3*t^2 + 2*t + 1)*X^3
  + (3*t^5 - 6*t^4 + 3*t^2)*X^2
  + (3*t^6 - 6*t^5 + 3*t^4)*X
  - t^9 + 3*t^8 - 3*t^7 + t^6.
```

The discriminant of the Tate family is

```text
Delta(t) = t^7*(t-1)^7*(t^3 - 8*t^2 + 5*t + 1).
```

For rational t ≠ 0,1, the remaining cubic factor cannot vanish. It is monic with constant coefficient 1, so a rational root would be an integer dividing 1; neither 1 nor -1 is a root. Thus every rational fiber used below is nonsingular.

The equation G21(t,X)=0 says that E_t has a rational cyclic subgroup of order 3: a rational root of psi3 is the x-coordinate of a pair {R,-R}, and that pair is Galois invariant. The additional equation Z^2=D21 chooses an actual rational generator R. The stronger argument below already excludes the rational cyclic subgroup.

## 2. The correct modular diagram and diamond action

Let C be the normalization of G21(t,X)=0. Moduli-theoretically C records triples

```text
(E, P7, C3),
```

where P7 is a chosen point of order 7 and C3 is a cyclic subgroup of order 3.

The factorization is

```text
X_1(21)  -- degree 2 -->  C  -- degree 3 -->  X_0(21).
```

For the first map, if R generates a cyclic subgroup of order 21, send

```text
R ↦ (3*R, <7*R>).
```

For a fixed pair (P7,C3), the two generators of C3 are the two generic points in the fiber.

Changing the chosen order-7 generator by P7 ↦ 2*P7 gives the order-3 transformation

```text
sigma(t,X) = ((t-1)/t, (X - t^2*(t-1))/t^4).
```

Direct substitution gives

```text
sigma^3 = identity,
t^16 * G21(sigma(t,X)) = G21(t,X).
```

On the t-coordinate this is the familiar cycle

```text
t ↦ (t-1)/t ↦ 1/(1-t) ↦ t.
```

## 3. Explicit invariant functions and quotient equation

Define

```text
q(t) = t^2 - t + 1,

s(t) = (t^3 - 3*t + 1)/(t*(t-1)),

r(t,X) = ((t^2-t+1)*X - t^2*(t-1))
         /(t^2*(t-1)^2).
```

Both s and r are invariant under sigma. Define

```text
R21(s,r) =
    3*r^4
  + (s^2 - 7*s + 9)*r^3
  + 6*(s-3)*r^2
  + 12*r
  - s.
```

The key exact certificate is

```text
t^8*(t-1)^8 * R21(s(t),r(t,X))
  = (t^2-t+1)^4 * G21(t,X).
```

This is a literal polynomial identity after denominators are cleared. In Lean it is proved by `field_simp` followed by `ring`.

Hence, for t ≠ 0,1,

```text
G21(t,X)=0  implies  R21(s(t),r(t,X))=0.
```

The parameter t is recovered over the quotient by the cubic

```text
t^3 - s*t^2 + (s-3)*t + 1 = 0.
```

Indeed, substituting the definition of s and clearing the denominator t*(t-1) proves this identity immediately.

This already exhibits C as a cyclic cubic cover of the genus-1 quotient.

## 4. Explicit map from the quotient to 21a1

Set

```text
d(r) = r^2 - r + 1.
```

For rational r this denominator is nonzero because

```text
4*d(r) = (2*r-1)^2 + 3 > 0.
```

Define

```text
w(s,r) = (2*r^3*s - 7*r^3 + 6*r^2 - 1)/(r^2-r+1).
```

The discriminant of R21, viewed as a quadratic in s, factors as

```text
(-7*r^3 + 6*r^2 - 1)^2
  - 4*r^3*(3*r^4 + 9*r^3 - 18*r^2 + 12*r)
= -(r+1)*(3*r-1)*(4*r+1)*(r^2-r+1)^2.
```

Equivalently, the exact polynomial certificate is

```text
(r^2-r+1)^2
  * (w(s,r)^2 + (r+1)*(3*r-1)*(4*r+1))
= 4*r^3*R21(s,r).
```

Thus R21(s,r)=0 implies

```text
w^2 = -(r+1)*(3*r-1)*(4*r+1).
```

Now define

```text
x = -3*r - 1,
y = (3*w + 3*r + 1)/2.
```

Then

```text
2*y + x = 3*w
```

and

```text
(x+2)*(x-2)*(4*x+1)
  = -9*(r+1)*(3*r-1)*(4*r+1).
```

Therefore

```text
(2*y+x)^2 = (x+2)*(x-2)*(4*x+1),
```

which is equivalent to

```text
E0 : y^2 + x*y = x^3 - 4*x - 1.
```

The requested explicit rational map C → 21a1 is therefore

```text
s = (t^3 - 3*t + 1)/(t*(t-1)),

r = ((t^2-t+1)*X - t^2*(t-1))/(t^2*(t-1)^2),

w = (2*r^3*s - 7*r^3 + 6*r^2 - 1)/(r^2-r+1),

x = -3*r - 1,

y = (3*w + 3*r + 1)/2.
```

The x-coordinate can be written directly as

```text
x = (t^2*(t-1)*(4-t) - 3*(t^2-t+1)*X)
    /(t^2*(t-1)^2).
```

All denominators are nonzero on the rational affine chart t ≠ 0,1.

## 5. Explicit determination of E0(Q)

Completing the square on E0 gives

```text
(2*y+x)^2 = (x+2)*(x-2)*(4*x+1).
```

The eight rational points are

```text
O,
(-2,1),
(2,-1),
(-1/4,1/8),
(-1,-1),
(-1,2),
(5,8),
(5,-13).
```

The first three affine points are the three nonzero 2-torsion points. If

```text
P = (-1,-1),
T = (-2,1),
```

then direct chord-and-tangent calculation gives

```text
2*P = (2,-1),
P+T = (5,8),
T+(2,-1) = (-1/4,1/8).
```

Hence these eight points form a subgroup

```text
H = <P,T> ≅ Z/4Z × Z/2Z.
```

It remains to prove there are no additional rational points without assuming rank 0.

### 5.1 A convenient 2-isogeny pair

Set

```text
u = 4*(x-2),
W = 4*(2*y+x).
```

This identifies E0 with

```text
E1 : W^2 = u*(u+9)*(u+16)
           = u^3 + 25*u^2 + 144*u.
```

Quotienting by the rational point (0,0) gives the 2-isogenous curve

```text
E2 : V^2 = v^3 - 50*v^2 + 49*v
           = v*(v-1)*(v-49).
```

For u ≠ 0, the isogeny is

```text
phi(u,W) =
  (W^2/u^2, W*(144-u^2)/u^2).
```

For v ≠ 0, the dual isogeny is

```text
dualPhi(v,V) =
  (V^2/(4*v^2), V*(49-v^2)/(8*v^2)).
```

The exceptional points O and (0,0) are handled by the usual separate clauses. A direct calculation gives

```text
dualPhi(phi(Q)) = 2*Q on E1,
phi(dualPhi(Q')) = 2*Q' on E2.
```

These are again denominator-clearing ring identities.

### 5.2 Kummer images

For a curve

```text
Y^2 = X^3 + a*X^2 + b*X
```

with rational point (0,0), define its Kummer square class by

```text
alpha(O) = 1,
alpha(0,0) = b,
alpha(X,Y) = X modulo rational squares, when X ≠ 0.
```

A squarefree representative d dividing b occurs exactly when the quartic

```text
N^2 = d*M^4 + a*M^2*e^2 + (b/d)*e^4
```

has a primitive nonzero integer solution. This follows by writing X = d*(M/e)^2 in lowest terms.

For E1, a=25 and b=144, so the possible squarefree classes are

```text
d in {1,-1,2,-2,3,-3,6,-6}.
```

The four classes

```text
1, -1, -3, 3
```

occur. Explicit witnesses are

```text
d =  1 : (M,e,N) = (0,1,12),
d = -1 : (M,e,N) = (4,1,0),
d = -3 : (M,e,N) = (2,1,2),
d =  3 : (M,e,N) = (2,1,14).
```

They are represented on E1 by

```text
O,
(-16,0),
(-12,-12),
(12,84).
```

The even classes d=2,-2,6,-6 are impossible by one uniform mod-8/mod-16 argument. The equation is

```text
N^2 = d*M^4 + 25*M^2*e^2 + (144/d)*e^4.
```

For primitive M,e:

* M odd and e even: the right side is 2 or 6 modulo 8.
* M and e both odd: it is 3 or 7 modulo 8.
* M even: then e is odd. Modulo 16, M^4 is 0, the middle term is 0 or 4, and `(144/d)*e^4` is 8. The total is 8 or 12 modulo 16.

None is a square. Therefore

```text
image(alpha1) = {1,-1,-3,3}.
```

For E2, a=-50 and b=49, so the possible squarefree classes are

```text
d in {1,-1,7,-7}.
```

The classes -1 and -7 give negative-definite quartics and are impossible for a primitive nonzero pair. For d=7 the equation is

```text
N^2 = 7*M^4 - 50*M^2*e^2 + 7*e^4.
```

If exactly one of M,e is even, the right side is 7 modulo 8. If both are odd, then modulo 16 it is

```text
7 + 7 - 2 = 12.
```

Therefore

```text
image(alpha2) = {1}.
```

### 5.3 Explicit kernel reconstruction

The kernel statements needed for 2-descent can be proved directly from the displayed isogenies.

On E1, if u=z^2, a preimage under dualPhi is found by solving

```text
v^2 - (4*u+50)*v + 49 = 0.
```

Its discriminant is

```text
16*(u^2 + 25*u + 144) = (4*W/z)^2.
```

Thus alpha1(Q)=1 exactly when Q lies in dualPhi(E2(Q)).

On E2, if v=z^2, a preimage under phi is found by solving

```text
u^2 + (25-v)*u + 144 = 0.
```

Its discriminant is

```text
v^2 - 50*v + 49 = (V/z)^2.
```

Thus alpha2(Q')=1 exactly when Q' lies in phi(E1(Q)).

The usual fact that alpha is a homomorphism to the square-class group can also be proved directly from the chord formula, or packaged once for curves with a rational point (0,0).

Now take Q in E1(Q). Choose one of the four explicit representatives T_d with the same alpha1 class. Then

```text
alpha1(Q-T_d)=1,
```

so Q-T_d = dualPhi(Q') for some Q' in E2(Q). Since every point of E2 has alpha2 class 1, write Q'=phi(R). Hence

```text
Q = T_d + 2*R.
```

Thus every rational point is congruent modulo 2*E1(Q) to one of four explicit torsion representatives.

### 5.4 Axiom-free termination by 2-adic separatedness

Do not finish the preceding coset calculation by inserting an abstract rank-zero assertion. Iterate it instead.

For every Q in E0(Q) and every n≥1, there are T_n in H and Q_n in E0(Q) such that

```text
Q = T_n + 2^n*Q_n.
```

Because H has exponent 4,

```text
4*Q = 2^n*(4*Q_n)
```

for every n.

The discriminant of E0 is

```text
Delta(E0) = 3969 = 3^4*7^2,
```

so the integral model has good reduction at 2. A direct count gives

```text
#E0(F_2) = 4.
```

Therefore 4*Q and every 4*Q_n lie in the formal kernel of reduction at 2.

Let z=-x/y be the standard local parameter at infinity. On the formal kernel, z lies in 2*Z_2. The formal doubling series has the form

```text
[2](z) = 2*z + sum_{k≥2} c_k*z^k,
with every c_k in Z_2.
```

Hence

```text
v_2([2](z)) ≥ v_2(z)+1.
```

A formal-kernel point divisible by 2^n inside the formal kernel for every n has a local parameter of arbitrarily large 2-adic valuation, and is therefore the identity. Applying this to 4*Q gives

```text
4*Q = O.
```

Thus every rational point is 4-torsion.

At the good prime 5, another direct count gives

```text
#E0(F_5) = 8.
```

Reduction at 5 is injective on 2-power torsion. Therefore E0(Q) has at most eight points. The eight displayed points already exist, so they exhaust E0(Q).

This proves, without `AddGroup.FG`, Mordell–Weil, BSD, or a rank axiom,

```text
E0(Q) = H ≅ Z/4Z × Z/2Z.
```

Rank 0 is a consequence, not an assumption.

## 6. Cusps and noncuspidal rational points of X_0(21)

The quotient parameter s maps X_0(21) to X_0(7). The two cusp values on X_0(7) are

```text
s = infinity,
s = 8.
```

The value 8 follows directly from

```text
t^3 - 8*t^2 + 5*t + 1 = 0
```

and the definition of s.

The four rational cusps on E0 are

```text
O,
(-1,2),
(-2,1),
(5,-13).
```

The four noncuspidal rational points are

```text
(2,-1),
(-1/4,1/8),
(-1,-1),
(5,8).
```

For an affine E0 point define

```text
r = -(x+1)/3,
w = (2*y+x)/3.
```

The values are:

| E0 point | cusp? | r | w | s |
|---|---:|---:|---:|---:|
| O | yes | infinity | infinity | infinity |
| (-1,2) | yes | 0 | 1 | infinity |
| (-2,1) | yes | 1/3 | 0 | 8 |
| (5,-13) | yes | -2 | -7 | 8 |
| (2,-1) | no | -1 | 0 | 6 |
| (-1/4,1/8) | no | -1/4 | 0 | -33/2 |
| (-1,-1) | no | 0 | -1 | 0 |
| (5,8) | no | -2 | 7 | 15/8 |

At r=0, the affine formula for w gives w=-1. Consequently the cusp (-1,2), which has w=1, is not in the image of this affine chart. The point O is also not in the image because x=-3*r-1 is finite.

## 7. Explicit fibers and direct proof that G21=0 has no rational point

For an affine rational point of C, the parameter t must satisfy

```text
f_s(T) = T^3 - s*T^2 + (s-3)*T + 1 = 0.
```

### 7.1 Noncuspidal target points

At (2,-1), one has s=6, so

```text
T^3 - 6*T^2 + 3*T + 1 = 0.
```

It is monic with constant coefficient 1. The only possible rational roots are 1 and -1; neither is a root.

At (-1/4,1/8), one has s=-33/2, so

```text
2*T^3 + 33*T^2 - 39*T + 2 = 0.
```

The rational-root candidates are

```text
1,-1,2,-2,1/2,-1/2,
```

and direct evaluation excludes all of them. Equivalently, its reduction modulo 5 has no root.

At (-1,-1), one has s=0, so

```text
T^3 - 3*T + 1 = 0.
```

Again the only possible rational roots are 1 and -1, and neither works. Reduction modulo 2 is T^3+T+1, which has no root.

At (5,8), one has s=15/8, so

```text
8*T^3 - 15*T^2 - 9*T + 8 = 0.
```

The rational-root candidates are

```text
±1, ±2, ±4, ±8, ±1/2, ±1/4, ±1/8,
```

and none is a root. More economically, its reduction modulo 5 is

```text
3*T^3 + T + 3,
```

which has no root in F_5.

### 7.2 Cuspidal target points

The two finite cusps (-2,1) and (5,-13) both have s=8, so a point above either would require

```text
T^3 - 8*T^2 + 5*T + 1 = 0.
```

The only possible rational roots are 1 and -1, and neither works.

The remaining two cusps, O and (-1,2), are not in the finite affine image as explained above.

Therefore every possible image point is excluded. We have proved the global statement

```text
For all t,X in Q,
  t ≠ 0 and t ≠ 1  imply  G21(t,X) ≠ 0.
```

This is stronger than a small-height search: it excludes every height. I did not rely on an external bounded-height brute-force computation; the finite quotient-fiber calculation above is an exact exhaustive search. Any correct bounded-height search must return the empty set.

As an external sanity check only, the known classification of rational isogeny–torsion graphs also forbids coexistence of a rational 7-torsion point and a rational 3-isogeny. That deeper classification is unnecessary here and should not be imported into the Lean proof.

## 8. Consequence for the original X_1(21) target

Suppose rational t,X,Z satisfy

```text
t ≠ 0,
t ≠ 1,
G21(t,X)=0,
Z^2=D21(t,X).
```

The stronger theorem already contradicts G21(t,X)=0. Hence there is no such rational triple. The hypothesis Z^2=D21(t,X) is intentionally unused in the final Lean theorem.

## 9. Lean 4 proof architecture

The quotient and fiber part is very Lean-friendly because every difficult map is accompanied by a short exact polynomial certificate. The code below gives the intended theorem interfaces and exact algebraic identities. I have not claimed it was compiled in this connector session, because the connector exposes repository reads and writes but no Lean execution; the only remaining implementation-sensitive work is the elliptic-curve point type and formal-kernel API.

### 9.1 Definitions

```lean
import Mathlib

open Polynomial

namespace X1_21

noncomputable section

abbrev Q := Rat

def G21 (t X : Q) : Q :=
  3 * X^4
    + (t^4 - 6*t^3 + 3*t^2 + 2*t + 1) * X^3
    + (3*t^5 - 6*t^4 + 3*t^2) * X^2
    + (3*t^6 - 6*t^5 + 3*t^4) * X
    - t^9 + 3*t^8 - 3*t^7 + t^6

def D21 (t X : Q) : Q :=
  4 * X^3
    + (t^4 - 6*t^3 + 3*t^2 + 2*t + 1) * X^2
    + (2*t^5 - 4*t^4 + 2*t^2) * X
    + t^6 - 2*t^5 + t^4

def q7 (t : Q) : Q := t^2 - t + 1

def s21 (t : Q) : Q :=
  (t^3 - 3*t + 1) / (t * (t - 1))

def r21 (t X : Q) : Q :=
  ((t^2 - t + 1) * X - t^2 * (t - 1)) /
    (t^2 * (t - 1)^2)

def R21 (s r : Q) : Q :=
  3*r^4 + (s^2 - 7*s + 9)*r^3
    + 6*(s - 3)*r^2 + 12*r - s

def w21 (s r : Q) : Q :=
  (2*r^3*s - 7*r^3 + 6*r^2 - 1) / (r^2 - r + 1)

def e21x (r : Q) : Q := -3*r - 1

def e21y (s r : Q) : Q :=
  (3*w21 s r + 3*r + 1) / 2

def OnE21 (x y : Q) : Prop :=
  y^2 + x*y = x^3 - 4*x - 1
```

### 9.2 Cleared-denominator certificates

```lean
lemma s21_cubic (t : Q) (ht0 : t ≠ 0) (ht1 : t ≠ 1) :
    t^3 - s21 t * t^2 + (s21 t - 3) * t + 1 = 0 := by
  field_simp [s21, ht0, ht1]
  ring

lemma quotient_certificate (t X : Q)
    (ht0 : t ≠ 0) (ht1 : t ≠ 1) :
    t^8 * (t - 1)^8 * R21 (s21 t) (r21 t X)
      = q7 t ^ 4 * G21 t X := by
  field_simp [s21, r21, R21, q7, G21, ht0, ht1]
  ring

lemma quadDen_ne (r : Q) : r^2 - r + 1 ≠ 0 := by
  intro h
  have hs : 0 ≤ (2*r - 1)^2 := sq_nonneg (2*r - 1)
  nlinarith

lemma w_certificate (s r : Q) :
    (r^2 - r + 1)^2 *
        (w21 s r ^ 2 + (r + 1)*(3*r - 1)*(4*r + 1))
      = 4*r^3 * R21 s r := by
  field_simp [w21, quadDen_ne]
  ring

lemma map_to_E21 (s r : Q) (hR : R21 s r = 0) :
    OnE21 (e21x r) (e21y s r) := by
  have hw := w_certificate s r
  rw [hR, mul_zero] at hw
  field_simp [OnE21, e21x, e21y, w21, quadDen_ne] at *
  nlinarith
```

If the last proof is syntactically brittle, retain `hw`, unfold only `OnE21`, `e21x`, and `e21y`, and close with `linear_combination` plus `ring_nf`. The mathematical certificate is exactly `w_certificate`.

From `quotient_certificate`, nonvanishing of `t^8*(t-1)^8` yields R21=0 whenever G21=0.

```lean
    (x = 5     ∧ y = 8)     ∨
    (x = 5     ∧ y = -13) := by

```

The descent should be split into reusable pieces.


## 10. Formalization order

The shortest axiom-free implementation order is:

1. Land the quotient and map certificates (`s21_cubic`, `quotient_certificate`, `w_certificate`, `map_to_E21`).
2. Land the two explicit isogenies and quadratic kernel-reconstruction lemmas.
3. Land the six local Kummer obstruction lemmas modulo 8 and 16.
4. Prove the four-coset statement modulo doubling.
5. Reuse or add the curve-specific 2-adic separatedness lemma.
6. Prove the eight-point exhaustion of E0(Q).
7. Close the seven finite image cases and then the original theorem.

The quotient identities, map, fiber calculations, and rational-root exclusions require no new number-theory infrastructure beyond `field_simp`, `ring`, `norm_num`, and Mathlib's rational-root theorem. The only substantial reusable infrastructure is the explicit 2-isogeny exactness and the formal-kernel separatedness lemma. Neither requires an axiom or an abstract finite-generation theorem.
