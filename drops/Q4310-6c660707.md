# Rational 35-torsion: explicit obstruction and the low-genus escape

## Executive verdict

Order 35 is **not** a wall like order 18.

The direct `X_1(35)` curve is large:

```text
g(X_1(35)) = 25.
```

The raw equation obtained by putting a 5-division point on Kubert's order-7 family is correspondingly unattractive. However, its `X`-coordinate already determines a rational cyclic subgroup of order 5. Together with the rational cyclic subgroup of order 7, this gives a rational cyclic subgroup of order 35. Therefore the problem immediately descends to

```text
X_0(35),
```

which is a hyperelliptic genus-3 curve.

More importantly, this genus-3 curve has an explicit degree-2 quotient to the rank-zero elliptic curve

```text
E35 : Y^2 + Y = X^3 + X^2 + 9*X + 1
```

(Cremona `35A1`, LMFDB `35.a1`). Its rational points are

```text
E35(Q) = { O, (1,3), (1,-4) } ≅ Z/3Z.
```

The three fibers of the degree-2 quotient are elementary:

- the fibers above `O` and `(1,-4)` are the four rational cusps of `X_0(35)`;
- the fiber above `(1,3)` consists of the two quadratic points with `x^2+x-1=0` and is not rational.

Thus one can prove

```text
X_0(35)(Q) = {four cusps}
```

without formalizing the genus-3 Jacobian.

So the recommended Lean route is:

```text
order-7 Kubert family + psi_5 root
  -> rational 35-isogeny
  -> explicit X_0(35) model
  -> explicit degree-2 map to E35
  -> rank-zero exhaustion of E35(Q)
  -> three finite fiber checks
  -> contradiction.
```

This is structurally closer to the `15/21` strategy than to the `18` strategy. There is one new seam: an explicit algebraic bridge from the Kubert/division-polynomial data to the chosen model of `X_0(35)`. The arithmetic after that bridge is elliptic, not a higher-genus Jacobian build.

# 1. The order-7 Kubert family

Use the Tate normal form

```text
E(b,c): y^2 + (1-c)xy - b y = x^3 - b x^2,
P7=(0,0).
```

Kubert's order-7 parametrization is

```text
b = t^3-t^2 = t^2(t-1),
c = t^2-t.
```

In long Weierstrass notation

```text
y^2 + a1*x*y + a3*y = x^3 + a2*x^2 + a4*x + a6,
```

this gives

```text
a1 = 1+t-t^2,
a2 = t^2(1-t),
a3 = t^2(1-t),
a4 = 0,
a6 = 0.
```

The discriminant is

```text
Delta7(t) = t^7 (t-1)^7 (t^3-8t^2+5t+1).
```

Hence the noncuspidal/nonsingular chart is

```text
t != 0,
t != 1,
t^3-8t^2+5t+1 != 0.
```

The standard `b`-invariants are

```text
b2 = t^4 - 6t^3 + 3t^2 + 2t + 1,
b4 = t^5 - 2t^4 + t^2,
b6 = t^6 - 2t^5 + t^4,
b8 = -t^9 + 3t^8 - 3t^7 + t^6.
```

All of these identities are direct `ring` certificates from the definitions

```text
b2=a1^2+4a2,
b4=a1*a3+2a4,
b6=a3^2+4a6,
b8=a1^2*a6+4a2*a6-a1*a3*a4+a2*a3^2-a4^2.
```

# 2. The explicit obstruction curve `G35(t,X)=0`

Let `X` denote a prospective rational `x`-coordinate of a nonzero 5-torsion point.

Define

```text
D2(t,X)
  = 4X^3 + b2 X^2 + 2b4 X + b6.
```

On the curve this is

```text
D2(t,X) = psi_2(X,Y)^2
        = (2Y+a1*X+a3)^2.
```

Define the third division polynomial

```text
P3(t,X)
  = 3X^4 + b2 X^3 + 3b4 X^2 + 3b6 X + b8.
```

Thus `P3=psi_3`.

Write `psi_4=psi_2*P4`, where

```text
P4(t,X) =
    2X^6
  + b2 X^5
  + 5b4 X^4
  + 10b6 X^3
  + 10b8 X^2
  + (b2*b8-b4*b6) X
  + (b4*b8-b6^2).
```

The standard division-polynomial recurrence gives

```text
psi_5 = psi_4*psi_2^3 - psi_3^3
      = D2^2*P4 - P3^3.
```

Therefore take

```text
G35(t,X) := D2(t,X)^2 * P4(t,X) - P3(t,X)^3.
```

This is a completely explicit polynomial in `Q[t,X]`. It is degree 12 in `X`. For Lean, the nested form above is preferable to a large expanded coefficient list: the certificate

```text
G35 = psi_5
```

is one `ring` normalization after specializing the general division-polynomial formulas.

Compile-shaped definitions are:

```lean
def a1_7 (t : ℚ) : ℚ := 1+t-t^2
def a2_7 (t : ℚ) : ℚ := t^2*(1-t)
def a3_7 (t : ℚ) : ℚ := t^2*(1-t)

def b2_7 (t : ℚ) : ℚ := t^4-6*t^3+3*t^2+2*t+1
def b4_7 (t : ℚ) : ℚ := t^5-2*t^4+t^2
def b6_7 (t : ℚ) : ℚ := t^6-2*t^5+t^4
def b8_7 (t : ℚ) : ℚ := -t^9+3*t^8-3*t^7+t^6

def D2_35 (t X : ℚ) : ℚ :=
  4*X^3 + b2_7 t*X^2 + 2*b4_7 t*X + b6_7 t

def P3_35 (t X : ℚ) : ℚ :=
  3*X^4 + b2_7 t*X^3 + 3*b4_7 t*X^2
    + 3*b6_7 t*X + b8_7 t

def P4_35 (t X : ℚ) : ℚ :=
    2*X^6
  + b2_7 t*X^5
  + 5*b4_7 t*X^4
  + 10*b6_7 t*X^3
  + 10*b8_7 t*X^2
  + (b2_7 t*b8_7 t-b4_7 t*b6_7 t)*X
  + (b4_7 t*b8_7 t-(b6_7 t)^2)

def G35 (t X : ℚ) : ℚ :=
  (D2_35 t X)^2 * P4_35 t X - (P3_35 t X)^3
```

## Exact point versus cyclic subgroup

For an actual rational point of order 5, one also needs a rational square root

```text
Z^2 = D2(t,X),
Z = 2Y+a1X+a3,
Y = (Z-a1X-a3)/2.
```

Thus the exact `X_1(35)`-type affine system is

```text
G35(t,X)=0,
Z^2=D2(t,X),
Delta7(t) != 0.
```

However, the square equation is unnecessary for exclusion.

If `X` is rational and `psi_5(X)=0`, choose a 5-torsion point `Q` with that `x`-coordinate. For every Galois element `sigma`,

```text
x(sigma Q)=sigma(x(Q))=X=x(Q).
```

Since `Q` is not 2-torsion, the fiber of the `x`-map is `{Q,-Q}`. Hence

```text
sigma Q = Q or -Q,
```

so the cyclic subgroup `<Q>` is Galois-stable. Therefore a rational root of `G35(t,X)` already gives a rational cyclic 5-isogeny.

The rational point `P7=(0,0)` gives a rational cyclic subgroup of order 7. Since 5 and 7 are coprime, the sum of the two stable subgroups is a Galois-stable cyclic subgroup of order 35. Consequently:

> A noncuspidal rational solution of `G35(t,X)=0` gives a noncuspidal rational point on `X_0(35)`.

This proves the stronger target

```lean
theorem G35_ne_zero
    (t X : ℚ)
    (ht0 : t != 0)
    (ht1 : t != 1)
    (hDelta : t^3-8*t^2+5*t+1 != 0) :
    G35 t X != 0
```

once `X_0(35)(Q)` has been exhausted.

# 3. Geometry: why `X_1(35)` is the wrong curve

For `N=35`, the index of `Gamma_1(35)` in `PSL_2(Z)` is 576 and the number of cusps is 48. There are no elliptic fixed points. Hence

```text
g(X_1(35)) = 1 + 576/12 - 48/2 = 25.
```

The natural map

```text
X_1(35) -> X_0(35)
```

has degree

```text
phi(35)/2 = 12.
```

The curve `X_0(35)` has genus 3. It is hyperelliptic. Thus the immediate quotient already changes the problem from genus 25 to genus 3.

The Jacobian decomposition is

```text
J_0(35)  ~_Q  E35 x A35,
```

where

- `E35` is the elliptic curve `35A1` above;
- `A35` is the 2-dimensional GL2-type factor attached to the degree-2 newform orbit `35.2.a.b`;
- `End_Q(A35) tensor Q = Q(sqrt(17))`;
- both factors have rank 0.

The 2-dimensional factor is represented in the LMFDB by the genus-2 isogeny class `1225.a`. Thus the notation “`35b`” should not be read as a second elliptic curve: it is a modular abelian surface.

None of `J_1(35)` is needed for the rational torsion exclusion.

# 4. An explicit model of `X_0(35)`

A model used in Galbraith's thesis and in public Magma computations is

```text
C35 : z^2 = H35(x),
```

where

```text
H35(x) =
    x^8 - 4x^7 - 6x^6 - 4x^5 - 9x^4
  + 4x^3 - 6x^2 + 4x + 1.
```

The four rational cusps are

```text
infinityPlus,
infinityMinus,
(0,1),
(0,-1).
```

The polynomial satisfies the exact reciprocal identity

```text
x^8 H35(-1/x) = H35(x).
```

Therefore

```text
iota(x,z) = (-1/x, z/x^4)
```

is a rational involution. On this modular model it is the genus-one Atkin-Lehner involution (identified with `w_5`; the hyperelliptic involution is `w_35`).

The invariant functions

```text
u = x - 1/x,
v = z/x^2
```

give the quotient curve

```text
Cq : v^2 = u^4 - 4u^3 - 2u^2 - 16u - 19.
```

The certificate is a direct substitution:

```text
H35(x)/x^4
  = (x^4+x^-4)
    -4(x^3-x^-3)
    -6(x^2+x^-2)
    -4(x-x^-1)-9
  = u^4-4u^3-2u^2-16u-19.
```

Thus `C35 -> Cq` is a degree-2 map.

# 5. The quotient is the rank-zero elliptic curve `35A1`

Put

```text
A(u)=u^2-2u-3=(u+1)(u-3).
```

A particularly useful identity is

```text
(u^4-4u^3-2u^2-16u-19) - A(u)^2 = -28(u+1).
```

Hence on `Cq`,

```text
(v-A(u))(v+A(u)) = -28(u+1).
```

Away from the exceptional points define

```text
r  = v-A(u),
xi = (u+1)/r,
eta = 1 + 4xi(u-1).
```

Then

```text
eta^2 = 1 - 16xi + 64xi^2 - 224xi^3.
```

Now set

```text
XE = 1-14xi,
YE = (7eta-1)/2 = 3+14xi(u-1).
```

A direct expansion gives

```text
YE^2 + YE = XE^3 + XE^2 + 9XE + 1.
```

Therefore the explicit elliptic quotient is

```text
E35 : YE^2+YE=XE^3+XE^2+9XE+1.
```

The rational map can be recorded as

```text
u = x-1/x,
v = z/x^2,
A = u^2-2u-3,
r = v-A,
XE = 1 - 14*(u+1)/r,
YE = 3 + 14*(u+1)*(u-1)/r.
```

Every displayed identity is polynomial/rational-function arithmetic and is suitable for `field_simp; ring` after separating the exceptional divisors.

For generic points the inverse formulas begin with

```text
xi = (1-XE)/14,
u  = 1 + (YE-3)/(1-XE),
v  = A(u) + (u+1)/xi.
```

The original `x`-coordinate is then recovered from

```text
x^2-u*x-1=0,
```

and `z=v*x^2`.

# 6. The three fibers

The elliptic curve has

```text
E35(Q) = { O, T, -T },
T=(1,3),
-T=(1,-4).
```

The nonzero points have order 3.

The quotient map extends across the exceptional points as follows.

## Fiber above `O`

One point at infinity of the quartic `Cq` maps to `O`. Its inverse image on `C35` is

```text
{ infinityPlus, (0,1) }.
```

Both are cusps.

## Fiber above `(1,-4)`

The other point at infinity of `Cq` maps to `(1,-4)`. Its inverse image is

```text
{ infinityMinus, (0,-1) }.
```

Both are cusps.

## Fiber above `(1,3)`

The remaining rational point of `Cq` lying over `(1,3)` is

```text
(u,v)=(-1,0).
```

Recovering `x` gives

```text
x^2+x-1=0,
z=0.
```

The discriminant is 5, so this fiber consists of two points over `Q(sqrt(5))` and contains no rational point.

Consequently

```text
C35(Q)
  = { infinityPlus, infinityMinus, (0,1), (0,-1) }.
```

These are precisely the four cusps, so `X_0(35)(Q)` has no noncuspidal point.

This is the decisive elementary reduction. It uses a rank-zero elliptic curve and three fibers, not the genus-3 Jacobian.

# 7. How to prove `E35(Q)` in the shared Lean framework

Cremona's minimal model has coefficients

```text
[a1,a2,a3,a4,a6]=[0,1,1,9,1],
```

rank 0, and torsion order 3.

The points `(1,3)` and `(1,-4)` are visibly negatives, and direct addition verifies that they have order 3.

The curve has good reduction at 2 and

```text
#E35(F_2)=3.
```

Thus it fits the shared weak-descent/separatedness pattern particularly well.

Let

```text
H={O,T,-T}.
```

Then `H` has exponent 3. Prove the fixed 2-descent statement

```text
for every P in E35(Q),
there exist h in H and Q in E35(Q) such that P=h+2Q.
```

Together with 2-adic separatedness, the group-theory theorem audited in Q4293 gives

```text
3P=O for every P in E35(Q).
```

Good reduction at 2 is injective on this odd torsion, and `#E35(F_2)=3`. Therefore

```text
E35(Q)=H.
```

The only curve-specific arithmetic still needed here is a small elliptic 2-descent (or an equivalent 3-isogeny descent). No genus-3 Jacobian formal group is needed.

# 8. What the published computations do

The literature-faithful route is slightly heavier than the elliptic-fiber shortcut.

A public Magma computation for `X(b5,b7)=X_0(35)` does the following:

1. constructs `SmallModularCurve(35)`;
2. verifies that all rational points are cusps;
3. identifies it with the hyperelliptic model `C35` above;
4. computes the cuspidal subgroup of its Jacobian as

   ```text
   Z/24Z x Z/2Z;
   ```

5. computes

   ```text
   Sel_2(J_0(35)) ≅ Z/2Z x Z/2Z;
   ```

6. concludes that the Jacobian has rank 0 and equals its cuspidal subgroup.

This appears explicitly in Samir Siksek's public file

```text
progs2/Xb5b7.txt
```

and the model is attributed there to Galbraith's thesis, Section 4.4.

Bruin-Najman likewise state that the rank-zero claims for the hyperelliptic `X_0(n)` are proved using Magma's genus-2/hyperelliptic `2`-descent machinery. Their Proposition 3 proves that `J_0(n)(Q)` equals the cuspidal subgroup; `n=35` is one of the easy cases where ordinary good-reduction torsion bounds already prove equality after rank zero is known.

Thus the **published robust route** uses the full genus-3 Jacobian. The **elliptic quotient route above** is an explicit algebraic compression of the same curve and is better suited to this Lean project.

# 9. Classical literature context

## Kubert

Kubert's 1976 paper supplies the Tate normal form and the order-7 parametrization used to define `G35`. It does not appear to give a special factor descent for order 35 comparable to the familiar `X_1(16)` Fermat reduction.

## Mazur and Kenku

A rational 35-torsion point gives a rational cyclic 35-isogeny. The classical rational-isogeny theorem excludes degree 35:

- Mazur determined the possible prime degrees and proposed the full list;
- Kenku completed the composite-degree cases in a series of papers.

Using that theorem would close the argument immediately, but formalizing it wholesale would be excessive for this project. The explicit `X_0(35)` quotient proof isolates exactly the degree-35 case.

## Kenku-Momose

Kenku-Momose concerns torsion over quadratic fields. It is not needed for the rational exclusion. The relevant rational modular curve is `X_0(35)`.

## Galbraith and later explicit work

Galbraith gives equations for the modular curve with simultaneous 5- and 7-isogenies. Bruin-Najman and later computations use the same genus-3 hyperelliptic curve and its rank-zero Jacobian.

No useful route through `J_1(35)` was found or is needed.

# 10. Lean difficulty verdict

## Arithmetic verdict

**Elementary quotient seam, not a higher-genus wall.**

The core arithmetic after reaching `X_0(35)` is:

```text
one rank-zero elliptic curve
+ one degree-2 quotient map
+ three fibers.
```

This is close in spirit to the `15/21` cases.

## New infrastructure actually required

There are two one-off algebraic bridges.

### Bridge A: division polynomial to rational isogeny

Formalize:

```text
rational X with psi_5(X)=0
  -> Galois-stable pair {Q,-Q}
  -> rational cyclic subgroup C5.
```

Together with the rational `C7`, construct `C35`.

This is elementary Galois/elliptic point arithmetic.

### Bridge B: moduli datum to the chosen `X_0(35)` model

Mathlib does not currently provide modular curves as moduli spaces. Therefore one must either:

1. extract an explicit rational map from the Kubert variables `(t,X)` to the Galbraith coordinates `(x,z)` and verify it by polynomial identities; or
2. package a fixed algebraic theorem identifying the cyclic-35-isogeny moduli curve with `C35`.

This map extraction is the main missing certificate. It is a one-curve elimination/q-expansion computation, not a Jacobian theory build.

## Recommended implementation order

```text
1. Land E7(t), b2,b4,b6,b8, D2, P3, P4, G35.
2. Prove G35=psi5 by ring.
3. Prove rational psi5 root -> rational C5.
4. Construct the rational C35 subgroup.
5. Land C35 and the explicit involution iota.
6. Prove the quotient quartic by field_simp/ring.
7. Prove the birational map from the quartic to E35.
8. Exhaust E35(Q) with the shared elliptic rank-zero toolkit.
9. Check the three fibers.
10. Add the explicit moduli bridge from step 4 to C35.
```

If the moduli bridge is available, 35 closes without any new higher-genus arithmetic infrastructure.

# 11. Final direct answers

## (1) What is `G35`?

It is

```text
G35(t,X)=D2(t,X)^2 P4(t,X)-P3(t,X)^3,
```

with the explicit coefficients given in Section 2. The exact rational-point lift additionally satisfies `Z^2=D2(t,X)`.

## (2) Is there a rank-zero elliptic quotient?

Yes. There is a degree-2 quotient

```text
X_0(35) -> E35,
E35: Y^2+Y=X^3+X^2+9X+1,
```

and `E35(Q)≅Z/3Z`.

The decomposition is

```text
J_0(35) ~ E35 x A35,
```

where `A35` is a rank-zero abelian surface with real multiplication by `Q(sqrt(17))`.

## (3) Is 35 a wall like 18?

No. Directly attacking `X_1(35)` would be a wall, but the rational 5-division root already descends the problem to `X_0(35)`, and `X_0(35)` has the explicit rank-zero elliptic quotient above.

## (4) Final classification

```text
35 is elementary/intermediate, not a Jacobian wall.
```

It needs one new explicit modular-bridge computation, but the point-exhaustion engine is the same rank-zero elliptic/descent machinery already needed for 15 and 21.
