# 3. `IsogenyData`: the explicit degree-three maps

Define

## 3.1 The forward map

For `u != 0`, define

\boxed{
\xi=\frac{C(u)}{u^2},
\qquad
\eta=\frac{A(u)w+B(u)}{u^3}.

\tag{phi}

```text
O       |-> O
(0,0)   |-> O
(0,-2)  |-> O.
```

In original `E0` coordinates, use `u=x-1` and `w=y+2x-2` in those formulas.

The exact denominator-cleared landing certificate is

\[
\begin{aligned}

&\qquad{}-C^3-30u^4C-26u^6\\
&=A^2\bigl(w^2-3uw+2w-u^3\bigr).
\end{aligned}
\tag{VELU}

This compiles as one `ring` proof.

A useful homogeneous tuple on the affine projective chart is obtained by putting

\[
\begin{aligned}
C_h&=U^3-6UZ^2+4Z^3,\\

[U:W:Z]\longmapsto

At the projective origin this tuple has a removable base point; define its value there to be `O`. At `U=0` and `Z=1`, the two affine kernel points both map to `[0:1:0]`.

The `xi`-map has numerator of degree `3`, denominator of degree `2`, and `C(0)=4`; hence it has degree `3`. In characteristic zero it is separable, so this is a degree-three isogeny.

# 6. Decidable local cube predicates

## 6.1 The inert prime over `2`

The completion has residue field

\[
\mathcal O_L/\mathfrak p_2\cong\mathbf F_8.
\]

The group `F_8^*` has order `7`, so cubing is bijective. The principal-unit group is pro-`2`, and `3` is a unit, so cubing is also an automorphism there. Thus

\[
\boxed{
x\in L_{\mathfrak p_2}^{\times3}
\iff v_2(x)\equiv0\pmod3.}
\]

A Lean predicate can therefore be only

```lean
def isCubeAt2 (x : L2ˣ) : Bool :=
  (Int.emod (v2 x) 3 == 0)
```

with no residue test.

## 6.2 The ramified prime over `3`

The uniformizer satisfies

\[
\pi^3+3\pi^2-3=0.
\]

Let

\[
R_5=\mathcal O_L/(\pi^5).
\]

Then

```text
#R5             = 3^5 = 243
#R5^*           = 2*3^4 = 162
#(R5^*)^3       = 6
#R5^*/(R5^*)^3  = 27.
```

Modulo `pi^5`,

\[
3\equiv\pi^3,
\qquad
3\pi\equiv\pi^4.
\]

Writing a principal unit as `1+t`, one obtains

\[
(1+t)^3\equiv1+c\pi^3+c\pi^4\pmod{\pi^5},
\]

where `c` is the coefficient of `pi` in `t` modulo `3`. Hence the complete list of unit cubes in `R5` is

\[
\boxed{
\left\{\varepsilon(1+c\pi^3+c\pi^4):
\varepsilon\in\{1,-1\},\ c\in\mathbf F_3\right\}.
}
\]

There are six entries, as required.

Moreover `U_5=(U_2)^3` by the `3`-adic logarithm: multiplication by `3` sends `pi^2 O` isomorphically onto `pi^5 O`. Therefore

\[
\boxed{
x\in L_{\mathfrak p_3}^{\times3}
\iff
v_\pi(x)\equiv0\pmod3
\text{ and }
\pi^{-v_\pi(x)}x\bmod\pi^5
\text{ lies in the six-element list}.}
\]

A directly executable predicate is:

```lean
def cubeResiduesPi5 : Finset R5 :=
  { 1,
    1 + pi^3 + pi^4,
    1 - pi^3 - pi^4,
    -1,
    -(1 + pi^3 + pi^4),
    -(1 - pi^3 - pi^4) }

def isCubeAt3 (x : L3ˣ) : Bool :=
  (Int.emod (vPi x) 3 == 0) &&
  (unitPartModPi5 x ∈ cubeResiduesPi5)
```

The actual quotient type and `unitPartModPi5` are arithmetic-infrastructure choices; the finite list is fixed.

\[

# 9. The weak descent

Let `P in E(L)`.

1. Its dual Kummer class is one of
   \[
   1,[2],[4].
   \]

2. Since
   \[
   \delta_{\widehat\phi}(T)=[4],
   \qquad
   \delta_{\widehat\phi}(-T)=[2],
   \]
   choose `n in {0,1,2}` such that
   \[
   \delta_{\widehat\phi}(P)=\delta_{\widehat\phi}(nT).
   \]

3. Kummer exactness gives
   \[
   P-nT=\widehat\phi(Q')
   \]
   for some `Q' in E'(L)`.

4. Since `Sel^phi` is trivial, the actual quotient
   \[
   E'(L)/\phi E(L)
   \]
   is trivial. Hence `Q'=phi(Q)`.

5. Therefore
   \[
   P=nT+\widehat\phi\phi(Q)
    =nT+3Q.
   \]

Thus

\[
\boxed{
E_0(L)=\langle T\rangle+3E_0(L).
}
\]

```lean
theorem weak_three_descent
    (I : IsogenyData (L := L) a)
    (D : KummerData (L := L) a I)
    (P : EPoint (L := L)) :
    ∃ n : Fin 3, ∃ Q : EPoint (L := L),
      P = n.val • T + 3 • Q := by
  have hpass := D.deltaDual_local P
  rcases passDual_iff _ |>.mp hpass with ⟨k, hk⟩
  obtain ⟨n, hn⟩ := dualLine_represented k
  have hdelta : D.deltaDual (P - n.val • T) = 0 := by
    rw [map_sub, D.deltaDual_T, hk, hn]
    abel
  obtain ⟨Q', hQ'⟩ := D.kernelDual.mp hdelta
  have hphi : D.deltaPhi Q' = 0 := passPhi_iff _ |>.mp (D.deltaPhi_local Q')
  obtain ⟨Q, hQ⟩ := D.kernelPhi.mp hphi
  refine ⟨n, Q, ?_⟩
  calc
    P = n.val • T + I.phihat Q' := by
      rw [hQ']
      abel
    _ = n.val • T + I.phihat (I.phi Q) := by rw [hQ]
    _ = n.val • T + 3 • Q := by rw [I.phihat_phi]
```
