# N18 Route C, Block 1: complete explicit quotient data

Let

\[
L=\mathbf Q(a),\qquad a^3=3a+1,
\]

and let

\[
C:\quad y^2=f(x),
\qquad
f(x)=x^6+4x^5+10x^4+10x^3+5x^2+2x+1.
\]

Put

\[
A=-a-1,\qquad q=a^2-1.
\]

The involutions are

\[
\sigma(x,y)=
\left(
 \frac{Ax-a}{x-A},
 \frac{q^3y}{(x-A)^3}
\right),
\qquad
h(x,y)=(x,-y),
\qquad
\tau=h\sigma.
\]

Everything below was checked exactly in the number field
\(\mathbf Q[a]/(a^3-3a-1)\). No numerical recognition is used.

# 0. Constants used throughout

Define the two fixed points of the Möbius transformation on the
\(x\)-line by

\[
r_+=A+q=a^2-a-2,
\qquad
r_-=A-q=-a^2-a.
\]

The basic identities are

\[
q^2=A^2-a=a^2+a+1,
\qquad
q^3=3a^2+3a,
\]

\[
r_++r_-=2A,\qquad r_+r_-=a,\qquad r_+-r_-=2q.
\]

Introduce

\[
\boxed{
\begin{aligned}
c_0&=84a^2-132a-48,\\
c_2&=420a^2+780a+240,\\
c_3&=1800a^2+3384a+960.
\end{aligned}}
\]

The products needed for the monic Weierstrass models are

\[
\boxed{
\begin{aligned}
d_+&=c_0c_3^2
   =15185664a^2+28539648a+8080128,\\
d_{-,4}&=c_0c_2
   =2880a^2-3600a-1440,\\
d_{-,6}&=c_3c_0^2
   =17280a^2-24192a-10368.
\end{aligned}}
\]

For `field_simp`, the following explicit inverse certificates are useful:

\[
q^{-1}=\frac{2a^2-a-4}{3},
\]

\[
c_0^{-1}=\frac{2a^2+5a+3}{12},
\qquad

\]

Equivalently, the denominator-free identities are

\[
q(2a^2-a-4)=3,
\]

\[
c_0(2a^2+5a+3)=12,
\qquad
c_3(6a^2-15a+7)=24.
\]

In particular, all of \(q,c_0,c_3\) are nonzero.

# 1. One Möbius coordinate handles both quotients

Define

\[
\boxed{
z=\frac{x-r_+}{x-r_-}.}
\]

The inverse formula is

\[
\boxed{
x=\frac{zr_--r_+}{z-1}.}
\]

The elementary identities

\[
\sigma_x-r_+
 =-\frac{q(x-r_+)}{x-A},
\qquad
\sigma_x-r_-
 = \frac{q(x-r_-)}{x-A}
\]

give

\[
\boxed{z\circ\sigma=-z.}
\]

Also

\[
x-A=-q\frac{z+1}{z-1},
\]

so

\[
\frac{q^3}{(x-A)^3}
 =-\frac{(z-1)^3}{(z+1)^3}.
\]

Now set

\[
\boxed{v=(z-1)^3y.}
\]

Then

\[
\sigma(z,v)=(-z,v),
\qquad
\tau(z,v)=(-z,-v).
\]

The central polynomial identity is

\[
\boxed{
(z-1)^6
 f\!\left(\frac{zr_--r_+}{z-1}\right)
 =c_3z^6+c_2z^4+c_0.
}
\tag{1}
\]

Consequently

\[
\boxed{v^2=c_3z^6+c_2z^4+c_0.}
\tag{2}
\]

Two useful evaluations are

\[
f(r_+)=c_0,
\qquad
f(r_-)=c_3.
\]

These also show directly that the projective quotient maps written below
have no base points.

# 2. The quotient by \(\sigma\)

## 2.1 Invariant generators and raw quotient equation

Put

\[
\boxed{u=z^2.}
\]

Since \(v\) is fixed by \(\sigma\), the fixed field is

\[
L(C)^{\langle\sigma\rangle}=L(u,v).
\]

Indeed,

\[
L(C)=L(z,v),
\qquad z^2=u,
\]

and the nontrivial element of this quadratic extension is exactly
\(z\mapsto-z\), namely \(\sigma\).

The affine quotient equation is

\[
\boxed{
v^2=c_3u^3+c_2u^2+c_0.
}
\tag{3}
\]

## 2.2 Monic Weierstrass model \(E_+\)

Set

\[
X_+=c_3u,
\qquad
Y_+=c_3v.
\]

Then the smooth projective quotient is the elliptic curve

\[
\boxed{
E_+:\quad
Y_+^2=X_+^3+c_2X_+^2+d_+.
}
\tag{4}
\]

In full coefficients,

\[
\boxed{
\begin{aligned}
Y_+^2={}&X_+^3
 +(420a^2+780a+240)X_+^2\\
&+15185664a^2+28539648a+8080128.
\end{aligned}}
\]

Its generalized Weierstrass coefficients are

```text
[0,
 420*a^2 + 780*a + 240,
 0,
 0,
 15185664*a^2 + 28539648*a + 8080128]
```

## 2.3 Explicit quotient map \(q_+:C\to E_+\)

On the affine chart \(x\ne r_-\),

\[
\boxed{
\begin{aligned}
X_+&=c_3\left(\frac{x-r_+}{x-r_-}\right)^2,\\[2mm]
Y_+&=-\frac{8c_3q^3y}{(x-r_-)^3}.
\end{aligned}}
\tag{5}
\]

Equivalently, using \(z\),

\[
X_+=c_3z^2,
\qquad
Y_+=c_3(z-1)^3y.
\]

### Global projective formula

Write the weighted projective model of \(C\) as

\[
Y_C^2=F_h(X_C,Z_C),
\qquad
x=X_C/Z_C,\quad y=Y_C/Z_C^3,
\]

and put

\[
D_+=X_C-r_+Z_C,
\qquad
D_-=X_C-r_-Z_C.
\]

For the ordinary projective Weierstrass coordinates
\([\mathcal X:\mathcal Y:\mathcal Z]\) on \(E_+\), formula (5) is

\[
\boxed{
q_+(X_C:Y_C:Z_C)
=
\bigl[
 c_3D_+^2D_-:
 -8c_3q^3Y_C:
 D_-^3
\bigr].
}
\tag{6}
\]

The three entries have the same weighted degree on \(C\). If \(D_-=0\),
then \(Y_C^2=c_3Z_C^6\ne0\), so the entries do not vanish
simultaneously. Thus (6) is a global morphism, not merely an affine
rational map.

## 2.4 Generic inverse / the two points in a fiber

Given an affine point \((X_+,Y_+)\in E_+(\overline L)\), put

\[
u=\frac{X_+}{c_3}.
\]

Choose either root \(z\) of

\[
z^2=u.
\]

Then

\[
\boxed{
\begin{aligned}
x&=\frac{zr_--r_+}{z-1},\\[2mm]
y&=\frac{Y_+}{c_3(z-1)^3}.
\end{aligned}}
\tag{7}
\]

The choices \(z\) and \(-z\) give the two points in the generic fiber,
and they are exchanged by \(\sigma\).

# 3. The quotient by \(\tau=h\sigma\)

## 3.1 Invariant generators and raw quotient equation

Because \(\tau(z,v)=(-z,-v)\), define

\[
\boxed{w=zv=z(z-1)^3y.}
\]

Then

\[
L(C)^{\langle\tau\rangle}=L(u,w),
\qquad u=z^2,
\]

and the affine quotient equation is

\[
\boxed{
w^2=u(c_3u^3+c_2u^2+c_0).
}
\tag{8}
\]

## 3.2 Monic Weierstrass model \(E_-\)

On \(u\ne0\), set

\[
X_-=\frac{c_0}{u},
\qquad
Y_-=\frac{c_0w}{u^2}.
\]

Then the smooth projective quotient is

\[
\boxed{
E_-:\quad
Y_-^2=X_-^3+d_{-,4}X_-+d_{-,6}.
}
\tag{9}
\]

In full coefficients,

\[
\boxed{
\begin{aligned}
Y_-^2={}&X_-^3
 +(2880a^2-3600a-1440)X_-\\
&+17280a^2-24192a-10368.
\end{aligned}}
\]

Its generalized Weierstrass coefficients are

```text
[0,
 0,
 0,
 2880*a^2 - 3600*a - 1440,
 17280*a^2 - 24192*a - 10368]
```

## 3.3 Explicit quotient map \(q_-:C\to E_-\)

On the affine chart \(x\ne r_+\),

\[
\boxed{
\begin{aligned}
X_-&=c_0\left(\frac{x-r_-}{x-r_+}\right)^2,\\[2mm]
Y_-&=-\frac{8c_0q^3y}{(x-r_+)^3}.
\end{aligned}}
\tag{10}
\]

Equivalently,

\[
X_-=\frac{c_0}{z^2},
\qquad
Y_-=\frac{c_0(z-1)^3y}{z^3}.
\]

### Global projective formula

With \(D_\pm\) as above,

\[
\boxed{
q_-(X_C:Y_C:Z_C)
=
\bigl[
 c_0D_-^2D_+:
 -8c_0q^3Y_C:
 D_+^3
\bigr].
}
\tag{11}
\]

If \(D_+=0\), then \(Y_C^2=c_0Z_C^6\ne0\), so again there is no
common zero. Hence (11) is a global morphism.

## 3.4 Generic inverse / the two points in a fiber

Given an affine point \((X_-,Y_-)\), put

\[
u=\frac{c_0}{X_-}.
\]

Choose a root \(z\) of \(z^2=u\). Then

\[
\boxed{
\begin{aligned}
x&=\frac{zr_--r_+}{z-1},\\[2mm]
y&=\frac{Y_-z^3}{c_0(z-1)^3}.
\end{aligned}}
\tag{12}
\]

The choices \(z\) and \(-z\) are exchanged by \(\tau\).

# 7. What is literally `field_simp` + `ring_nf`?

## 7.1 Pure rational-function identities

Each of the following is a rational-function identity whose coefficient
reduction uses only

\[
a^3=3a+1.
\]

1. The involution-preservation identity
   \[
   (x-A)^6
   f\!\left(\frac{Ax-a}{x-A}\right)
   =q^6f(x).
   \]
2. The formula \(\sigma^2=1\), using
   \[
   \sigma_x-A=\frac{q^2}{x-A}.
   \]
3. The identities \(z\circ\sigma=-z\),
   \(\sigma(v)=v\), and \(\tau(v)=-v\).
4. The transformed sextic identity (1).
5. The quotient equations (3) and (8).
6. The monic Weierstrass equations (4) and (9).
7. The affine quotient-map equations (5) and (10), or their projective
   versions (6) and (11).
8. The isomorphism formulas (14)--(15) and (18)--(19), including both
   inverse-composition checks.
9. The direct formulas (16), (20), and (21).
10. The fact that (22)--(23) lands on \(\widehat E_0\).

On affine charts, `field_simp` needs the displayed denominator
hypotheses such as \(x\ne r_-\), \(x\ne r_+\), or \(u\ne0\). The
projective formulas (6) and (11) eliminate these chart hypotheses.

## 7.2 Facts that are not merely one ring normalization

Three small structural statements require more than `ring_nf`, although
none requires analytic or Jacobian machinery.

### A. Fixed-field / quotient identification

To conclude that the invariant functions actually generate the quotient
function field, use

\[
L(C)=L(z,v),\qquad z^2=u,
\]

for \(\sigma\), and

\[
L(C)=L(z,w),\qquad z^2=u,\qquad v=w/z,
\]

for \(\tau\). This is an elementary degree-two function-field argument.
The recovery formulas (7) and (12) provide the needed inverse explicitly.

### B. Extension over the omitted affine points

This is automatic from the denominator-free projective formulas (6) and
(11). Checking that their entries never vanish simultaneously uses
\(f(r_+)=c_0\ne0\) and \(f(r_-)=c_3\ne0\), together with the explicit
inverse certificates for \(c_0,c_3\).

### C. Calling \(162b2\) the 3-isogenous companion

Equation compatibility of (22)--(23) is a ring identity. The statement
that it is a degree-3 isogeny with the stated kernel uses the elementary
elliptic-curve group law, or a pre-existing Vélu-isogeny theorem.

No identity in Sections 1--5 requires a second algebraic relation for
\(a\), a square root, a unit computation, a class-group computation, or
an analytic input.
