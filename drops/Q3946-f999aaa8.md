# Q3946: FLT Lean 4 cyclic order 14 Kubert bridge

## Setup and normalization

Use the order-7 parameter

\[
t = \frac{d+1}{2}.
\]

Then the stated parametrization is the usual Kubert order-7 form

\[
c = \frac{d^2-1}{4} = t(t-1), \qquad
b = \frac{(d-1)(d+1)^2}{8} = t^2(t-1).
\]

After this substitution, the 2-division cubic is

\[
T_t(X) = 4X^3
 + (t^4 - 6t^3 + 3t^2 + 2t + 1)X^2
 + 2t^2(t-1)(t^2-t-1)X
 + t^4(t-1)^2.
\]

Equivalently, directly in `d`,

\[
T_d(X)=4X^3
+ \frac{d^4-8d^3-18d^2+8d+33}{16}X^2
+ \frac{(d-1)(d+1)^2(d^2-5)}{16}X
+ \frac{(d-1)^2(d+1)^4}{64}.
\]

## 1. Discriminant

With the standard cubic discriminant convention for the polynomial exactly as written above,

\[
\operatorname{Disc}_X(T_t)
= 16\,t^7(t-1)^7(t^3 - 8t^2 + 5t + 1).
\]

In the original `d` parameter this is

\[
\operatorname{Disc}_X(T_d)
= \frac{(d-1)^7(d+1)^7(d^3 - 13d^2 - 9d + 13)}{8192}.
\]

Since `(d-1)^7(d+1)^7 = (d^2-1)^7`, the same answer can also be written as

\[
\operatorname{Disc}_X(T_d)
= \frac{(d^2-1)^7(d^3 - 13d^2 - 9d + 13)}{2^{13}}.
\]

If instead one clears denominators first, for example by using `64*T_d`, then the discriminant is multiplied by `64^4`, a rational square. Thus the odd square-class factor is unchanged.

## 2. Factored form

The factored forms are therefore:

\[
\boxed{\operatorname{Disc}_X(T_t)
= 16\,t^7(t-1)^7(t^3 - 8t^2 + 5t + 1)}
\]

and

\[
\boxed{\operatorname{Disc}_X(T_d)
= \frac{(d-1)^7(d+1)^7(d^3 - 13d^2 - 9d + 13)}{8192}}.
\]

A direct Sage check is:

```sage
from sage.all import QQ, PolynomialRing, factor

R = PolynomialRing(QQ, names=("d", "X"))
d, X = R.gens()

c = (d**2 - 1) / 4
b = (d - 1) * (d + 1)**2 / 8

T = 4*X**3 + ((1 - c)**2 - 4*b)*X**2 + 2*b*(c - 1)*X + b**2
Delta = T.discriminant(X)

print(factor(Delta))
# (1/8192) * (d - 1)^7 * (d + 1)^7 * (d^3 - 13*d^2 - 9*d + 13)
```

The corresponding `t` check is:

```sage
from sage.all import QQ, PolynomialRing, factor

S = PolynomialRing(QQ, names=("t", "X"))
t, X = S.gens()

b = t**2 * (t - 1)
c = t * (t - 1)

T = 4*X**3 + ((1 - c)**2 - 4*b)*X**2 + 2*b*(c - 1)*X + b**2
Delta = T.discriminant(X)

print(factor(Delta))
# 16 * t^7 * (t - 1)^7 * (t^3 - 8*t^2 + 5*t + 1)
```

## 3. The square-discriminant curve is not Cremona 96A1

Assume `b != 0`. In the `t` coordinate this excludes `t = 0` and `t = 1`; in the `d` coordinate it excludes `d = -1` and `d = 1`.

Removing the visible square factor from the discriminant gives

\[
\operatorname{Disc}_X(T_t)
= \bigl(4t^3(t-1)^3\bigr)^2\,
 t(t-1)(t^3 - 8t^2 + 5t + 1).
\]

Thus the condition that the discriminant be a rational square is equivalent, away from `t = 0,1`, to the genus-2 hyperelliptic curve

\[
\eta^2 = t(t-1)(t^3 - 8t^2 + 5t + 1).
\]

In the `d` coordinate, one exact equivalent model is

\[
Y^2 = 2(d^2-1)(d^3 - 13d^2 - 9d + 13).
\]

The right-hand side has degree `5` and is squarefree: the cubic factor has discriminant `49^2`, and it does not vanish at `t=0` or `t=1`. Therefore the smooth projective model has genus

\[
\left\lfloor \frac{5-1}{2} \right\rfloor = 2.
\]

So this square-discriminant curve cannot be birationally equivalent to

\[
w^2 = u^3 + u^2 - 2u,
\]

because that curve is elliptic, hence genus `1`. Genus is a birational invariant over any field extension, so the obstruction is decisive.

## Consequence for the Lean bridge

The discriminant-square condition is the wrong replacement for the hypothesis

\[
\exists X \in \mathbb Q,\quad T_2(b,c,X)=0.
\]

For a cubic over `Q`, having one rational root is not equivalent to having square discriminant. Square discriminant says that the splitting field has even Galois group; if the cubic is irreducible, it describes cyclic cubic specializations, not rational-root specializations. If the cubic has one rational root, the discriminant is square only when the remaining quadratic factor also splits.

Therefore the intended order-14 Kubert bridge should keep the rational root `X` and work with the full curve

\[
T_t(X)=0,
\]

not with the auxiliary square-discriminant curve. The computation above shows exactly why the discriminant route leads to a genus-2 curve rather than to the Cremona `96A1` obstruction curve.
