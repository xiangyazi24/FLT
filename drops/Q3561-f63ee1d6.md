# Q3561: proving `rightIntegrand_integrableOn_Ioi_root`

## Robust decomposition

Use two cuts:

```lean
a := e + δ / 2
R := max a (tailThreshold A B)
```

where `δ` comes from `rightIntegrand_integrableOn_near_root`. Then prove:

1. near root: `IntegrableOn f (Ioo e (e + δ))` from the existing theorem;
2. middle: `IntegrableOn f (Ioc a R)` by finite-interval integrability on the right component;
3. tail: `IntegrableOn f (Ioi R)` from `rightIntegrand_integrableOn_Ioi_of_tailThreshold_le`;
4. combine middle + tail to get `IntegrableOn f (Ioi a)` using `Ioc a R ∪ Ioi R = Ioi a` or just `mono_set`;
5. combine near + right tail and use `Ioi e ⊆ Ioo e (e + δ) ∪ Ioi a`.

The important API choice is `Ioc a R` for the middle piece. This includes the cut point `R`, so no singleton/a.e. cleanup is needed when joining with `Ioi R`.

## Main code

```lean
import Mathlib.Analysis.SpecialFunctions.ImproperIntegrals
import FLT.Assumptions.MazurProof.RealTopologyS4

noncomputable section
open Set MeasureTheory
open scoped Topology

namespace MazurProof.RealTopology

theorem rightIntegrand_integrableOn_Ioi_root
    {A B e : ℝ}
    (hroot : shortCubic A B e = 0)
    (hderiv : 0 < shortCubicDeriv A B e)
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x) :
    IntegrableOn (rightIntegrand A B) (Ioi e) := by
  classical
  rcases rightIntegrand_integrableOn_near_root
      (A := A) (B := B) (e := e) hroot hderiv with
    ⟨δ, hδ, hnear⟩

  let a : ℝ := e + δ / 2
  have ha_def : a = e + δ / 2 := rfl
  have he_lt_a : e < a := by
    rw [ha_def]
    linarith
  have ha_lt_eδ : a < e + δ := by
    rw [ha_def]
    linarith

  let R : ℝ := max a (tailThreshold A B)
  have hRge_a : a ≤ R := by
    dsimp [R]
    exact le_max_left _ _
  have hRge_tail : tailThreshold A B ≤ R := by
    dsimp [R]
    exact le_max_right _ _

  have htail : IntegrableOn (rightIntegrand A B) (Ioi R) :=
    rightIntegrand_integrableOn_Ioi_of_tailThreshold_le
      (A := A) (B := B) hRge_tail

  have hmid_interval :
      IntervalIntegrable (rightIntegrand A B) volume a R :=
    rightIntegrand_intervalIntegrable_of_right_of_le
      (A := A) (B := B) (e := e) hposRight (show e ≤ a from he_lt_a.le)

  have hmid : IntegrableOn (rightIntegrand A B) (Ioc a R) :=
    (intervalIntegrable_iff_integrableOn_Ioc_of_le
      (f := rightIntegrand A B) (μ := volume) hRge_a).mp hmid_interval

  have hright_union :
      IntegrableOn (rightIntegrand A B) (Ioc a R ∪ Ioi R) :=
    hmid.union htail

  have hright : IntegrableOn (rightIntegrand A B) (Ioi a) := by
    refine hright_union.mono_set ?_
    intro x hx
    by_cases hxR : x ≤ R
    · exact Or.inl ⟨hx, hxR⟩
    · exact Or.inr (lt_of_not_ge hxR)

  have hall_union :
      IntegrableOn (rightIntegrand A B) (Ioo e (e + δ) ∪ Ioi a) :=
    hnear.union hright

  refine hall_union.mono_set ?_
  intro x hx
  by_cases hxa : x ≤ a
  · exact Or.inl ⟨hx, lt_of_le_of_lt hxa ha_lt_eδ⟩
  · exact Or.inr (lt_of_not_ge hxa)

end MazurProof.RealTopology
```

## APIs used

The combining APIs are exactly:

```lean
#check IntegrableOn.union
#check IntegrableOn.mono_set
#check intervalIntegrable_iff_integrableOn_Ioc_of_le
#check IntervalIntegrable.mono_set
```

The finite-interval conversion used above is:

```lean
(intervalIntegrable_iff_integrableOn_Ioc_of_le
  (f := rightIntegrand A B) (μ := volume) hRge_a).mp hmid_interval
```

This is preferable to converting to `Ioo`, because `Ioc a R ∪ Ioi R = Ioi a` extensionally. With `Ioo a R`, the point `R` would be missing and you would need an a.e. equality or a singleton-integrability patch.

## Fallback: derive the middle interval from continuity

If the interval-integrability lemma is inconvenient to elaborate, derive it directly from `rightIntegrand_continuousOn_Ioi_of_right`:

```lean
  have hcont_Icc : ContinuousOn (rightIntegrand A B) (Icc a R) := by
    refine (rightIntegrand_continuousOn_Ioi_of_right
      (A := A) (B := B) (e := e) hposRight).mono ?_
    intro x hx
    exact he_lt_a.trans_le hx.1

  have hmid_interval :
      IntervalIntegrable (rightIntegrand A B) volume a R :=
    ContinuousOn.intervalIntegrable_of_Icc hRge_a hcont_Icc
```

Then keep the same `intervalIntegrable_iff_integrableOn_Ioc_of_le` conversion and union proof.

## Optional exact set equalities

The proof above uses `mono_set`, which is usually less brittle than rewriting sets. If you prefer exact set rewrites, these two extensional equalities are the relevant ones:

```lean
lemma Ioc_union_Ioi_eq_Ioi_of_le {a R : ℝ} (hR : a ≤ R) :
    Ioc a R ∪ Ioi R = Ioi a := by
  ext x
  constructor
  · rintro (hx | hx)
    · exact hx.1
    · exact lt_of_le_of_lt hR hx
  · intro hx
    by_cases hxR : x ≤ R
    · exact Or.inl ⟨hx, hxR⟩
    · exact Or.inr (lt_of_not_ge hxR)

lemma Ioi_subset_near_union_right
    {e δ a : ℝ} (ha : a < e + δ) :
    Ioi e ⊆ Ioo e (e + δ) ∪ Ioi a := by
  intro x hx
  by_cases hxa : x ≤ a
  · exact Or.inl ⟨hx, lt_of_le_of_lt hxa ha⟩
  · exact Or.inr (lt_of_not_ge hxa)
```

Those are not necessary for the theorem, but they are useful if the final proof becomes hard to read.
