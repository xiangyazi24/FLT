# Fixed-instance Jacobian arithmetic for \(X_1(18)\)

## Executive decision

For this project, the smallest **foundational** construction is still a fixed-instance balanced-Mumford/Cantor implementation.  It should be specialized to this one sextic and should prove its group laws by transport from a semantic divisor-class model; it should **not** try to prove associativity by expanding the Cantor formulas.

A 21-element lookup group is much smaller **after** rank zero and the torsion theorem are already available, and it is ideal for the final cusp enumeration.  It cannot replace the foundational Jacobian group used by the 2-descent and the 2-adic argument.  Doing so is circular:

```text
2-descent needs J(Q), subtraction, doubling, and the quotient J(Q)/2J(Q)
    ↓
rank zero
    ↓
J(Q) = J(Q)_tors ≅ Z/21
    ↓
only now can the 21-element table be proved exhaustive.
```

Defining a standalone `ZMod 21` and checking its addition table proves only that `ZMod 21` is a group.  The hard bridge is a bijection with the actual divisor classes; proving that bridge already requires the Jacobian arithmetic and the rank-zero/torsion results.

The recommended hybrid is therefore:

1. build a minimal fixed balanced-Mumford Jacobian sufficient for descent, localization, and Abel–Jacobi;
2. prove rank zero and torsion order 21;
3. thereafter replace almost all computation by a certified equivalence
   `N18Jac ≃+ ZMod 21` and a 21-row table.

The single hard foundational theorem is the fixed-curve **balanced normal-form theorem plus correctness of composition/reduction**.  All group axioms then follow in about 50 lines by injectivity of the semantic interpretation.

# 0. Important even-degree correction

The curve has no rational Weierstrass point, but because the sextic is monic it has two rational points at infinity, denoted

```text
∞⁺, ∞⁻,
```

which are exchanged by the hyperelliptic involution.  They are not Weierstrass points.

For genus \(g=2\), fix

```text
D∞ = ∞⁺ + ∞⁻.
```

The authoritative balanced normal form is a triple `(u,v,n)` with

```text
u monic,
deg u ≤ 2,
deg v < deg u,
u ∣ f - v²,
0 ≤ n ≤ 2 - deg u.
```

It represents

\[
  \operatorname{div}[u,v]
  + n\infty^+
  + (2-\deg u-n)\infty^-
  - (\infty^+ + \infty^-).
\]

Thus:

```text
zero       = (1, 0, 1)
negative   = (u, -v, 2 - deg(u) - n).
```

In particular, `(1,0,0)` is the class `∞⁻-∞⁺`, not the identity.  This is the main bookkeeping point that must be correct before implementing the even-degree algorithm.

This is the specialization to \(g=2\) of the balanced divisor representation in Proposition 2.4 and §3 of Sutherland, *Fast Jacobian arithmetic for hyperelliptic curves of genus 3*, arXiv:1607.08602, which in turn uses the Galbraith–Harrison–Mireles Morales balanced representation.

# 1. Fixed polynomial and its unusually useful square approximation

For this curve define

\[
 f=x^6+4x^5+10x^4+10x^3+5x^2+2x+1.
\]

The balanced algorithm precomputes the unique monic cubic \(V\) such that
`degree (f - V^2) ≤ 2`.  Here it is exceptionally simple:

\[
 V=x^3+2x^2+3x-1,
 \qquad
 f-V^2=8x.
\]

This should be banked immediately.  It makes all infinity-adjustment certificates much smaller than for a generic sextic.

The corresponding principal-divisor identities are

\[
 \operatorname{div}(y-V)
   =(0,-1)+2\infty^+-3\infty^-,
\]

\[
 \operatorname{div}(y+V)
   =(0,1)+2\infty^--3\infty^+.
\]

The polynomial part is just `(y-V)(y+V)=8x`; the orders at infinity are fixed local-coordinate calculations.  These two identities are the fixed N18 replacement for a general-purpose “infrastructure adjustment” library.

# 2. Minimal representation

Use a raw data structure plus a validity predicate.  This is more convenient than storing proofs in every intermediate object, because composition first produces a semireduced object of degree at most four.

Use `Polynomial.degree`, not `natDegree`, for `deg v < deg u`: the zero polynomial has degree `⊥`, so `(u,v)=(1,0)` satisfies the condition without a special case.

```lean
namespace N18Jac

open Polynomial

structure RawRep where
  u : QX
  v : QX
  n : ℕ
  deriving DecidableEq

/-- Balanced reduced Mumford validity for genus 2. -/
def RawRep.Valid (D : RawRep) : Prop :=
  D.u.Monic ∧
  D.u.natDegree ≤ 2 ∧
  D.v.degree < D.u.degree ∧
  D.u ∣ f - D.v^2 ∧
  D.u.natDegree + D.n ≤ 2

abbrev Rep := {D : RawRep // D.Valid}

/-- Intermediate output of composition, represented relative to `2*D∞`. -/
def RawRep.SemiValid (D : RawRep) : Prop :=
  D.u.Monic ∧
  D.u.natDegree ≤ 4 ∧
  D.v.degree < D.u.degree ∧
  D.u ∣ f - D.v^2 ∧
  D.u.natDegree + D.n ≤ 4

abbrev SemiRep := {D : RawRep // D.SemiValid}

@[ext]
lemma Rep.ext {D E : Rep}
    (hu : D.1.u = E.1.u) (hv : D.1.v = E.1.v) (hn : D.1.n = E.1.n) :
    D = E := by
  apply Subtype.ext
  cases D with
  | mk D hD =>
    cases E with
    | mk E hE =>
      simp only at hu hv hn
      cases D
      cases E
      simp_all

private def zeroRaw : RawRep :=
  { u := 1, v := 0, n := 1 }

private lemma zeroRaw_valid : zeroRaw.Valid := by
  constructor
  · simp [zeroRaw]
  constructor
  · norm_num [zeroRaw]
  constructor
  · simp [zeroRaw]
  constructor
  · simp [zeroRaw]
  · norm_num [zeroRaw]

instance : Zero Rep := ⟨⟨zeroRaw, zeroRaw_valid⟩⟩

lemma zero_u : (0 : Rep).1.u = 1 := rfl
lemma zero_v : (0 : Rep).1.v = 0 := rfl
lemma zero_n : (0 : Rep).1.n = 1 := rfl

/-- Hyperelliptic involution, including the swap of the two infinity slots. -/
def negRaw (D : RawRep) : RawRep :=
  { u := D.u
    v := -D.v
    n := 2 - (D.u.natDegree + D.n) }

lemma negRaw_valid (D : Rep) : (negRaw D.1).Valid := by
  rcases D.2 with ⟨hu, hdeg, hvdeg, hdvd, hbal⟩
  refine ⟨hu, hdeg, ?_, ?_, ?_⟩
  · simpa [negRaw] using hvdeg
  · simpa [negRaw, sq] using hdvd
  · dsimp [negRaw]
    omega

def negRep (D : Rep) : Rep := ⟨negRaw D.1, negRaw_valid D⟩

instance : Neg Rep := ⟨negRep⟩

end N18Jac
```

The `negRaw_valid` proof may need `simpa [pow_two]` instead of `[sq]` depending on the local Mathlib revision; there is no mathematical difficulty.

## Semantic meaning

Do not encode divisors as fields of `RawRep`.  Keep the interpretation in one theorem-facing function:

```lean
/-- Intended meaning:
`div[u,v] + n∞⁺ + (2-deg u-n)∞⁻ - D∞`. -/
noncomputable def denote (D : Rep) : N18Pic0 := ...
```

This separation is essential: polynomial arithmetic remains computational, while the divisor/principal-divisor mathematics is isolated in one module.

# 3. Cantor composition

For two reduced triples

```text
D₁=(u₁,v₁,n₁),  D₂=(u₂,v₂,n₂),
```

compute the generalized Cantor gcd:

\[
 d_1=\gcd(u_1,u_2)=e_1u_1+e_2u_2,
\]

\[
 d=\gcd(d_1,v_1+v_2)=c_1d_1+c_2(v_1+v_2).
\]

Put

\[
 s_1=c_1e_1,
 \quad s_2=c_1e_2,
 \quad s_3=c_2,
\]

so

\[
 d=s_1u_1+s_2u_2+s_3(v_1+v_2).
\]

Then

\[
 u_3=\frac{u_1u_2}{d^2},
\]

\[
 v_3=\left(
 \frac{s_1u_1v_2+s_2u_2v_1+s_3(v_1v_2+f)}{d}
 \right)\bmod u_3,
\]

and

\[
 n_3=n_1+n_2+\deg d.
\]

The output is semireduced and satisfies

```text
deg u₃ + n₃ ≤ 4.
```

It represents the sum relative to `2*D∞`:

\[
 \operatorname{div}[u_3,v_3]
 +n_3\infty^+
 +(4-\deg u_3-n_3)\infty^-
 -2D_\infty.
\]

This is why the balance bound is 4 in `SemiValid`.

# 4. Fixed N18 balanced reduction

A generic balanced-reduction library is unnecessary.  After composition, only the finite states

```text
(deg u,n) =
(0,0..4), (1,0..3), (2,0..2), (3,0..1), (4,0)
```

can occur.  The output must be one of

```text
(0,0..2), (1,0..1), (2,0).
```

Implement reduction as a fixed finite-state program driven by principal-function certificates.

## 4.1 Affine reduction move

Choose a polynomial `w` congruent to `v` modulo `u`.  Set

\[
 q=\frac{f-w^2}{u},
 \qquad
 u'=\operatorname{monic}(q),
 \qquad
 v'=(-w)\bmod u'.
\]

The principal divisor of `y-w` proves that the old and new triples represent the same class after updating the infinity counter according to the pole orders of `y-w` at `∞⁺,∞⁻`.

For degrees three and four, the required choices are especially small:

```text
deg u = 3, n = 0: choose w = v - u  (leading coefficient -1)
deg u = 3, n = 1: choose w = v + u  (leading coefficient +1)
deg u = 4:        choose w = v
```

They force cancellation of the degree-six leading term in `f-w²` where needed, so the quotient has degree at most two.  If further leading coefficients cancel, the output degree drops and the infinity counter is determined from the actual pole orders; do not hardwire the generic degree-two outcome.

## 4.2 Infinity-balancing move

When `deg u ≤ 2` but `deg u+n>2`, or after a degree-drop leaves the infinity count on the wrong side, use the two fixed relations

```text
div(y-V) = (0,-1) + 2∞⁺ - 3∞⁻
div(y+V) = (0, 1) + 2∞⁻ - 3∞⁺.
```

Operationally this composes the affine part with `(X, -1)` or `(X, 1)` and shifts the infinity counter by one, then performs at most one affine reduction.  Because `f-V²=8X`, every polynomial identity in these adjustment branches is tiny.

## 4.3 Certificate-oriented Lean interface

Do not initially make reduction a large opaque recursive function.  Define the certificate relation first; then write the finite branch program that produces a certificate.

```lean
namespace N18Jac

/-- A certified principal move using the function `y-w`. -/
structure PrincipalMove (S : SemiRep) where
  w : QX
  congruent : S.1.u ∣ w - S.1.v

  q : QX
  quotient_eq : S.1.u * q = f - w^2

  u' : QX
  v' : QX
  n' : ℕ

  u'_monic : u'.Monic
  v'_reduced : v'.degree < u'.degree
  v'_congr : u' ∣ v' + w
  curve_dvd : u' ∣ f - v'^2
  balanced : u'.natDegree + n' ≤ 2

  /-- Pole-order bookkeeping at the two rational points at infinity. -/
  ordInfPlus : ℤ
  ordInfMinus : ℤ
  infinity_balance :
    -- A concrete integer equality determined by the divisor of `y-w`.
    Prop

  /-- This is proved once from `quotient_eq`, `v'_congr`, and the
  two infinity-order calculations. -/
  same_class :
    denoteSemi S = denoteRaw {u := u', v := v', n := n'}

/-- The fixed 15-branch N18 program. -/
noncomputable def reductionMove (S : SemiRep) : PrincipalMove S := by
  -- Branch on `S.1.u.natDegree` and `S.1.n`.
  -- Use `w=v`, `v+u`, `v-u`, or the fixed V-adjustment.
  -- Each branch is polynomial `ring`, exact division, and degree arithmetic.
  sorry

noncomputable def reduce (S : SemiRep) : Rep :=
  let M := reductionMove S
  ⟨{u := M.u', v := M.v', n := M.n'},
    M.u'_monic,
    by omega,
    M.v'_reduced,
    M.curve_dvd,
    M.balanced⟩

noncomputable def addRep (D E : Rep) : Rep :=
  reduce (compose D E)

end N18Jac
```

For the actual implementation, replace the placeholder `infinity_balance : Prop` by the exact equality of coefficients of `∞⁺` and `∞⁻` in the two divisors.  Keeping it abstract in the first compile pass is useful because it cleanly identifies the only part not discharged by polynomial arithmetic.

## Why this is smaller than general Cantor arithmetic

The generic balanced algorithm handles arbitrary genus, arbitrary `f`, arbitrary support at infinity, and repeated reduction.  N18 needs:

- genus exactly two;
- a composition output of degree at most four;
- 15 possible `(degree,n)` states;
- the exceptionally short identity `f-V²=8X`;
- two fixed rational points `(0,±1)` for infinity adjustment.

This supports a finite branch proof rather than a reusable infrastructure implementation.

# 5. How to prove `AddCommGroup`

## Do not prove associativity by expanding formulas

A direct goal

```lean
addRep (addRep A B) C = addRep A (addRep B C)
```

would expand two gcd computations, several exact quotients, and the 15-way reduction on both sides.  This is the wrong proof architecture even for a fixed curve.

Instead prove a semantic normal-form theorem and transport the already-known divisor-class group law.

The required semantic API is only:

```lean
class N18Pic0 where ...
instance : AddCommGroup N18Pic0

denote : Rep → N18Pic0
balanced_normal_form : Function.Bijective denote
compose_reduce_sound :
  denote (addRep D E) = denote D + denote E
neg_sound : denote (-D) = -denote D
zero_sound : denote 0 = 0
```

Then every group axiom is one line after applying injectivity of `denote`.

## Minimal transport skeleton

```lean
namespace N18Jac

and principal divisors.  It need not be a general Picard-group library. -/

  sorry

theorem denote_bijective : Function.Bijective denote := by
  sorry

/-- Hard fixed theorem: the 15-branch program computes the sum class. -/
theorem denote_addRep (D E : Rep) :
    denote (addRep D E) = denote D + denote E := by
  -- composition soundness + `PrincipalMove.same_class`
  sorry

/-- Small once the hyperelliptic involution divisor identity is available. -/
theorem denote_negRep (D : Rep) :
    denote (-D) = -denote D := by
  sorry

lemma denote_zero : denote (0 : Rep) = 0 := by
  sorry

noncomputable def denoteEquiv : Rep ≃ N18Pic0 :=
  Equiv.ofBijective denote denote_bijective

noncomputable instance : Add Rep := ⟨addRep⟩

/-- The group laws are transported by `denote`; no Cantor-formula
associativity expansion occurs. -/
noncomputable instance instAddCommGroupRep : AddCommGroup Rep where
  add := addRep
  add_assoc := by
    intro A B C
    apply denote_bijective.1
    simp only [denote_addRep, add_assoc]
  zero := 0
  zero_add := by
    intro A
    apply denote_bijective.1
    simp only [denote_addRep, denote_zero, zero_add]
  add_zero := by
    intro A
    apply denote_bijective.1
    simp only [denote_addRep, denote_zero, add_zero]
  neg := negRep
  neg_add_cancel := by
    intro A
    apply denote_bijective.1
    simp only [denote_addRep, denote_negRep, denote_zero, neg_add_cancel]
  add_comm := by
    intro A B
    apply denote_bijective.1
    simp only [denote_addRep, add_comm]
  nsmul := nsmulRec
  nsmul_zero := by intro; rfl
  nsmul_succ := by intro; rfl

  zsmul_succ' := by intro; rfl
  zsmul_neg' := by intro; rfl

```

The exact fields requested by `AddCommGroup` can change slightly with the Mathlib revision.  A more robust local implementation can first transport `Add`, `Zero`, and `Neg` along `denoteEquiv`, then invoke Mathlib's typeclass-transport helper.  The proof principle is unchanged.

## What the semantic layer really costs

There is no existing Mathlib genus-2 divisor/Picard infrastructure.  The fixed semantic layer must establish:

1. the divisor of `x-a` and of `y-w(x)` on this sextic;
2. soundness of the Mumford affine divisor encoded by `(u,v)`;
3. the two infinity valuations;
4. existence and uniqueness of the genus-two balanced normal form;
5. composition and reduction preserve divisor class.

This is the genuine mathematical core.  Hiding it in a field called `same_class` is acceptable during module staging, but it cannot remain an axiom in the final development.

A reasonable size estimate is:

| Layer | Fixed-instance Lean size |
|---|---:|
| polynomial and degree certificates | 200–400 lines |
| raw/reduced/semireduced structures | 200–350 lines |
| xgcd composition executor | 600–1,000 lines |
| 15-case N18 reduction executor | 800–1,500 lines |
| divisor semantics and normal-form correctness | 2,500–5,000 lines |
| final `AddCommGroup` transport | 50–150 lines |

The last line is easy; the semantic normal-form theorem is the hard part.

# 6. Can a 21-element table replace all of this?

## 6.1 What is genuinely trivial

Once a bijection with `ZMod 21` has been proved, the computational group is immediate:

```lean
abbrev N18TableGroup := ZMod 21
```

There is no reason to hand-write a 21-by-21 addition table: the existing `ZMod 21` addition is the table.  A 21-row representative list is enough.

```lean
namespace N18Jac

abbrev Index := ZMod 21

/-- Filled after the generator and its first 20 multiples have been computed. -/
def rep21 : Index → Rep := by
  intro i
  -- finite lookup table of explicit `(u,v,n)` triples
  exact 0   -- placeholder

structure TableCertificate where
  rep : Index → Rep
  rep_zero : rep 0 = 0
  rep_add : ∀ i j, rep (i + j) = rep i + rep j
  injective : Function.Injective rep
  surjective : Function.Surjective rep

noncomputable def tableEquiv (C : TableCertificate) : Index ≃+ Rep where
  toFun := C.rep
  invFun := Function.invFun C.rep
  left_inv := Function.leftInverse_invFun C.injective
  right_inv := Function.rightInverse_invFun C.surjective
  map_add' := C.rep_add

end N18Jac
```

For explicit entries, `rep_add` can be reduced to 441 equalities and checked with `native_decide` **after** the addition on `Rep` exists and every row has been normalized.

## 6.2 What is not trivial

The field

```lean
surjective : Function.Surjective rep
```

means

```text
every rational balanced Mumford triple is one of these 21 rows.
```

This is exactly the global exhaustiveness theorem.  It cannot be proved by `native_decide`, because the coefficients of `u` and `v` range over `ℚ`, an infinite type.  Rank zero and a torsion certificate are what prove it.

Likewise, replacing `Rep` by `ZMod 21` at the start leaves an unproved bridge

```lean
actual divisor classes of C over Q  ≃+  ZMod 21.
```

That bridge is not a definition; it is the theorem being sought.

## 6.3 Circularity with the descent proof

The fixed 2-descent uses:

```text
P - Q
2 • P
J(Q)/2J(Q)
the Kummer homomorphism δ
localization J(Q) → J(Q₂).
```

All of these require an actual group law on rational divisor classes before rank zero is known.  A table whose exhaustiveness is justified by rank zero therefore cannot supply that law.

The only way to use the table foundationally would be to assume that the 21 rows are all of `J(Q)`.  That assumption is stronger than the desired rank-zero theorem and is precisely the bare arithmetic axiom the project is trying to avoid.

```text
→ composition/reduction soundness
→ AddCommGroup
→ 2-descent and local separatedness.
```

The 21-element table is off the critical path until after rank zero.

---

# 8. Ruthless minimum

The minimum new genus-two infrastructure is **not** “all of Cantor arithmetic in general.”  It is exactly:

1. one fixed reduced triple type with the correct even-degree infinity counter;
2. one fixed xgcd composition program;
3. one 15-branch reduction program using `V` and `(0,±1)`;
4. one fixed semantic theorem saying these triples are unique normal forms for rational divisor classes and the program respects addition;
5. transport of the group structure.

Do not build:

- schemes or a general Jacobian variety;
- a general Picard functor;
- arbitrary genus Cantor arithmetic;
- arbitrary number-field base change;
- a generic real-hyperelliptic infrastructure;
- a hand-written 21-by-21 group table.

Do build the 21-row table later, because it will make the final Abel–Jacobi/cusp proof almost entirely `native_decide` and `norm_num`.

# Bottom line

For foundational use, **fixed balanced Cantor is smaller than the finite-table proposal once the cost of proving exhaustiveness is counted**.  The finite table saves no hard theorem and introduces a circular dependency with rank zero.

The practical plan is a hybrid:

```text
small fixed balanced Jacobian for the proof of rank zero;
ZMod 21 table for every computation after rank zero.
```

The representation should use `n : ℕ` with `deg u+n≤2`, the identity `(1,0,1)`, and inverse counter `2-deg u-n`.  The special identity

```text
f = (x^3+2x^2+3x-1)^2 + 8x
```

is the main curve-specific simplification and should be exploited aggressively in the 15-case balanced-reduction module.
