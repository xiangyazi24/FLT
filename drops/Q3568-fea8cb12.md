# Q3568: S5 `thetaCandidate` into `AddCircle`

## Verdict

Define a real-valued representative first, then coerce it into `AddCircle`. Use the half-open fundamental domain

```lean
Set.Ioc (-(halfPeriod A B e)) (halfPeriod A B e)
```

for the period

```lean
(2 : ℝ) * halfPeriod A B e
```

because your branch convention gives representatives in exactly that interval:

* `O ↦ 0`, inside `(-T,T]`;
* root point `x = e, y = 0 ↦ T`, included by `Ioc`;
* lower branch `y < 0 ↦ sigma x`, in `(0,T)`;
* upper branch `0 ≤ y ↦ -sigma x`, in `(-T,0)`.

This avoids normalizing upper-branch values to `2*T - sigma x` and makes `AddCircle` injectivity reduce to raw real-coordinate equality using `AddCircle.coe_eq_coe_iff_of_mem_Ioc`.

## Definitions

Prefer defining on the point first, then restricting to the component kernel. This gives clean branch simplification lemmas that are not polluted by subtype proofs.

```lean
import Mathlib.Topology.Instances.AddCircle.Defs
import FLT.Assumptions.MazurProof.RealTopologyS5

noncomputable section
open Set
open scoped Topology

namespace MazurProof.RealTopology

abbrev thetaPeriod (A B e : ℝ) : ℝ :=
  (2 : ℝ) * halfPeriod A B e

/-- Raw real representative for the theta coordinate. This is not additive yet. -/
def thetaCoordPoint (A B e : ℝ) : Point (shortW A B) → ℝ
  | 0 => 0
  | Point.some x y h =>
      if x = e then
        halfPeriod A B e
      else if y < 0 then
        sigma A B x
      else
        - sigma A B x

/-- Raw representative restricted to the kernel of the S3 component map. -/
def thetaCoord
    {A B e : ℝ}
    (hroot : shortCubic A B e = 0)
    (hderiv : 0 < shortCubicDeriv A B e)
    (P : ComponentKer (A := A) (B := B) (e := e) hroot hderiv) : ℝ :=
  thetaCoordPoint A B e P.1

/-- Non-additive theta candidate. Additivity is a later Abel theorem. -/
def thetaCandidate
    {A B e : ℝ}
    (hroot : shortCubic A B e = 0)
    (hderiv : 0 < shortCubicDeriv A B e) :
    ComponentKer (A := A) (B := B) (e := e) hroot hderiv →
      AddCircle (thetaPeriod A B e) :=
  fun P => (thetaCoord hroot hderiv P : AddCircle (thetaPeriod A B e))

end MazurProof.RealTopology
```

If the zero constructor is not syntactically `0`, replace the first branch by the actual constructor used in S3/S5, for example `Point.zero` or `Point.infty`. The rest of the API is unchanged.

## Branch simplification lemmas

First prove the point-level simp lemmas. These should be mostly `simp [thetaCoordPoint]`.

```lean

  simp [thetaCoordPoint]

@[simp] theorem thetaCoordPoint_some_root
    {A B e y : ℝ} {h} :
    thetaCoordPoint A B e (Point.some e y h) = halfPeriod A B e := by

    {A B e x y : ℝ} {h}
    (hx : x ≠ e) (hy : y < 0) :
    thetaCoordPoint A B e (Point.some x y h) = sigma A B x := by
  simp [thetaCoordPoint, hx, hy]

theorem thetaCoordPoint_some_upper_of_not_lt
    {A B e x y : ℝ} {h}

    thetaCoordPoint A B e (Point.some x y h) = - sigma A B x := by
  simp [thetaCoordPoint, hx, hy]

    {A B e x y : ℝ} {h}

  exact thetaCoordPoint_some_upper_of_not_lt
    (A := A) (B := B) (e := e) (x := x) (y := y)
```

## Representative range lemma

This is the key pre-injectivity lemma. It is also the reason to use `Ioc (-T) T`.

```lean
namespace MazurProof.RealTopology

theorem thetaCoord_mem_Ioc_neg_halfPeriod
    {A B e : ℝ}
    {hroot : shortCubic A B e = 0}
    {hderiv : 0 < shortCubicDeriv A B e}
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x)
    (P : ComponentKer (A := A) (B := B) (e := e) hroot hderiv) :
    thetaCoord hroot hderiv P ∈
      Ioc (-(halfPeriod A B e)) (halfPeriod A B e) := by
  classical
  have hT : 0 < halfPeriod A B e := halfPeriod_pos hroot hderiv hposRight
  -- Case split on `P.1`.
  -- * zero: coordinate is `0`, so `-T < 0 ≤ T`.
  -- * affine with `x = e`: coordinate is `T`, so it is in `Ioc (-T) T`.
  -- * affine with `e < x` and `y < 0`: use
  --     `sigma_pos_of_right ... hex` and `sigma_lt_halfPeriod_of_right ... hex`.
  -- * affine with `e < x` and `¬ y < 0`: coordinate is `-sigma x`, use the same two sigma bounds.
  -- The S5 branch lemma gives `x = e ∨ e < x` for affine kernel points.
  -- All interval goals should close with `constructor <;> linarith`.
  admit

end MazurProof.RealTopology
```

When implementing, replace the `admit` with your existing S5 affine case lemmas. No new analytic theorem is needed. The only facts used in branch cases are already checked:

## Equality in AddCircle reduces to equality of representatives

This theorem is the main `AddCircle` API seam. It should compile once `thetaCoord_mem_Ioc_neg_halfPeriod` is proved.

```lean
namespace MazurProof.RealTopology

theorem thetaCandidate_eq_iff_thetaCoord_eq
    {A B e : ℝ}
    {hroot : shortCubic A B e = 0}
    {hderiv : 0 < shortCubicDeriv A B e}
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x)
    (P Q : ComponentKer (A := A) (B := B) (e := e) hroot hderiv) :
    thetaCandidate hroot hderiv P = thetaCandidate hroot hderiv Q ↔
      thetaCoord hroot hderiv P = thetaCoord hroot hderiv Q := by
  classical
  let T : ℝ := halfPeriod A B e
  let p : ℝ := (2 : ℝ) * T
  have hT : 0 < T := by
    dsimp [T]
    exact halfPeriod_pos hroot hderiv hposRight
  have hp : 0 < p := by
    dsimp [p]
    nlinarith
  letI : Fact (0 < p) := ⟨hp⟩
  have hp_end : -T + p = T := by
    dsimp [p]
    ring
  have hPmem : thetaCoord hroot hderiv P ∈ Ioc (-T) (-T + p) := by
    simpa [T, hp_end] using thetaCoord_mem_Ioc_neg_halfPeriod hposRight P
  have hQmem : thetaCoord hroot hderiv Q ∈ Ioc (-T) (-T + p) := by
    simpa [T, hp_end] using thetaCoord_mem_Ioc_neg_halfPeriod hposRight Q
  simpa [thetaCandidate, thetaCoord, thetaPeriod, T, p] using
    (AddCircle.coe_eq_coe_iff_of_mem_Ioc (p := p) (a := -T) hPmem hQmem)

end MazurProof.RealTopology
```

If `simpa [thetaCandidate, thetaCoord, thetaPeriod, T, p]` is too aggressive, prove the two directions manually:

```lean
  constructor
  · intro h
    exact (AddCircle.coe_eq_coe_iff_of_mem_Ioc (p := p) (a := -T) hPmem hQmem).mp
      (by simpa [thetaCandidate, thetaPeriod, p] using h)
  · intro h
    simpa [thetaCandidate, thetaPeriod, p, h]
```

## Useful endpoint helper

You probably will not need this if using `Ioc (-T) T`, but it is useful when rewriting root endpoints in `AddCircle`.

```lean
namespace MazurProof.RealTopology

lemma neg_halfPeriod_eq_halfPeriod_addCircle
    {A B e : ℝ} :
    (((- halfPeriod A B e) : ℝ) : AddCircle (thetaPeriod A B e)) =
      ((halfPeriod A B e : ℝ) : AddCircle (thetaPeriod A B e)) := by
  let T : ℝ := halfPeriod A B e
  let p : ℝ := (2 : ℝ) * T
  have h : (((-T + p) : ℝ) : AddCircle p) = ((-T : ℝ) : AddCircle p) :=
    AddCircle.coe_add_period (p := p) (-T)
  have hp_end : -T + p = T := by
    dsimp [p]
    ring
  simpa [thetaPeriod, T, p, hp_end] using h.symm

end MazurProof.RealTopology
```

## Raw injectivity decomposition

Prove injectivity at the real-coordinate level before mentioning `AddCircle` again.

Recommended theorem:

```lean
namespace MazurProof.RealTopology

theorem thetaCoord_injective
    {A B e : ℝ}
    {hroot : shortCubic A B e = 0}
    {hderiv : 0 < shortCubicDeriv A B e}
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x) :
    Function.Injective
      (thetaCoord (A := A) (B := B) (e := e) hroot hderiv) := by
  -- Branch-classify `P` and `Q` using the existing S5 lemmas.
  -- Coordinate buckets:
  --   * `0` only for `O`;
  --   * `T` only for the root point `x = e`;
  --   * `(0,T)` only for lower branch `y < 0`, coordinate `sigma x`;
  --   * `(-T,0)` only for upper branch `0 ≤ y`, coordinate `-sigma x`.
  -- In same lower/lower or upper/upper cases, recover `x` from strict antitonicity of sigma.
  -- Then recover `y` from the S5 branch lemma `y = ± sqrt(shortCubic A B x)` and the sign condition.
  admit

end MazurProof.RealTopology
```

The strict-antitone API to try first is:

```lean
#check StrictAntiOn.injectiveOn
#check StrictMonoOn.injectiveOn
```

If `StrictAntiOn.injectiveOn` is not available under that exact name, the manual proof is only a few lines:

```lean
have hanti := strictAntiOn_sigma_Ioi hroot hderiv hposRight
have hx_eq : x₁ = x₂ := by
  by_contra hne
  rcases lt_or_gt_of_ne hne with hlt | hgt
  · have hs := hanti hx₁ hx₂ hlt
    -- `hs : sigma A B x₂ < sigma A B x₁`, contradict coordinate equality.
    linarith
  · have hs := hanti hx₂ hx₁ hgt
    linarith
```

For point equality, add a tiny constructor-extensionality lemma if there is not already one:

## AddCircle injectivity theorem

Once the two previous lemmas exist, the raw candidate injectivity is short and contains all AddCircle reasoning in one line.

```lean
namespace MazurProof.RealTopology

theorem thetaCandidate_injective
    {A B e : ℝ}
    {hroot : shortCubic A B e = 0}
    {hderiv : 0 < shortCubicDeriv A B e}
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x) :
    Function.Injective
      (thetaCandidate (A := A) (B := B) (e := e) hroot hderiv) := by
  intro P Q hPQ
  apply thetaCoord_injective (A := A) (B := B) (e := e) hposRight
  exact (thetaCandidate_eq_iff_thetaCoord_eq hposRight P Q).mp hPQ

end MazurProof.RealTopology
```

This proves injectivity of the raw/non-additive theta function. Do not package it as an `AddMonoidHom` until the Abel additivity theorem is available.

## Implementation order

1. Add `thetaPeriod`, `thetaCoordPoint`, `thetaCoord`, and `thetaCandidate`.
2. Close the point-level branch simp lemmas by `simp [thetaCoordPoint]`.
3. Close the kernel branch simp lemmas by rewriting `hP : P.1 = ...` and using the point-level lemmas.
4. Prove `thetaCoord_mem_Ioc_neg_halfPeriod` by S5 branch cases and the already-checked `sigma_pos_of_right` / `sigma_lt_halfPeriod_of_right`.
5. Prove `thetaCandidate_eq_iff_thetaCoord_eq` using `AddCircle.coe_eq_coe_iff_of_mem_Ioc`.
6. Prove `thetaCoord_injective` by branch buckets and `strictAntiOn_sigma_Ioi`.
7. Derive `thetaCandidate_injective` from (5) and (6).
