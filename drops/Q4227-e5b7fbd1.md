# A preliminary logical correction

“\(J_1(18)(\mathbf Q)\) has rank \(0\)” and “\(X_1(18)(\mathbf Q)\) consists only of cusps” are not literally equivalent statements in general.

For this curve the usual route is:

1. prove \(J(\mathbf Q)\) has rank \(0\);
2. determine \(J(\mathbf Q)_{\mathrm{tors}}\cong\mathbf Z/21\mathbf Z\);
3. choose a rational cusp \(P_0\) and use the injective Abel–Jacobi map
   
   \[
   C(\mathbf Q)\longrightarrow J(\mathbf Q),\qquad P\longmapsto [P-P_0];
   \]
4. check which of the 21 torsion classes lie on the embedded curve.

That last finite check yields the six rational points, which are the cusps. Rank zero is the global input, but the point classification still needs the torsion/image calculation.

# (a) Direct 2-descent on \(J_1(18)\)

## The exact numerical answer

The LMFDB record gives

\[
\operatorname{rank}J(\mathbf Q)=0,\qquad
	ext{2-Selmer rank}=0,\qquad
J(\mathbf Q)_{\mathrm{tors}}\cong\mathbf Z/21\mathbf Z.
\]

Because \(J(\mathbf Q)[2]=0\), the 2-Selmer rank zero statement is the strongest possible outcome: the 2-Selmer group has no nonzero class contributing to the Mordell–Weil rank. There is no residual dimension that would require a Cassels–Tate pairing. Fisher–Yan’s pairing machinery is relevant when ordinary 2-descent leaves a positive upper bound; it is unnecessary here.

The public Magma code confirms the correct computational setting:

```magma
R<x> := PolynomialRing(Rationals());
f := R![1, 2, 5, 10, 10, 4, 1];
C := HyperellipticCurve(f);
J := Jacobian(C);

RankBounds(J);
TorsionSubgroup(J);
```

The expected certified outputs are rank bounds \(0,0\) and torsion invariants `[21]`. I have not rerun Magma here; these are the proved database values and the values targeted by the published verification scripts.

## Why this is a small arithmetic certificate

For a genus-2 curve \(y^2=f(x)\), the Bruin–Stoll 2-descent is expressed in the degree-six étale algebra

\[
L=\mathbf Q[T]/(f(T)).
\]

Only finitely many squareclasses can occur: outside a finite set \(S\), valuations are forced to be even, and a norm condition cuts the resulting \(S\)-unit squareclass group down further. Every remaining nontrivial global candidate is then removed by a local condition.

For this particular \(J\), the data are unusually favorable:

- the conductor is \(324\);
- the only bad rational primes are \(2\) and \(3\);
- the associated degree-six 2-torsion/root field in LMFDB has small discriminant \(41472\);
- the final Selmer rank is already zero;
- no Cassels–Tate pairing and no search for Mordell–Weil generators is needed.

Conceptually, the finite certificate can be made to contain only:

```text
1. the integral basis and multiplication table of the fixed degree-6 algebra L;
2. a certified list of S-unit squareclasses satisfying the norm condition;
3. a proof that this list is exhaustive;
4. for every nontrivial candidate, one place v and a local obstruction witness;
5. the conclusion that the global 2-Selmer group is trivial.
```

Local obstruction witnesses should be chosen in a kernel-friendly form: a valuation parity contradiction, a nonsquare residue, or a finite congruence tree proving that a covering has no point over \(\mathbf Q_v\). Avoid asking Lean to implement general \(p\)-adic point search.

## What Lean would actually have to formalize

The phrase “finite computation” can be misleading. The finite list is the easy part. A verified checker also needs a theorem saying that the checked objects really bound \(J(\mathbf Q)\).

At minimum one needs the following layers.

### 1. A concrete model of the Jacobian

For an odd-degree hyperelliptic model with a rational Weierstrass point, ordinary reduced Mumford pairs are relatively clean. Here the natural model has degree six and no rational Weierstrass point, so the even-degree case has to be handled correctly. Choices include:

- divisor classes/Picard group abstractly;
- balanced divisors for an even-degree hyperelliptic curve;
- a purpose-built generalized Mumford representation and Cantor composition;
- explicit Kummer-surface coordinates plus a separately proved descent bridge.

Mathlib currently has substantial Weierstrass-curve/elliptic-curve infrastructure, but I found no existing hyperelliptic Jacobian, Mumford representation, genus-2 Selmer group, or Mordell–Weil-rank implementation. Even the current elliptic-height development still lists the basic naïve-height and approximate-parallelogram ingredients as TODO; see [`Mathlib/NumberTheory/Height/EllipticCurve.lean`](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/NumberTheory/Height/EllipticCurve.lean).

### 2. The descent map and its kernel

One needs a proved map of the schematic form

\[
\delta:J(\mathbf Q)/2J(\mathbf Q)\longrightarrow
L^	imes/(L^{	imes 2}\mathbf Q^	imes),
\]

with the norm condition and the theorem identifying its image with a subgroup of the 2-Selmer group. Proving that the kernel is exactly \(2J(\mathbf Q)\) is not a `native_decide` fact; it is the central descent theorem.

### 3. Completeness of the global candidate list

Lean must know why no squareclass was omitted. This normally uses ideal factorization, an \(S\)-class group calculation, units modulo squares, and norm relations. For a fixed small field these can all be checked by explicit witnesses and Minkowski-style bounds, but the proof objects still have to be designed.

### 4. Sound local-image tests

For \(v=\infty,2,3\), and any auxiliary good primes used by the computation, every rejected candidate needs a theorem that the supplied finite witness excludes it from the local Kummer image. This is manageable if the external program emits simple residue/valuation certificates rather than an opaque “Magma says false.”

### 5. The bridge from Selmer vanishing to rank zero

The standard inequality

\[
\operatorname{rank}J(\mathbf Q)\leq
\dim_{\mathbf F_2}\operatorname{Sel}^{(2)}(J/\mathbf Q)
-\dim_{\mathbf F_2}J(\mathbf Q)[2]
\]

uses the Kummer exact sequence together with finite generation of \(J(\mathbf Q)\). Thus a completely foundational Lean proof also needs either:

- an appropriate Mordell–Weil finite-generation theorem for this abelian variety; or
- a concrete height/no-infinite-halving argument for this \(J\).

Neither is currently an off-the-shelf Mathlib lemma. This is why I rate the fixed-instance route at the high end of (ii), and a general implementation as (iii).

## A realistic verified-certificate architecture

Do **not** begin by implementing all genus-2 arithmetic as a computer algebra system. Separate a small trusted theorem layer from a data checker.

A plausible interface is:

```lean
structure N18TwoDescentCertificate where
  -- exact algebraic data
  integralBasis      : ...
  multiplicationTable : ...
  ringOfIntegersProof : ...

  -- finite global squareclass computation
  sPrimes            : Finset ...
  unitSquareclasses  : Finset ...
  classGroupWitness  : ...
  globalCandidates   : Finset ...
  candidates_complete : ...

  -- one checkable local obstruction for each nontrivial candidate
  localObstruction   :
    ∀ c ∈ globalCandidates, c ≠ 1 → LocalObstructionWitness c

  -- optional independent torsion data
  torsionGenerator   : ...
  torsionOrderProof  : ...
```

The core reusable theorems would then be only:

```lean
-- Schematic, not current Mathlib syntax.
theorem genusTwo_descent_injects_mod_two
    (C : EvenDegreeGenusTwoCurve ℚ) :
    Injective (descentMap C) := ...

theorem local_obstruction_sound
    (w : LocalObstructionWitness c) :
    c ∉ localKummerImage C w.place := ...

theorem rank_le_twoSelmerRank
    (J : GenusTwoJacobian ℚ) :
    mwRank J ≤ twoSelmerRank J := ...
```

Then the N18-specific proof is mostly evaluation of exact algebraic identities and finite lists.

This is much preferable to importing a huge output transcript. The certificate should be small enough that an independent Sage/Magma exporter and Lean checker can be compared byte-for-byte.

# (b) Descent on the elliptic \(\mathbf Q\)-curve over \(K=\mathbf Q(\zeta_3)\)

Mathematically, this is valid. Over the splitting field \(K\), the surface becomes isogenous to elliptic factors, schematically

\[
J_K \sim E	imes E^\sigma,
\]

with \(E\) a \(\mathbf Q\)-curve. One can transfer the rank question through the isogeny/Weil-restriction description and prove rank zero by computing \(E(K)\).

It is not, however, clearly a smaller certificate.

## Why the apparent dimension reduction does not buy much

A full 2-descent on an elliptic curve over \(K\) requires:

- the ring of integers of \(K\);
- prime ideals above \(2\), \(3\), and the discriminant/conductor primes;
- \(K\)-unit and ideal-class squareclasses;
- the cubic étale algebra cut out by the 2-division polynomial of \(E\), unless \(E\) has a \(K\)-rational 2-isogeny or unusually split 2-torsion;
- local Kummer images over \(K_\mathfrak p\);
- proof that the isogeny transfers the desired rank statement.

Although \(\mathbf Z[\zeta_3]\) itself is Euclidean, the cubic 2-division algebra over \(K\) is the real global object. Viewed over \(\mathbf Q\), it is again essentially degree six. The LMFDB record’s degree-six 2-torsion field and odd rational torsion show that there is no obvious rational-2-torsion shortcut on the surface.

There is one circumstance in which (b) could overtake (a): an explicit model of \(E/K\) with a \(K\)-rational 2-isogeny and very small isogeny-Selmer groups. Before committing to (b), one should run:

```magma
K<w> := QuadraticField(-3);
// construct the explicit Q-curve E/K
IsIsogenous(...);
TwoIsogeny := ...;              // only if one actually exists
RankBounds(E);
```

and inspect whether the proof uses only \(K^	imes/K^{	imes 2}\), rather than a cubic extension of \(K\). I found no evidence in the available record that this exceptional simplification occurs. Without it, (b) duplicates the same degree-six arithmetic while adding:

1. elliptic descent over a number field;
2. an explicit isogeny \(J_K	o E	imes E^\sigma\);
3. descent of the rank statement from \(K\) back to \(\mathbf Q\).

Mathlib’s elliptic group law helps, but Mathlib still does not provide elliptic 2-Selmer computations over quadratic fields. My rating is therefore **(iii)** for the current project, not (ii).

# (c) CM, Heegner, Kolyvagin, or Kato

There is a terminology trap here. LMFDB records `end_alg = CM`, but also

```text
is_simple_base = true
is_simple_geom = false
geom_end_alg = M_2(Q)
```

This describes the imaginary-quadratic endomorphism/inner-twist structure of the \(\mathbf Q\)-simple GL2-type surface. It does **not** say that the elliptic factor over the splitting field is a CM elliptic curve. If the elliptic factor had genuine CM, the geometric endomorphism algebra would be larger than \(M_2(\mathbf Q)\).

Consequently there is no elementary “CM class number” proof of rank zero hiding here.

There is an analytic route:

1. compute an exact nonzero modular-symbol value \(L(f,1)\);
2. use Kato’s Euler-system theorem (or a suitable Gross–Zagier/Kolyvagin package) to deduce algebraic rank zero for the modular abelian variety.

Indeed the LMFDB record marks analytic rank zero as proved, and the literature uses modular-symbol/Kato arguments to pass from nonvanishing to algebraic rank zero in this setting. But from a Lean perspective, this route requires formalizing a large portion of:

- modular forms and their attached Galois representations;
- modular symbols and comparison with \(L(f,1)\);
- the construction of the modular abelian variety \(A_f\);
- Euler systems, Selmer groups, and Kato’s rank theorem;
- the identification \(A_f\sim J_1(18)\).

That is enormously larger than checking the degree-six 2-descent certificate. Heegner/Kolyvagin is not a shortcut; Heegner points are most naturally suited to analytic rank one, and the rank-zero deduction still rests on deep global theorems.

Rating: **(iii), genuinely out of current Lean reach for this application**.

# (d) A map to a rank-zero elliptic curve over \(\mathbf Q\)

There is no such missing map.

If \(C/\mathbf Q\) has a nonconstant morphism

\[
\phi:C\longrightarrow E
\]

to an elliptic curve over \(\mathbf Q\), then after choosing a rational base point, \(\phi\) induces a nonzero homomorphism

\[
\phi_*:J(C)\longrightarrow E.
\]

Its image is a positive-dimensional abelian subvariety of \(E\), hence all of \(E\). Therefore \(E\) is an elliptic quotient, and \(J(C)\) is not \(\mathbf Q\)-simple. But the exact LMFDB record says \(J_1(18)\) is \(\mathbf Q\)-simple. Hence no nonconstant map \(X_1(18)	o E\) over \(\mathbf Q\) exists.

The visible order-three automorphism does have a low-genus quotient, but the quotient is genus zero, not genus one. The published `MWSieve-x1_18.m` code explicitly finds the order-three automorphism and constructs its quotient curve in order to obtain a degree-three divisor. It does not produce an elliptic quotient.

Maps to elliptic curves after base extension are precisely the situation in (b), and do not yield a rational elliptic factor.

So (d) is not merely “hard”; it is mathematically ruled out.

# What should be axiomatized if the full checker is too large?

There are three possible axiom boundaries, ordered from worst to best.

## 1. Bare rank axiom

```lean
axiom n18_jacobian_rank_zero : MWRank J18 = 0
```

This is concise but opaque. It records neither the method nor a checkable arithmetic invariant.

## 2. Exact descent-result axiom

```lean
axiom n18_twoSelmerRank_zero : TwoSelmerRank J18 = 0
```

or, matching the external routine more literally,

```lean
axiom n18_rankBounds : RankBounds J18 = (0, 0)
```

This is the best **practical** boundary. It says exactly what the finite external computation proves, is independently reproducible, and can later be replaced by a verified certificate without changing downstream N18 code.

## 3. General descent-correctness theorem plus checked instance data

The ideal architecture is to make the arithmetic data fully checked and leave no N18-specific axiom. If a temporary assumption is unavoidable, place it in the general theorem connecting an accepted descent certificate to the rank bound, not in the numerical N18 result:

```lean
-- Temporary general theorem boundary, reusable for later genus-2 work.
axiom verifiedTwoDescent_rankBound
    (C : GenusTwoCurve ℚ)
    (cert : VerifiedTwoDescentCertificate C) :
    MWRank C.jacobian ≤ cert.selmerRank
```

Then all N18-specific statements—including that `cert.selmerRank = 0`—are proved by kernel-checked finite computation. This is a materially better trust story than a bare arithmetic axiom.

# Recommended execution plan

## Phase A: confirm and export the exact finite certificate

Use Magma’s genus-2 rank machinery on the fixed model and modify/instrument the descent routine to emit:

1. the defining algebra and integral basis;
2. factorizations of \(2\), \(3\), and any auxiliary primes;
3. unit and class-group-mod-2 generators with witnesses;
4. the complete global squareclass candidate list;
5. one simple local obstruction for each nontrivial candidate;
6. the final statement “2-Selmer rank \(=0\).”

Do not export a procedural transcript. Export normalized mathematical data.

## Phase B: prove the finite algebraic checks in Lean

Prioritize exact checks that Mathlib already handles well:

- polynomial arithmetic over \(\mathbf Z,\mathbf Q,\mathbf F_p\);
- irreducibility/separability certificates;
- matrix multiplication and determinant identities;
- explicit ideal principality witnesses;
- finite-vector-space enumeration;
- residue-field nonsquare checks;
- bounded congruence trees with `native_decide` only after their soundness theorem is proved.

## Phase C: add the smallest reusable genus-2 theorem layer

Implement only what this certificate requires:

1. the fixed even-degree Jacobian representation or fixed Kummer model;
2. the descent map;
3. its mod-2 injectivity/kernel theorem;
4. local-image soundness;
5. the rank bridge, via Mordell–Weil finite generation or a concrete height argument.

## Phase D: enumerate the curve points

Once \(J(\mathbf Q)\cong\mathbf Z/21\mathbf Z\) is known, enumerate the 21 classes and prove that exactly six lie in the Abel–Jacobi image. Identify those six with the cusps. This final step should be substantially smaller than the rank proof.

# Final recommendation

The arithmetic situation is better than the question’s alternatives suggest:

- **the direct 2-Selmer group is already trivial;**
- **no Cassels–Tate pairing is required;**
- **there is no rational elliptic quotient;**
- **the geometric elliptic splitting does not give genuine CM and does not simplify the 2-descent without a special 2-isogeny;**
- **Kato/Kolyvagin is far beyond the required complexity.**

Therefore:

> **Choose (a). Build, if resources permit, a fixed-instance verified Bruin–Stoll/Stoll 2-descent certificate checker for `324.a.648.1`. This is the single most promising axiom-free route.**

But one should not label it “elementary and formalizable now.” The missing genus-2 Jacobian/descent/rank bridge is a genuine mini-library. If the goal is to close N18 in the present FLT development rather than start that library, then a single localized assumption

```lean
n18_twoSelmerRank_zero : TwoSelmerRank J18 = 0
```

is the genuinely minimal practical arithmetic axiom. It is strictly preferable to a bare `rank = 0` axiom because it exposes the exact finite certificate that can later replace it.
