# N18 Route C rank-zero core: adversarial R1 infrastructure audit

## Verdict

There is no axiom-free route in this setting that makes the present semantic gaps disappear.
The checked `3 + 81 = 84` table is only the **last finite calculation** in a descent. By itself it says nothing about arbitrary points of `E0(L)`, nothing about `E0(L)/3E0(L)`, and nothing about infinite `3`-divisibility.

There is, however, a genuinely smaller **curve-specific coordinate route** that avoids building three large general theories:

1. no general category of elliptic-curve isogenies is needed;
2. no abstract Galois-cohomological definition of a Selmer group is needed;
3. no general `WeierstrassCurve.formalGroup` or point-reduction API is needed.

The price is that one must prove concrete replacements having exactly the same mathematical content:

```text
explicit total point maps + pointwise dual composition,
explicit Kummer fiber/coset exactness,
S-supported cube-class normal forms for every actual point,
sound local necessary conditions for every actual point,
a strict coordinate filtration entered by every 7-multiple,
and a direct [3]-parameter valuation-growth theorem.
```

Those obligations are unavoidable. They can be made fixed-curve polynomial/valuation theorems, but cannot be inferred from the finite candidate table.

The shortest faithful strategy is therefore:

```text
abstract isogeny/Kummer/Selmer theory      -> do not build
abstract elliptic formal-group/reduction    -> do not build

replace by:
  two direct Kummer preimage theorems,
  four fixed S-unit/local-soundness theorems,
  one variable-change point equivalence,
  one 7-multiple chart-entry theorem,
  one explicit tripling valuation theorem.
```

This is still substantial new infrastructure, but it is materially smaller than a general isogeny-descent and local formal-group library.

# 1. Why the 84-entry table cannot imply weak descent

Suppose the repository has finite types

```lean
abbrev PhiCandidate  := Fin 3
abbrev DualCandidate := Fin 4 -> Fin 3
```

and checked theorems of the shape

```lean
theorem phi_table (c : PhiCandidate) :
    phiPass c <-> c = 0

theorem dual_table (c : DualCandidate) :
    dualPass c <-> exists k : Fin 3, c = dualLine k
```

These theorems mention no elliptic-curve point. Lean cannot derive a theorem about `E0L.Point` from them until maps and soundness theorems connect every point to a candidate.

Even adding arbitrary candidate-valued functions is insufficient. For example, take

```text
G = Z x Z/3,
T = (0,1).
```

Use the same finite tables and define both candidate maps to be constantly a surviving candidate. All finite statements remain true, but

```text
G = <T> + 3G
```

is false: `(1,0)` is not in `<T> + 3G`.

The missing property is **kernel/coset exactness**. To bound `G/3G` by a finite candidate set, one needs an injective map from the quotient. Concretely, equality of Kummer candidates must imply that the difference of the two points lies in an isogeny image, and the two isogenies must compose to `[3]`. That is precisely the descent theorem which the table does not prove.

A useful logical decomposition is:

```text
finite table
  + every actual Kummer class has a candidate
  + every actual class passes the local predicates
  + equality/triviality of Kummer classes detects isogeny cosets
  + phihat(phi(Q)) = 3Q
  --------------------------------------------------------------
  E0(L) = <T> + 3E0(L).
```

Deleting any line above breaks the implication.

## What “84 candidates” actually means

The two searches live in different cohomological targets:

```text
phi side:     3 anti-invariant classes over M = L(sqrt(-3)),
dual side:   81 S-unit cube classes over L.
```

Thus `84` is `3 + 81`, not the cardinality of one group and not a bound on `E0(L)/3E0(L)` without the semantic bridges.

## 2.1 What can be avoided: bundled additivity

For the weak-descent conclusion, it is not logically necessary to prove that the point maps are bundled additive homomorphisms. A smaller interface suffices:

```lean
noncomputable def phiPoint    : EPoint -> EhatPoint
noncomputable def phihatPoint : EhatPoint -> EPoint

theorem phihat_phi_point (P : EPoint) :
    phihatPoint (phiPoint P) = 3 • P
```

Together with direct Kummer fiber theorems below, this proves weak descent without ever forming the abstract exact sequence of Mordell-Weil quotients.

A total point definition and the pointwise composition identity are still unavoidable. The existing denominator-cleared curve-preservation identity proves only that the generic formula lands on the target; it does not handle:

```text
O,
(0,0),
(0,-2),
zeros of generic denominators,
or the composition with the dual map.
```

The generic composition is a fixed rational-function identity; all exceptional branches are finite.

## 2.2 Concrete cube-class types

One may avoid `H^1` entirely. Define only the concrete quotient groups required by the two functions:

```text
DualCubeClass = L^*/L^{*3},
PhiCubeClass  = the anti-invariant S-cube-class quotient over
                M = L(sqrt(-3)).
```

The Kummer values are the familiar explicit functions.

On `E3Translated`, the dual Kummer value is

```text
O       -> 1,
(0,0)   -> 1/2,       whose cube class is [4],
```

The target is the anti-invariant class of `h`.

## 2.3 The two unavoidable Kummer exactness theorems

The minimal direct-coordinate theorems are:

```lean
theorem dual_kummer_zero_iff_dual_range (P : EPoint) :
    dualKummerClass P = 0 <->
      exists Q : EhatPoint, phihatPoint Q = P

theorem phi_kummer_zero_iff_phi_range (Q : EhatPoint) :
    phiKummerClass Q = 0 <->
      exists P : EPoint, phiPoint P = Q
```

These are the concrete replacements for Kummer exactness. They cannot be omitted.

They can be proved without abstract cohomology:

* image implies trivial class: substitute the explicit isogeny formula and exhibit the cube;
* trivial class implies image: choose a cube-root witness and give explicit rational formulas for a preimage;
* verify the source equation and the image identity using `field_simp` and `ring`;
* discharge the finitely many zero/denominator/kernel branches separately.

For the `phi` side, “trivial” must mean zero in the **correct anti-invariant quotient**. Merely proving that `h(xi,eta)` is a cube in `M` is not a safe substitute unless the Galois descent of the cube root back to an `L`-rational preimage is also proved.

An exact polynomial-style replacement theorem can be exported as follows:

```lean
/-- Forward and reverse coordinate certificates for the dual fiber. -/
theorem dual_preimage_certificate
    (P : EPoint) :
    dualKummerClass P = 0 <->
      exists (r : L) (Q : EhatPoint),
        r ^ 3 = dualKummerValue P /\
        phihatPoint Q = P

/-- The analogous anti-invariant certificate for phi. -/
theorem phi_preimage_certificate
    (Q : EhatPoint) :
    phiKummerClass Q = 0 <->
      exists P : EPoint, phiPoint P = Q
```

The right sides are finite systems of rational polynomial equations once the exceptional branches are split. A Gröbner-generated witness formula, checked by `ring`, is a valid implementation.

## 2.4 Avoiding a full Kummer homomorphism

The dual table has the three surviving classes represented by `O`, `T`, and `-T`. One does not need to prove that `dualKummerClass` is a group homomorphism on all pairs. It is enough to prove translation by the two kernel points.

On the generic translated chart, for `u != 0`, direct generalized-Weierstrass addition gives

```text
P + T = (-2w/u^2, -4w/u^3),

P - T =
  ( 2(w-3u+2)/u^2,
   -2(w-3u+2)^2/u^3 ).
```

Since

```text
w(w-3u+2) = u^3,
```

these imply, modulo cubes,

```text
[delta(P+T)] = [4] [delta(P)],
[delta(P-T)] = [2] [delta(P)].
```

The `u=0` cases are the finite points `T` and `-T`.

Therefore the following two theorems replace a general homomorphism proof:

```lean
theorem dual_kummer_add_T (P : EPoint) :
    dualKummerClass (P + T) = dualKummerClass P + classFour

theorem dual_kummer_sub_T (P : EPoint) :
    dualKummerClass (P - T) = dualKummerClass P + classTwo
```

This is substantially smaller than proving `phiPoint` and `phihatPoint` additive or developing divisors of Kummer functions in general.

# 3. The global candidate bridge which the finite table still needs

Let

```text
S = {p2=(2), p3=(pi)},
pi = a-1,
a^3 = 3a+1.
```

For the dual side, the claimed global basis is

```text
[a], [a+1], [2], [pi].
```

The exact all-points normal-form theorem is:

```lean
theorem dual_kummer_global_normal_form (P : EPoint) :
    exists i j k l : Fin 3, exists r : Lˣ,
      dualKummerValue P =
        a^i * (a+1)^j * 2^k * pi^l * r^3
```

Here powers use the representatives `0,1,2` of `Fin 3`.

For the `phi` side, with `M = Q(zeta_9)`, the exact theorem is:

```lean
theorem phi_kummer_global_normal_form (Q : EhatPoint) :
    exists e : Fin 3, exists r : Mˣ,
      phiKummerValue Q = zeta9^e * r^3
```

in the anti-invariant quotient.

These two theorems are the smallest faithful replacements for a formal Selmer-group construction. Their proofs require real arithmetic:

1. prove the Kummer value has valuation divisible by `3` outside `S`;
2. use the class-number-one/principal-ideal input;
3. prove the displayed unit and prime classes span the relevant `S`-unit quotient;
4. handle the Kummer special points.

A Boolean candidate type does not prove any of these assertions.

## 3.1 What can be polynomial

The support theorem can largely be reduced to fixed Bezout/resultant identities.

On the translated source,

```text
w(w-3u+2) = u^3.
```

One proves that the two factors can have a common prime divisor only above `2` or `3`. A fixed coordinate-ring Bezout identity witnessing this fact implies that, outside `S`, each factor has valuation divisible by `3`. Thus `[w]` is `S`-supported.

On the quotient side,

```text
h * conjugate(h) = X^3
```

in the completed-square coordinate. A second fixed Bezout identity shows that the common support of `h` and `conjugate(h)` is contained in `S`.

These are good `ring`/ideal-membership certificates. They do **not** replace the class-number/unit-basis theorem needed to turn an arbitrary supported class into one of the finite coordinates.

## 3.2 Only local containment is required

It is unnecessary to formalize the exact local Kummer image as a subgroup with a computed cardinality. For the global elimination, one needs only necessary conditions:

```lean
theorem dual_actual_point_passes_p2 (P : EPoint) :
    dualPass2 (dualCandidate P)

theorem dual_actual_point_passes_p3 (P : EPoint) :
    dualPass3 (dualCandidate P)

theorem phi_actual_point_passes_p2 (Q : EhatPoint) :
    phiPass2 (phiCandidate Q)

theorem phi_actual_point_passes_p3 (Q : EhatPoint) :
    phiPass3 (phiCandidate Q)
```

Then the checked finite tables are sufficient.

This is smaller than proving equality with the full local image. The predicates may be implemented as solvability in finite quotients `O/pi^N` and `O/2^N`; soundness says that every actual local/global point produces a residue witness. Exhaustive finite search then eliminates the candidates.

At `p3`, do not use the false shortcut

```text
unit is a cube iff its residue is a cube.
```

Residue characteristic equals `3`; principal units contribute nontrivial cube classes. The soundness theorem must use the principal-unit filtration or a sufficiently deep finite quotient.

## 3.3 The true arithmetic capstones

After the global-normal-form and local-soundness proofs, the finite tables give exactly:

```lean
theorem dual_survivor_of_point (P : EPoint) :
    exists i : Fin 3,
      dualKummerClass P = dualKummerClass (i.val • T)

theorem phi_trivial_of_point (Q : EhatPoint) :
    phiKummerClass Q = 0
```

These, rather than the raw 84-entry theorem, are the useful descent outputs.

# 4. A complete weak-descent proof using only the minimal interface

Once the preceding concrete theorems exist, the proof does not need abstract Selmer groups, quotient cardinalities, or finite generation.

```lean
theorem e0_weak_three_descent (P : EPoint) :
    exists i : Fin 3, exists Q : EPoint,
      P = i.val • T + 3 • Q := by
  obtain ⟨i, hi⟩ := dual_survivor_of_point P

  -- Use one of the three explicit T-translation identities to make
  -- the dual Kummer class trivial.
  have hzero :
      dualKummerClass (P - i.val • T) = 0 := by
    fin_cases i
    all_goals simpa using hi

  obtain ⟨R, hR⟩ :=
    (dual_kummer_zero_iff_dual_range (P - i.val • T)).mp hzero

  have hphi : phiKummerClass R = 0 := phi_trivial_of_point R
  obtain ⟨Q, hQ⟩ :=
    (phi_kummer_zero_iff_phi_range R).mp hphi

  refine ⟨i, Q, ?_⟩
  rw [← hR, hQ, phihat_phi_point]
  abel
```

The exact orientation of the equality returned by the two range theorems may change a few rewrites, but no new mathematical step is present.

This proof demonstrates the minimum semantic burden:

```text
finite survivors alone: insufficient;
finite survivors + two range exactness theorems + composition: sufficient.
```

# 5. The shortest faithful 3-adic separatedness route

For separatedness, it is unnecessary to construct the completion `L_pi`, a general formal group, or an equivalence between the entire reduction kernel and a formal group.

All division points occurring in the global weak-descent iteration are still `L`-rational. Work directly with the discrete valuation `ord_pi` on `L`.

## 5.1 Use a fixed good model

Freeze one explicit good integral model over `L` with unit discriminant at `pi`, together with a point equivalence from the base change of `E0`. For example, the previously checked model with discriminant `-8` is suitable.

The required bridge is:

```lean
noncomputable def toGood : E0LPoint ≃+ EGoodPoint
```

with explicit affine coordinate formulas. Pinned Mathlib has the action of `VariableChange` on Weierstrass equations, but not the needed point-level additive equivalence. This adapter is genuinely new, though reusable for every later model change.

## 5.2 Define a strict coordinate filtration, not a formal group

On the good model define

```text
z = -x/y,
w = -1/y.
```

Use a total function with value `0` at `O`; the filtration must explicitly exclude a zero affine parameter.

```lean
noncomputable def formalZ : EGoodPoint -> L
  | 0 => 0
  | .some x y _ => -x / y

def FormalLevel (n : Nat) (P : EGoodPoint) : Prop :=
  P = 0 \/
    formalZ P ≠ 0 /\
    (n : Int) ≤ ordPi (formalZ P)
```

The two local theorems required by the existing abstract group glue are:

```lean
/-- Every 7-multiple lies in the first strict formal chart. -/
theorem seven_nsmul_formalLevel_one (P : EGoodPoint) :
    FormalLevel 1 (7 • P)

/-- Multiplication by 3 raises the strict level. -/
theorem three_nsmul_formalLevel_succ
    {n : Nat} (hn : 1 ≤ n) {P : EGoodPoint}
    (hP : FormalLevel n P) :
    FormalLevel (n + 1) (3 • P)
```

Finally:

```lean
theorem formalLevel_separated {P : EGoodPoint}
    (hP : forall n : Nat, FormalLevel n P) :
    P = 0
```

The last theorem is elementary: for a fixed nonzero `P`, `formalZ P` is a fixed nonzero element of `L`, hence has a finite integer valuation. Choose `n` larger than that valuation.

This three-theorem filtration is the concrete replacement for the absent formal-kernel equivalence.

## 5.3 Exact polynomial theorem replacing the formal-group API

For a generalized integral Weierstrass equation, the formal coordinates satisfy

```text
w = z^3 + a1*z*w + a2*z^2*w + a3*w^2 + a4*z*w^2 + a6*w^3.
```

If `ord_pi(z) >= 1`, the factor multiplying `w` after rearrangement is a unit, so

```text
ord_pi(w) = 3 * ord_pi(z).
```

Obtain fixed rational functions for the parameter of `3P`:

```text
z(3P) = N3(z,w) / D3(z,w).
```

The finite polynomial certificates actually needed are

```text
N3(z,w) - 3z belongs to the ideal (z^2, w),
D3(z,w) - 1  belongs to the ideal (z, w),
```

with coefficients integral at `pi`.

A Lean-facing version is:

```lean
theorem triple_parameter_identity (P : EGoodPoint) :
    formalZ (3 • P) =
      eval₂ z w tripleN / eval₂ z w tripleD

theorem tripleN_shape :
    tripleN = 3 * Z + Z^2 * R20 + W * R01

theorem tripleD_shape :
    tripleD = 1 + Z * S10 + W * S01
```

for fixed integral polynomials `R20`, `R01`, `S10`, and `S01`.

Let `r = ord_pi(z) >= 1`. Since `ord_pi(3)=3` and `ord_pi(w)=3r`,

```text
ord_pi(3z)       = r+3,
ord_pi(z^2 R20) >= 2r,
ord_pi(w R01)   >= 3r,
ord_pi(D3)       = 0.
```

Therefore

```text
ord_pi(z(3P)) >= min(r+3,2r,3r) >= r+1.
```

Cancellation only raises the valuation. This proves `three_nsmul_formalLevel_succ` directly.

No infinite formal series and no completion are required.

## 5.4 Exact finite theorem replacing the point-reduction API

The residue curve over `F_3` has seven points, so

```lean
theorem reduction_curve_exponent_seven
    (Q : EGoodReduction.Point) :
    7 • Q = 0 := by
  decide
```

is finite.

That theorem still does not speak about `EGoodPoint`. The missing bridge is exactly:

```lean
theorem seven_nsmul_formalLevel_one (P : EGoodPoint) :
    FormalLevel 1 (7 • P)
```

It can be proved curve-specifically without a general reduction homomorphism:

1. normalize projective coordinates at `pi`;
2. split into reduction-at-infinity and affine-reduction cases;
3. use the finite seven-point table;
4. verify the sevenfold projective coordinate formulas reduce to infinity;
5. translate reduction at infinity into positive valuation of `-x/y`.

An alternative is to use projective division-polynomial formulas for `[7]`: prove by finite evaluation that `psi_7` vanishes on all six affine residue points, then show the projective `[7]` coordinates have reduction `[0:1:0]`. This is a large but purely fixed polynomial certificate.

Thus the general reduction-kernel equivalence can be avoided, but the **entry theorem for all points** cannot.

## 5.5 Why no other prime helps

At a prime not above `3`, the linear coefficient of `[3](z)` is the unit `3`. Multiplication by `3` is locally invertible on the formal chart, so nonzero points there can be infinitely `3`-divisible. A `2`-adic copy of the existing rational argument cannot prove `3`-adic separatedness.

The prime over `3` is therefore structurally unavoidable. Ramification is harmless here; it gives `ord_pi(3)=3`, which strengthens the linear-term valuation.

# 6. Assembling the exponent 21

The already-proved pure group argument applies to the concrete filtration above.

From weak descent,

```text
P = t + 3Q,   t in <T>,   3t = 0,
```

multiplication by `21` kills the `t` term and gives an iterated decomposition

```text
21P = 3^n (21Q_n)
```

for every `n`.

Every `21Q_n` is a `7`-multiple:

```text
21Q_n = 7(3Q_n),
```

so it lies in `FormalLevel 1`. Repeated use of the tripling theorem places the fixed point `21P` in every `FormalLevel n`. Separatedness gives

```text
21P = 0.
```

The multiplier `21 = lcm(3,7)` is exact for this argument:

```text
3 kills the weak-descent subgroup <T>,
7 kills the residue group.
```

No finite-generation theorem is used.

# 9. Rejected shortcuts

## Reduction bounds alone

Good-prime reduction injects prime-to-residue-characteristic **torsion**. It does not inject all of `E0(L)` and cannot prove rank zero before torsion has been established.

## Database torsion/rank records

The record `E0(L)_tors = Z/21` is an external answer, not a proof of weak descent or separatedness.

## “Finite mod-3 quotient” without Kummer exactness

A finite target bounds `E0(L)/3E0(L)` only after proving that the induced quotient map is injective. That injectivity is Kummer exactness.

## A height enumeration

A finite height search requires a proved global height bound or Mordell-Weil finite generation. It is not shorter in the present library.

## Analytic rank or Kolyvagin

That replaces the missing elementary infrastructure by substantially deeper absent infrastructure and violates the intended proof boundary.

## A different local prime

At residue characteristic different from `3`, multiplication by `3` is locally invertible and cannot supply the needed separated filtration.

# 10. Recommended build order

The most efficient bottom-up order is:

```text
1. Total phi/phihat point functions and phihat_phi_point.
2. dual_kummer_zero_iff_dual_range and phi_kummer_zero_iff_phi_range.
3. The two explicit T-translation Kummer formulas.
4. S-support Bezout identities.
5. The two S-unit normal-form theorems.
6. Necessary p2/p3 finite-congruence soundness.
7. Apply the existing 84 table and prove e0_weak_three_descent.
8. Build the generic point equivalence for a VariableChange.
9. Define ord_pi, formalZ, and FormalLevel on the fixed good model.
10. Prove seven_nsmul_formalLevel_one.
11. Generate and certify the weighted tripling numerator/denominator identities.
12. Prove formalLevel growth, separatedness, and finally [21]E0(L)=0.
```

Steps 2, 5, 6, 10, and 11 are the genuine load-bearing items. Everything else is already present, finite, or short composition.

# Bottom line

The existing 84-entry computation is valuable and should be retained, but it is not yet a Selmer proof in Lean. It becomes one only after the global candidate and Kummer/local soundness bridges are proved.

The shortest axiom-free implementation does **not** build a general isogeny/Selmer/formal-group stack. It proves the following fixed-curve facts directly:

```text
Kummer class zero <-> explicit isogeny preimage,       twice;
every point's class has one of the finite S-coordinates;
```
