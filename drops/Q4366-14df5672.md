# N18 Route C: explicit cubic-field splitting foundation

## Verdict

The splitting claim is correct, with one useful refinement:

```text
J(C)_L  ~  E0_L × E0_L,
L = Q(a),  a^3 = 3a + 1.
```

The proof can be separated into a completely explicit algebraic layer and one standard geometric lemma.

The explicit layer consists only of:

1. a Möbius involution on the x-line and its weight-3 action on y;
2. two polynomial identities in `L[x]` or `L[z]`;
3. two degree-2 quotient maps;
4. explicit Weierstrass changes of variables;
5. an explicit rational 3-isogeny.

Every identity in items 1–5 reduces by `field_simp` and `ring_nf` using only

```text
a^3 = 3*a + 1.
```

The geometric lemma is the standard fact that two independent elliptic quotient maps of a genus-2 curve induce an isogeny from the product of the elliptic quotients to the Jacobian.

A correction of terminology is important. One quotient is L-isomorphic to `E0`. The companion quotient is L-isomorphic to a rational curve `Ehat0` that is 3-isogenous over Q to `E0`. Thus both quotient factors are L-isogenous to `E0`, which is exactly what is needed.

The rational elliptic curve is

```text
E0 : y^2 + x*y + y = x^3 - x^2 - 5*x + 5.
```

Its labels are:

```text
LMFDB:   162.c3
Cremona: 162b1
```

Over Q it has rank 0 and torsion Z/3Z. The point `(1,0)` generates the rational 3-torsion. Over L its torsion grows, but this does not affect the splitting argument.

# 1. The cubic field

Let

```text
p(T) = T^3 - 3*T - 1,
L = Q(a),
p(a) = 0.
```

The polynomial has no rational root, so it is irreducible. Its discriminant is

```text
Disc(p) = 81.
```

Because the discriminant is a square, the Galois group of the irreducible cubic is `A3`, hence cyclic of order 3. All three roots are real. One may take

```text
a = 2*cos(pi/9),
```

so

```text
L = Q(zeta_9)^+.
```

The field label is `3.3.81.1`.

The ring of integers is `Z[a]`. Its class number is 1, although this fact is not needed for the splitting identities. A short proof is available: the totally real cubic Minkowski bound is

```text
(3! / 3^3) * sqrt(81) = 2.
```

Modulo 2,

```text
p(T) = T^3 + T + 1,
```

which has no root in F2 and is irreducible. Thus 2 is inert and there is no ideal of norm 2. Every ideal class has a representative of norm at most 2, so every class is principal.

# 4. The non-hyperelliptic involution

## 4.1 Projective formula

Define

```text
sigma [X:Z:Y]
  = [ A0*X - a*Z : X - A0*Z : q0^3*Y ].
```

On the affine chart `Z=1`, this is

```text
sigma_x(x) = (A0*x - a) / (x - A0)

sigma(x,y)
  = ( sigma_x(x), q0^3*y/(x-A0)^3 ).
```

Thus, in the notation requested in the question,

```text
u(x) = A0*x - a,
w(x) = x - A0,
v(x) = q0^3.
```

No extension beyond L appears.

## 4.2 Involution certificate

Let

```text
M = [[A0, -a],
     [1,  -A0]].
```

The exact matrix identity is

```text
M^2 = q0^2 * I2.
```

Indeed the off-diagonal entries cancel, and the diagonal entry is

```text
A0^2 - a = q0^2.
```

Therefore applying sigma twice gives

```text
[X:Z:Y] -> [q0^2*X : q0^2*Z : q0^6*Y],
```

which is the same weighted-projective point. Hence `sigma^2=id`.

On the affine chart there is an even shorter certificate:

```text
sigma_x(x) = A0 + q0^2/(x-A0),

sigma_x(x)-A0 = q0^2/(x-A0),

sigma_x(sigma_x(x)) = x.
```

The y-multipliers also multiply to 1:

```text
(q0^3/(x-A0)^3)
*
(q0^3/(sigma_x(x)-A0)^3)
= 1.
```

These are direct `field_simp` identities.

## 4.3 Curve-preservation certificate

The load-bearing polynomial identity is

```text
F(A0*X-a*Z, X-A0*Z) = q0^6 * F(X,Z).              (PRES)
```

This is a homogeneous polynomial identity in `L[X,Z]`. It is exactly the certificate Lean should check with `ring_nf` after reducing powers of `a` by `a^3=3a+1`.

In affine form, `(PRES)` is

```text
(A0*x-a)^6
+ 4*(A0*x-a)^5*(x-A0)
+ 10*(A0*x-a)^4*(x-A0)^2
+ 10*(A0*x-a)^3*(x-A0)^3
+ 5*(A0*x-a)^2*(x-A0)^4
+ 2*(A0*x-a)*(x-A0)^5
+ (x-A0)^6
=
q0^6*f(x).                                         (PRES-aff)
```

Consequently

```text
(q0^3*y/(x-A0)^3)^2 = f(sigma_x(x))
```

whenever `y^2=f(x)`.

The involution is not the hyperelliptic involution because its x-coordinate is nontrivial. It commutes with the hyperelliptic involution

```text
h(x,y) = (x,-y).
```

The fixed x-coordinates of `sigma_x` are the roots of


```text

y0^2 + x0*y0 + y0 - x0^3 + x0^2 + 5*x0 - 5.
```

Thus E0 is isomorphic to


The point `(1,0)` becomes `(u,w)=(0,0)`. The line `w=0` has triple intersection at this point, so it has exact order 3.

```text
Bnum = -18*u^2 + 24*u - 8

xi  = Cnum/u^2
```

# 10. The Jacobian splitting

Let

```text
omega1 = dx/y,
omega2 = x*dx/y
```

be the standard basis of regular differentials on C.

On `Qplus`, use

```text
omega_plus = dt/(2*s).
```

A direct differentiation gives

```text
pi_plus^*(omega_plus)
  = (x-rp)/(4*q0^2) * dx/y.                        (D+)
```

On `Qminus`, use

```text
omega_minus = dT/(2*S).
```

Then

```text
pi_minus^*(omega_minus)
  = -(x-rm)/(4*q0^2) * dx/y.                       (D-)
```

Relative to the basis `(omega1,omega2)`, the coefficient matrix is

```text
1/(4*q0^2) * [[-rp,  1],
              [ rm, -1]].
```

Its determinant is

```text
(rp-rm)/(16*q0^4)
= 2*q0/(16*q0^4)
= 1/(8*q0^3),
```

which is nonzero.

Therefore the pullbacks of the elliptic differentials form a basis of `H^0(C,Omega^1)`. In characteristic zero, the homomorphism induced by pullback,

```text
Eplus × Eminus -> J(C)_L,
```

has an isomorphism on tangent spaces and finite kernel. It is an isogeny. Equivalently, the dual pushforward map

```text
J(C)_L -> Eplus × Eminus
```

is an isogeny.

Using `(ISO+)`, `(ISO-)`, and `(VELU)`, this becomes

```text
J(C)_L ~ E0_L × Ehat0_L ~ E0_L × E0_L.
```

An explicit isogeny in the direction `E0_L^2 -> J(C)_L` is

```text
(P,Q) |-> pi_plus^*(P) + pi_minus^*(phi(Q)).
```

Its dual supplies the requested direction

```text
J(C)_L -> E0_L^2.
```

No genus-2 Mordell-Weil or rank calculation enters this splitting proof.

# 11. Exact field of definition

All coefficients of sigma and both quotient maps belong to L:

```text
A0,q0,rp,rm,hp,hm,mu,c0,c2,c3 in L.
```

In particular, the apparent square root in the Möbius fixed-point calculation is already

```text
sqrt(A0^2-a) = q0 = a^2-1 in L.
```

Thus no quadratic or larger extension is needed.

The involution does not descend to Q. Its unordered pair of fixed x-coordinates has monic polynomial

```text
X^2 - 2*A0*X + a.
```

If sigma were defined over Q, this fixed divisor on the x-line would be Galois-stable over Q, and the monic polynomial would have rational coefficients. But

```text
A0=-a-1 not in Q,
a not in Q.
```

Hence sigma is not defined over Q. Since `[L:Q]=3` is prime, L has no proper intermediate field. Therefore the field of definition of sigma is exactly L.

The same conclusion applies to the full pair of elliptic quotient maps. Their formulas are defined over L, and the Galois conjugates of sigma give the other conjugate non-hyperelliptic involutions.

Therefore L is exactly the elliptic splitting field used here:

```text
L = Q(zeta_9)^+,
[L:Q]=3.
```

# 12. Rank consequence and its precise scope

Because base extension is injective on rational points,

```text
rank_Q J(Q) <= rank_L J(L).
```

The explicit isogeny gives

```text
rank_L J(L) = 2*rank_L E0(L).
```

Hence

```text
rank_Q J(Q) <= 2*rank_L E0(L).                     (RANK)
```

This implication is rigorous once the standard facts that isogenous abelian varieties have equal Mordell-Weil rank and that Mordell-Weil groups are finitely generated are available.

The splitting foundation by itself does not prove `rank E0(L)=0`. That is the one separate global arithmetic input. The rational rank-zero statement `rank E0(Q)=0` does not automatically imply the L-rank-zero statement. A descent over L or another valid rank theorem is still required.

For orientation:

```text
E0(Q)tors = Z/3Z,
E0(L)tors = Z/21Z.
```

The torsion growth is compatible with the conductor-8 base-change curve over the cubic field. It does not affect `(RANK)`.
