# Q3563: `halfPeriod_pos`

## Preferred proof

Use Mathlib’s Bochner integral positivity theorem for nonnegative real-valued integrable functions:

```lean
#check integral_pos_iff_support_of_nonneg_ae
#check integral_eq_zero_iff_of_nonneg_ae
#check integral_nonneg_of_ae
```

For this theorem, take the measure to be `volume.restrict (Ioi e)`. The support has positive restricted measure because every point of `Ioi e` is in the support of `rightIntegrand A B` by `rightIntegrand_pos_of_right`.

```lean
import Mathlib.Analysis.SpecialFunctions.ImproperIntegrals
import FLT.Assumptions.MazurProof.RealTopologyS4

noncomputable section
open Set MeasureTheory
open scoped Topology

namespace MazurProof.RealTopology

theorem halfPeriod_pos
    {A B e : ℝ}
    (hroot : shortCubic A B e = 0)
    (hderiv : 0 < shortCubicDeriv A B e)
    (hposRight : ∀ ⦃x : ℝ⦄, e < x → 0 < shortCubic A B x) :
    0 < halfPeriod A B e := by
  classical
  have hInt : Integrable (rightIntegrand A B) (volume.restrict (Ioi e)) :=
    rightIntegrand_integrableOn_Ioi_root
      (A := A) (B := B) (e := e) hroot hderiv hposRight

  have hnonneg_ae : 0 ≤ᵐ[volume.restrict (Ioi e)] rightIntegrand A B :=
    Eventually.of_forall fun x =>
      rightIntegrand_nonneg (A := A) (B := B) (x := x)

  have hIoi_support : Ioi e ⊆ Function.support (rightIntegrand A B) := by
    intro x hx
    dsimp [Function.support]
    exact (rightIntegrand_pos_of_right
      (A := A) (B := B) (e := e) hposRight hx).ne'

  have hsupport_pos :
      0 < (volume.restrict (Ioi e)) (Function.support (rightIntegrand A B)) := by
    have hIoi_pos : 0 < (volume.restrict (Ioi e)) (Ioi e) := by
      -- `simp` uses measurability of `Ioi` and `Real.volume_Ioi`.
      simp
    exact hIoi_pos.trans_le (measure_mono hIoi_support)

  rw [halfPeriod, sigma]
  exact (integral_pos_iff_support_of_nonneg_ae hnonneg_ae hInt).2 hsupport_pos

end MazurProof.RealTopology
```

## If the `simp` line for restricted measure is brittle

Replace the proof of `hIoi_pos` by the explicit restricted-measure calculation:

```lean
  have hIoi_pos : 0 < (volume.restrict (Ioi e)) (Ioi e) := by
    rw [Measure.restrict_apply measurableSet_Ioi]
    simp
```

If your pinned Mathlib’s `Measure.restrict_apply` rewrites to the opposite intersection order, the same proof still closes with `simp`; it only needs `Ioi e ∩ Ioi e = Ioi e` and `Real.volume_Ioi`.

## Finite-subinterval fallback

If you prefer not to use the full infinite interval measure, use a finite interval inside the support.

```lean
  have hIoo_support : Ioo e (e + 1) ⊆ Function.support (rightIntegrand A B) := by
    intro x hx
    dsimp [Function.support]
    exact (rightIntegrand_pos_of_right
      (A := A) (B := B) (e := e) hposRight hx.1).ne'

  have hIoo_pos : 0 < (volume.restrict (Ioi e)) (Ioo e (e + 1)) := by
    rw [Measure.restrict_apply measurableSet_Ioo]
    have hinter : Ioo e (e + 1) ∩ Ioi e = Ioo e (e + 1) := by
      ext x
      constructor
      · intro hx
        exact hx.1
      · intro hx
        exact ⟨hx, hx.1⟩
    rw [hinter]
    simpa [Real.volume_Ioo] using
      (show (0 : ℝ≥0∞) < ENNReal.ofReal ((e + 1) - e) by norm_num)

  have hsupport_pos :
      0 < (volume.restrict (Ioi e)) (Function.support (rightIntegrand A B)) :=
    hIoo_pos.trans_le (measure_mono hIoo_support)
```

The finite-subinterval route uses these APIs:

```lean
#check Measure.restrict_apply
#check measurableSet_Ioo
#check Real.volume_Ioo
#check measure_mono
```

## Notes

The proof does not need a separate theorem stating that the integral over a positive-measure finite interval is positive. `integral_pos_iff_support_of_nonneg_ae` is exactly the clean API: integrability plus a.e. nonnegativity reduce positivity of the integral to positive measure of the support.
