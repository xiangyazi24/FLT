# N = 35: concrete X₁(35) → X₀(35) → 35a1 reduction

## Executive verdict

There are two separate issues.

1. **The arithmetic endpoint is small and elementary.** A standard model of X₀(35) has a degree-two Atkin–Lehner quotient birational to the rank-zero elliptic curve 35a1. The quotient map, all three rational points of 35a1, and every fiber above them have short explicit formulas. No genus-3 Jacobian descent is needed.

2. **The raw Kubert-to-X₀(35) coordinate bridge is the bulky part.** Starting from

```text
G35(t,X) = 0,
V² = D2(t,X),
```

one must quotient by the degree-12 diamond action and normalize before reaching a convenient genus-3 model. I did not find a published coefficient list for that rational map in Kubert coordinates. It should be generated once by Magma or Sage and then checked by polynomial identities. This is an **explicit-map wall, not a Diophantine wall**.

Thus:

- with the abstract modular interpretation `(E,P35) ↦ (E,<P35>)` available, N = 35 is close to N = 21 and is a days-scale arithmetic proof;
- if the proof must begin with the raw `(t,X,V)` equations and end with one giant ring certificate, the map-generation phase is substantially larger than N = 21, although the resulting certificate is finite and mechanically checkable.

The useful chain is

```text
(t,X,V)  ⇢  (z,w) on X₀(35)  ⇢  (u,v) on C  ⇢  (x,y) on 35a1.
```

The last two arrows are completely explicit below.

## 1. The elliptic target 35a1

### 1.1 Cremona model and Mordell–Weil group

The Cremona model 35a1 is

```text
E: y² + y = x³ + x² + 9x + 1.
```

Its generalized Weierstrass tuple is

```text
[a1,a2,a3,a4,a6] = [0,1,1,9,1].
```

It has conductor 35, Mordell–Weil rank 0, and

```text
E(Q) ≅ Z/3Z.
```

The complete rational point set is

```text
E(Q) = { O, (1,3), (1,-4) }.
```

The two affine points are negatives of one another and have exact order 3.

### 1.2 A rational-3-torsion model

The change of variables

```text
X0 = x - 1,
Y0 = y - 2x - 1
```

takes E to

```text
E0: Y0² + 4 X0 Y0 + 7 Y0 = X0³.
```

The two nonzero torsion points become

```text
(1,3)  ↦  (0,0),
(1,-4) ↦  (0,-7).
```

The tangent `Y0 = 0` has triple contact at `(0,0)`. A convenient Vélu quotient by `<(0,0)>` is

```text
E0': Y0² + 4 X0 Y0 + 7 Y0 = X0³ - 140 X0 - 791,
```

which minimizes to 35a2. A standard rational 3-isogeny descent on `E0 → E0'` gives rank 0.

For a formal build, isolate the arithmetic input as a theorem such as

```lean
-- O is treated separately in the projective model.
theorem rat_points_35a1_affine (x y : ℚ)
    (h : y^2 + y = x^3 + x^2 + 9*x + 1) :
    (x = 1 ∧ y = 3) ∨ (x = 1 ∧ y = -4)
```

The torsion calculation itself is tiny:

```text
#E(F₂) = 3,
#E(F₃) = 3.
```

The prime-to-2 torsion injects at 2, and the prime-to-3 torsion injects at 3. Hence the rational torsion has order dividing 3; the displayed point proves it is exactly Z/3Z. Only the rank upper bound needs descent machinery.

## 2. The exact Kubert source

Put the rational 7-torsion point at the Tate origin. Set

```text
b = t²(t-1),
c = t(t-1).
```

The order-7 Kubert family is

```text
Et: y² + (1+t-t²)xy - t²(t-1)y = x³ - t²(t-1)x²,
P7 = (0,0).
```

The coefficients are

```text
a1 = 1+t-t²,
a2 = -t²(t-1),
a3 = -t²(t-1),
a4 = 0,
a6 = 0,

b2 = t⁴ - 6t³ + 3t² + 2t + 1,
b4 = t²(t-1)(t²-t-1),
b6 = t⁴(t-1)²,
b8 = -t⁶(t-1)³.
```

Define

```text
D2(t,X) = 4X³ + b2 X² + 2b4 X + b6,

D3(t,X) = 3X⁴ + b2 X³ + 3b4 X² + 3b6 X + b8,

H4(t,X) = 2X⁶ + b2 X⁵ + 5b4 X⁴ + 10b6 X³ + 10b8 X²
          + (b2 b8 - b4 b6)X + (b4 b8 - b6²).
```

Then the fifth division polynomial is

```text
G35(t,X) = D2(t,X)² H4(t,X) - D3(t,X)³ = ψ5(Et;X).
```

For an actual rational point `Q5 = (X,Y)` on Et, put

```text
V = 2Y + a1 X + a3.
```

The exact same-curve 5-plus-7 system is

```text
G35(t,X) = 0,
V² = D2(t,X),
Δ(Et) ≠ 0.
```

The square equation is essential: `G35 = 0` alone only gives a rational x-coordinate and may represent a 5-torsion point defined over a quadratic extension.

From P7 and Q5, the subgroup

```text
C35 = <P7,Q5>
```

is cyclic of order 35 and is defined over Q. Abstractly this already gives

```text
(Et,C35) ∈ X₀(35)(Q).
```

This moduli-theoretic arrow is the cleanest route if a usable definition of X₀(35) is available.

## 3. A standard explicit model of X₀(35)

Use the genus-3 hyperelliptic model

```text
H: w² = f(z),

f(z) = z⁸ - 4z⁷ - 6z⁶ - 4z⁵ - 9z⁴
       + 4z³ - 6z² + 4z + 1.
```

The four rational cusps are

```text
(0,1), (0,-1), ∞₊, ∞₋.
```

The polynomial satisfies

```text
f(z) = z⁸ f(-1/z).
```

Hence H has the involution

```text
ι(z,w) = (-1/z, w/z⁴).
```

On this chosen model, ι is one of the two proper Atkin–Lehner involutions w5 and w7. The precise label depends on the selected isomorphism from Magma's `SmallModularCurve(35)` model and is irrelevant to the exclusion. The hyperelliptic involution is w35; composing it with ι gives the other proper Atkin–Lehner involution.

## 4. Explicit Atkin–Lehner quotient H → C

The invariant functions are

```text
u = z - 1/z,
v = w/z².
```

They satisfy

```text
C: v² = F(u),
F(u) = u⁴ - 4u³ - 2u² - 16u - 19.
```

The certifying identity is simply

```text
f(z) = z⁴ F(z - 1/z).
```

The quartic factors at its rational point:

```text
F(u) = (u+1)(u³ - 5u² + 3u - 19).
```

Thus C is a genus-1 curve with rational point `(-1,0)`.

---

## 5. Explicit birational map C → 35a1

Set

```text
q(u) = (u+1)(u-3) = u² - 2u - 3,
d = v - q(u).
```

On `d ≠ 0`, define

```text
x = 1 - 14(u+1)/d,
y = 3 + 14(u²-1)/d.
```

Then `(x,y)` lies on 35a1. The key certificate is

```text
d³ [ y² + y - x³ - x² - 9x - 1 ]
  = 98(u+1)² [ v² - F(u) ].
```

This is directly suitable for `field_simp` followed by `ring`.

For `x ≠ 1`, an inverse on the corresponding affine open is

```text
u = 1 + (3-y)/(x-1),
d = -14(u+1)/(x-1),
v = d + q(u).
```

The map extends over the missing points on the smooth projective models.

## 6. Direct map H → 35a1

For implementation, eliminate u and v. Define

```text
B(z) = z² + z - 1,

A(z) = (z²+z-1)(z²-3z-1)
     = z⁴ - 2z³ - 5z² + 2z + 1,

C0(z) = z⁴ - 3z² + 1,

D(z,w) = w - A(z).
```

Then

```text
x = 1 - 14 z B(z) / D(z,w),
y = 3 + 14 C0(z) / D(z,w).
```

Put

```text
XN = D - 14 z B,
YN = 3D + 14 C0.
```

Thus `x = XN/D` and `y = YN/D`. The complete denominator-cleared certificate is

```text
D YN² + D² YN - XN³ - D XN² - 9D² XN - D³
  = 98 B(z)² [ w² - f(z) ].
```

There is also a short denominator certificate:

```text
f(z) - A(z)² = -28 z³ B(z).
```

Consequently, if `z,w ∈ Q`, `w² = f(z)`, `z ≠ 0`, and `D(z,w) = 0`, then `B(z) = 0`. But

```text
z² + z - 1 = 0
```

has discriminant 5 and no rational root. Therefore every rational noncuspidal affine point of H lies in the open set where the displayed map to 35a1 is defined. The case `z = 0` consists exactly of the two finite rational cusps.

This is a complete hand-sized implementation of `X₀(35) → 35a1`.

## 7. Rational points and fiber exclusion

Because

```text
E(Q) = { O, (1,3), (1,-4) },
```

the smooth projective quartic has exactly

```text
C(Q) = { ∞₊, ∞₋, (-1,0) }.
```

Choose the labels of its two points at infinity so that

```text
∞₋     ↦ O,
∞₊     ↦ (1,3),
(-1,0) ↦ (1,-4).
```

### 7.1 Fibers over the two infinite points

Their inverse images on H are precisely the four rational cusps

```text
(0,1), (0,-1), ∞₊, ∞₋.
```

### 7.2 Fiber over `(-1,0)`

A lift must satisfy

```text
u = z - 1/z = -1,
```

so

```text
z² + z - 1 = 0.
```

Thus

```text
z = (-1 ± √5)/2,
w = 0.
```

These are quadratic CM points of discriminant -35, not rational points. Therefore

```text
X₀(35)(Q) = { (0,1), (0,-1), ∞₊, ∞₋ },
```

and every rational point is cuspidal.

A rational point of exact order 35 would make its cyclic subgroup into a noncuspidal rational point of X₀(35), giving the contradiction.

## 8. What the raw `(t,X,V) → (z,w)` bridge must contain

This is the one coefficient list that is not present as a small published formula in the sources I found.

The normalization of

```text
G35(t,X) = 0,
V² = D2(t,X)
```

encodes ordered 5- and 7-generators. Passing to X₀(35) quotients by

```text
(Z/35Z)× / {±1},
```

which has order 12. This degree-12 quotient explains why the analogue of the N = 21 map is much larger.

### 8.1 Natural generator-independent invariants

Let `Q5 = (X,Y)`, where

```text
Y = (V - a1 X - a3)/2.
```

Use the invariant functions

```text
J0 = j(Et),
J5 = j(Et / <Q5>),
J7 = j(Et / <P7>).
```

They do not depend on the choices of generators of the 5- and 7-subgroups and therefore descend to X₀(35). Generically the triple records the elliptic curve together with its two coprime cyclic subgroups, hence the cyclic 35-subgroup.

The first is compact:

```text
J0 = c4(t)³ / Δ(t),
c4 = b2² - 24b4.
```

The other two can be generated by Vélu formulas from small kernel polynomials.

For the 5-kernel, put

```text
Phi2(t,X) = X⁴ - b4 X² - 2b6 X - b8,
X2 = x(2Q5) = Phi2(t,X) / D2(t,X).
```

The two nonzero x-coordinates modulo sign are X and X2, so a denominator-cleared kernel polynomial is

```text
K5(Z) = (Z-X)(D2 Z - Phi2).
```

For the 7-kernel in Tate normal form, the three nonzero x-coordinates modulo sign are `0,b,c`, so

```text
K7(Z) = Z(Z-b)(Z-c).
```

Applying Vélu to K5 and K7 gives explicit rational functions `J5(t,X)` and `J7(t)`. This is cleaner than expanding all diamond automorphisms by hand.

### 8.2 Required generated output

The CAS stage should output rational functions

```text
z = Z1(t,X,V) / Z0(t,X,V),
w = W1(t,X,V) / W0(t,X,V)
```

identifying the diamond fixed field with the function field of H. They can be obtained by any of these equivalent procedures:

1. compute the fixed field of the diamond action on the normalization of the Kubert system;
2. compute J0, J5, J7, match them with the corresponding degeneracy-map functions on Magma's `SmallModularCurve(35)`, and transfer through `IsIsomorphic` to H;
3. match sufficiently long q-expansions by linear algebra, then verify the recovered rational functions algebraically.

The Magma database already stores the X₀(35) model, degeneracy maps, q-expansions, and Atkin–Lehner maps. The relevant setup is structurally

```magma
X0 := SmallModularCurve(35);
w5 := AtkinLehnerInvolution(X0,35,5);
w7 := AtkinLehnerInvolution(X0,35,7);

Qz<z> := PolynomialRing(Rationals());
H := HyperellipticCurve(
  z^8 - 4*z^7 - 6*z^6 - 4*z^5 - 9*z^4
      + 4*z^3 - 6*z^2 + 4*z + 1);

tf, phi := IsIsomorphic(X0,H);
assert tf;
```

The construction of the normalized Kubert map can use fixed fields, function-field homomorphisms, or interpolation in J0, J5, J7.

### 8.3 Exact certificate shape

Let `fh(Z1,Z0) = Z0^8 f(Z1/Z0)` be the homogenization of f. The bridge should include a saturation factor S and polynomials R1 and R2 satisfying

```text
S^m [ W1² Z0⁸ - W0² fh(Z1,Z0) ]
  = R1(t,X,V) G35(t,X)
    + R2(t,X,V) [ V² - D2(t,X) ].
```

This is the precise N = 35 analogue of a certificate such as

```text
t^8 (t-1)^8 R21 = q7^4 G21.
```

The multiplier `S^m` records only excluded cusp, discriminant, and coordinate-denominator loci. Lean does not trust the CAS; it verifies this polynomial identity.

### 8.4 Homogeneous composition with the small H → E certificate

Once Z0, Z1, W0, W1 are known, define

```text
Bh = Z1² + Z1 Z0 - Z0²,

Ah = Z1⁴ - 2 Z1³ Z0 - 5 Z1² Z0² + 2 Z1 Z0³ + Z0⁴,

Ch = Z1⁴ - 3 Z1² Z0² + Z0⁴,

Dh = W1 Z0⁴ - W0 Ah,

Xh = Dh - 14 W0 Z1 Z0 Bh,
Yh = 3 Dh + 14 W0 Ch.
```

Then

```text
x = Xh/Dh,
y = Yh/Dh,
```

and the universal composite identity is

```text
Dh Yh² + Dh² Yh - Xh³ - Dh Xh² - 9 Dh² Xh - Dh³
  = 98 W0 Bh² [ W1² Z0⁸ - W0² fh(Z1,Z0) ].
```

Combining this with the bridge certificate gives the final direct ideal-membership identity

```text
S^m * EllipticNumerator(t,X,V)
  = Astar * G35 + Bstar * (V²-D2)
```

without rediscovering or expanding the elliptic quotient map.

## 10. Difficulty versus N = 15, 21, 18

### Arithmetic difficulty

Once the X₀(35) model is accepted, 35 is **closer to 15 and 21 than to 18**:

- the decisive quotient is elliptic;
- the target has rank 0 and only three rational points;
- the only finite noncuspidal-looking quotient point fails to lift over Q because `z²+z-1 = 0`;
- no genus-2, genus-3, or genus-25 Jacobian arithmetic is required.

### Coordinate difficulty

It is not a literal repeat of N = 21. For 21, X₀(21) itself is genus 1. For 35, the raw Tate route includes

1. normalization of the ψ5-plus-square system;
2. a degree-12 diamond quotient to X₀(35);
3. a degree-2 Atkin–Lehner quotient.

The last step is tiny; the first coordinate transformation can have large numerators and denominators.

### Does the same 2-adic-separatedness template apply?

**At the finite-point and fiber layer, yes.** Once the point lands on a rank-zero elliptic target, the N = 21 architecture applies: enumerate the finite Mordell–Weil group, separate the target points, and exclude each fiber by explicit polynomial conditions.

**For the rank-zero proof, do not force a specifically 2-adic descent.** The target has rational 3-torsion, and the natural small descent is the 3-isogeny descent above. If the N = 21 framework treats the finite Mordell–Weil list as certified input, it can be reused unchanged.

### Scheduling verdict

- **With abstract modular curves or an imported X₀(35) model:** days-scale after N = 15 and N = 21.
- **With a pre-generated Kubert bridge:** also days-scale for Lean verification; all downstream identities are mechanical.
- **Requiring Codex alone to discover the Kubert bridge by hand:** a poor dispatch. Expect a multi-day CAS reconnaissance plus formal verification, potentially week-scale depending on coefficient size.

The final verdict is:

> N = 35 has an elementary rank-zero elliptic-quotient proof, but the direct Kubert-coordinate realization is not presently a hand-sized N21-style identity. Generate that bridge once, certify it by ideal membership, and the rest is short.

## 11. Acceptance checklist for the generated bridge

Require the CAS job to deliver:

1. explicit integer polynomials Z0, Z1, W0, W1;
2. a saturation factor S, with every factor assigned to a cusp, discriminant, or coordinate-denominator locus;
3. explicit R1 and R2 for the bridge identity;
4. factorizations of the exceptional loci `Z0 W0 Dh S = 0` modulo the two source equations;
5. images of all source cusps, so no projective chart is omitted;
6. verification that the chosen proper AL involution becomes `(z,w) ↦ (-1/z,w/z⁴)` or its composition with the hyperelliptic involution;
7. images of `O, (1,3), (1,-4)`, with their fibers factored over Q;
8. a machine-readable generated-data file separate from the human derivation.

With those artifacts, the Lean side is almost entirely `field_simp`, `ring`, denominator nonvanishing, and the certified rational-point list for 35a1.
