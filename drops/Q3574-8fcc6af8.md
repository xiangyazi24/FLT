# Q3574: first S6 lemmas for theta additivity

Start with one-variable branch charts, not the global homomorphism. The local object is the real lift of the additivity gap on a chart where a moving point P(x), a fixed affine point Q, and the sum P(x)+Q all stay on chosen branches. Prove that this real lift has derivative zero, then prove it is constant on finite intervals by interval FTC, and only after that coerce equal real lifts to AddCircle.

## First branch layer

Define an auxiliary two-case type RealBranch with lower and upper. Define the branch y-coordinate as minus sqrt(shortCubic A B x) on lower and plus sqrt(shortCubic A B x) on upper. Define the branch theta lift as sigma A B x on lower and 2 * halfPeriod A B e - sigma A B x on upper.

First easy theorem: thetaRep_eq_branch_thetaLift. For an affine kernel point P.1 = Point.some x y hpt with e < x, prove either 0 <= y and thetaRep P is the upper branch lift, or y < 0 and thetaRep P is the lower branch lift. This is just by_cases hy : 0 <= y, using thetaRep_some_upper and thetaRep_some_lower.

## Sigma derivative layer

Prove sigma derivative through finite interval integrals. First show local equality near x: if e < a and a < x, then sigma A B u equals sigma A B a minus the interval integral from a to u of rightIntegrand A B for all u sufficiently near x. Use eventually_gt_nhds, rightIntegrand_integrableOn_Ioi_root, and intervalIntegral.integral_interval_add_Ioi.

Then prove hasDerivAt_sigma_of_right: for e < x, HasDerivAt (sigma A B) (-(rightIntegrand A B x)) x. Choose a = (e+x)/2. Apply intervalIntegral.integral_hasDerivAt_right to the finite interval integral and transfer across the eventual equality.

Probe these names in the local build: intervalIntegral.integral_interval_add_Ioi, intervalIntegral.integral_hasDerivAt_right, intervalIntegral.integral_hasDerivAt_left, ContinuousAt.stronglyMeasurableAtFilter, rightIntegrand_continuousOn_Ioi_of_right, and rightIntegrand_intervalIntegrable_of_right_of_le.
