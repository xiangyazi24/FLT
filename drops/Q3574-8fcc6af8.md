# Q3574: first S6 lemmas for theta additivity

Start with one-variable branch charts, not the global homomorphism. The local object is the real lift of the additivity gap on a chart where a moving point P(x), a fixed affine point Q, and the sum P(x)+Q all stay on chosen branches. Prove that this real lift has derivative zero, then prove it is constant on finite intervals by interval FTC, and only after that coerce equal real lifts to AddCircle.

## First branch layer

Define an auxiliary two-case type RealBranch with lower and upper. Define the branch y-coordinate as minus sqrt(shortCubic A B x) on lower and plus sqrt(shortCubic A B x) on upper. Define the branch theta lift as sigma A B x on lower and 2 * halfPeriod A B e - sigma A B x on upper.

First easy theorem: thetaRep_eq_branch_thetaLift. For an affine kernel point P.1 = Point.some x y hpt with e < x, prove either 0 <= y and thetaRep P is the upper branch lift, or y < 0 and thetaRep P is the lower branch lift. This is just by_cases hy : 0 <= y, using thetaRep_some_upper and thetaRep_some_lower.

## Sigma derivative layer

Prove sigma derivative through finite interval integrals. First show local equality near x: if e < a and a < x, then sigma A B u equals sigma A B a minus the interval integral from a to u of rightIntegrand A B for all u sufficiently near x. Use eventually_gt_nhds, rightIntegrand_integrableOn_Ioi_root, and intervalIntegral.integral_interval_add_Ioi.

Then prove hasDerivAt_sigma_of_right: for e < x, HasDerivAt (sigma A B) (-(rightIntegrand A B x)) x. Choose a = (e+x)/2. Apply intervalIntegral.integral_hasDerivAt_right to the finite interval integral and transfer across the eventual equality.

Probe these names in the local build: intervalIntegral.integral_interval_add_Ioi, intervalIntegral.integral_hasDerivAt_right, intervalIntegral.integral_hasDerivAt_left, ContinuousAt.stronglyMeasurableAtFilter, rightIntegrand_continuousOn_Ioi_of_right, and rightIntegrand_intervalIntegrable_of_right_of_le.

## Algebraic addition chart

Wrap the existing point-addition formulas with chart names addSlopeChart, addXChart, and addYChart, where the moving point is (x, RealBranch.yCoord br A B x) and Q is fixed as (xQ,yQ). Probe WeierstrassCurve.Affine.Point.add_some, WeierstrassCurve.Affine.Point.add_of_Y_eq, slope, addX, addY, shortW_point_add_some, and shortW_point_add_vertical.

The first algebra theorem should only extract coordinates of P(x)+Q from the existing formula. After that, prove the invariant differential identity: under curve equations and denominator side conditions, deriv (fun u => addXChart br A B e xQ yQ u) x times the inverse of addYChart at x equals the inverse of the moving branch y-coordinate. This should be a pure calculation after expanding slope, addX, and addY, using field_simp and ring_nf.

Concrete theorem name to target: addXChart_deriv_mul_inv_addYChart_eq_inv_branchY.

Useful calculus probes for the chart formulas: HasDerivAt.sqrt, Real.hasDerivAt_sqrt, HasDerivAt.inv, HasDerivAt.div, HasDerivAt.mul, HasDerivAt.comp, hasDerivAt_pow, and hasDerivAt_id.

## Branch derivative signs

Define branchThetaDerivFactor lower = -1 and upper = 1. Prove branchThetaDerivFactor_mul_rightIntegrand_eq_inv_yCoord: for e < x, branchThetaDerivFactor br * rightIntegrand A B x equals the inverse of RealBranch.yCoord br A B x. This is a two-case proof using Real.sqrt_pos.2 (hposRight hx).

Then prove branch lift derivative: HasDerivAt (RealBranch.thetaLift br A B e) (branchThetaDerivFactor br * rightIntegrand A B x) x. The lower branch is hasDerivAt_sigma_of_right; the upper branch is the derivative of 2*T - sigma.

## Local additivity lift

Define localAdditivityLift brP brR A B e xQ yQ thetaQ x as the theta lift of the result branch at addXChart, minus the theta lift of the moving branch at x, minus thetaQ.

The chart-local derivative theorem should assume the invariant differential identity and prove HasDerivAt localAdditivityLift 0 x by the chain rule. Keep all branch compatibility facts as explicit hypotheses at first; later they can be discharged by finite branch cases.

## Derivative zero to local constancy

Do not introduce manifold theory. Use finite interval FTC. The helper theorem to add is: if F is continuous on Icc a b and HasDerivAt F 0 x for every x in Ioo a b, then F b = F a.

Probe these names: intervalIntegral.integral_eq_sub_of_hasDerivAt, intervalIntegral.integral_deriv_eq_sub', intervalIntegral.integral_const, intervalIntegral.intervalIntegrable_const, and ContinuousOn.intervalIntegrable_of_Icc. The proof is to apply FTC to show F b - F a is the integral of the zero derivative, hence zero.

Once real lifts are equal, equality in AddCircle is immediate by coercion: from h : F b = F a, the goal ((F b : ℝ) : AddCircle p) = ((F a : ℝ) : AddCircle p) closes by simpa [h].
