# Cyclic order 16: the correct Kubert relation, the missing square, and why the elliptic target does not apply

## Verdict

There are three separate facts here.

1. A rational point of exact order \(16\) gives the usual genus-\(2\) modular curve \(X_1(16)\). In Tate normal form the canonical raw Kubert equation is the polynomial \(F_{16}(r,s)=0\) displayed below. This uses only the cyclic point; it does **not** use full rational \(2\)-torsion.

2. The point \(8P\) supplies one rational root of the \(2\)-division cubic. It does **not** make the residual quadratic split. The condition called `eta^2 = discQ16bc b c` is, up to the square normalization used in the file, precisely the condition that the residual quadratic split, hence that the other two \(2\)-torsion points are rational. It is an extra \(\mathbf Z/2\) hypothesis.

3. There is no nonconstant rational map from the cyclic modular curve \(X_1(16)\) to

\[
E_0:\qquad w^2=u^3-u^2-u.
\]

In particular, there cannot be the requested cyclic-case birational formulas to \(E_0\). The existing theorem `EN16_point_of_Phi16_and_disc` lives on the **double cover** obtained by adjoining the square root of the residual \(2\)-torsion discriminant. It cannot be descended after deleting `eta`.

The correct cyclic bridge is instead the explicit birational equivalence with the genus-\(2\) curve

\[
C_{16}:\qquad V^2=U(U^2+1)(U^2+2U-1).
\]

I give the complete formulas below, including a particularly simple inverse chart from the raw Kubert coordinates. They are suitable for `field_simp`/`ring` proofs.

## 1. Tate normal form and the exact order-\(16\) relation

Let

\[
E_{b,c}:\quad y^2+(1-c)xy-by=x^3-bx^2,\qquad P=(0,0).
\]

For a point of order \(>3\), the usual Tate-normal-form change of variables is defined over the ground field. Thus a rational point \(P\) of exact order \(16\) can be put in this form over \(\mathbf Q\), without choosing any second point of order \(2\).

The discriminant is

\[
\Delta(b,c)
 =b^3\bigl(16b^2-8bc^2-20bc+b+c(c-1)^3\bigr).
\]

The first multiples are

\[
P=(0,0),\qquad 2P=(b,bc),\qquad 3P=(c,b-c).
\]

Consequently, for an exact \(16\)-torsion point,

\[
b\ne0,\qquad c\ne0,\qquad b\ne c.
\]

Introduce the standard raw Kubert coordinates

\[
r=rac bc,\qquad s=rac{c^2}{b-c}.
\]

Equivalently,

\[
c=s(r-1),\qquad b=rs(r-1).
\]

### The raw equation

The correct square-free exact-order component is

\[
\boxed{\begin{aligned}
F_{16}(r,s)={}&r^3s^2-4r^3s+2r^3
 +3r^2s^2+2r^2s-2r^2\\
&-rs^5+4rs^4-10rs^3+6rs^2-3rs+r+s^4.
\end{aligned}}
\]

For \(\Delta(b,c)\ne0\), with \(b=rs(r-1)\) and \(c=s(r-1)\), Sutherland's exact-order proposition says

\[
P=(0,0)	ext{ has exact order }16
\quad\Longleftrightarrow\quad
F_{16}(r,s)=0.
\]

This is stronger than merely saying that \(16P=0\). In the construction, the factors

\[
s,\qquad r-1,\qquad F_8(r,s)=rs-2r+1
\]

are removed before taking the square-free order-\(16\) component. Thus \(F_{16}=0\) is not the order-\(8\) component with a different name.

One way to derive it is to use \(9P=-7P\), hence \(x(9P)=x(7P)\). The relevant formulas are

\[
x(7P)=
 rac{rs(r-1)(s-1)(rs-2r+1)}{(r-s)^2},
\]

\[
x(9P)=
 rac{s(r-1)(rs-2r+1)(rs^2-3rs+r+s^2)}
 {(r-s^2+s-1)^2}.
\]

After clearing denominators and saturating by the degenerate and lower-order factors, the remaining square-free factor is exactly \(F_{16}\).

### A direct polynomial in the Tate coefficients \(b,c\)

If the repository wants a denominator-free polynomial directly in the coefficients of \(E_{b,c}\), define

\[
\widehat\Phi_{16}(b,c)
 :=c^3(b-c)^5
 F_{16}\left(\frac bc,\frac{c^2}{b-c}\right).
\]

This is the following integral polynomial:

\[
\boxed{\begin{aligned}
\widehat\Phi_{16}(b,c)={}&-bc^{12}
 +(b-c)(4b+c)c^{10}
 -10b(b-c)^2c^8\\
&+b(b-c)^3(b^2+3bc+6c^2)c^4\\
&-b(b-c)^4(4b^2-2bc+3c^2)c^2\\
&+b(b-c)^5(2b^2-2bc+c^2).
\end{aligned}}
\]

Hence, under \(c\ne0\) and \(b-c\ne0\),

\[
\widehat\Phi_{16}(b,c)=0
\quad\Longleftrightarrow\quad
F_{16}\left(\frac bc,\frac{c^2}{b-c}\right)=0.
\]

There is another useful normalization. Put \(d=b/c\), while retaining \(c\) as the Tate coefficient. Define

\[
\begin{aligned}
\Psi_{16}(d,c)={}&-dc^5+(d-1)(4d+1)c^4
 -10d(d-1)^2c^3\\
&+d(d-1)^3(d^2+3d+6)c^2\\
&-d(d-1)^4(4d^2-2d+3)c\\
&+d(d-1)^5(2d^2-2d+1).
\end{aligned}
\]

Then the normalization identity is simply

\[
\boxed{
\Psi_{16}(d,s(d-1))=(d-1)^5F_{16}(d,s).
}
\]

This is a plain polynomial identity and should close with `ring`. Also

\[
\widehat\Phi_{16}(b,c)=c^8\Psi_{16}(b/c,c).
\]

Therefore the quickest way to audit the existing repository definition is:

* unfold `Phi16`;
* compare it to either \(\widehat\Phi_{16}\) or \(\Psi_{16}\);
* prove the normalization by `field_simp` using `c ≠ 0` and `b - c ≠ 0`, followed by `ring`.

If the current `Phi16` still contains the factor corresponding to \(F_8\), then it is an unsaturated \(16P=0\) equation, not the exact-order \(X_1(16)\) equation.

A direct Lean-style definition of the canonical raw polynomial is:

```lean
def F16rs (r s : ℚ) : ℚ :=
    r^3 * s^2 - 4 * r^3 * s + 2 * r^3
  + 3 * r^2 * s^2 + 2 * r^2 * s - 2 * r^2
  - r * s^5 + 4 * r * s^4 - 10 * r * s^3
  + 6 * r * s^2 - 3 * r * s + r + s^4
```

## 2. What \(8P\) gives, and what it does not give

For a general Weierstrass equation, set

\[
Y=2y+a_1x+a_3.
\]

For the Tate model,

\[
a_1=1-c,\qquad a_2=-b,\qquad a_3=-b,\qquad a_4=a_6=0,
\]

so

\[
Y^2=f_2(X):=4X^3+B_2X^2+2B_4X+B_6,
\]

where

\[
B_2=(1-c)^2-4b,\qquad B_4=b(c-1),\qquad B_6=b^2.
\]

The roots of \(f_2\) are the \(x\)-coordinates of the three nonzero geometric \(2\)-torsion points.

For a cyclic point \(P\) of order \(16\), the point \(8P\) is rational. Thus

\[
\alpha:=x(8P)\in\mathbf Q
\]

is one rational root of \(f_2\). In the raw coordinates one may take

\[
\alpha=
rac{r(r-1)(r-s)(r-s^2+s-1)}{(rs-2r+1)^2}.
\]

The denominator is nonzero on the exact order-\(16\) locus because \(rs-2r+1=0\) is the order-\(8\) component.

Now factor

\[
f_2(X)=(X-\alpha)Q_{16}(X),
\]

where \(Q_{16}\) is quadratic over \(\mathbf Q\). The cyclic datum proves only that this factorization has coefficients in \(\mathbf Q\). It does not prove that \(Q_{16}\) has a rational root.

For a separable cubic,

\[
\operatorname{Disc}(f_2)
 =Q_{16}(\alpha)^2\operatorname{Disc}(Q_{16}).
\]

Therefore, in square classes,

\[
[\operatorname{Disc}(f_2)]
 =[\operatorname{Disc}(Q_{16})].
\]

Moreover,

\[
\operatorname{Disc}(Q_{16})	ext{ is a square in }\mathbf Q
\]

if and only if the residual quadratic splits over \(\mathbf Q\), if and only if the other two nonzero \(2\)-torsion points are rational. In that case one has an independent point \(T\in E[2](\mathbf Q)\) with \(T\ne8P\), and

\[
\langle P,T\rangle\simeq \mathbf Z/16\mathbf Z\times\mathbf Z/2\mathbf Z.
\]

Thus, up to whatever square factor was cleared in `discQ16bc`, the hypothesis

```text
eta^2 = discQ16bc b c
```

is exactly the **extra full-\(2\)-torsion condition**. It is not a consequence of the existence of \(8P\).

A particularly relevant counterexample is the proposed target curve itself:

\[
w^2=u(u^2-u-1).
\]

It has the rational \(2\)-torsion root \(u=0\), but the residual quadratic \(u^2-u-1\) has discriminant \(5\), which is not a square in \(\mathbf Q\). One rational root of a cubic plainly does not make its discriminant a square.

### What replaces the square condition in the cyclic case?

There is no additional square condition on the cyclic moduli problem. The cyclic moduli curve is already a genus-\(2\) double cover of a projective line. Its intrinsic square coordinate is

\[
V^2=U(U^2+1)(U^2+2U-1),
\]

as derived below. This square is obtained by normalizing the order-\(16\) equation itself. It is unrelated to splitting the residual \(2\)-division quadratic.

## 3. Why the requested map to \(w^2=u^3-u^2-u\) cannot exist

The smooth projective completion of the cyclic order-\(16\) locus is \(X_1(16)\), of genus \(2\). The target \(E_0\) is an elliptic curve, of genus \(1\). Hence the two curves are not birational.

More strongly, there is no nonconstant rational map

\[
X_1(16)\dashrightarrow E_0
\]

over \(\mathbf Q\).

Here is a quick arithmetic proof. Since \(E_0\) is proper, a rational map from the smooth projective curve \(X_1(16)\) extends to a morphism. Choose a rational cusp as base point and translate \(E_0\) so that this cusp maps to the identity. A nonconstant morphism would induce a nonzero homomorphism

\[
J_1(16)\longrightarrow E_0.
\]

Its image would be all of \(E_0\), so \(E_0\) would be an isogeny quotient of \(J_1(16)\).

The modular curve \(X_1(16)\), and therefore \(J_1(16)\), has good reduction at every odd prime. In particular it has good reduction at \(5\), and every abelian quotient of it has good reduction at \(5\).

For

\[
E_0:\quad w^2=u^3-u^2-u,
\]

the standard invariants are

\[
c_4=64,\qquad \Delta=80,\qquad
j=\frac{c_4^3}{\Delta}=\frac{16384}{5}.
\]

The \(j\)-invariant is not \(5\)-adically integral, so \(E_0\) has bad reduction at \(5\). This contradicts its being an isogeny quotient of \(J_1(16)\).

Consequently, no collection of rational functions in the pure cyclic Tate data can produce a nonconstant point of \(E_0\) and be verified by a global `ring` identity. Such formulas would define precisely the impossible rational map above.

This also explains the role of the existing theorem. The locus

\[
F_{16}(r,s)=0,\qquad \eta^2=\operatorname{discQ16bc}(r,s)
\]

is a different curve: a degree-\(2\) cover of \(X_1(16)\) carrying the choice of the extra rational \(2\)-torsion. That cover may map to \(E_0\). The map need not, and in this case cannot, descend through the deck involution \(\eta\mapsto-\eta\).

## 4. The correct explicit cyclic bridge: Tate data to the genus-\(2\) \(X_1(16)\)

### 4.1 Sutherland's optimized plane model

An optimized affine model of \(Y_1(16)\) is

\[
C_{\mathrm{opt}}:\qquad
 y^2+(x^3+x^2-x+1)y+x^2=0.
\]

A point \((x,y)\) on this curve maps to the raw Kubert coordinates by

\[
\boxed{
 r=\frac{x^2-xy+y^2+y}{x^2+x-y-1},\qquad
 s=\frac{x-y}{x+1}.
}
\]

Then

\[
c=s(r-1),\qquad b=rs(r-1).
\]

These are the standard \(X_1(16)\to\) Tate-normal-form formulas.

### 4.2 A simple inverse chart from \((r,s)\)

The inverse can be written much more simply than a generic elimination formula. Put

\[
q=1-s,\qquad
 a=r-1+s-s^2,\qquad
 e=2r-rs-1.
\]

On the chart \(a\ne0\), define

\[
\boxed{
 x=\frac{(1-s)(r-s)}{r-1+s-s^2},\qquad
 y=(1-s)x-s.
}
\]

The following identities are direct polynomial/rational identities:

\[
x+1=\frac e a,
\]

\[
x-y=s(x+1),
\]

\[
x^2+x-y-1=\frac{(1-s)^3e}{a^2},
\]

\[
x^2-xy+y^2+y
 =r(x^2+x-y-1),
\]

and, most importantly,

\[
\boxed{
 a^4\bigl(y^2+(x^3+x^2-x+1)y+x^2\bigr)
 =(1-s)^2eF_{16}(r,s).
}
\]

Thus \(F_{16}(r,s)=0\) gives a point on \(C_{\mathrm{opt}}\), and the two displayed forward fractions recover the original \(r,s\), whenever their denominators are nonzero.

This is an especially convenient Lean implementation: prove the boxed numerator identity once by `field_simp` and `ring`, then rewrite by `hF : F16rs r s = 0`.

A staged definition looks like:

```lean
def a16 (r s : ℚ) : ℚ := r - 1 + s - s^2
def e16 (r s : ℚ) : ℚ := 2*r - r*s - 1

def x16 (r s : ℚ) : ℚ :=
  (1 - s) * (r - s) / a16 r s

def y16 (r s : ℚ) : ℚ :=
  (1 - s) * x16 r s - s
```

The exceptional equations \(s=1\), \(a=0\), or \(e=0\) are boundary-chart equations. On \(F_{16}=0\), their surviving points are cuspidal/degenerate. For example,

\[
F_{16}(r,1)=-(r-1)^3.
\]

For an exact order-\(16\) point they are excluded by nonsingularity and exactness. In Lean it is reasonable to prove the three denominator lemmas separately, by substituting the vanishing equation into `F16rs` and the Tate discriminant.

### 4.3 Completion of the square

Let

\[
A(x)=x^3+x^2-x+1,\qquad z=2y+A(x).
\]

Then

\[
\begin{aligned}
z^2
 &=A(x)^2-4x^2\\
 &=(x^2-1)(x^2+1)(x^2+2x-1).
\end{aligned}
\]

The verification is just

\[
z^2-(x^2-1)(x^2+1)(x^2+2x-1)
 =4\bigl(y^2+A(x)y+x^2\bigr).
\]

### 4.4 The standard hyperelliptic model

Set

\[
\boxed{
 U=\frac{1-x}{1+x},\qquad
 V=\frac{2z}{(1+x)^3}.
}
\]

Then

\[
\boxed{
V^2=U(U^2+1)(U^2+2U-1).
}
\]

The inverse formulas are

\[
\boxed{
 x=\frac{1-U}{1+U},\qquad
 z=\frac{4V}{(1+U)^3},\qquad
 y=\frac{z-(x^3+x^2-x+1)}2.
}
\]

Combining the two stages gives an entirely explicit rational-function bridge from the Tate data:

\[
r=\frac bc,\qquad s=\frac{c^2}{b-c},
\]

\[
x=\frac{(1-s)(r-s)}{r-1+s-s^2},\qquad
 y=(1-s)x-s,
\]

\[
z=2y+x^3+x^2-x+1,\qquad
 U=\frac{1-x}{1+x},\qquad
 V=\frac{2z}{(1+x)^3}.
\]

The first coordinate simplifies to

\[
\boxed{
U=\frac{rs-1+2s-2s^2}{2r-rs-1}.
}
\]

For Lean, keeping \(V\) in the staged form through \(x,y,z\) is preferable to expanding its numerator. Every verification is then a small `field_simp` followed by `ring`.

### Suggested algebraic lemma sequence

```lean
-- 1. Raw order-16 point gives the optimized model.
lemma opt_identity (r s : ℚ) (ha : a16 r s ≠ 0) :
    (a16 r s)^4 *
      (y16 r s ^ 2
       + ((x16 r s)^3 + (x16 r s)^2 - x16 r s + 1) * y16 r s
       + (x16 r s)^2)
      = (1 - s)^2 * e16 r s * F16rs r s := by
  field_simp [x16, y16, a16, e16, ha]
  ring

-- 2. Complete the square.
lemma complete_square_identity (x y : ℚ) :
    let A := x^3 + x^2 - x + 1
    (2*y + A)^2 - (x^2 - 1)*(x^2 + 1)*(x^2 + 2*x - 1)
      = 4 * (y^2 + A*y + x^2) := by
  dsimp
  ring

-- 3. Apply the Möbius change of variables.
-- Prove after field_simp [hx1] and ring.
```

The first proof script may need only minor syntactic adjustment depending on the repository's simplifier normal form; the mathematical identity is the boxed identity above.

## 5. Cusps on the correct cyclic model

For

\[
C_{16}:\quad V^2=U(U^2+1)(U^2+2U-1),
\]

the open modular curve \(Y_1(16)\) is obtained by deleting the points whose \(U\)-coordinate satisfies

\[
U(U-1)(U+1)(U^2+1)(U^2-2U-1)(U^2+2U-1)=0,
\]

and by deleting the point(s) over \(U=\infty\).

Thus the geometric cusp \(U\)-values are

\[
\boxed{
U=\infty,\quad 0,\quad \pm1,\quad
U^2+1=0,\quad U^2-2U-1=0,\quad U^2+2U-1=0.
}
\]

The rational cusps are the six rational points

\[
\boxed{
\infty,\qquad (0,0),\qquad (1,2),\ (1,-2),\qquad
(-1,2),\ (-1,-2).
}
\]

In the optimized \((x,y)\)-chart, the finite rational cusp representatives include

\[
(1,-1),\qquad (0,0),\qquad (0,-1),\qquad (-1,-1),
\]

with the remaining two represented at infinity in that plane model.

There are no corresponding “target \(u\)-values” on \(w^2=u^3-u^2-u\) for the pure cyclic problem, because there is no cyclic-case map to that elliptic curve. The \(U\)-values above are the cusp values for the correct genus-\(2\) obstruction.

Determining that \(C_{16}(\mathbf Q)\) consists only of these cusps is the genuine downstream theorem needed to exclude rational cyclic \(16\)-torsion. A proof about rational points on \(E_0\) cannot replace it without the extra discriminant-square hypothesis.

## 6. Recommended change to the Lean architecture

The clean separation is:

1. **Cyclic layer.** From a rational exact order-\(16\) point, construct Tate \(b,c\), prove the exact raw equation \(F_{16}(r,s)=0\), and construct a noncuspidal rational point on

   \[
   V^2=U(U^2+1)(U^2+2U-1).
   \]

2. **Extra-\(2\)-torsion layer.** Retain the existing theorem

   ```text
   EN16_point_of_Phi16_and_disc
   ```

   only for the stronger hypotheses `Phi16 = 0` and `eta^2 = discQ16bc`. Its input moduli problem is the full-\(2\)-torsion cover, not \(X_1(16)\).

3. Do not add a lemma claiming that `x(8 • P)` makes `discQ16bc` a square. The correct lemma says only that the \(2\)-division cubic has one rational root and therefore factors as a rational linear factor times a rational quadratic.

A suitable new theorem should look conceptually like

```lean
theorem X1N16_point_of_Phi16
    (b c : ℚ)
    (hdisc : tateDisc b c ≠ 0)
    (h16 : Phi16 b c = 0)
    (hexact : -- exclusions if Phi16 was not already saturated) :
    ∃ U V : ℚ,
      V^2 = U * (U^2 + 1) * (U^2 + 2*U - 1) ∧
      U * (U - 1) * (U + 1)
        * (U^2 + 1) * (U^2 - 2*U - 1) * (U^2 + 2*U - 1) ≠ 0 := by
  ...
```

The formulas in Section 4 supply the body of this theorem. The remaining work is denominator/cusp bookkeeping, not another elliptic-curve birational transformation.
