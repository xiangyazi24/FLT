# 1. Correct curve data

Write

```text
E  : Y^2 = X^3 - 31 X^2 + 240 X,
E' : V^2 = T^3 + 62 T^2 + T.
```

For a curve

```text
y^2 = x^3 + a*x^2 + b*x
```

with rational `(0,0)`-torsion, the standard `2`-isogenous curve is

```text
v^2 = t^3 - 2*a*t^2 + (a^2 - 4*b)*t.
```

Here `a=-31`, `b=240`, and `a^2-4*b=1`, giving the displayed `E'`.
On the non-kernel affine charts the isogenies are

```text
phi(X,Y) =
  (Y^2/X^2, Y*(240-X^2)/X^2),

phihat(T,V) =
  (V^2/(4*T^2), V*(1-T^2)/(8*T^2)).
```

The omitted values are the usual values at infinity and at `(0,0)`.  Direct substitution proves that these maps land on the opposite curves and that

```text
phihat (phi P) = 2*P.
```

The homogeneous Kummer quartics are

```text
E, class d:
  R^2 = d*M^4 - 31*M^2*N^2 + (240/d)*N^4,

E', class d:
  R^2 = d*M^4 + 62*M^2*N^2 + (1/d)*N^4.
```

The finite local conclusions are the previously found ones:

```text
alpha(E(Q))   = {1,3,5,15},
alpha'(E'(Q)) = {1}.
```

The classes on `E` may be represented by

```text
O, (12,12), (20,20), (15,0),
```

respectively.  The second image equality implies that `phi` is surjective; the two exact-kernel statements then give

```text
ker(alpha) = 2*E(Q).
```

Thus every rational point has a decomposition

```text
P = T + 2*Q
```

with `T` in the known eight-point subgroup

```text

     (0,0), (15,0), (16,0),

```

Every point of `H` is killed by `4`.

# 2. Good model at `2`

Use

```text
X = 4*x + 12,
Y = 8*y + 4*x + 4.
```

The inverse formulas are

```text
x = (X-12)/4,
y = (Y-X+8)/8.
```

The transformed equation is

```text
E0 : y^2 + x*y + y = x^3 + x^2 - 5*x + 2.
```

The following unconditional identity is the robust Lean bridge:

```lean

lemma n15_good_model_identity (x y : ℚ) :
    (8*y + 4*x + 4)^2
      - (4*x + 12) * ((4*x + 12) - 15) * ((4*x + 12) - 16)
    = 64 * (y^2 + x*y + y - (x^3 + x^2 - 5*x + 2)) := by
  ring
```

The discriminants are

```text
Δ(E)  = 2^12 * 3^2 * 5^2,
Δ(E0) = 3^2 * 5^2 = 225.
```

Hence `E0` has good reduction at `2`, but bad reduction at `5`.
Modulo `2`, the affine equation is

```text
y^2 + x*y + y = x^3 + x^2 + x.
```

Its affine points are

```text
(0,0), (0,1), (1,1),
```

and there is one point at infinity.  Therefore `E0(F_2)` has order and exponent `4`.
A finite regression check is:


The local formal parameter at infinity is

```text
z(P) = -x(P)/y(P).
```

For the elliptic formal group over `Z_2`, multiplication by two has the form

```text
[2](Z) = 2*Z + Z^2*G(Z),
```

with `G` integral.  Thus for a nonzero point in the formal kernel,

```text
v2(z(P)) >= 1
```

and, provided `2P` is nonzero,

```text
v2(z(2P)) >= v2(z(P)) + 1.
```

This is enough for separatedness.  Equality is not needed.
What is needed is an actual Lean bridge proving that the rational-function parameter on the point group is the evaluation of the formal-group parameter and that every intermediate double stays in the kernel.

# 3. The generic weak-descent and separatedness core

The following is the reusable group-theoretic core.  It contains no finite-generation assumption.

```lean
import Mathlib

set_option maxHeartbeats 0

namespace N15RankZeroCore

/-- An element admitting a `2^n`-th root for every `n`. -/
def InfinitelyTwoDivisible
    {G : Type*} [AddCommGroup G] (P : G) : Prop :=
  ∀ n : ℕ, ∃ Q : G, (2 ^ n) • Q = P

/-- The output of the explicit two-isogeny/Kummer descent. -/
structure WeakTwoDescent (G : Type*) [AddCommGroup G] where
  H : AddSubgroup G
  killH : ∀ T : H, 4 • (T : G) = 0
  split : ∀ P : G, ∃ T : H, ∃ Q : G, P = (T : G) + 2 • Q

namespace WeakTwoDescent

/-- Iterating weak descent makes `4P` divisible by every power of two.
The witness is retained in the form `4Q`, which is important when putting it
in a reduction kernel. -/
lemma four_roots
    {G : Type*} [AddCommGroup G]
    (D : WeakTwoDescent G) (P : G) :
    ∀ n : ℕ, ∃ Q : G, (2 ^ n) • (4 • Q) = 4 • P := by
  intro n
  induction n with
  | zero =>
      exact ⟨P, by simp⟩
  | succ n ih =>
      rcases ih with ⟨Q, hQ⟩
      rcases D.split Q with ⟨T, R, hQR⟩
      have h4Q : 4 • Q = 2 • (4 • R) := by
        rw [hQR, nsmul_add, D.killH T]
        simp [nsmul_nsmul, Nat.mul_comm, Nat.mul_left_comm, Nat.mul_assoc]
      refine ⟨R, ?_⟩
      calc
        (2 ^ n.succ) • (4 • R) = (2 ^ n) • (2 • (4 • R)) := by
          simp [pow_succ, nsmul_nsmul, Nat.mul_comm, Nat.mul_left_comm,
            Nat.mul_assoc]
        _ = (2 ^ n) • (4 • Q) := by rw [← h4Q]
        _ = 4 • P := hQ

lemma four_infinitelyTwoDivisible
    {G : Type*} [AddCommGroup G]
    (D : WeakTwoDescent G) (P : G) :
    InfinitelyTwoDivisible (4 • P) := by
  intro n
  rcases D.four_roots P n with ⟨Q, hQ⟩
  exact ⟨4 • Q, hQ⟩

end WeakTwoDescent

/-- The exact local facts needed from the concrete good model at two. -/
structure TwoAdicKernel
    (G R : Type*) [AddCommGroup G] [AddCommGroup R]
    (red : G →+ R) where
  z : red.ker → ℚ
  z_pos : ∀ {P : red.ker}, P ≠ 0 → 1 ≤ padicValRat 2 (z P)
  double_growth : ∀ {P : red.ker}, P ≠ 0 → 2 • P ≠ 0 →
    padicValRat 2 (z P) + 1 ≤ padicValRat 2 (z (2 • P))

namespace TwoAdicKernel

lemma val_growth
    {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    {red : G →+ R}
    (F : TwoAdicKernel G R red)
    {Q : red.ker} :
    ∀ n : ℕ, (2 ^ n) • Q ≠ 0 →
      (n : ℤ) + 1 ≤ padicValRat 2 (F.z ((2 ^ n) • Q)) := by
  intro n
  induction n with
  | zero =>
      intro hQ
      simpa using F.z_pos hQ
  | succ n ih =>
      intro hfinal
      let S : red.ker := (2 ^ n) • Q
      have hpow : (2 ^ n.succ) • Q = 2 • S := by
        simp [S, pow_succ, nsmul_nsmul, Nat.mul_comm, Nat.mul_left_comm,
          Nat.mul_assoc]
      have h2S : 2 • S ≠ 0 := by
        intro hz
        apply hfinal
        rw [hpow]
        exact hz
      have hS : S ≠ 0 := by
        intro hz
        apply h2S
        rw [hz]
        simp
      have hIH : (n : ℤ) + 1 ≤ padicValRat 2 (F.z S) := by
        simpa [S] using ih hS
      have hdouble := F.double_growth hS h2S
      rw [hpow]
      omega

/-- A formal-kernel point divisible by every power of two is zero. -/
theorem eq_zero_of_infinitelyTwoDivisible
    {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    {red : G →+ R}
    (F : TwoAdicKernel G R red)
    {P : red.ker}
    (hdiv : InfinitelyTwoDivisible P) :
    P = 0 := by
  by_contra hP
  let v : ℤ := padicValRat 2 (F.z P)
  have hv1 : 1 ≤ v := by
    simpa [v] using F.z_pos hP
  have hv0 : 0 ≤ v := by omega
  let n : ℕ := v.toNat + 1
  rcases hdiv n with ⟨Q, hQ⟩
  have hnonzero : (2 ^ n) • Q ≠ 0 := by
    rw [hQ]
    exact hP
  have hgrowth := F.val_growth (Q := Q) n hnonzero
  rw [hQ] at hgrowth
  fold v at hgrowth
  have hvnat : (v.toNat : ℤ) = v := Int.toNat_of_nonneg hv0
  dsimp [n] at hgrowth
  omega

end TwoAdicKernel

/-- All concrete data required to turn weak descent into exponent four. -/
structure RankZeroData
    (G R : Type*) [AddCommGroup G] [AddCommGroup R] where
  descent : WeakTwoDescent G
  red : G →+ R
  killRed : ∀ r : R, 4 • r = 0
  formal : TwoAdicKernel G R red

namespace RankZeroData

/-- Weak descent plus two-adic separatedness proves that every global point is
killed by four. -/
theorem four_nsmul_eq_zero
    {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    (D : RankZeroData G R) (P : G) :
    4 • P = 0 := by
  let P4 : D.red.ker :=
    ⟨4 • P, by
      change D.red (4 • P) = 0
      simpa using D.killRed (D.red P)⟩
  have hdiv : InfinitelyTwoDivisible P4 := by
    intro n
    rcases D.descent.four_roots P n with ⟨Q, hQ⟩
    let Q4 : D.red.ker :=
      ⟨4 • Q, by
        change D.red (4 • Q) = 0
        simpa using D.killRed (D.red Q)⟩
    refine ⟨Q4, ?_⟩
    apply Subtype.ext
    change (2 ^ n) • (4 • Q) = 4 • P
    exact hQ
  have hP4 : P4 = 0 := D.formal.eq_zero_of_infinitelyTwoDivisible hdiv
  have hval := congrArg Subtype.val hP4
  simpa [P4] using hval

end RankZeroData

end N15RankZeroCore
```

# 5. Correct final exhaustion after exponent four

Once the concrete `RankZeroData` exists, the generic theorem gives

```text
4*P = O
```

for every `P in E(Q)`.  At that point an odd-prime cardinality argument is unnecessary: the seven affine points can be obtained directly from the duplication formula.

For an affine point `(X,Y)` with `Y != 0`,

```text
x(2P) = (X^2 - 240)^2 / (4*Y^2).
```

Since `4P=O`, the point `2P` is one of

```text
O, (0,0), (15,0), (16,0).
```

The finite cases are controlled by the following polynomial identities.

```lean
lemma n15_double_to_15_identity (X : ℚ) :
    (X^2 - 240)^2 - 60 * X * (X-15) * (X-16)
      = (X^2 - 30*X + 240)^2 := by
  ring

lemma n15_double_to_16_identity (X : ℚ) :
    (X^2 - 240)^2 - 64 * X * (X-15) * (X-16)
      = (X-12)^2 * (X-20)^2 := by
  ring
```

The cases are:

* `2P=O`: `Y=0`, so `X=0`, `15`, or `16`.
* `2P=(0,0)`: `X^2=240`, impossible over `Q`; equivalently `240` is not a rational square.
* `2P=(15,0)`: `X^2-30X+240=0`, but this is `(X-15)^2+15=0`, impossible.
* `2P=(16,0)`: `(X-12)^2*(X-20)^2=0`, so `X=12` or `20`; the curve equation gives `Y=±12` or `±20`.

This produces precisely

```text
(0,0), (15,0), (16,0),
(12,12), (12,-12),
(20,20), (20,-20).
```

If one nevertheless wants a finite-field finish, the correct prime is `7`:

```lean
abbrev N15F7 := ZMod 7

def n15EF7 (p : N15F7 × N15F7) : Prop :=
  p.2^2 = p.1 * (p.1-15) * (p.1-16)

def n15EAffineF7 : Finset (N15F7 × N15F7) :=
  Finset.univ.filter n15EF7

example : n15EAffineF7.card = 7 := by
  native_decide
```

Adding the point at infinity gives `#E(F_7)=8`.  The reductions of the known rational points are exactly

```text
O,
(0,0), (1,0), (2,0),
(5,5), (5,2),
(6,6), (6,1).
```

By contrast, modulo `5` the equation is singular at `(0,0)` and has only four affine solutions; there is no valid good-reduction injection theorem to invoke there.
