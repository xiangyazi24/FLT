# Order 21: the square condition is unnecessary, but the curve `G21 = 0` is not `X₁(21)`

## Executive verdict

**Question 1: yes.** The affine rational points of

```text
G21 t X = 0
```

are exactly

```text
(t,X) = (0,0), (0,-1/3), (1,0), (1,-1/3).
```

Consequently

```lean
t ≠ 0 → t ≠ 1 → G21 t X = 0 → False
```

is true, and the hypothesis `Z ^ 2 = D21 t X` is not needed.

There are two important corrections to the proposed route.

1. The normalization of `G21 = 0` is **not** `X₁(21)` and is not birational to an elliptic curve. It is the intermediate modular curve

   ```text
   X_Δ(21),  Δ = {±1, ±8} ⊂ (Z/21Z)×,
   ```

   of genus `3`. The square condition `Z² = D21` restores a choice of generator of the rational order-3 subgroup and gives the genus-5 `X₁(21)` cover.

2. The elliptic curve

   ```text
   21a1 : y^2 + x*y = x^3 - 4*x - 1
   ```

   has

   ```text
   21a1(Q) ≅ Z/2Z × Z/4Z,
   ```

   not `Z/8Z`. It nevertheless has exactly eight rational points. The proof below determines all eight without a Mordell--Weil or rank axiom.

Thus option (a) in the question is impossible literally: a genus-3 curve cannot be birational to `21a1`. The correct cheap proof is a **degree-3 quotient**

```text
X_Δ(21)  --->  X₀(21) = 21a1
```

followed by an explicit check that none of the four noncuspidal rational points of `X₀(21)` lifts to a rational order-7 Kubert parameter `t`.

I did not claim to run a Python/Sage brute-force scan, since the delivery instructions explicitly prohibit the sandbox/code interpreter. The calculation below is stronger than a small-height search: it exhausts `X₀(21)(Q)` and every rational lift, and hence proves the displayed four-point list at **all** heights.

# 1. What `G21` and `D21` actually encode

Put

```text
b = t^2*(t-1),       c = t*(t-1).
```

The order-7 Tate normal form is

```text
E_t : y^2 + (1-c)*x*y - b*y = x^3 - b*x^2,
```

with `(0,0)` the distinguished point of order `7`. Its standard invariants are

```text
b2 = t^4 - 6*t^3 + 3*t^2 + 2*t + 1,
b4 = t^5 - 2*t^4 + t^2,
b6 = t^6 - 2*t^5 + t^4,
b8 = -t^9 + 3*t^8 - 3*t^7 + t^6.
```

Hence

```text
G21(t,X) = 3*X^4 + b2*X^3 + 3*b4*X^2 + 3*b6*X + b8
```

is exactly the third division polynomial `ψ₃(X)`.

A rational root `X` of `G21(t,-)` therefore gives a rational **cyclic subgroup** of order `3`: the two geometric points above `X` may be conjugate. It does not yet give a rational generator.

Completing the square with

```text
Z = 2*y + (1-c)*X - b
```

gives

```text
Z^2 = 4*X^3 + b2*X^2 + 2*b4*X + b6 = D21(t,X).
```

Thus:

```text
G21 = 0             rational order-3 subgroup,
G21 = 0, Z^2 = D21 rational order-3 generator.
```

A rational order-7 generator together with a rational order-3 subgroup gives a rational cyclic subgroup of order `21`, hence a rational point of `X₀(21)`. The diamond operators preserving the order-7 generator and allowed to negate the order-3 generator form

```text
Δ = {±1, ±8}.
```

Jeon--Kim's genus table gives `g(X_Δ(21)) = 3`; this is the precise modular interpretation of the normalization of `G21 = 0`.

# 2. Three small polynomial certificates for the quotient map

These identities are useful because they replace a large elimination against `G21` by three `ring` proofs.

Define

```text
M21(t,X) := 6*X^2 + b2(t)*X + b4(t).
```

Also put

```text
h7(t)    := t^3 - 8*t^2 + 5*t + 1,
d7(t)    := t*(t-1),
disc7(t) := t^7*(t-1)^7*h7(t),
q7(t)    := t^2 - t + 1,
p7(t)    := t^6 - 11*t^5 + 30*t^4 - 15*t^3 - 10*t^2 + 5*t + 1,
c4_7(t)  := q7(t)*p7(t).
```

Then, identically in `t,X`, one has

```text
(1) M21^2 - (12*X + b2)*D21 = -4*G21.
```

The discriminant certificate is

```text
(2) M21^3 - 27*D21^2 - disc7
      = (b2^2 - 36*b4 - 12*b2*X - 72*X^2)*G21.
```

Finally,

```text
(3) M21*(M21^3 - 24*D21^2) - c4_7*D21^2
      = -4*(M21^2 + (12*X+b2)*D21)*G21.
```

The conceptual universal identities behind these are, for

```text
D = 4*x^3 + B2*x^2 + 2*B4*x + B6,
M = 6*x^2 + B2*x + B4,
ψ3 = 3*x^4 + B2*x^3 + 3*B4*x^2 + 3*B6*x + B8,
```

with `4*B8 = B2*B6-B4^2`,

```text
M^2 - (12*x+B2)*D = -4*ψ3,
M^3 - 27*D^2 - Δ = (B2^2-36*B4-12*B2*x-72*x^2)*ψ3,
M*(M^3-24*D^2)-c4*D^2 = -4*(M^2+(12*x+B2)*D)*ψ3.
```

All three are direct `ring` identities.

Under `G21 t X = 0`, they imply

```text
M21^3 - 27*D21^2 = disc7(t),
M21*(M21^3 - 24*D21^2) = c4_7(t)*D21^2.
```

They also give the denominator facts cleanly. If `D21 = 0`, identity (1) gives `M21 = 0`, and then identity (2) gives `disc7 = 0`. For rational `t ≠ 0,1`, this is impossible: the remaining factor `h7` is a monic integral cubic with constant term `1`, and its only possible rational roots are `±1`, neither of which is a root. Therefore

```text
D21(t,X) ≠ 0,
M21(t,X)^3 - 27*D21(t,X)^2 ≠ 0.
```

These are the exact hypotheses needed for the rational quotient functions below.

A Lean shape is:

```lean
lemma M21_sq_identity (t X : ℚ) :
    M21 t X ^ 2 - (12*X + b2_21 t) * D21 t X = -4 * G21 t X := by
  ring

lemma M21_disc_identity (t X : ℚ) :
    M21 t X ^ 3 - 27 * D21 t X ^ 2 - disc7 t =
      (b2_21 t ^ 2 - 36*b4_21 t - 12*b2_21 t*X - 72*X^2) * G21 t X := by
  ring

lemma M21_c4_identity (t X : ℚ) :
    M21 t X * (M21 t X ^ 3 - 24 * D21 t X ^ 2)
        - c4_7 t * D21 t X ^ 2 =
      -4 * (M21 t X ^ 2 + (12*X+b2_21 t)*D21 t X) * G21 t X := by
  ring
```

After these lemmas, every use of `hG : G21 t X = 0` is a rewrite or a one-line `linear_combination`.

# 3. Explicit rational functions from `(t,X)` to the `X₀(21)` fiber product

## 3.1 The order-7 parameter

Set

```text
s = h7(t) / (t*(t-1)),
S = 49/s = 49*t*(t-1)/h7(t).
```

The two small identities

```text
h7^2 + 13*h7*d7 + 49*d7^2 = q7^3,
h7^2 +  5*h7*d7 +    d7^2 = p7
```

are again `ring`.

It follows that the source `j`-invariant of the order-7 Tate family is

```text
J7small(s)
  = (s^2+13*s+49)*(s^2+5*s+1)^3/s
  = c4_7(t)^3/disc7(t).
```

For compatibility with the standard `X₀(21)` formulas below, use the Atkin--Lehner reciprocal parameter `S=49/s` and define

```text
J7src(S)
  = (S^2+13*S+49)*(S^2+245*S+2401)^3/S^7.
```

Direct substitution gives

```text
J7src(49/s) = J7small(s).
```

## 3.2 The order-3 subgroup parameter

Let

```text
q3 = M21(t,X)^3 / D21(t,X)^2.
```

For the order-3 Tate normal form `y²+a1*x*y+a3*y=x³`, the invariant `a1^3/a3` has

```text
j = q3*(q3-24)^3/(q3-27).
```

Certificates (2) and (3) prove, without choosing a square root of `D21`, that

```text
q3*(q3-24)^3/(q3-27) = c4_7(t)^3/disc7(t).
```

Define the classical `X₀(3)` Hauptmodul

```text
m = 729*D21(t,X)^2 /
      (M21(t,X)^3 - 27*D21(t,X)^2).
```

Then

```text
q3 = 27*(m+27)/m
```

and therefore

```text
J3src(m) = (m+27)*(m+243)^3/m^3
         = c4_7(t)^3/disc7(t).
```

Consequently the explicit pair

```text
S(t)   = 49*t*(t-1)/h7(t),
m(t,X) = 729*D21(t,X)^2 /
           (M21(t,X)^3 - 27*D21(t,X)^2)
```

satisfies

```text
J7src(S(t)) = J3src(m(t,X)).
```

This is the algebraic degree-3 quotient from the genus-3 curve `G21=0` to the standard fiber-product model of `X₀(21)`. Notice that it uses `D21` only as a polynomial value; it does **not** require a rational `Z` with `Z²=D21`.

A denominator-cleared fiber equation is

```text
Fiber21(S,m) :=
  m^3 * (S^2+13*S+49) * (S^2+245*S+2401)^3
  - S^7 * (m+27) * (m+243)^3 = 0.
```

The proof of `Fiber21 (S t) (m t X) = 0` should be staged through the three syzygies, not proved by expanding the final numerator from scratch.

# 4. An explicit `X₀(21)` model and its map to `21a1`

A convenient genus-one model is

```text
C21 : R^2 = r^4 - 6*r^3 - 17*r^2 - 6*r + 1.          (4.1)
```

This is the `N=21` model in Mark van Hoeij's machine-readable `X0N/Parametrization` table.

Define

```text
A(r) = r^4 - 6*r^3 - 3*r^2 - 6*r + 1,
B(r) = r^2 - 3*r + 1,
N(r) = 1 - 7*r + 7*r^3 - r^4,
P(r) = r^2 - 4*r + 1.
```

On the chart `r ≠ 0`, the source order-7 and source order-3 parameters are

```text
S = (A(r) + B(r)*R)/(2*r),
m = (N(r) + P(r)*R)^2/(4*r).                         (4.2)
```

Changing `R` to `-R` simultaneously swaps the two isogenous endpoint parameters.

The following denominator-free relations are useful for Lean:

```text
F7(r,S) =
    S*r^4 - (6*S+49)*r^3 - 3*S*r^2
      - (S^2+6*S)*r + S,
```

and

```text
K(r) = r^8 - 14*r^7 + 49*r^6 + 14*r^5 - 154*r^4
         + 14*r^3 + 49*r^2 - 14*r + 1,

F3(r,m) = r*m^2 - K(r)*m + 729*r^7.
```

Substitution of (4.2), followed by (4.1), gives

```text
F7(r,S)=0,
F3(r,m)=0.
```

Conversely, away from the cusps, `r` is the unique common root of `F7(-,S)` and `F3(-,m)`, and then

```text
R = (2*r*S - A(r))/B(r).                             (4.3)
```

For rational `r`, `B(r) ≠ 0`: a rational root of the monic polynomial `r²-3r+1` would be `±1`, and neither works.

## Recommended Lean certificate for the fiber-product normalization

Do not hand-maintain a single enormous expanded `(S,m) ↦ r` fraction. Generate the first nonzero subresultant of `F7` and `F3` with respect to `r`. It is linear:

```text
L1(S,m)*r + L0(S,m).
```

Store `L0,L1` as coefficient arrays and store the Bezout certificate

```text
L1(S,m)*r + L0(S,m)
  = U(r,S,m)*F7(r,S) + V(r,S,m)*F3(r,m).             (4.4)
```

Then define

```text
r = -L0(S,m)/L1(S,m)
```

on the noncuspidal chart and prove (4.1)--(4.3) by `field_simp`, `linear_combination`, and `ring`.

A reproducible CAS generation script is only:

```sage
R.<r,S,m> = PolynomialRing(QQ, order='lex')
F7 = S*r^4 - (6*S+49)*r^3 - 3*S*r^2 - (S^2+6*S)*r + S

       + 14*r^3 + 49*r^2 - 14*r + 1
F3 = r*m^2 - K*m + 729*r^7
subs = F7.subresultants(F3, r)
[q for q in subs if q.degree(r) == 1]
```

The expanded coefficients are purely mechanical data. I am deliberately not inventing them without running the prohibited computation environment. Equations (4.1)--(4.4) specify exactly what should be generated and what Lean must verify.

## 4.1 Small birational map from the quartic to `21a1`

For `r ≠ 0`, put

```text
U = (R - 1 + 3*r)/r^2,
V = 2*(U^2-1)*r + 6*(1-U).
```

Substituting `R = 1-3*r+U*r²` into (4.1) gives

```text
(U^2-1)*r^2 + 6*(1-U)*r + 2*(U+13) = 0.             (4.5)
```

The discriminant of this quadratic in `r` is

```text
V^2 = -4*(U-1)*(2*U+5)*(U+7).                       (4.6)
```

Now set

```text
u = -2*U - 6,
v = V.
```

Then

```text
v^2 = (u+1)*(u-8)*(u+8).                            (4.7)
```

Finally define

```text
xE = u/4 = -(U+3)/2,
yE = (v-u)/8 = (V+2*U+6)/8.
```

A direct `ring` computation turns (4.7) into

```text
21a1 : yE^2 + xE*yE = xE^3 - 4*xE - 1.              (4.8)
```

On the inverse chart `xE ≠ -1,-2`, the formulas are particularly small:

```text
r = (yE - xE - 3)/((xE+1)*(xE+2)),
U = -2*xE - 3,
R = 1 - 3*r + U*r^2.                                (4.9)
```

The points with `xE=-1` or `xE=-2` are handled as the finite exceptional chart and the two points at infinity of the quartic.

Every identity in this subsection is a `field_simp` followed by `ring`; no modular-form theorem is needed once (4.1) is accepted.

# 5. Axiom-free determination of `21a1(Q)`

The complete list is

```text

(-1,2), (-1,-1),

```

The first three affine points in the second line are the three nonzero points of order `2`. The other four affine points have order `4`. Thus the group is `Z/2 × Z/4`.

Here is a proof that does not assume Mordell--Weil finite generation or a database rank calculation.

```text
          = x0*(x0-9)*(x0+7).                       (5.2)
```

The inverse is

```text
xE = (x0-1)/4,
```

The eight points (5.1) become

## 5.2 Explicit 2-isogeny descent

For

```text
E(a,B) : y^2 = x^3 + a*x^2 + B*x
```

the standard 2-isogenous curve is

```text
E'(a,B) : Y^2 = X^3 - 2*a*X^2 + (a^2-4*B)*X.
```

Here `a=-2`, `B=-63`, so

```text
E' : Y^2 = X^3 + 4*X^2 + 256*X.                     (5.4)
```

The coordinate maps are

```text
φ(x,y) = (y^2/x^2, y*(-63-x^2)/x^2),
φhat(X,Y) = (Y^2/(4*X^2), Y*(256-X^2)/(8*X^2)),
```

with the usual special values at `O` and the kernel points. Direct substitution proves

```text
φhat ∘ φ = [2].
```

For `y²=x³+a*x²+B*x`, use the squareclass map

```text
α(O)=1,
α((0,0))=B,
α((x,y))=[x] in Q×/Q×².
```

A squarefree class `d | B` is represented exactly when the quartic covering

```text
N^2 = d*U^4 + a*U^2*V^2 + (B/d)*V^4               (5.5)
```

has a primitive integral solution. The kernel is the image of the dual isogeny.

### Descent on `E`

The possible squarefree classes are

```text
±1, ±3, ±7, ±21.
```

The four classes

```text
1, -3, -7, 21
```

are represented by the torsion points with `x0=9,-3,0,21` respectively.

The four other classes are impossible. Their covering equations are

```text
d=-1 : N^2 =  -U^4 - 2*U^2*V^2 + 63*V^4,
d= 3 : N^2 = 3*U^4 - 2*U^2*V^2 - 21*V^4,
d= 7 : N^2 = 7*U^4 - 2*U^2*V^2 -  9*V^4,
d=-21: N^2 =-21*U^4 - 2*U^2*V^2 +  3*V^4.
```

For primitive `U,V`, if exactly one is even, the right side is `3` or `7` modulo `8`, hence not a square. Thus both are odd. For odd `U,V`, every one of the four right sides is `12` modulo `16`, again impossible.

Therefore

```text
im(α_E) = {1,-3,-7,21}.                             (5.6)
```

This finite residue check is ideal for a `ZMod 16` lemma or `native_decide`.

### Descent on `E'`

The possible squarefree classes are

```text
±1, ±2.
```

The classes `-1` and `-2` give negative-definite right sides over `R`, hence are impossible.

For `d=2`, equation (5.5) is

```text
N^2 = 2*U^4 + 4*U^2*V^2 + 128*V^4.                 (5.7)
```

Modulo `8`, `U` must be even. Primitivity makes `V` odd. Write `U=2*u`, `N=4*n`; then

```text
n^2 = 2*u^4 + u^2*V^2 + 8*V^4.
```

Modulo `8`, `u` must also be even. Write `u=2*w`, `n=2*z`; then

```text
z^2 = 8*w^4 + w^2*V^2 + 2*V^4,
```

whose right side is `2`, `3`, or `6` modulo `8`, never a square. Hence

```text
im(α_E') = {1}.                                     (5.8)
```

From the kernel descriptions, (5.8) gives

```text
E'(Q) = φ(E(Q)),
```

and hence

```text
ker(α_E) = φhat(E'(Q)) = [2]E(Q).
```

Together with (5.6), this proves that `E(Q)/2E(Q)` has exactly four classes, all represented by points in the explicit eight-point subgroup `T` from (5.3).

## 5.3 Closing the descent without Mordell--Weil

One still has to rule out a nonzero infinitely 2-divisible subgroup. This can be done locally and does not require finite generation.

Use the original minimal model (4.8). Its discriminant is

```text
3^4 * 7^2,
```

so it has good reduction at `2`. Direct enumeration gives

```text
#E(F_2)=4.
```

Let `E₁(Q₂)` be the kernel of reduction and use the usual formal parameter `T=-x/y` at infinity. The formal multiplication series has

```text
[2](T) = 2*T + terms of degree at least 2
```

with coefficients in `Z₂`. Hence, for `v₂(T) ≥ 1`,

```text
v₂([2](T)) ≥ v₂(T)+1.                               (5.9)
```

If a rational point `P` belongs to `2^n E(Q)` for every `n`, write

```text
P = 2^n Q_n.
```

For `n≥2`, the reduction of `4*Q_n` is zero because `#E(F₂)=4`, so `4*Q_n ∈ E₁(Q₂)`. By (5.9),

```text
P = 2^(n-2)*(4*Q_n)
```

lies in the `(n-1)`-st formal filtration. This for all `n` forces `P=O`. Thus

```text
⋂ n, 2^n E(Q) = {O}.                                (5.10)
```

Now take arbitrary `P∈E(Q)`. Since every class modulo `2E(Q)` is represented by `T`, recursively write

```text
P = T0 + 2*P1,
P1 = T1 + 2*P2,
...
```

The subgroup `T` has exponent `4`, so for every `n≥2`,

```text
P = (T0 + 2*T1) + 2^n*P_n.
```

By (5.10), `P=T0+2*T1∈T`. This proves (5.1) axiom-free.

For Lean, the only non-polynomial local lemma is the very small formal-filtration statement (5.9). It can be proved either from the integral formal-group doubling series or directly from the duplication formula and `padicValRat`. No Mordell--Weil theorem, rank oracle, BSD input, or database certificate occurs.

# 7. None of the four noncuspidal fibers lifts to a rational `t`

Recall

```text
S = 49/s,
s = h7(t)/(t*(t-1)).
```

The set in (6.3) is stable under `x ↦ 49/x`, so it is equivalent to

```text
s ∈ {-2, -8, -49/8, -49/2}.                         (7.1)
```

For a fixed value `s`, the equation `h7(t)=s*t*(t-1)` is

```text
t^3 - (s+8)*t^2 + (s+5)*t + 1 = 0.                 (7.2)
```

The four cases are

```text
s=-2    : t^3 - 6*t^2 + 3*t + 1 = 0,
s=-8    : t^3 - 3*t + 1 = 0,
s=-49/8 : 8*t^3 - 15*t^2 - 9*t + 8 = 0,
s=-49/2 : 2*t^3 + 33*t^2 - 39*t + 2 = 0.            (7.3)
```

None has a rational root.

- The first two are monic with constant term `1`; the only possible rational roots are `±1`, and direct substitution rejects both.
- For the third, the rational-root theorem makes the denominator divide `8`, hence it is a unit modulo `5`. Reduction modulo `5` gives

  ```text
  3*T^3 + T + 3,
  ```

  which has no root in `F_5`.
- For the fourth, the denominator divides `2`, and reduction modulo `5` gives

  ```text
  2*T^3 + 3*T^2 + T + 2,
  ```

  which also has no root in `F_5`.

The two finite-field checks can be closed by `native_decide` over `ZMod 5` after the denominator-unit lemma.

Therefore a rational point with `t ≠ 0,1` and `G21 t X=0` cannot exist.

At the two remaining fibers,

```text

```
