# Lean-formalizable exclusion of simultaneous rational 5- and 3-torsion

Let

\[
E_b:\qquad y^2+(1-b)xy-by=x^3-bx^2,
\]

with distinguished point \((0,0)\) of order \(5\), and assume

\[
\Delta_b=b^5(b^2-11b-1)\ne 0.
\]

I will prove directly that there are no \(b,x,y\in\mathbf Q\) satisfying the curve equation and \(\psi_3(b,x)=0\). The useful route is:

1. compute \(\psi_3\);
2. put \(u=x/b\), turning \(\psi_3=0\) into the genus-one quartic
   \[
   w^2=u(u-1)(3u+1)(3u-4);
   \]
3. classify every rational point on that quartic by an explicit \(2\)-isogeny descent on
   \[
   Y^2=X(X-15)(X-16);
   \]
4. check that the four non-boundary rational points of the quartic do not lift to rational \(y\) on \(E_b\).

No database rank computation is used. The only rank conclusion is obtained from the displayed \(2\)-descent and elementary congruences modulo \(8\) and \(16\).

## (a) The division polynomial

For a generalized Weierstrass equation

\[
y^2+a_1xy+a_3y=x^3+a_2x^2+a_4x+a_6,
\]

the standard quantities are

\[
\begin{aligned}
b_2&=a_1^2+4a_2,\\
b_4&=2a_4+a_1a_3,\\
b_6&=a_3^2+4a_6,\\
b_8&=a_1^2a_6+4a_2a_6-a_1a_3a_4+a_2a_3^2-a_4^2.
\end{aligned}
\]

Here

\[
a_1=1-b,\qquad a_2=-b,\qquad a_3=-b,\qquad a_4=a_6=0.
\]

Therefore

\[
\boxed{b_2=b^2-6b+1},
\]

\[
\boxed{b_4=b^2-b},
\]

\[
\boxed{b_6=b^2},
\]

and

\[
\boxed{b_8=-b^3}.
\]

Thus

\[
\begin{aligned}
\psi_3(b,x)
 &=3x^4+b_2x^3+3b_4x^2+3b_6x+b_8\\
 &=\boxed{3x^4+(b^2-6b+1)x^3+3(b^2-b)x^2+3b^2x-b^3}.
\end{aligned}
\]

All of these identities are direct `ring` computations.

## (b) Eliminate \(y\), then normalize \(x\) by \(b\)

### The exact square condition coming from the curve equation

Put

\[
z:=2y+(1-b)x-b.
\]

Completing the square gives the equivalent equation

\[
\boxed{
 z^2=4x^3+(b^2-6b+1)x^2+2(b^2-b)x+b^2.
}
\tag{1}
\]

Conversely, a rational \(z\) satisfying (1) gives

\[
y=\frac{z-(1-b)x+b}{2}\in\mathbf Q.
\]

Thus eliminating \(y\) does **not** produce one polynomial equality in \(b,x\) alone: over \(\mathbf Q\), it produces the assertion that the right side of (1) is a rational square. The projection of the original system to \((b,x)\) is exactly

\[
\psi_3(b,x)=0
\quad\text{and}\quad
4x^3+(b^2-6b+1)x^2+2(b^2-b)x+b^2\in \mathbf Q^{\times 2}\cup\{0\}.
\]

### The decisive substitution \(u=x/b\)

Nonsingularity gives \(b\ne0\). Set

\[
u:=\frac{x}{b},\qquad x=bu.
\]

Substitution into the polynomial from part (a), followed by division by \(b^3\), gives

\[
\boxed{
\frac{\psi_3(b,bu)}{b^3}
 =b^2u^3+3bu^2(u-1)^2+(u-1)^3.
}
\tag{2}
\]

Hence \(\psi_3=0\) is equivalent to

\[
\boxed{b^2u^3+3bu^2(u-1)^2+(u-1)^3=0.}
\tag{3}
\]

Under \(b\ne0\), equation (3) immediately excludes \(u=0\) and \(u=1\).

Regard (3) as a quadratic equation in \(b\). Its discriminant is

\[
\begin{aligned}
D
 &=9u^4(u-1)^4-4u^3(u-1)^3\\
 &=u^3(u-1)^3(9u^2-9u-4)\\
 &=u^3(u-1)^3(3u+1)(3u-4).
\end{aligned}
\]

Define the rational function

\[
\boxed{
 w:=\frac{2u^3b+3u^2(u-1)^2}{u(u-1)}.
}
\tag{4}
\]

Squaring (4) and using (3) gives

\[
\boxed{w^2=u(u-1)(3u+1)(3u-4).}
\tag{5}
\]

Conversely, if \(u,w\in\mathbf Q\), \(u\ne0,1\), and (5) holds, then

\[
\boxed{
 b=\frac{(u-1)\bigl(w-3u(u-1)\bigr)}{2u^2}
}
\tag{6}
\]

satisfies (3). Then \(x=bu\). Thus (5), on the indicated open subset, is birationally equivalent to \(\psi_3=0\).

On the locus (3), the lift condition (1) also simplifies. Dividing (1) by \(b^2\) and reducing with (3) gives

\[
\boxed{
\left(\frac zb\right)^2
 =\frac{u-1}{u}\Bigl(bu^2(u+1)+u-1\Bigr).
}
\tag{7}
\]

Equation (7) is optional for the proof, but it is a convenient smaller expression for the final lift check.

### Literal denominator clearing

First, here is the direct clearing in the variables requested in the question. Write

\[
b=\frac mn,\qquad x=\frac pq,
\]

with \(n,q>0\), \(\gcd(m,n)=\gcd(p,q)=1\). Then \(\psi_3=0\) is exactly

\[
\boxed{
\begin{aligned}
0={}&3n^3p^4+n(m^2-6mn+n^2)p^3q\\
 &+3n(m^2-mn)p^2q^2+3nm^2pq^3-m^3q^4.
\end{aligned}
}
\tag{8}
\]

If \(z\) is as in (1), put \(Z=nq^2z\). Equation (1) is exactly

\[
\boxed{
\begin{aligned}
Z^2=q\bigl(&4n^2p^3+(m^2-6mn+n^2)p^2q\\
            &+2(m^2-mn)pq^2+m^2q^3\bigr).
\end{aligned}
}
\tag{9}
\]

The right side is an integer. A rational number whose square is an integer is an integer, so \(Z\in\mathbf Z\). Equations (8) and (9) are a fully denominator-cleared version of the original system.

For the actual descent, clearing after the substitution \(u=x/b\) is much smaller. Write

\[
b=\frac mn,\qquad u=\frac rs,
\]

with \(n,s>0\) and both fractions reduced. Equation (3) becomes

\[
\boxed{
 m^2r^3s+3mnr^2(r-s)^2+n^2s(r-s)^3=0.
}
\tag{10}
\]

Let \(W=s^2w\). From (5), \(W^2\in\mathbf Z\), hence \(W\in\mathbf Z\), and

\[
\boxed{
W^2=r(r-s)(3r+s)(3r-4s).
}
\tag{11}
\]

The original variables are recovered by

\[
\boxed{
 b=\frac{(r-s)\bigl(W-3r(r-s)\bigr)}{2r^2s},
}
\tag{12}
\]

\[
\boxed{
 x=\frac{(r-s)\bigl(W-3r(r-s)\bigr)}{2rs^2}.
}
\tag{13}
\]

Thus (11) is the clean primitive Diophantine relation. It is much better for Lean than (8): it involves one square and four linear factors.

## (c) Explicit \(2\)-isogeny descent for the quartic

Let

\[
C:\qquad w^2=u(u-1)(3u+1)(3u-4).
\]

### Birational map to a cubic

For \(u\ne0\), define

\[
\boxed{
X=12+\frac4u=\frac{4(3u+1)}u,\qquad
Y=\frac{4w}{u^2}.
}
\tag{14}
\]

A direct expansion gives

\[
Y^2=X(X-15)(X-16).
\]

So set

\[
\boxed{
E:\qquad Y^2=X(X-15)(X-16)
      =X^3-31X^2+240X.
}
\tag{15}
\]

For \(X\ne12\), the inverse map is

\[
\boxed{
 u=\frac4{X-12},\qquad
 w=\frac{4Y}{(X-12)^2}.
}
\tag{16}
\]

The two points at infinity on the smooth projective model of \(C\) map to \((12,12)\) and \((12,-12)\). The point \((u,w)=(0,0)\) maps to the point at infinity of \(E\).

It remains to determine \(E(\mathbf Q)\), and this curve has an unusually clean \(2\)-isogeny descent.

### Coordinate form of the \(2\)-isogeny descent lemma

For

\[
E_{a,B}: y^2=x^3+ax^2+Bx,
\]

put

\[
E'_{a,B}: v^2=t^3-2at^2+(a^2-4B)t.
\]

There are \(2\)-isogenies

\[
\phi:E_{a,B}\longrightarrow E'_{a,B},
\]

\[
\phi(x,y)=
\left(
 \frac{y^2}{x^2},
 \frac{y(B-x^2)}{x^2}
\right)
\quad(x\ne0),
\tag{17}
\]

and

\[
\widehat\phi:E'_{a,B}\longrightarrow E_{a,B},
\]

\[
\widehat\phi(t,v)=
\left(
 \frac{v^2}{4t^2},
 \frac{v(a^2-4B-t^2)}{8t^2}
\right)
\quad(t\ne0),
\tag{18}
\]

with the usual values at the kernel points. Direct substitution verifies

\[
\widehat\phi\circ\phi=[2].
\tag{19}
\]

Define the square-class map

\[
\alpha_{a,B}:E_{a,B}(\mathbf Q)\longrightarrow
\mathbf Q^\times/\mathbf Q^{\times2}
\]

by

\[
\alpha(O)=1,\qquad
\alpha((0,0))=B,\qquad
\alpha((x,y))=x\pmod{\mathbf Q^{\times2}}\quad(x\ne0).
\tag{20}
\]

The function \(x\) has divisor \(2(0,0)-2O\), so (20) is a homomorphism. Equations (17) and (18), together with the quadratic formula for a preimage, give

\[
\boxed{\ker\alpha_{a,B}=\widehat\phi(E'_{a,B}(\mathbf Q)).}
\tag{21}
\]

The image can be tested by a homogeneous quartic. Let \(d\) be a squarefree representative of a square class. Then \(d\) occurs in \(\operatorname{im}\alpha_{a,B}\) if and only if there are coprime integers \(M,N\), not both zero, and \(R\in\mathbf Z\) such that

\[
\boxed{
R^2=dM^4+aM^2N^2+\frac BdN^4.
}
\tag{22}
\]

Here \(d\) may be chosen with prime support contained in the prime support of \(B\). Indeed, for a prime \(\ell\nmid B\), an odd value of \(v_\ell(x)\) makes

\[
v_\ell\bigl(x(x^2+ax+B)\bigr)
\]

odd, whether \(v_\ell(x)>0\) or \(v_\ell(x)<0\), contradicting that this valuation is \(2v_\ell(y)\).

For completeness, (22) is obtained simply by writing

\[
x=d\frac{M^2}{N^2},\qquad
 y=d\frac{MR}{N^3}
\]

and substituting in the cubic. Conversely, a solution of (22) gives that rational point. Thus every part of this descent is an explicit polynomial identity or a valuation parity argument.

### Apply the lemma to \(E:Y^2=X^3-31X^2+240X\)

Here

\[
a=-31,\qquad B=240,\qquad a^2-4B=961-960=1.
\]

The \(2\)-isogenous curve is therefore

\[
\boxed{
E':\qquad V^2=T^3+62T^2+T.
}
\tag{23}
\]

#### The image on \(E\)

A squarefree representative for \(\alpha(E(\mathbf Q))\) lies in

\[
\{\pm1,\pm2,\pm3,\pm5,\pm6,\pm10,\pm15,\pm30\}.
\]

For such \(d\), equation (22) is

\[
R^2=dM^4-31M^2N^2+\frac{240}{d}N^4.
\tag{24}
\]

**Negative \(d\).** If \(d<0\), all three terms on the right of (24) are nonpositive and at least one is negative. Hence there is no solution.

**Even positive \(d\in\{2,6,10,30\}\).** Assume \(\gcd(M,N)=1\).

* If \(M,N\) are both odd, then modulo \(8\), using \(-31\equiv1\pmod8\) and \(8\mid240/d\), the right side is
  \[
  d+1\equiv3\text{ or }7\pmod8,
  \]
  not a square.
* If \(M\) is odd and \(N\) is even, the right side is \(d\) or \(d+4\) modulo \(8\), hence \(2\) or \(6\), not a square.
* The only remaining primitive parity is \(M\) even and \(N\) odd. Write \(M=2M_1\). The right side of (24) is divisible by \(4\), so \(R=2R_1\), and division by \(4\) gives
  \[
  R_1^2=4dM_1^4-31M_1^2N^2+\frac{60}{d}N^4.
  \tag{25}
  \]
  Modulo \(8\), the first term vanishes. If \(M_1\) is odd, the right side is \(1+60/d\equiv3\) or \(7\). If \(M_1\) is even, it is \(60/d\) or \(60/d+4\equiv2\) or \(6\). Again impossible.

Thus no even \(d\) occurs.

The remaining positive odd classes all occur, witnessed by displayed rational points:

\[
\begin{array}{c|c|c}
d&\text{point on }E&X\text{-coordinate}\ 
\hline
1&(16,0)&16=1\cdot4^2\\
3&(12,12)&12=3\cdot2^2\\
5&(20,20)&20=5\cdot2^2\\
15&(15,0)&15=15\cdot1^2.
\end{array}
\]

Consequently

\[
\boxed{\alpha(E(\mathbf Q))=\{1,3,5,15\}.}
\tag{26}
\]

#### The image on \(E'\)

For \(E'\), the coefficient \(B'\) is \(1\), so only \(d=1\) or \(d=-1\) is possible. The class \(d=1\) occurs. If \(d=-1\), equation (22) is

\[
R^2=-M^4+62M^2N^2-N^4.
\tag{27}
\]

If exactly one of \(M,N\) is even, the right side is \(7\pmod8\). If both are odd, then odd fourth powers are \(1\pmod{16}\), while \(M^2N^2\equiv1\) or \(9\pmod{16}\); in either case

\[
-M^4+62M^2N^2-N^4\equiv-1+14-1\equiv12\pmod{16},
\]

not a square. Thus

\[
\boxed{\alpha'(E'(\mathbf Q))=\{1\}.}
\tag{28}
\]

#### Descent conclusion

By (21) for \(E'\), equation (28) says that \(\phi:E(\mathbf Q)\to E'(\mathbf Q)\) is surjective. Hence, using (19),

\[
\widehat\phi(E'(\mathbf Q))
 =\widehat\phi(\phi(E(\mathbf Q)))
 =[2]E(\mathbf Q).
\]

By (21) for \(E\),

\[
\ker\alpha=[2]E(\mathbf Q).
\]

Therefore (26) gives the exact quotient

\[
\boxed{
E(\mathbf Q)/2E(\mathbf Q)\cong\{1,3,5,15\},
\qquad |E(\mathbf Q)/2E(\mathbf Q)|=4.
}
\tag{29}
\]

This is the actual rank computation; no assertion such as “LMFDB says rank zero” is being invoked. Since

\[
E[2](\mathbf Q)=\{O,(0,0),(15,0),(16,0)\}
\]

has four elements, the finitely generated abelian-group identity

\[
|E(\mathbf Q)/2E(\mathbf Q)|=2^{r}|E[2](\mathbf Q)|
\]

forces \(r=0\). Equivalently, \(E(\mathbf Q)\) has no point of infinite order.

There is also a direct infinite-descent formulation that avoids using the phrase “rank zero.” The four classes in (29) are represented by torsion points

\[
O,\qquad (15,0),\qquad (12,12),\qquad(20,20).
\]

Indeed, the tangent slopes at \((12,12)\) and \((20,20)\) are respectively \(-3\) and \(5\), and in both cases doubling gives \((16,0)\). Thus every \(P\in E(\mathbf Q)\) has

\[
P=T+2Q
\]

with \(T\) torsion. Iterating and applying the canonical height gives

\[
\widehat h(Q_n)=4^{-n}\widehat h(P).
\]

If \(P\) had infinite order, these would be infinitely many distinct rational points of bounded height, contradicting Northcott. This is a literal infinite descent in height.

#### Determine the torsion points by one finite-field count

The discriminant of (15) is

\[
2^{12}3^25^2,
\]

so \(7\) is a prime of good reduction. Modulo \(7\), equation (15) is

\[
Y^2=X(X-1)(X-2).
\]

For \(X=0,1,2,3,4,5,6\), the numbers of \(Y\)-solutions are respectively

\[
1,1,1,0,0,2,2.
\]

Including the point at infinity,

\[
\#E(\mathbf F_7)=8.
\]

Reduction at a good odd prime is injective on rational torsion, so \(|E(\mathbf Q)_{\rm tors}|\le8\). We already have eight distinct rational points:

\[
\boxed{
E(\mathbf Q)=
\{O,(0,0),(15,0),(16,0),(12,\pm12),(20,\pm20)\}.
}
\tag{30}
\]

### Rational points on the quartic

Using (16), the list (30) gives

\[
\boxed{
C(\mathbf Q)=
\left\{
(0,0),
(1,0),
\left(-\frac13,0\right),
\left(\frac43,0\right),
\left(\frac12,\frac54\right),
\left(\frac12,-\frac54\right),
\infty_+,
\infty_-
\right\}.
}
\tag{31}
\]

The correspondence is

\[
\begin{array}{c|c}
(u,w)&(X,Y)\\
\hline
(0,0)&O\\
(1,0)&(16,0)\\
(-1/3,0)&(0,0)\\
(4/3,0)&(15,0)\\
(1/2,5/4)&(20,20)\\
(1/2,-5/4)&(20,-20)\\
\infty_+&(12,12)\\
\infty_-&(12,-12).
\end{array}
\]

In the primitive integer equation (11), after normalizing \(s>0\), the finite possibilities are therefore

\[
(r,s,W)=(0,1,0),(1,1,0),(-1,3,0),(4,3,0),(1,2,5),(1,2,-5).
\]

This is the finite classification requested in denominator-cleared form.

## Back-substitute and test the rational-\(y\) lift

The point \(u=0\) is not in the inverse chart (6), and \(u=1\) forces \(b=0\), hence is a cusp/degenerate value. The two points at infinity are also boundary points. The remaining four points give, via (6) and \(x=bu\), exactly

\[
\boxed{
(b,x)=
\left(8,-\frac83\right),
\left(-\frac18,-\frac16\right),
(-2,-1),
\left(\frac12,\frac14\right).
}
\tag{32}
\]

For reference, all four do satisfy the nonsingularity factor:

\[
\begin{array}{c|c}
b&b^2-11b-1\\
\hline
8&-25\\
-1/8&25/64\\
-2&25\\
1/2&-25/4.
\end{array}
\]

Thus the final obstruction really is the failure to lift the rational \(x\)-coordinate to a rational point of order \(3\), not singularity.

Now evaluate the right side of (1). Let

\[
R(b,x):=4x^3+(b^2-6b+1)x^2+2(b^2-b)x+b^2.
\]

For the four pairs (32), direct arithmetic gives

\[
\begin{array}{c|c|c}
b&x&R(b,x)\\
\hline
8&-8/3&-5120/27=-15(32/9)^2\\
-1/8&-1/6&-5/6912=-15(1/144)^2\\
-2&-1&5\\
1/2&1/4&5/64=5(1/8)^2.
\end{array}
\tag{33}
\]

The first two values are negative, so they cannot be rational squares. The last two would imply that \(5\) is a square in \(\mathbf Q\), which is impossible by parity of the \(5\)-adic valuation (equivalently, by unique factorization in \(\mathbf Z\)). Therefore no rational \(z\), and hence no rational \(y\), exists for any pair in (32).

This proves

\[
\boxed{
\nexists\,b,x,y\in\mathbf Q:\quad
b^5(b^2-11b-1)\ne0,
\quad (b,x,y)\in E_b,
\quad \psi_3(b,x)=0.
}
\]

## Suggested Lean decomposition

A robust formalization can be split into the following small lemmas.

```lean
-- Algebraic setup
def psi3 (b x : ℚ) : ℚ :=
  3*x^4 + (b^2 - 6*b + 1)*x^3
    + 3*(b^2 - b)*x^2 + 3*b^2*x - b^3

def liftRad (b x : ℚ) : ℚ :=
  4*x^3 + (b^2 - 6*b + 1)*x^2
    + 2*(b^2 - b)*x + b^2
```

1. `psi3_formula`: derive the four \(b_i\) and the displayed polynomial using `ring`.
2. `curve_iff_square`: with `z = 2*y + (1-b)*x - b`, prove the completed-square identity by `ring`.
3. `psi3_normalize`: under `b ≠ 0`, set `u = x / b`; prove (2) by `field_simp` followed by `ring`.
4. `psi3_to_quartic`: under `u ≠ 0,1`, define \(w\) by (4); prove (5), and prove the inverse formula (6), again by `field_simp` and `ring`.
5. `quartic_birational`: verify (14)--(16) by `field_simp` and `ring`.
6. `square_mod8` and `square_mod16`: package the residue lists
   \[
   t^2\bmod8\in\{0,1,4\},\qquad
   t^2\bmod16\in\{0,1,4,9\},
   \]
   together with `odd fourth ≡ 1 mod 16`.
7. `E_kummer_image`: formalize (24) and the three parity cases excluding even and negative \(d\).
8. `Eprime_kummer_image`: formalize the modulo \(8/16\) exclusion for (27).
9. `E_rat_points`: use the explicit isogenies, the exact Kummer images, and the eight-point count modulo \(7\) to obtain (30).
10. `quartic_rat_points`: transport (30) through the birational maps to obtain the finite disjunction (31).
11. `candidate_lift_false`: substitute the four pairs (32) into `liftRad`; `norm_num` proves the values in (33), after which sign and the nonsquareness of \(5\) finish.

A convenient final theorem statement is:

```lean
theorem no_rational_5_and_3_torsion
    (b x y : ℚ)
    (hdisc : b^5 * (b^2 - 11*b - 1) ≠ 0)
    (hcurve : y^2 + (1-b)*x*y - b*y = x^3 - b*x^2)
    (hpsi : psi3 b x = 0) : False := by
  -- complete square, normalize, classify quartic point, check four lifts
  ...
```

The genuinely arithmetic core is only the finite square-class list and the residue contradictions in (24), (25), and (27); everything else is rational polynomial algebra.
