# Audit verdict

The theorem is **true as stated**.

Let `G` be an additive commutative group, `H : AddSubgroup G`, and `e : ℕ`. Assume:

```text
H-exp:   for every t ∈ H, e • t = 0;
weak:    for every x ∈ G, there are t ∈ H and y ∈ G with x = t + 2 • y;
sep:     if x is divisible by 2^n for every n, then x = 0.
```

Then every `x : G` satisfies

```text
e • x = 0.
```

The proposed logic is correct. There is no hidden parity condition on `e`, no requirement that `H` contain all 2-torsion, and no finite-generation hypothesis.

---

# 1. Iterating weak descent

The exact inductive statement is:

```text
for every n and x, there exist t_n ∈ H and y_n ∈ G such that
x = t_n + 2^n • y_n.
```

## Base case

For `n=0`, take

```text
t_0 = 0,
y_0 = x.
```

Then

```text
x = 0 + 1 • x = t_0 + 2^0 • y_0.
```

## Inductive step

Assume

```text
x = t_n + 2^n • y_n,
t_n ∈ H.
```

Apply weak descent to `y_n`:

```text
y_n = u + 2 • z,
u ∈ H.
```

Then

```text
x
= t_n + 2^n • (u + 2 • z)
= t_n + 2^n • u + 2^(n+1) • z
= (t_n + 2^n • u) + 2^(n+1) • z.
```

Set

```text
t_(n+1) = t_n + 2^n • u.
```

Because `H` is an additive subgroup:

```text
t_n ∈ H,
u ∈ H,
2^n • u ∈ H,
t_n + 2^n • u ∈ H.
```

Thus the induction is valid.

The accumulated term is explicitly

```text
t_n = t_0 + 2 • t_1 + 2^2 • t_2 + ... + 2^(n-1) • t_(n-1),
```

where each one-step correction belongs to `H`.

# 2. Why `e • x` is infinitely 2-divisible

From the iterated decomposition,

```text
x = t_n + 2^n • y_n,
t_n ∈ H.
```

Multiply by `e`:

```text
e • x
= e • t_n + e • (2^n • y_n)
= 0 + 2^n • (e • y_n)
= 2^n • (e • y_n).
```

The first equality uses distributivity of natural scalar multiplication over addition. The second uses the exponent hypothesis on `H`. The third uses

```text
e • (2^n • y_n) = 2^n • (e • y_n),
```

because both sides are `(e * 2^n) • y_n`, up to commutativity of multiplication in `ℕ`.

For every `n`, therefore, the witness

```text
q_n = e • y_n
```

satisfies

```text
2^n • q_n = e • x.
```

Hence `e • x` is infinitely 2-divisible. Separatedness gives

```text
e • x = 0.
```

This closes the theorem.

# 3. Hidden-assumption audit

## `e` need not be even

No step divides by `e`, compares `e` with 2, or assumes `gcd(e,2)=1`. The theorem works for every natural number `e`.

If `e=0`, the conclusion is trivially true because `0 • x = 0`.

## `H` need not contain all 2-torsion

The proof only uses:

```text
∀ t ∈ H, e • t = 0.
```

There is no need for `G[2] ≤ H`, or for any relation between `H` and the 2-primary torsion of `G`.

## `H` being a subgroup is sufficient

The induction uses exactly:

```text
0 ∈ H;
H is closed under addition;
H is closed under natural multiples.
```

That is supplied by `H : AddSubgroup G`.

A useful application warning: if the object called `H` is only a finite **set of representatives**, rather than an additive subgroup, then the statement `t_n ∈ H` generally fails. There are two repairs:

1. prove those representatives form a subgroup; or
2. track the weighted sum of representatives directly and prove that `e` kills every accumulated sum.

For the theorem exactly as stated, there is no problem because `H` is a subgroup.

## Weak descent must apply to every element of `G`

At the induction step it is applied to the newly produced `y_n`. Thus the hypothesis must be genuinely

```text
∀ x : G, ...
```

not merely a statement for a selected subset unless that subset is also proved stable under taking the descent remainder.

## Additive commutativity is the clean sufficient assumption

The proof uses

```text
e • (a+b) = e • a + e • b.
```

For the intended elliptic-curve/Jacobian applications, `G` is an additive commutative group, so this is exactly the right setting.

## No finite generation or Mordell-Weil input

The conclusion follows entirely from weak descent and separatedness. It does not use `AddGroup.FG`, Mordell-Weil, rank, or structure theory of finitely generated abelian groups.

# 4. Lean-shaped proof

The following is the direct Mathlib formulation. The names used are standard current Mathlib names: `AddSubgroup.zero_mem`, `AddSubgroup.add_mem`, `AddSubgroup.nsmul_mem`, `nsmul_add`, and `nsmul_nsmul`.

```lean
import Mathlib.Algebra.Group.Subgroup.Basic
import Mathlib.SetTheory.Cardinal.NatCard

namespace WeakDescentSeparatedness

variable {G : Type*} [AddCommGroup G]

/-- An element is divisible by every power of two. -/
def InfinitelyTwoDivisible (x : G) : Prop :=
  ∀ n : ℕ, ∃ q : G, (2 ^ n) • q = x

/-- Iterating `x = t + 2y` accumulates a single correction in the subgroup. -/
lemma iterated_weak_descent
    (H : AddSubgroup G)
    (hdesc : ∀ x : G, ∃ t ∈ H, ∃ y : G, x = t + 2 • y) :
    ∀ n : ℕ, ∀ x : G,
      ∃ t ∈ H, ∃ y : G, x = t + (2 ^ n) • y := by
  intro n
  induction n with
  | zero =>
      intro x
      exact ⟨0, H.zero_mem, x, by simp⟩
  | succ n ih =>
      intro x
      obtain ⟨t₀, ht₀, y₀, hxy₀⟩ := ih x
      obtain ⟨t₁, ht₁, y₁, hy₀⟩ := hdesc y₀
      refine ⟨t₀ + (2 ^ n) • t₁,
        H.add_mem ht₀ (H.nsmul_mem ht₁ _), y₁, ?_⟩
      calc
        x = t₀ + (2 ^ n) • y₀ := hxy₀
        _ = t₀ + (2 ^ n) • (t₁ + 2 • y₁) := by rw [hy₀]
        _ = (t₀ + (2 ^ n) • t₁) + (2 ^ (n + 1)) • y₁ := by
          simp [nsmul_add, nsmul_nsmul, pow_succ, add_assoc]

/-- Weak descent plus 2-adic separatedness forces the ambient group
    to have exponent dividing `e`. -/
theorem exponent_of_weak_descent_and_two_adic_separatedness
    (H : AddSubgroup G)
    (e : ℕ)
    (hHexp : ∀ t : G, t ∈ H → e • t = 0)
    (hdesc : ∀ x : G, ∃ t ∈ H, ∃ y : G, x = t + 2 • y)
    (hsep : ∀ x : G, InfinitelyTwoDivisible x → x = 0) :
    ∀ x : G, e • x = 0 := by
  intro x
  apply hsep (e • x)
  intro n
  obtain ⟨t, ht, y, hxy⟩ := iterated_weak_descent H hdesc n x
  refine ⟨e • y, ?_⟩
  calc
    (2 ^ n) • (e • y) = e • ((2 ^ n) • y) := by
      simp [nsmul_nsmul, Nat.mul_comm]
    _ = e • x := by
      rw [hxy, nsmul_add, hHexp t ht, zero_add]

end WeakDescentSeparatedness
```

The proof is structurally robust. Depending on the exact pinned Mathlib commit, the final `simp` line in the induction may prefer `Nat.pow_succ` rather than `pow_succ`, or `simpa [pow_succ, nsmul_nsmul, add_assoc]`; this is elaboration-level syntax, not a mathematical gap.

A subtype-form exponent hypothesis is equally valid:

```lean
hHexp : ∀ t : H, e • (t : G) = 0
```

Then the only change is to use

```lean
hHexp ⟨t, ht⟩
```

in the final proof.

# 5. The finite-target corollary

The proposed corollary is also correct, with one wording distinction.

Define the `e`-torsion subtype informally by

```text
G[e] = {x : G | e • x = 0}.
```

The theorem proves

```text
G = G[e]
```

in the sense that every element of `G` lies in that subtype.

Suppose there is an injective map, in particular an injective additive homomorphism,

```text
φ : G[e] → F
```

and `F` is finite. Compose `φ` with

```text
G → G[e],
x ↦ ⟨x, proof that e • x = 0⟩.
```

This produces an injection

```text
G ↪ F.
```

Therefore `G` is finite and

```text
|G| ≤ |F|.
```

No surjectivity is needed.

A Lean-shaped cardinality lemma is:

```lean
open Function

variable {F : Type*} [Finite F]

/-- Here `ETorsion` may be implemented as the subtype
    `{x : G // e • x = 0}` or as an `AddSubgroup`. -/
theorem natCard_le_of_injective_on_eTorsion
    (e : ℕ)
    (hkill : ∀ x : G, e • x = 0)
    (φ : {x : G // e • x = 0} → F)
    (hφ : Injective φ) :
    Nat.card G ≤ Nat.card F := by
  apply Nat.card_le_card_of_injective
    (fun x : G => φ ⟨x, hkill x⟩)
  intro x y hxy
  exact congrArg Subtype.val (hφ hxy)
```

Current Mathlib supplies

```lean
Nat.card_le_card_of_injective
```

in the cardinality infrastructure imported by

```lean
Mathlib.SetTheory.Cardinal.NatCard
```

and it derives finiteness of the source from an injection into a finite target.

## If `N` is the size of the target

If

```text
|F| = N,
```

then

```text
|G| ≤ N.
```

## If `N` is the size of the image

If

```text
|im φ| = N
```

and `φ` is injective, then the stronger statement holds:

```text
|G| = N.
```

Indeed, an injective function is a bijection from its domain onto its range. Thus saying “image size `N` implies `|G|≤N`” is correct but weaker than what is available.

# 6. Application checklist

For each elliptic/Jacobian application, the shared theorem is valid once the following four objects are genuinely proved:

1. `H : AddSubgroup G`;
2. `∀ t ∈ H, e • t = 0`;
3. `∀ x, ∃ t ∈ H, ∃ y, x = t + 2 • y`;
4. `∀ x, (∀ n, ∃ q, 2^n • q = x) → x = 0`.

Then one obtains

```text
∀ x, e • x = 0.
```

To obtain a finite cardinality bound, one additionally needs an actual injective map on all `e`-torsion. In a reduction argument, this means a total projective reduction map or an equivalent fixed-curve construction—not merely an affine reduction formula defined for some coordinates.

# Final verdict

- The main theorem is correct.
- The induction is correct.
- No condition that `e` be even is needed.
- No condition that `H` contain 2-torsion is needed.
- Subgroup closure is exactly what validates the accumulated `t_n ∈ H` statement.
- The finite-target corollary is correct.
- If `N` is the exact image size, the conclusion strengthens from `|G|≤N` to `|G|=N`.
