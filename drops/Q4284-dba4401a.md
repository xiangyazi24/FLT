# 1. Factorization and irreducibility over Q

Put

```text
r^2 = -2,
k = Q(r),
s = -2 + 2*r.
```

Define

```text
g_r(x) = x^3 + (2-2*r)*x^2 + (-1-2*r)*x - 1,
g_bar(x) = x^3 + (2+2*r)*x^2 + (-1+2*r)*x - 1.
```

Direct multiplication gives the exact factorization over `k`:

```text
f(x) = g_r(x) * g_bar(x).
```

So `f` does **not** factor over Q, but it factors as two conjugate cubics over `Q(sqrt(-2))`.

## 1.1 The order-three Möbius symmetry

The rational transformation

```text
sigma(x) = -1/(x+1)
```

has order three and satisfies

```text
(x+1)^6 * f(-1/(x+1)) = f(x).
```

For a root `alpha` of `f`, its orbit is

```text
alpha,
-1/(alpha+1),
-(alpha+1)/alpha.
```

The orbit invariant is

```text
s(alpha) = (alpha^3 - 3*alpha - 1)/(alpha^2+alpha).
```

The denominator is nonzero because `f(0)=f(-1)=1`. One checks

```text
s(alpha)^2 + 4*s(alpha) + 12 = 0.
```

Thus

```text
r = (s(alpha)+2)/2 is in Q(alpha),
r^2=-2.
```

The orbit cubic is

```text
X^3 - s*X^2 -(s+3)*X - 1,
```

which is exactly `g_r` for `s=-2+2r`.

## 1.2 Irreducibility of the cubic over k

The ring of integers of `k=Q(r)` is

```text
O_k = Z[r],
Disc(k) = -8,
O_k^x = {+1,-1}.
```

If `g_r` were reducible over `k`, its monic cubic form would give a root in `k`. Such a root is integral, and the constant term `-1` makes it a unit of `O_k`, hence it must be `+1` or `-1`. But

```text
g_r(1)  = 1 - 4*r != 0,
g_r(-1) = 1 != 0.
```

Therefore `g_r` is irreducible over `k`. Since `k` is already contained in `Q(alpha)`,

```text
[Q(alpha):Q] = [Q(alpha):k] * [k:Q] = 3*2 = 6.
```

Hence:

```text
f is irreducible over Q.
```

The etale algebra is therefore a single field, not a product:

```text
L = Q[alpha] = Q[T]/(f(T)),
degree(L/Q)=6.
```

# 2. Ring of integers and discriminants

Work over `k=Q(r)` with `r^2=-2`. The relative polynomial is `g_r`.

## 2.1 Relative discriminant

For

```text
g_r(X)=X^3-sX^2-(s+3)X-1,
s=-2+2r,
```

the cubic discriminant simplifies to

```text
Disc(g_r) = 2*s - 3
          = -7 + 4*r
          = (1+2*r)^2
          = (1-r)^4.
```

The last equality is as ideals/elements up to the unit `-1`, since

```text
1+2*r = -(1-r)^2.
```

Let

```text
p = (1-r),
q = (1+r),
(3)=p*q,
Norm_k/Q(p)=Norm_k/Q(q)=3.
```

Shift `X=Z+1`. The polynomial becomes

```text
g_r(Z+1)
 = Z^3 + (3-s) Z^2 - 3*s Z - 2*s - 3.
```

Writing `s=-2p`, the coefficients have p-valuations

```text
v_p(3-s)=1,
v_p(-3s)>=2,
v_p(-2s-3)=1.
```

Thus `g_r(Z+1)` is Eisenstein at `p`. It follows locally that `O_{L,p}=O_{k,p}[alpha]`. At every other prime, the relative polynomial discriminant is a unit, so the same order is maximal there. Therefore

```text
O_L = O_k[alpha].
```

## 2.2 Integral basis

An exact Z-basis is

```text
1, alpha, alpha^2, r, r*alpha, r*alpha^2.
```

This is the most natural basis for Lean: it is the tensor/power basis obtained from

```text
O_k = Z[1,r]
and
O_L = O_k[1,alpha,alpha^2].
```

For conversion to the ordinary power basis of `alpha`, the following identity is useful:

```text
2*r = 2*alpha^5 + 7*alpha^4 + 17*alpha^3
      + 13*alpha^2 + 8*alpha + 3.
```

It follows that the same integral basis can be written as

```text
b0 = 1,
b1 = alpha,
b2 = alpha^2,

b3 = (2*alpha^5 + 7*alpha^4 + 17*alpha^3
      + 13*alpha^2 + 8*alpha + 3)/2,

b4 = (-alpha^5 - 3*alpha^4 - 7*alpha^3
      - 2*alpha^2 - alpha - 2)/2,

b5 = (alpha^5 + 3*alpha^4 + 8*alpha^3
      + 4*alpha^2 + 1)/2.
```

The determinant of this basis relative to

```text
1,alpha,alpha^2,alpha^3,alpha^4,alpha^5
```

is `-1/8`. Hence

```text
[O_L : Z[alpha]] = 8.
```

The identity for `r` is checked without any number-field black box: if

```text
D=X*(X+1),
A=X^3+2X^2-X-1,
H=2X^5+7X^4+17X^3+13X^2+8X+3,
```

then

```text
D*H - A = (2X+1)*f.
```

Since `2r=(s+2)=A(alpha)/D(alpha)`, this proves the displayed formula.

## 2.3 Field discriminant

The relative discriminant ideal is `p^4`, so

```text
Disc(L)
 = Disc(k)^3 * Norm_k/Q(p^4)
 = (-8)^3 * 3^4
 = -41472
 = -2^9 * 3^4.
```

The sign is negative because the signature is

```text
(r1,r2)=(0,3).
```

The polynomial discriminant is larger by the square of the index:

```text
Disc(f)
 = Disc(L) * 8^2
 = -2^15 * 3^4
 = -2654208.
```

These identities also explain why reduction modulo 2 of the power-basis polynomial is non-squarefree even though 2 is not in the relative cubic discriminant: the power order `Z[alpha]` has index 8.

# 3. Prime decomposition at S={2,3}



## 3.2 The prime 3

```text
(3)=p*q,
p=(1-r),
q=(1+r).
```


# 4. Class group

The Minkowski bound for a degree-six field of signature `(0,3)` is

```text
M_L = (4/pi)^3 * (6!/6^6) * sqrt(41472) < 6.50 < 7.
```

Every ideal class therefore contains an integral ideal of norm at most 6.

- There is no prime ideal of norm 2 or 4: the only prime over 2 has norm 8.
- The only prime ideal of norm 3 is `P3=(pi)`, which is principal.
- There is no prime ideal of norm 5: direct evaluation gives no root of `f mod 5`:

```text
f(0),f(1),f(2),f(3),f(4) mod 5 = 1,3,2,3,1.
```

- Norm 6 would require a norm-2 prime factor, which does not exist.

Therefore every ideal class is principal:

```text
Cl(O_L)=0.
```

In particular

```text
Cl(O_L)[2]=0.
```

This is an entirely explicit class-group certificate; no class-group algorithm is needed in Lean beyond formalizing the Minkowski-bound argument and the displayed prime decompositions.
