# N18 Route C — base-change interface reference draft

## Verdict

The seam should expose

```text
N18Mumford ℚ  --coefficients-->  N18Mumford L
      | classOf                         | classOf
      v                                 v
 Pic^0(C_ℚ)      --baseChangePic-->  Pic^0(C_L).
```

The best implementation does **not** put Hilbert 90 on the critical path. Use the unique balanced/reduced Mumford representative over each field:

1. extend `u` and `v` coefficientwise by `algebraMap ℚ L` and leave the infinity orientation unchanged;
2. prove this representative has the extended oriented ideal class;
3. uniqueness of the reduced representative over `L`, plus injectivity of `algebraMap ℚ L`, proves `baseChangePic` injective.

Hilbert 90 gives an independent abstract proof and is described below. It is useful as a mathematical audit, but it requires more geometry/descent infrastructure.

Two warnings are load-bearing:

* `ClassGroup.extendedHom Aℚ AL` is **not** injective for arbitrary domain extensions; affine ideal classes can capitulate. Injectivity here belongs to the projective degree-zero/oriented group.
* A bounded exponent does not by itself imply finiteness. The annihilator and finiteness descents are separate lemmas.

# 2. Coefficient extension on a balanced Mumford triple

Assume a representative has fields analogous to

```text
u : K[X]
v : K[X]
orientation : ℤ
u monic, deg u ≤ 2, deg v < deg u, u ∣ f-v²,
balanced orientation conditions.
```

The plain function is

```lean
namespace N18Mumford

noncomputable def mapCoeffs

    (ι : K →+* K') (hι : Function.Injective ι)
    (D : N18Mumford K) : N18Mumford K' := by
  refine
    { u := D.u.map ι
      v := D.v.map ι
      orientation := D.orientation
      u_monic := ?_
      u_degree := ?_
      v_degree := ?_
      divides_curve := ?_
      orientation_bound := ?_ }
  · exact D.u_monic.map ι
  · -- `natDegree` is preserved because `ι` is injective.
    simpa using D.u_degree
  · simpa using D.v_degree
  · rcases D.divides_curve with ⟨q, hq⟩

end N18Mumford
```

# 4. `baseChangeMumford` and `baseChangePic`

Do not prove separately that the Cantor/reduction formulas commute with base change. Transport additivity through the oriented class groups:

```lean
noncomputable def baseChangeMumford : MQ →+ ML :=
  mumfordEquivL.symm.toAddMonoidHom.comp
    (orientedClassBaseChange.comp mumfordEquivQ.toAddMonoidHom)

@[simp] theorem baseChangeMumford_apply (D : MQ) :
    baseChangeMumford D = mumfordMapCoeffs D := by
  apply mumfordEquivL.injective
  simpa [baseChangeMumford] using (classOf_mumfordMapCoeffs D).symm

noncomputable abbrev baseChangePic : JQ →+ JL :=
  orientedClassBaseChange

@[simp] theorem classOf_baseChangeMumford (D : MQ) :
    mumfordEquivL (baseChangeMumford D) =
      baseChangePic (mumfordEquivQ D) := by
  simpa only [baseChangeMumford_apply] using classOf_mumfordMapCoeffs D
```

Thus the requested compatibility is a `[simp]` lemma, not an additional geometric theorem.

# 5. Injectivity via unique reduced representatives

```lean
theorem baseChangeMumford_injective :
    Function.Injective baseChangeMumford := by
  intro D₁ D₂ h
  apply mumfordMapCoeffs_injective
  simpa only [baseChangeMumford_apply] using h

/-- `Pic^0(C)(ℚ) → Pic^0(C)(L)` is injective. -/
theorem baseChangePic_injective : Function.Injective baseChangePic := by
  intro x y hxy
  have hM :
      baseChangeMumford (mumfordEquivQ.symm x) =
        baseChangeMumford (mumfordEquivQ.symm y) := by
    apply mumfordEquivL.injective
    calc
      mumfordEquivL (baseChangeMumford (mumfordEquivQ.symm x)) =
          baseChangePic (mumfordEquivQ (mumfordEquivQ.symm x)) :=
        classOf_baseChangeMumford (mumfordEquivQ.symm x)
      _ = baseChangePic x := by rw [mumfordEquivQ.apply_symm_apply]
      _ = baseChangePic y := hxy
      _ = baseChangePic (mumfordEquivQ (mumfordEquivQ.symm y)) := by
        rw [mumfordEquivQ.apply_symm_apply]
      _ = mumfordEquivL (baseChangeMumford (mumfordEquivQ.symm y)) :=
        (classOf_baseChangeMumford (mumfordEquivQ.symm y)).symm
  exact mumfordEquivQ.symm.injective
    (baseChangeMumford_injective hM)
```

This requires only:

```text
• uniqueness of reduced oriented representatives over ℚ and L;
• preservation of reducedness under coefficient extension;
• injectivity of algebraMap ℚ L;
• classOf_mumfordMapCoeffs.
```

It avoids an abstract Picard scheme and avoids Galois descent in the main build.

# 6. Abstract Hilbert-90 backup

The mathematical theorem is:

> If `X/k` is proper and geometrically integral, and `K/k` is finite Galois, then `Pic(X) → Pic(X_K)` is injective, because `Γ(X_K,O)^× = K^×` and `H¹(Gal(K/k),K^×)=0`.

For a class whose pullback is trivial:

1. choose a trivialization over `K`;
2. comparing it with all Galois conjugates gives a cocycle
   `c : Gal(K/k) → Kˣ`;
3. apply the pinned Mathlib theorem

```lean
groupCohomology.isMulCoboundary₁_of_isMulCocycle₁_of_aut_to_units
```

4. rescale the trivialization by the resulting `β : Kˣ`;
5. the rescaled trivialization is Galois invariant and descends.

At the rational-function level, if an extended divisor class is generated by `α ∈ L(C)ˣ`, then `g(α)/α` has zero divisor and is therefore a constant in `Lˣ`; Hilbert 90 rescales `α` to a Galois-invariant element of `ℚ(C)ˣ`.

A project theorem may be stated as

```lean
theorem orientedClassBaseChange_injective_hilbert90 :
    Function.Injective orientedClassBaseChange := by
  -- Construct the cocycle from a trivialization/principal generator,
  -- invoke Hilbert 90, descend the invariant generator, and preserve
  -- the infinity orientation.
  sorry
```

The rational infinity points are not needed for Hilbert 90. They provide the rational orientation/basepoint and the identification of the concrete divisor quotient with `Pic^0(C)(ℚ)`.

Only injectivity is asserted. Surjectivity onto Galois-fixed classes can have a Brauer obstruction and is not needed.

# 8. Compiler-final generic core

This code compiled unchanged against the pinned FLT/Mathlib setup (`EXIT_STATUS=0`). The project-specific obligations are precisely the fields of `Data`.

```lean
import Mathlib

set_option autoImplicit false

namespace FLT.CyclicExclusion.N18.BaseChangeReference

section Generic

variable {MQ ML JQ JL : Type*}
variable [AddCommGroup MQ] [AddCommGroup ML]
variable [AddCommGroup JQ] [AddCommGroup JL]

structure Data (MQ ML JQ JL : Type*)
    [AddCommGroup MQ] [AddCommGroup ML]
    [AddCommGroup JQ] [AddCommGroup JL] where
  classQ : MQ ≃+ JQ
  classL : ML ≃+ JL
  mapCoeffs : MQ → ML
  mapCoeffs_injective : Function.Injective mapCoeffs
  orientedClassBaseChange : JQ →+ JL
  class_mapCoeffs : ∀ M : MQ,
    classL (mapCoeffs M) = orientedClassBaseChange (classQ M)

namespace Data

variable (d : Data MQ ML JQ JL)

noncomputable def baseChangeMumford : MQ →+ ML :=
  d.classL.symm.toAddMonoidHom.comp
    (d.orientedClassBaseChange.comp d.classQ.toAddMonoidHom)

@[simp] theorem baseChangeMumford_apply (M : MQ) :
    d.baseChangeMumford M = d.mapCoeffs M := by
  apply d.classL.injective
  simpa [baseChangeMumford] using (d.class_mapCoeffs M).symm

noncomputable abbrev baseChangePic : JQ →+ JL :=
  d.orientedClassBaseChange

@[simp] theorem class_baseChangeMumford (M : MQ) :
    d.classL (d.baseChangeMumford M) =
      d.baseChangePic (d.classQ M) := by
  simpa only [baseChangeMumford_apply] using d.class_mapCoeffs M

theorem baseChangeMumford_injective :
    Function.Injective d.baseChangeMumford := by
  intro x y hxy
  apply d.mapCoeffs_injective
  simpa only [baseChangeMumford_apply] using hxy

theorem baseChangePic_injective : Function.Injective d.baseChangePic := by
  intro x y hxy
  have hM : d.baseChangeMumford (d.classQ.symm x) =
      d.baseChangeMumford (d.classQ.symm y) := by
    apply d.classL.injective
    calc
      d.classL (d.baseChangeMumford (d.classQ.symm x)) =
          d.baseChangePic (d.classQ (d.classQ.symm x)) :=
        d.class_baseChangeMumford (d.classQ.symm x)
      _ = d.baseChangePic x := by rw [d.classQ.apply_symm_apply]
      _ = d.baseChangePic y := hxy
      _ = d.baseChangePic (d.classQ (d.classQ.symm y)) := by
        rw [d.classQ.apply_symm_apply]
      _ = d.classL (d.baseChangeMumford (d.classQ.symm y)) :=
        (d.class_baseChangeMumford (d.classQ.symm y)).symm
  exact d.classQ.symm.injective (d.baseChangeMumford_injective hM)

theorem annihilator_descends
    (d : Data MQ ML JQ JL) (n : ℕ)
    (hL : ∀ y : JL, n • y = 0) (x : JQ) :
    n • x = 0 := by
  apply d.baseChangePic_injective
  rw [map_nsmul, hL, map_zero]

@[reducible] noncomputable def finite_source_of_finite_target
    (d : Data MQ ML JQ JL) [Finite JL] : Finite JQ :=
  Finite.of_injective d.baseChangePic d.baseChangePic_injective

@[reducible] noncomputable def finite_curvePoints_of_finite_pic
    (d : Data MQ ML JQ JL) {CPoint : Type*} [Finite JL]
    (abelJacobi : CPoint → JQ)
    (hAJ : Function.Injective abelJacobi) : Finite CPoint := by
  letI : Finite JQ := d.finite_source_of_finite_target
  exact Finite.of_injective abelJacobi hAJ

end Data
end Generic
end FLT.CyclicExclusion.N18.BaseChangeReference
```
