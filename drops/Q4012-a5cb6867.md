# Q4012: explicit 2-descent data for 11a3

I would not bake the earlier informal sentence "the full 2-descent over K gives Sel2(E/Q)=0" into Lean until one extra finite table has been generated. The global squareclass part is explicit and small; the exact local failure place for each of the three non-identity classes should be obtained by a finite residue enumerator, not guessed.

## Field and bad primes

For

```text
E : y^2 + y = x^3 - x^2,
```

completing the square with `z = 2*y + 1` gives

```text
z^2 = 4*x^3 - 4*x^2 + 1.
```

With `beta = 2*x`, the 2-torsion cubic is

```text
f(T) = T^3 - 2*T^2 + 2.
```

So use

```text
K = Q(beta),   beta^3 - 2*beta^2 + 2 = 0.
```

The discriminant is

```text
disc(f) = -44 = -4*11.
```

Hence the rational primes in the descent support are only

```text
S_Q = {2, 11}.
```

The infinite place is also part of the Selmer condition, but the candidate classes below are positive at the unique real embedding, so the real place should not be the source of the obstruction.

## Prime decomposition and norm data

Modulo `2`,

```text
f(T) == T^3 mod 2.
```

Thus `2` is totally ramified. Since

```text
Norm(beta) = -2,
```

one may use

```text
(2) = p2^3,   p2 = (beta),   Norm(p2)=2.
```

Modulo `11`,

```text
f(T) == (T - 3)*(T - 5)^2 mod 11.
```

Thus

```text
(11) = p11a * p11b^2,
```

where `p11a` has `beta == 3 mod 11` and `p11b` is the ramified prime with `beta == 5 mod 11`.

Useful principal generators are:

```text
Norm(beta - 3) = -f(3) = -11.
pi := beta^2 + beta + 3,
Norm(pi) = 121 = 11^2.
```

The norm of `pi` follows from the multiplication matrix for `a + b*beta + c*beta^2`, using `beta^3 = 2*beta^2 - 2`:

```text
[ a        -2*c          -2*b - 4*c ]
[ b         a            -2*c       ]
[ c         b + 2*c       a + 2*b + 4*c ]
```

Plugging `(a,b,c)=(3,1,1)` gives determinant `121`.

## S-unit squareclasses with square rational norm

A convenient unit is

```text
eps := beta - 1,
Norm(eps) = -f(1) = -1.
```

The relevant S-unit squareclasses are generated by

```text
-1, eps=beta-1, beta, beta-3, pi=beta^2+beta+3.
```

The rational norm squareclasses are

```text
-1       -> -1
eps      -> -1
beta     -> -2
beta - 3 -> -11
pi       -> 1.
```

Over `F_2`, using basis `[-1], [2], [11]`, this is

```text
-1       -> (1,0,0)
eps      -> (1,0,0)
beta     -> (1,1,0)
beta - 3 -> (1,0,1)
pi       -> (0,0,0).
```

Therefore the square-rational-norm kernel is generated by

```text
eta := -eps = 1 - beta,
pi  := beta^2 + beta + 3.
```

So the candidate group is exactly

```text
H = {1, eta, pi, eta*pi}
  = {1, 1-beta, beta^2+beta+3, (1-beta)*(beta^2+beta+3)}.
```

This is the main explicit certificate. A rank-zero 2-descent reduces to ruling out local points on the three non-identity coverings.

## Local obstruction table

I cannot honestly provide the exact table saying which of the three non-identity classes fails at `Q_2` and which fails at `Q_11` without running or reconstructing the local-solubility checker. The safe table shape is:

```text
squareclass                         obstruction place
-----------------------------------------------------
1 - beta                            Q_2 or Q_11
beta^2 + beta + 3                   Q_2 or Q_11
(1 - beta)*(beta^2 + beta + 3)       Q_2 or Q_11
```

The real place should not obstruct these classes: the real root of `T^3 - 2*T^2 + 2` is negative, hence both `1-beta` and `beta^2+beta+3` are positive under the real embedding.

So the honest answer to item 3 is: the candidate squareclasses are explicit, but the exact local obstruction place for each non-identity class still needs a finite residue checker.

## Finite local checks

For a candidate `delta in H`, write the covering condition as

```text
delta * w^2 = X - beta,
w = a + b*beta + c*beta^2,
X in Q.
```

Using

```text
beta^3 = 2*beta^2 - 2,
beta^4 = 4*beta^2 - 2*beta - 4,
```

we get

```text
w^2 = s0 + s1*beta + s2*beta^2
```

where

```text
s0 = a^2 - 4*b*c - 4*c^2,
s1 = 2*a*b - 2*c^2,
s2 = b^2 + 2*a*c + 4*b*c + 4*c^2.
```

For `delta = eta = 1-beta`, multiplication by `1-beta` sends `s0+s1*beta+s2*beta^2` to

```text
(s0 + 2*s2) + (s1 - s0)*beta + (-s1 - s2)*beta^2.
```

Therefore the `eta` covering equations are

```text
s1 + s2 = 0,
s1 - s0 = -1,
```

or equivalently

```text
2*a*b + b^2 + 2*a*c + 4*b*c + 2*c^2 = 0,
-a^2 + 2*a*b + 4*b*c + 2*c^2 = -1.
```

The equations for `delta = pi` and `delta = eta*pi` are obtained by the same multiplication-matrix expansion.

A `Q_p` local failure can be certified by proving that the corresponding expanded system has no primitive solution modulo `p^N` for some finite `N`, with `p = 2` or `p = 11`. Those finite residue statements are suitable for `native_decide` or, for small moduli, `norm_num` after expansion.

## Can the proof be reduced to finite Lean checks?

Mostly yes.

Finite/kernel-checkable parts:

1. irreducibility of `T^3 - 2*T^2 + 2` by rational-root check;
2. discriminant computation `disc = -44`;
3. mod `2` and mod `11` factorization;
4. norm identities for `beta`, `beta-1`, `beta-3`, and `pi`;
5. `F_2` linear algebra giving `H = {1, eta, pi, eta*pi}`;
6. each local nonsolubility certificate once `p`, `N`, and the residue equations are fixed.

The one global input is completeness of the S-unit list. To make this self-contained, prove class number one for the cubic field of discriminant `-44`, or prove the required principalization lemma directly for this field. Since the discriminant is tiny, a Minkowski-bound proof should be feasible in Lean.

## Bottom line

The explicit safe certificate currently is:

```text
Bad primes: 2 and 11.
K = Q(beta), beta^3 - 2*beta^2 + 2 = 0, disc(K)=-44.
Norm-square supported squareclasses:
  1,
  eta = 1 - beta,
  pi = beta^2 + beta + 3,
  eta*pi.
```

To finish the rank-zero proof, generate finite local obstruction certificates for `eta`, `pi`, and `eta*pi` at `Q_2` and/or `Q_11`. Once those three finite checks are in Lean, the descent proves

```text
Sel^(2)(E/Q) = 0.
```

Since `E(Q)_tors` is `Z/5Z`, multiplication by `2` is bijective on torsion, so `E(Q)/2E(Q)=0` exactly means `rank E(Q)=0`.
