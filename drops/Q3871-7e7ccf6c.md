# Cyclic order 27: simplest route and what does not work

## Executive answer

There is no purely same-curve elementary contradiction from the points `3P` and `9P`.  If `P` has order `27`, then

```text
3P has order 9,
9P has order 3,
9P = 3*(3P),
```

so these points are nested in one cyclic subgroup.  They do not produce independent rational `3`-torsion, and the abstract torsion structure theorem with `m1 <= 2` still allows the cyclic group `Z/27Z`.

The cleanest route that avoids writing down a Velu quotient is instead:

```text
P in E(Q), order(P)=27
  ==> C = <P> is a rational cyclic subgroup of E[27]
  ==> (E,C) is a noncuspidal rational point on X0(27)
  ==> use the Fermat-cubic model of X0(27)
  ==> FLT for exponent 3 classifies the rational points
  ==> remaining cusp/CM cases do not lift to a rational generator of order 27.
```

This avoids constructing the quotient curve `E/C`.  It does not avoid modular curves: it uses the forgetful map

```text
X1(27) -> X0(27),    (E,P) |-> (E,<P>).
```

That forgetful map is much simpler than a full Velu implementation.

## Correction to the degree-3 quotient idea

The degree-3 quotient is not analogous to the degree-2 tricks for orders `20` and `24`.

For `20` and `24`, the dual kernel has order `2`.  A rational subgroup of order `2` has a unique nonzero element, so that element is automatically rational.

For order `27`, set

```text
Q = 9P,
phi : E -> E' = E/<Q>.
```

Then `phi(P)` has order `9`: `9*phi(P)=0`, and if a smaller positive multiple killed it then the corresponding multiple of `P` would have to lie in `{0,Q,2Q}`, which is impossible by orders.

However, the dual kernel

```text
ker(phi_hat) subset E'[3]
```

is generally only a Galois-stable subgroup of order `3`, not a rational point of order `3`.  For an order-3 subgroup, Galois can swap the two nonzero generators by sign.  Thus the quotient does **not** automatically give rational torsion `Z/3Z x Z/9Z` on `E'`.

This is the key difference from the order-2 cases.  If the dual 3-kernel were pointwise rational, then `E'(Q)` would contain independent rational `3`-torsion and an order-`9` point, contradicting `m1 <= 2`.  The reason this shortcut fails is exactly that the dual kernel need not have a rational generator.

## X0(27) and the Fermat cubic

A rational point of order `27` directly gives a rational point on `X0(27)` by taking the cyclic subgroup it generates.  No quotient construction is needed for this implication if `X0(27)` is formulated as pairs `(E,C)` with `C` a rational cyclic subgroup.

The standard low-genus target is a Fermat-cubic model, schematically

```text
U^3 + V^3 = W^3.
```

Using `fermatLastTheoremThree`, the rational points on this curve are the coordinate-zero points after clearing denominators.  Under the modular identification of this Fermat cubic with `X0(27)`, those rational points correspond to cusps and the exceptional CM point with

```text
j = -12288000.
```

The CM point must be handled separately.  It represents a rational cyclic `27`-isogeny, but its kernel does not have a rational generator.  Therefore it is a rational point of `X0(27)` but not a rational point of `X1(27)`.

In a formal proof, isolate this as a lemma such as

```text
no_rational_27_torsion_of_j_eq_neg12288000
```

This can be proved by an explicit model plus reduction at a good prime, by checking the relevant 27-division polynomial for the finitely many twists, or by a Galois-character computation for the CM kernel.  It should not be hidden in the Fermat-cubic argument.

## Tate normal form: two choices, two different systems

There are two possible Tate-normal-form setups, and they should not be confused.

### 1. Put `P` itself at the Tate origin

If the marked Tate-origin point is the order-`27` point `P`, then the exact-order condition is

```text
psi_27(0,0) = 0,
psi_9(0,0) != 0,
b != 0,
Delta(b,c) != 0.
```

After removing the predictable power of `b`, this becomes

```text
F27(b,c) = 0,
F9(b,c) != 0.
```

This is a model of `X1(27)` after removing degeneracies.  It is high genus and is much harder than the genus-one `X0(27)` Fermat-cubic route.

### 2. Put `R = 3P` at the Tate origin

If the marked point is instead

```text
R = 3P,
```

then `R` has order `9`, so the Tate condition is the known small equation

```text
F9(b,c) = (b-c)^3 + c^3*(b-c-c^2) = 0.
```

But the extra order-`27` condition is not another useful `F27` equation at this origin.  Since `R` already has order `9`, it automatically satisfies `[27]R=0`.  The correct extra condition is rational 3-divisibility:

```text
there exists S in E(Q) such that [3]S = R.
```

In coordinates this is

```text
F9(b,c)=0,
S=(X,Y) lies on the Tate curve,
[3](X,Y)=(0,0).
```

Eliminating `X,Y` gives the cover `X1(27) -> X1(9)`.  This is again a high-genus problem.  It only becomes the Fermat-cubic problem after passing through the forgetful map to `X0(27)`.

## Recommended proof architecture

The most economical formal route is:

1. Prove a simple modular interpretation lemma:

   ```text
   HasRationalPointOfOrder E 27
     ==> rational point on X0(27) whose cyclic subgroup has a rational generator.
   ```

2. Prove or import the explicit identification of `X0(27)` with the Fermat cubic.

3. Use `fermatLastTheoremThree` to classify rational points on that cubic.

4. Show the cusp cases are impossible for a nonsingular elliptic curve with a finite cyclic subgroup of order `27`.

5. Show the CM point `j=-12288000` has no rational lift to `X1(27)`, equivalently no rational point of order `27` on the corresponding rational elliptic curves.

If modular curves are not yet available, the computational substitute is to write explicit rational functions from the Tate-normal-form parameter space for `X1(27)` to the Fermat-cubic model of `X0(27)`.  That is still the forgetful map `X1(27) -> X0(27)` in coordinates, and it should be far smaller than solving the full `F27(b,c)=0` system.

## Final conclusion

The simplest proof is not a same-curve group-theory argument and not a raw `F27` division-polynomial attack.  It is the `X0(27)` forgetful-map argument:

```text
rational 27-torsion point
  ==> rational cyclic subgroup of order 27
  ==> rational point on X0(27)
  ==> Fermat cubic rational point
  ==> cusp or CM point
  ==> no rational generator of order 27.
```

The degree-3 quotient can be useful if you already have a 3-isogeny API, but it does not by itself create independent rational 3-torsion on the quotient.  The dual kernel is rational as a subgroup, not necessarily pointwise rational.
