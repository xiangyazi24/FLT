# Route-selection memo for global additivity of `thetaCandidate`

## Executive recommendation

Use **one fixed-`Q`, branchwise propagation argument, normalized at `P → O`**.  Do not try to evaluate every local-constancy interval by a separate algebraic basepoint.  For fixed `Q`, define

```text
D_Q(P) = thetaCandidate (P + Q) - thetaCandidate P - thetaCandidate Q
```

as an `AddCircle (2*T)`-valued function on the identity component.  On each upper/lower branch, remove the finite set where the affine chord chart is singular or the output hits a junction.  Your existing derivative-zero lemmas prove `D_Q` is locally constant on each resulting open interval.  Then:

1. prove the constant on the unbounded tail interval is `0` by taking `x → ∞`, so `P(x) → O` and `P(x)+Q → Q`;
2. move leftward across the finitely many exceptional points using continuity of the actual defect `D_Q`, not by redoing derivative algebra;
3. take `x → e+` at the left endpoint to get the root input case;
4. handle `P = O` directly.

This is the cleanest route because the only normalization is the identity law at `O`.  The vertical point `P=-Q` and tangent point `P=Q` should be **patch points**, not primary basepoints.  The root endpoint should also be a patch point, except when `Q` is the root, where the same tail normalization still works.

## 1. Cleanest local-to-global route

Fix `Q` in the identity component.

### Case `Q = O`

This is immediate from the group identity:

```text
theta(P + O) - theta(P) - theta(O) = theta(P) - theta(P) - 0 = 0.
```

This case should be split first, before introducing chord coordinates.

### Case `Q` affine

Write `Q=(a,b)`.  If `Q` is not the root, then `a>e` and `b≠0`.  If `Q` is the root, then `a=e`, `b=0`.

For each input sign `s ∈ {upper, lower}`, set

```text
y_s(x) =  sqrt(f(x))     for upper,
y_s(x) = -sqrt(f(x))     for lower,
P_s(x) = (x, y_s(x)),    x>e.
```

Let

```text
F_s(x) = D_Q(P_s(x)).
```

The existing derivative/local-constancy lemmas show that `F_s` is locally constant on every open preconnected interval on which:

```text
x>e,
x-a ≠ 0,
P_s(x)+Q is affine with x-coordinate x3>e,
and the output branch sign is constant.
```

The global proof should not attempt to choose these intervals manually from the derivative proof.  Instead, define a finite exceptional set `E_{Q,s}` and prove that every connected component of `(e,∞) \ E_{Q,s}` satisfies the hypotheses of the local lemma.

The branchwise theorem is then:

```text
∀ x>e, F_s(x)=0.
```

Proof order on a branch:

1. On the final interval `(c,∞)` after the largest exception, use local constancy plus the limit `x→∞` to prove the constant is `0`.
2. Suppose an interval immediately to the right of an exception `r` has constant `0`.  Use continuity of `F_s` at the actual component point `P_s(r)` to prove `F_s(r)=0`.  Then use continuity from the left and local constancy on the interval to the left to prove that interval also has constant `0`.
3. Iterate.  Since there are at most two interior exceptions per branch, this can be done by an explicit case split on their order rather than by a general finite-partition theorem.
4. Once the first interval `(e,c)` has constant `0`, take `x→e+` to prove the root input case `D_Q(root)=0`.
5. `P=O` was already direct.

This proves `D_Q(P)=0` for all `P` after applying the existing branch-reduction lemmas.

## 2. How to evaluate constants

### Best basepoint: `x → ∞`

This is the normalization that minimizes algebra:

```text
P_s(x) → O,
P_s(x)+Q → Q,
theta(P_s(x)) → 0,
theta(P_s(x)+Q) → theta(Q).
```

Therefore

```text
F_s(x) = theta(P_s(x)+Q) - theta(P_s(x)) - theta(Q) → theta(Q)-0-theta(Q)=0.
```

If `F_s` is constant on a tail interval, uniqueness of limits in `AddCircle (2*T)` gives that constant equal to `0`.

This route uses only the identity law at `O`, continuity of translation by fixed `Q` at `O`, and the already checked `sigma(x) → 0` as `x → ∞`.

For affine chord coordinates, the tail algebra to package as lemmas is:

```text
m(x)  = (y-b)/(x-a),
x3(x)= m(x)^2 - A - x - a,
y3(x)= -(y + m(x)*(x3(x)-x)).
```

For non-root affine `Q=(a,b)`, assuming `y^2=f(x)` and `b^2=f(a)`, one exact identity is

```text
(chordX A x y a b - a) * (x-a)^2
  = (B + 2*A*a + 3*a^2)*x + (B*a - a^3) - 2*b*y.
```

So along either branch `y=±sqrt(f x)`, the right-hand side is `O(x) + O(x^(3/2))`, while `(x-a)^2` is `O(x^2)`, hence

```text
chordX A x y_s(x) a b → a.
```

Do not stop there: `x3→a` alone does **not** identify whether the output tends to `Q` or `-Q`.  You also need either

```text
chordY A x y_s(x) a b → b,
```

or, better if available, a projective/topological-group continuity lemma saying that affine points on either branch tend to `O` at infinity and addition is continuous, hence `P_s(x)+Q→Q`.

For `Q=root=(e,0)`, the tail algebra is especially clean.  If `f(e)=0`, `f'(e)=shortCubicDeriv A B e`, and `y^2=f(x)`, then

```text
chordX A x y e 0 - e = shortCubicDeriv A B e / (x-e),
chordY A x y e 0     = - y * shortCubicDeriv A B e / (x-e)^2.
```

Thus, for `x>e`, `chordX→e+` and the output sign is the opposite input sign.  Since `theta(root)=T` and the branch limits at `e+` are `T` modulo `2*T`, the same tail normalization gives

```text
D_root(P_s(x)) → theta(root)-0-theta(root)=0.
```

### Vertical basepoint `x → a`, where `P=-Q`

This is useful only as a patch point.  It proves the adjacent interval constants equal `0` because

```text
P_s(x) → -Q,
P_s(x)+Q → O,
theta(P_s(x)+Q) → 0,
theta(P_s(x)) → theta(-Q) = -theta(Q).
```

Hence

```text
F_s(x) → 0 - (-theta(Q)) - theta(Q)=0.
```

But this point exists only on the branch opposite to `Q`; it does not normalize the same branch, where `x=a` is the tangent/doubling point.  Therefore it is not a global basepoint.

### Root endpoint `x → e+`

This is also a patch point.  Once the leftmost open interval has already been shown to have constant `0`, take the limit to get

```text
D_Q(root)=0.
```

Using the root endpoint as the primary basepoint would require proving additivity for translation by the root, or proving the explicit root-translation integral identity, before the main argument.  That is unnecessary if the tail normalization is used.

### Tangent point `x=a`, where `P=Q`

Do **not** try to evaluate the constant here first.  At this point

```text
F_s(a)=theta(2Q)-2*theta(Q),
```

which is exactly a special case of the target theorem.  The correct move is:

1. prove the interval on one side of `a` has constant `0` from the tail or from previously propagated intervals;
2. prove the secant addition formula tends to the tangent/doubling value `2Q` as `x→a` along the same branch;
3. use continuity of `theta` at `2Q` to infer `F_s(a)=0`;
4. propagate to the interval on the other side.

This avoids circularity: continuity of addition at the tangent is allowed; additivity of `theta` at the tangent is what is being derived.

## 3. Finite exceptional set and partition facts

For fixed affine `Q=(a,b)` and input branch `s`, the minimal exceptional set is

```text
E_{Q,s} = E_den ∪ E_root,
```

where:

```text
E_den  = {a}, if a>e; otherwise ∅.
E_root = {x-coordinate of ((e,0) - Q)}, if that point is affine on branch s; otherwise ∅.
```

More explicitly:

* `x=a` is the only place where the secant formula with denominator `x-a` fails.  If the branch contains `Q`, this is the tangent/doubling point `P=Q`; if it contains `-Q`, this is the vertical point `P=-Q` and the sum is `O`.
* `P=(e,0)-Q` is the unique point whose sum with `Q` is the root `(e,0)`.  If it lies on the chosen affine branch, its `x`-coordinate is the only point where the output branch hits the root junction.

This gives at most two interior exceptions per branch.  It is better to prove finiteness via group cancellation/translation bijectivity than by solving polynomial equations.  Polynomial clearing is possible, but introduces square roots and possible extraneous roots after squaring.  The group-theoretic statement is sharper:

```text
P + Q = O       ↔ P = -Q,
P + Q = root    ↔ P = root - Q,
P = Q           ↔ branch-coordinate x = a on the branch containing Q.
```

The real-analysis/topology obligations are then:

1. **Interval decomposition.**  For a set with zero, one, or two exceptional real numbers in `(e,∞)`, decompose `(e,∞)` into the obvious open intervals: `(e,c)`, `(c,∞)`, or `(e,c₁)`, `(c₁,c₂)`, `(c₂,∞)`.  In Lean this can be done by explicit order case splits instead of a general finite-set sorting theorem.
2. **No exception on an interval.**  On such an interval, prove `x-a≠0` and `P_s(x)+Q` is neither `O` nor the root.  Since `P_s(x)+Q` remains in the identity component, branch reduction gives an upper or lower output point with `x3>e`.
3. **Output sign is constant.**  The function `x ↦ chordY A x y_s(x) a b` is continuous away from `x=a`.  If it had both signs on a connected interval, the intermediate value theorem would give a zero, hence an output two-torsion point.  In the identity component that means the root, already excluded.  Therefore the sign is constant on each interval.
4. **Apply local constancy.**  Use the existing AddCircle-valued local-constancy lemma on each interval.
5. **Endpoint and removable-singularity limits.**  Use continuity/asymptotic lemmas at `∞`, `e+`, vertical `P=-Q`, tangent `P=Q`, and output-root points to identify adjacent constants.

## 4. Case handling

### `Q=O`

Direct identity case.  No branch, chord, or integral argument is needed.

### `Q=root=(e,0)`

Use the same branchwise argument.  Here `x-a=x-e≠0` for all branch points with `x>e`, so there is no denominator exception inside `(e,∞)`.  Also `(e,0)-Q=O`, so there is no finite output-root preimage.  The two branches are locally constant on all of `(e,∞)` after proving the output sign is the opposite input sign.

Use the root-tail identities

```text
chordX A x y e 0 - e = f'(e)/(x-e),
chordY A x y e 0     = - y * f'(e)/(x-e)^2.
```

Since `f'(e)>0`, the output has `x3>e` and opposite sign.  Tail evaluation gives constant `0`; the endpoint `x→e+` gives the input-root case.  The point `root+root=O` can also be checked directly because `T+T=0` in `AddCircle (2*T)`.

### `Q` upper or lower, non-root

Assume `Q=(a,b)` with `a>e`, `b≠0`.

For the branch opposite to `Q`, the point `x=a` is vertical: `P=-Q`, so `P+Q=O`.  Its defect is already zero by negation compatibility:

```text
D_Q(-Q) = theta(O)-theta(-Q)-theta(Q)=0.
```

Use vertical asymptotics only to patch the adjacent local-constancy intervals.

For the branch containing `Q`, the point `x=a` is tangent: `P=Q`.  Do not prove `theta(2Q)=2theta(Q)` directly.  Prove that the secant formula tends to the tangent sum `2Q`, then infer the defect at `Q` from the already-zero adjacent interval by continuity.

For either branch, if `P+Q=root`, then `P=root-Q`.  This is at most one point.  Patch it by continuity of addition and the root continuity of `theta`.  If this point coincides with `P=Q`, then `2Q=root`; the same tangent-continuity patch handles it, with the output limit landing at the root.

### `P=-Q`

This is the only affine point where `P+Q=O`.  The theorem there is immediate from negation compatibility, but the local interval proof still needs the limit `P_s(x)+Q→O` as `x→a` on the vertical branch.  In chord coordinates `m→∞`, `x3→∞`, and `theta(P_s(x)+Q)→0` on either output sign because `sigma(x3)→0`.

### `P=Q`

This is the tangent/doubling point on the same branch as `Q`.  The value

```text
D_Q(Q)=theta(2Q)-2theta(Q)
```

must be obtained by continuity from a neighboring interval whose constant is already known to be zero.  This is the most common hidden circularity in this proof.

### `P+Q=root`

At a regular chord point, `x-a≠0` and the rational formula is continuous, so `P_s(x)+Q→root`.  The only analytic ingredient is

```text
sigma(x) → T as x → e+,
```

and the fact that upper and lower branch formulas both tend to `T` modulo `2*T`:

```text
-sigma(x) → -T = T  in AddCircle (2*T),
 sigma(x) →  T.
```

If `sigma_at_root` has not yet been proved, it is a real gap.

### `P+Q=O`

This is `P=-Q`.  Use direct negation compatibility for the point and vertical asymptotics for neighboring intervals.

## 5. Dependency DAG of concrete lemmas

### A. Continuity and endpoint behavior of `thetaCandidate`

**A1. Branch continuity.**

```text
x ↦ thetaCandidate(upperRight x) = -sigma(x) mod 2T
x ↦ thetaCandidate(lowerRight x) =  sigma(x) mod 2T
```

is continuous on `(e,∞)`.

Proof idea: continuity of `sigma` on `(e,∞)` from the integral/derivative facts already developed, plus continuity of real-to-`AddCircle` coercion and negation.

**A2. Infinity endpoint.**

```text
thetaCandidate(P_s(x)) → 0 as x→∞.
```

Proof idea: `sigma(x)→0` as `x→∞`.

**A3. Root endpoint.**

```text
thetaCandidate(upperRight x) → thetaCandidate(root),
thetaCandidate(lowerRight x) → thetaCandidate(root)
```

as `x→e+`.

Proof idea: prove or reuse `sigma(x)→T` as `x→e+`; then `-T=T` in `AddCircle (2*T)`.

Hidden gap: the context lists `sigma>0`, `sigma<T`, and `sigma→0` at infinity, but not explicitly `sigma→T` at the root.  The root continuity patches require this.

### B. Chord/addition continuity lemmas

**B1. Chord equals actual addition off `x=a`.**

For `x>e`, `x≠a`, and `P_s(x)` on the curve, the affine point produced by `chordX/chordY` is the actual sum `P_s(x)+Q`, unless the result is `O` or a junction handled separately.

Proof idea: use the existing affine addition formula lemmas from the Weierstrass development.

**B2. Tail addition continuity.**

```text
P_s(x)+Q → Q as x→∞.
```

Proof idea: either use continuity of the group law in projective coordinates at `O`, or prove directly from chord formulas.  For direct proof, use the exact identity

```text
(chordX A x y a b - a) * (x-a)^2
  = (B + 2*A*a + 3*a^2)*x + (B*a - a^3) - 2*b*y
```

plus a separate sign/`y3→b` lemma.  Do not infer the sign from `x3→a` alone.

**B3. Root-tail addition.**

For `Q=root`, prove

```text
chordX A x y e 0 = e + f'(e)/(x-e),
chordY A x y e 0 = -y*f'(e)/(x-e)^2.
```

Proof idea: `ring_nf` using `f(e)=0`, `y^2=f(x)`, and `shortCubicDeriv A B e = 3*e^2 + 2*A*e + B`.

**B4. Vertical limit.**

On the branch where `P_s(a)=-Q`, prove

```text
P_s(x)+Q → O as x→a, x≠a.
```

Proof idea: `y_s(x)-b → -2b ≠ 0`, so `m→±∞`, hence `x3→∞`; then `theta` of either output branch tends `0` because `sigma(x3)→0`.

**B5. Tangent limit.**

On the branch where `P_s(a)=Q`, prove

```text
P_s(x)+Q → Q+Q as x→a, x≠a.
```

Proof idea: the secant slope tends the tangent slope `f'(a)/(2*b)`, using the checked derivative of `sqrt(f x)`.  Then `x3,y3` tend to the tangent formula.  This is continuity of addition, not additivity of `theta`.

**B6. Output-root limit.**

At the unique point `P0=root-Q`, prove

```text
P_s(x)+Q → root as x→x0.
```

Proof idea: if `x0≠a`, the rational chord maps are continuous.  If it coincides with the tangent point, use B5 and the fact that `2Q=root`.

### C. Component and branch-reduction lemmas

**C1. Closure of the identity component under addition.**

For fixed `Q` and branch point `P_s(x)`, prove `P_s(x)+Q` is again in the identity component.

Proof idea: mathematically, the connected component of the identity in a topological group is a subgroup.  If this is not already formalized for the real Weierstrass point type, it is a major missing dependency.  Without it, branch reduction for the output cannot be applied.

**C2. Branch reduction for outputs.**

If an affine output in the identity component is not the root, then it has `x3>e` and lies on exactly one of the two signs.

This is already listed as checked, but the proof must be available for `P_s(x)+Q`, not just arbitrary input points.

**C3. Uniqueness of exceptional preimages.**

```text
P+Q=O    ↔ P=-Q,
P+Q=root ↔ P=root-Q.
```

Proof idea: group cancellation.  This gives finiteness of the exceptional set without solving equations.

### D. Interval local constancy and propagation

**D1. Local constancy on clean intervals.**

Use the existing lemmas for all four input/output branch signs.

Input hypotheses to package:

```text
I is an open interval and preconnected,
∀ x∈I, e<x,
∀ x∈I, x-a≠0,
∀ x∈I, output x3>e,
∀ x∈I, output sign is fixed.
```

Conclusion:

```text
F_s is constant on I.
```

**D2. Tail interval constant is zero.**

If `F_s` is constant on `(c,∞)`, then the constant is `0` by B2/A2 and uniqueness of limits.

**D3. Propagation across a point.**

Let `r` be an exceptional point.  Suppose `F_s=0` on the interval immediately to the right of `r`.  If `F_s` is continuous at `r`, then `F_s(r)=0`.  If `F_s` is locally constant on the interval immediately to the left, then that left interval also has constant `0`.

Proof idea: one-sided limits in a Hausdorff space.  In Lean, search around:

**D4. Branch global theorem.**

Because each branch has at most two interior exceptions, prove by explicit order cases:

```text
no exception,
one exception c,
two exceptions c1<c2,
two exceptions c2<c1,
coincident exceptions.
```

Avoid a general sorted-finset development unless it already exists in the project.

**D5. Global additivity.**

Use branch reduction for `P`:

```text
P=O       -> direct,
P=root    -> left-endpoint result from branch theorem,
P=upper   -> branch global theorem,
P=lower   -> branch global theorem.
```

Then discharge fixed `Q` by cases:

```text
Q=O       -> direct,
Q=root    -> affine/root branch argument,
Q=upper   -> affine branch argument,
Q=lower   -> affine branch argument.
```

## Adversarial checklist: hidden gaps to close before S7/S8

1. **Local constancy does not imply global constancy.**  A finite exceptional set can separate the branch.  You need continuity/removable-singularity lemmas at every separator.

2. **The tangent point is circular if used as a basepoint.**  `theta(2Q)=2theta(Q)` is the target, not an input.  Prove it by continuity from a neighboring zero interval.

3. **`x3→a` at infinity is insufficient.**  The output could tend to `Q` or `-Q`; prove `y3→b` or use projective continuity of addition at `O`.

4. **Root continuity requires `sigma→T` at `e+`.**  If only `sigma<T` is known, the root patches are not justified.

5. **Closure of the component under addition is essential.**  The output branch-reduction lemmas apply only after proving `P+Q` is still in the identity component.

6. **Other real two-torsion roots must be excluded by component closure.**  If the curve has other real roots, an affine output with `y=0` could be another root unless you know the output is in the identity component.  The stated branch reduction says the only identity-component affine junction is `(e,0)`; make sure it is used exactly there.

7. **AddCircle limit uniqueness must be available.**  To turn a locally constant tail with limit `0` into equality with `0`, use Hausdorffness/limit uniqueness for `AddCircle (2*T)`.

8. **Do not overbuild finite-set topology.**  There are at most two interior exceptional coordinates per branch.  Explicit interval case splits will likely be faster in Lean than a reusable sorted partition API.

The route above keeps the hard algebra confined to: tail addition continuity, vertical asymptotics, tangent continuity, and root endpoint continuity.  The derivative-zero lemmas then do exactly what they should: prove local constancy on clean intervals; all global information comes from continuity and the single normalization at `O`.
