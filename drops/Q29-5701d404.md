# X₁(19) → X₀(19): diamond traces, offsets, and CRT reconstruction

## Final normalization

Let

\[
\sigma(b,c)=\left(\frac{F_9(b,c)^3}{F_6(b,c)^8},
                 -\frac{cK(b,c)}{F_6(b,c)^4}\right),
\]

where

\[
\begin{aligned}
F_5&=b-c,\\
F_6&=b-c^2-c,\\
F_{7,\mathrm{std}}&=b^2-bc-c^3,\\
F_8&=2b^2-bc^2-3bc+c^2,\\
F_9&=b^3-3b^2c+bc^3+3bc^2-c^5-c^4-c^3,\\
K&=3b^4-b^3c^2-9b^3c+10b^2c^2+bc^4-5bc^3+c^6+c^4.
\end{aligned}
\]

Put

\[
\alpha=\frac{F_{7,\mathrm{std}}}{F_8},
\qquad
\beta=\frac{F_5F_{7,\mathrm{std}}}{F_9},
\]

and take the nine-term diamond traces

\[
U=\sum_{i=0}^{8}\alpha\circ\sigma^i,
\qquad
V=\sum_{i=0}^{8}\beta\circ\sigma^i.
\]

The correct affine change to

\[
X_0(19)=19\mathrm{a}2:\qquad y^2+y=x^3+x^2-9x-15
\]

is

\[
\boxed{x=U+2,\qquad y=U-V-1.}
\]

Equivalently, the trace coordinates themselves satisfy

\[
\boxed{
V^2-2UV+V=U^3+6U^2+8U-21.
}
\tag{1}
\]

Indeed, substituting `x = U + 2` and `y = U - V - 1` into the 19a2 equation reduces it exactly to (1).

The only other affine formula with the same `x` and the same function field is obtained by elliptic negation:

\[
-y-1=V-U.
\]

Thus, if the opposite sign convention for the identification with 19a2 is used, replace

\[
y=U-V-1
\]

by

\[
y'=V-U.
\]

The p=17 convention in the question was `y = U - V - 1`; retaining that convention at p=19 selects the first formula above.

## Check at the two finite rational points

At either finite rational point of 19a2 one has `x=5`, hence

\[
U=3.
\]

The two possible values of `V` are then

\[
\begin{array}{c|c|c}
(U,V)&(x,y)&\text{interpretation in the standard modular normalization}\\ \hline
(3,-7)&(5,9)&\text{noncuspidal point},\\
(3,12)&(5,-10)&\text{finite cusp}.
\end{array}
\]

So the most useful finite-field diagnostic is not just `U = 3`; it is

```text
noncuspidal fiber:  U = 3, V = -7,
cuspidal fiber:     U = 3, V = 12.
```

Modulo 1009, `-7` is `1002`.

If an existing computation returns `V=12` on the fiber that was intended to be noncuspidal, either the fiber was the cusp fiber or the chosen `X₀(19) ≃ 19a2` identification has been precomposed with negation.

# Polynomial normal forms A₁₉ and B₁₉

Let `F19(b,c)` be the primitive exact-order-19 factor, normalized to be monic of degree 15 in `b`. Since `F19` is monic in `b`, every class modulo `F19` has a unique representative of `b`-degree at most 14 over `ℚ(c)`.

For the above traces the integral normal forms are

\[
\boxed{
U=\frac{A_{19}(b,c)}{c^{36}},
\qquad
V=\frac{B_{19}(b,c)}{c^{37}}
\quad\text{in }\mathbf Q(X_1(19)).
}
\tag{2}
\]

The exponent

\[
36=\binom 92
\]

is the p=19 analogue of the p=17 exponent `28 = binom(8,2)`; the `β` trace carries one additional power of `c`.

Thus the map to the selected 19a2 model is

\[
\boxed{
\begin{aligned}
\operatorname{mapX}_{19}(b,c)
  &=\frac{A_{19}(b,c)+2c^{36}}{c^{36}},\\[1mm]
\operatorname{mapY}_{19}(b,c)
  &=\frac{cA_{19}(b,c)-B_{19}(b,c)-c^{37}}{c^{37}}.
\end{aligned}
}
\tag{3}
\]

The negated `y`-coordinate is especially simple:

\[
\operatorname{mapY}_{19}^{\iota}(b,c)
 =\frac{B_{19}(b,c)-cA_{19}(b,c)}{c^{37}}.
\]

The two finite fibers become the following polynomial systems:

\[
\begin{array}{c|c|c}
(x,y)&A_{19}&B_{19}\\ \hline
(5,9)&3c^{36}&-7c^{37},\\
(5,-10)&3c^{36}&12c^{37}.
\end{array}
\tag{4}
\]

For the order-19 exclusion, the first row is the load-bearing noncuspidal fiber.

# Exact cleared curve identity

Define

\[
X_n=A_{19}+2c^{36},
\qquad
Y_n=cA_{19}-B_{19}-c^{37}.
\]

Clearing the denominator `c^108` from the 19a2 equation gives

\[
\boxed{
 c^{34}Y_n^2+c^{71}Y_n-X_n^3-c^{36}X_n^2
 +9c^{72}X_n+15c^{108}
 =F_{19}\,Q_{19}
}
\tag{5}
\]

for an integral polynomial `Q19`. This is the certificate to export to Lean. Once (5) is stored, `on_X019_of_F19` is a `field_simp` followed by the polynomial identity and `F19(b,c)=0`.

Notice that (5) is an identity over `ℤ[b,c]`, not merely a finite-field test.

# Sage script: two-prime CRT reconstruction

The script below is self-contained. It does the following.

1. Reconstructs `F19` from the division-polynomial recurrence at the Tate origin.
2. Computes the nine diamond iterates in the finite algebra
   `𝔽_p[b]/(F19(b,c₀))` for many specializations `c=c₀`.
3. Recovers the 15 coefficient polynomials in `c` for `A19` and `B19` by adaptive interpolation.
4. Reconstructs the integer coefficients from two 61-bit primes by centered CRT.
5. Uses a third prime as a full stabilization check.
6. Verifies the trace relation (1) in independent finite algebras.
7. Verifies the exact integral divisibility (5).
8. Prints Sage expressions and Lean coefficient tables.

This coefficientwise interpolation is preferable to one giant bivariate Vandermonde matrix: the monicity and degree-15 equation in `b` reduce the problem to 30 ordinary univariate interpolations.

```sage

# so the extra EDS parameter is b^4.

    n = ZZ(n)
    if n in _pre:
        return _pre[n]
    if n == 0:
        z = R(0)
    elif n in (1,2):
        z = R(1)
    elif n == 3:

    elif n == 4:

             - prepsi0(m+1) * prepsi0(m+3) * prepsi0(m+4)^2)

                 - prepsi0(m+1) * prepsi0(m+3)^3)
        else:
            z = (prepsi0(m+4) * prepsi0(m+2)^3
                 - prepsi0(m+1) * prepsi0(m+3)^3 * b^4)
    _pre[n] = R(z)
    return _pre[n]

# 1. Arithmetic in k[z]/(f)
#
# We deliberately do not require f to be irreducible.  Division is
# allowed precisely when the denominator is coprime to f.  This makes
# almost every c-specialization usable and is much faster than hunting
# only for irreducible degree-15 specializations.
# ================================================================

class AlgElt:
    def __init__(self, modulus, value=0):
        self.f = modulus
        self.S = modulus.parent()
        self.v = self.S(value) % self.f

    def coerce(self, other):
        return other if isinstance(other, AlgElt) else AlgElt(self.f, other)

    def __add__(self, other):
        other = self.coerce(other)
        return AlgElt(self.f, self.v + other.v)
    __radd__ = __add__

    def __neg__(self):
        return AlgElt(self.f, -self.v)

    def __sub__(self, other):
        return self + (-self.coerce(other))

    def __rsub__(self, other):
        return self.coerce(other) - self

    def __mul__(self, other):
        other = self.coerce(other)
        return AlgElt(self.f, self.v * other.v)
    __rmul__ = __mul__

    def inverse(self):
        if self.v == 0:
            raise ZeroDivisionError
        g,s,t = self.v.xgcd(self.f)
        if g.degree() != 0:
            raise ZeroDivisionError
        return AlgElt(self.f, s / g[0])

    def __truediv__(self, other):
        return self * self.coerce(other).inverse()

    def __rtruediv__(self, other):
        return self.coerce(other) * self.inverse()

    def __pow__(self, n):
        n = ZZ(n)
        if n < 0:
            return self.inverse()^(-n)
        ans = AlgElt(self.f, 1)
        x = self
        while n:
            if n & 1:
                ans = ans*x
            x = x*x
            n //= 2
        return ans

    def __eq__(self, other):
        return self.v == self.coerce(other).v

    def coeff_vector(self, length=15):
        return [self.v[i] for i in range(length)]

# The formulas are repeated at the AlgElt level to avoid symbolic swell.
def eF5(B,C): return B-C
def eF6(B,C): return B-C^2-C
def eF7(B,C): return B^2-B*C-C^3
def eF8(B,C): return 2*B^2-B*C^2-3*B*C+C^2
def eF9(B,C):
    return B^3-3*B^2*C+B*C^3+3*B*C^2-C^5-C^4-C^3
def eK(B,C):
    return (3*B^4-B^3*C^2-9*B^3*C+10*B^2*C^2
            +B*C^4-5*B*C^3+C^6+C^4)

def esigma(B,C):
    d = eF6(B,C)
    return eF9(B,C)^3/d^8, -C*eK(B,C)/d^4

def trace_UV(B,C):
    B0,C0 = B,C
    U = B-B
    V = B-B
    for i in range(9):
        U += eF7(B,C)/eF8(B,C)
        V += eF5(B,C)*eF7(B,C)/eF9(B,C)
        B,C = esigma(B,C)
    # 3^9 = -1 mod 19, and the Tate-normal coarse point identifies P and -P.
    assert B == B0 and C == C0
    return U,V

class TraceSampler:
    def __init__(self, p):
        self.p = ZZ(p)
        self.k = GF(self.p)
        self.S.<z> = PolynomialRing(self.k)
        self.next_c = ZZ(1)
        self.samples = []

    def modulus_at(self, c0):
        c0 = self.k(c0)
        return self.S(sum(self.k(a)*c0^j*self.S.gen()^i
                          for a,i,j in F19_terms))

    def trace_at(self, c0):
        c0 = self.k(c0)
        if c0 == 0:
            raise ZeroDivisionError
        f = self.modulus_at(c0)
        if f.degree() != 15 or not f.is_squarefree():
            raise ZeroDivisionError
        B = AlgElt(f, self.S.gen())
        C = AlgElt(f, c0)
        U,V = trace_UV(B,C)
        return f,U,V

    def sample_at(self, c0):
        c0 = self.k(c0)
        f,U,V = self.trace_at(c0)
        A = U*c0^36
        B = V*c0^37
        return c0, A.coeff_vector(15), B.coeff_vector(15)

    def collect(self, n):
        while len(self.samples) < n:
            c0 = self.k(self.next_c)
            self.next_c += 1
            try:
                self.samples.append(self.sample_at(c0))
            except (ZeroDivisionError, ArithmeticError):
                pass
        return self.samples

# 3. Adaptive coefficientwise interpolation

def interpolate_vectors(k, samples, ntrain):
    T.<t> = PolynomialRing(k)
    train = samples[:ntrain]
    PA = []
    PB = []
    for i in range(15):
        PA.append(T.lagrange_polynomial([(x,a[i]) for x,a,bv in train]))
        PB.append(T.lagrange_polynomial([(x,bv[i]) for x,a,bv in train]))
    return PA,PB

def verify_interpolation(PA, PB, samples):
    for x,a,bv in samples:
        if any(PA[i](x) != a[i] for i in range(15)):
            return False
        if any(PB[i](x) != bv[i] for i in range(15)):
            return False
    return True

def polynomial_degree(P):
    return -1 if P == 0 else ZZ(P.degree())

def interpolate_mod_prime(p, start=32, nverify=24, max_train=1024):
    sampler = TraceSampler(p)
    ntrain = start
    while ntrain <= max_train:
        samples = sampler.collect(ntrain+nverify)
        PA,PB = interpolate_vectors(sampler.k, samples, ntrain)
        ok = verify_interpolation(PA,PB,samples[ntrain:ntrain+nverify])
        maxdeg = max([polynomial_degree(f) for f in PA+PB])
        print('p =',p,'train =',ntrain,'max c-degree =',maxdeg,'verified =',ok)
        # The safety gap prevents accepting an interpolation that merely
        # fills the entire training degree range.
        if ok and maxdeg <= ntrain-8:
            DA = {}
            DB = {}
            for i,P in enumerate(PA):
                for j,a in enumerate(P.list()):
                    if a:
                        DA[(i,j)] = ZZ(a)
            for i,P in enumerate(PB):
                for j,a in enumerate(P.list()):
                    if a:
                        DB[(i,j)] = ZZ(a)
            return DA,DB,maxdeg,sampler
        ntrain *= 2
    raise RuntimeError('increase max_train')

def crt_centered_pair(a,p,bv,q):
    a = ZZ(a) % p
    bv = ZZ(bv) % q
    z = a + p*(((bv-a)*inverse_mod(p,q)) % q)
```

## Why the quotient-algebra sampler is reliable

For a fixed `c₀`, the script works in

\[
\mathbf F_p[b]/(F_{19}(b,c_0)).
\]

It does not assume this algebra is a field. Every division requests an inverse by extended gcd and rejects the specialization if the denominator is a zero divisor. Thus every accepted sample computes the trace simultaneously on all geometric points of that fiber where the rational map is defined.

The resulting element has a unique representative of degree `<15` in `b`, which gives all 15 values

\[
a_0(c_0),\ldots,a_{14}(c_0)
\]

in one calculation. Interpolating each `a_i(c)` is therefore exact multivariate interpolation with the `b`-normal form built in.

# Lean-facing endpoint

A convenient interface is:

```lean
noncomputable def mapX19 (b c : ℚ) : ℚ :=
  (A19 b c + 2 * c ^ 36) / c ^ 36

noncomputable def mapY19 (b c : ℚ) : ℚ :=
  (c * A19 b c - B19 b c - c ^ 37) / c ^ 37
```

The central theorem should have the shape

```lean
theorem on_X019_of_F19
    {b c : ℚ}
    (hc : c ≠ 0)
    (hF : F19 b c = 0) :
    let x := mapX19 b c
    let y := mapY19 b c
    y ^ 2 + y = x ^ 3 + x ^ 2 - 9*x - 15 := by
  dsimp [mapX19, mapY19]
  field_simp [hc]
  -- use the imported cleared identity (5)
  rw [curveCertificate19]
  simp [hF]
```

The fiber conversion lemmas are then elementary:

```lean
lemma noncuspidal_fiber19
    {b c : ℚ} (hc : c ≠ 0)
    (hA : A19 b c = 3 * c^36)
    (hB : B19 b c = -7 * c^37) :
    mapX19 b c = 5 ∧ mapY19 b c = 9 := by
  constructor <;> field_simp [mapX19, mapY19, hc, hA, hB]

lemma cusp_fiber19
    {b c : ℚ} (hc : c ≠ 0)
    (hA : A19 b c = 3 * c^36)
    (hB : B19 b c = 12 * c^37) :
    mapX19 b c = 5 ∧ mapY19 b c = -10 := by
  constructor <;> field_simp [mapX19, mapY19, hc, hA, hB]
```

Exact syntax will depend on whether `A19` and `B19` are stored as multivariate polynomials, nested polynomials, or evaluation functions.

## Summary

The p=19 formulas matching the p=17 sign convention are

\[
\boxed{
U=\frac{A_{19}}{c^{36}},\quad
V=\frac{B_{19}}{c^{37}},\quad
x=U+2,\quad
 y=U-V-1.
}
\]

Hence

\[
\boxed{
\operatorname{mapX}_{19}=\frac{A_{19}+2c^{36}}{c^{36}},
\qquad
\operatorname{mapY}_{19}=\frac{cA_{19}-B_{19}-c^{37}}{c^{37}}.
}
\]

At the noncuspidal point `(5,9)`, the trace constants are exactly

\[
\boxed{U=3,\qquad V=-7.}
\]

At the finite cusp `(5,-10)`, they are

\[
\boxed{U=3,\qquad V=12.}
\]
