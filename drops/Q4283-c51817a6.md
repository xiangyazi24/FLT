# Design for the even-degree genus-2 halving theorem

## Executive answer

The cleanest formalization is **not** an explicit inverse to Cantor doubling on Mumford representatives.

For an even-degree hyperelliptic curve, the `x - T` map is a *fake* descent map: in general it can have a kernel larger than `2J(k)`.  The right proof therefore has two logically separate parts.

1. Compare the explicit divisor-evaluation map with the Kummer cocycle
   \[
   J(k)/2J(k) \longrightarrow H^1(k,J[2]).
   \]
2. Prove that, for this particular sextic, the homomorphism out of `H¹(k,J[2])` used by fake descent is injective.

The second part has an exceptionally small fixed-curve certificate.  Over
\[
K=\mathbf Q(s),\qquad s^2=-2,
\]
the sextic factors as
\[
\boxed{
 f(X)=g(X)\,\bar g(X)
}
\]
with
\[
 g(X)=X^3+(2+2s)X^2+(-1+2s)X-1
\]
and
\[
 \bar g(X)=X^3+(2-2s)X^2+(-1-2s)X-1.
\]
Thus the six branch points have a Galois-stable **unordered** partition into two sets of cardinality three.  This odd `3+3` partition makes the fake-descent kernel vanish.  Equivalently, it supplies a Galois-invariant element of the root-sign module having odd parity.

So the recommended theorem is the fixed-curve implication

```lean
/-- Minimal theorem actually needed by the rank argument. -/
theorem xTheta_trivial_imp_two_divisible
    (D : JQ)
    (hD : IsFakeTrivial (xThetaRaw D)) :
    ∃ D' : JQ, D = 2 • D'
```

rather than a generic algorithm returning a Mumford representation for `D'`.

After this theorem, a trivial **fake** 2-Selmer computation implies `J(Q)=2J(Q)`.  If the genuinely cohomological 2-Selmer group has already been proved trivial, even this theorem is unnecessary: the ordinary Kummer injection already gives `J(Q)/2J(Q)=0`.

# 1. State the target correctly

There are two equivalent formulations, but their kernels live in different domains.

Let

```text
δ₀ : J(k) → L×/(L×² k×)
```

be the raw `x-T` map.  The desired statement is

```text
ker δ₀ = 2 J(k).
```

Since `δ₀` kills doubles, it induces

```text
δ̄ : J(k)/2J(k) → L×/(L×² k×).
```

For the induced map the statement is simply

```text
δ̄ is injective.
```

In Lean, the lightest interface avoids constructing the quotient at first:

```lean
/-- `a` represents the identity in `L×/(L×² k×)`. -/
def IsFakeTrivial (a : Lˣ) : Prop :=
  ∃ q : kˣ, ∃ b : Lˣ, a = (Units.map (algebraMap k L) q) * b ^ 2

/-- The only direction needed for the rank-zero argument. -/
theorem xTheta_trivial_imp_two_divisible
    (D : Jk)
    (hD : IsFakeTrivial (xThetaRaw D)) :
    ∃ D' : Jk, D = 2 • D'
```

A quotient-valued map and the equality of kernels can be added after this theorem is stable.  This keeps the critical proof free from quotient-group rewriting.

# 2. The root-sign exact sequence

Let `k` be a field of characteristic different from `2`, let `f` be separable of degree six, and let `Ω` be the six roots of `f` in a chosen separable closure.

The most Lean-friendly model is additive over `F₂ := ZMod 2`.

## 2.1 The finite modules

Set

```text
V = Ω → F₂,
Δ = span{the all-one vector},
E = V / Δ.
```

Because `|Ω|=6` is even, coordinate sum vanishes on the all-one vector and descends to

```text
parity : E →ₗ[F₂] F₂.
```

The usual description of hyperelliptic two-torsion is

```text
J[2] = {even subsets of Ω} / {S ~ Ω \ S}.
```

In the additive notation this is exactly

```text
J[2] ≃ ker parity.
```

Hence there is a Galois-equivariant exact sequence

```text
0 → J[2] --α→ E --parity→ F₂ → 0.                 (RS)
```

Multiplicatively, `E` is `(μ₂^Ω)/μ₂`, `parity` is the product of the signs, and `(RS)` is the standard even-degree root-sign sequence.

## 2.2 Lean shape

A useful generic file should expose only the following API.

```lean
abbrev F2 := ZMod 2

noncomputable def RootVectors (Ω : Type*) := Ω → F2

noncomputable def diagonal
    [Fintype Ω] : Submodule F2 (RootVectors Ω) :=
  Submodule.span F2 {fun _ => 1}

noncomputable def RootSigns
    [Fintype Ω] := RootVectors Ω ⧸ diagonal (Ω := Ω)

noncomputable def parity
    [Fintype Ω] (hΩeven : Even (Fintype.card Ω)) :
    RootSigns Ω →ₗ[F2] F2 := ...
```

Then the hyperelliptic geometry supplies

```lean
noncomputable def jTwoEquivParityKernel :
    J2 ≃ₗ[F2] LinearMap.ker (parity hΩeven)
```

and one packages its inclusion as

```lean
noncomputable def alpha : J2 →ₗ[F2] RootSigns Ω :=
  (parity hΩeven).ker.subtype.comp jTwoEquivParityKernel.toLinearMap

lemma alpha_injective : Function.Injective alpha := ...

lemma range_alpha : LinearMap.range alpha = LinearMap.ker (parity hΩeven) := ...
```

All of `RootVectors`, `diagonal`, `RootSigns`, `parity`, and their finite-dimensional algebra is routine Mathlib work.  The new geometry is the equivalence `jTwoEquivParityKernel`.

# 3. The fixed curve has an invariant odd partition

For

\[
f=X^6+4X^5+10X^4+10X^3+5X^2+2X+1,
\]
let `S = Q[s]/(s²+2)` and let conjugation send `s` to `-s`.

Define

```lean
def g18 (s : S) : S[X] :=
  X^3 + C (2 + 2*s) * X^2 + C (-1 + 2*s) * X - 1
```

with the corresponding conjugate polynomial.  The certificate is a single polynomial identity:

```lean
lemma f18_factor_over_sqrt_neg_two :
    Polynomial.map (algebraMap ℚ S) f18 =
      g18 s * g18 (-s) := by
  rw [show s^2 = -2 by ...]
  ring
```

Coefficient-by-coefficient, the product is

```text
X⁶ coefficient: 1
X⁵ coefficient: (2+2s)+(2-2s) = 4
X⁴ coefficient: (-1+2s)+(-1-2s)+(2+2s)(2-2s) = -2+12 = 10
X³ coefficient: -2+(2+2s)(-1-2s)+(2-2s)(-1+2s) = -2+12 = 10
X² coefficient: -(2+2s)-(2-2s)+(-1+2s)(-1-2s) = -4+9 = 5
X coefficient: -((-1+2s)+(-1-2s)) = 2
constant: 1.
```

Let `A` be the three roots of `g18 s` and `B` the three roots of `g18 (-s)`.

- The subgroup fixing `S` preserves `A` and `B` separately.
- The nontrivial automorphism of `S/Q` swaps `A` and `B`.
- Therefore `{A,B}` is Galois-stable as an **unordered** partition.
- Separability of `f18` makes the two blocks disjoint and gives three distinct roots in each block.

Let `χA : Ω → F₂` be the characteristic function of `A`.  Its class

```text
z = [χA] ∈ RootSigns Ω
```

is Galois invariant: an automorphism either fixes `χA` or sends it to `χB = χA + 1`, and adding the all-one vector does not change the quotient class.  Moreover,

```text
parity z = |A| mod 2 = 3 mod 2 = 1.
```

Thus

```text
parity : (RootSigns Ω)^G → F₂
```

is surjective.

This is the fixed-curve form of the criterion in Bruin--Poonen--Stoll, Example 10.19: the fake kernel is zero when the branch set has a Galois-stable unordered partition into two odd-cardinality parts.

A convenient Lean structure is

```lean
structure GaloisStableOddPartition
    (G Ω : Type*) [Group G] [MulAction G Ω] [Fintype Ω] where
  left : Finset Ω
  right : Finset Ω
  disjoint : Disjoint left right
  union_eq : left ∪ right = Finset.univ
  left_odd : Odd left.card
  right_odd : Odd right.card
  stable_unordered : ∀ σ : G,
    (σ • left = left ∧ σ • right = right) ∨
    (σ • left = right ∧ σ • right = left)
```

and the generic output should be

```lean
theorem GaloisStableOddPartition.exists_fixed_parity_one
    (P : GaloisStableOddPartition G Ω) :
    ∃ z : RootSigns Ω,
      (∀ σ : G, σ • z = z) ∧ parity P.card_even z = 1
```

For the fixed sextic, the only nontrivial inputs are the displayed factorization and squarefreeness of `f18`.

Irreducibility of either cubic is **not** needed.  The partition is by the roots of the two coprime cubic factors, not by individual Galois orbits.

# 4. The algebraic heart: a direct cocycle lemma

There is no need to build a long exact cohomology sequence in order to prove injectivity.  The following direct diagram chase is short and robust.

Assume the exact sequence `(RS)`, and suppose there is a fixed `z : E` with `parity z = 1`.

Let

```text
c : G → J[2]
```

be a one-cocycle.  Suppose its image under `α` is a coboundary, so that for some `e : E`,

```text
α(c σ) = σ • e - e                                  (1)
```

for every `σ`.

Apply `parity` to `(1)`.  Since `parity ∘ α = 0`,

```text
σ • parity(e) = parity(e).
```

The target `F₂` has trivial action.  Put

```text
e₀ = e - parity(e) • z.
```

Then `parity(e₀)=0`, so exactness gives `t : J[2]` with

```text
α(t)=e₀.
```

Since `z` is fixed,

```text
α(c σ - (σ • t - t)) = 0.
```

Injectivity of `α` yields

```text
c σ = σ • t - t.
```

Therefore `c` itself is a coboundary.

## 4.1 Lean statement

This is the reusable theorem to prove first.

```lean
theorem isCoboundary_of_map_isCoboundary_of_fixed_parity_one
    {F G J2 E : Type*}
    [Field F] [CharP F 2]
    [Group G]
    [AddCommGroup J2] [Module F J2]
    [AddCommGroup E] [Module F E]
    (rhoJ : Representation F G J2)
    (rhoE : Representation F G E)
    (alpha : J2 →ₗ[F] E)
    (parity : E →ₗ[F] F)
    (alpha_equivariant : ...)
    (parity_equivariant : ...)
    (halpha : Function.Injective alpha)
    (hexact : LinearMap.range alpha = LinearMap.ker parity)
    (z : E)
    (hz_fixed : ∀ σ : G, rhoE σ z = z)
    (hz_parity : parity z = 1)
    (c : G → J2)
    (hc : IsAddCocycle rhoJ c)
    (hmap : ∃ e : E, ∀ σ : G,
      alpha (c σ) = rhoE σ e - e) :
    ∃ t : J2, ∀ σ : G,
      c σ = rhoJ σ t - t := by
  ...
```

At the pinned Mathlib revision, the low-degree group-cohomology file already defines

```text
groupCohomology.cocycles₁
groupCohomology.coboundaries₁
groupCohomology.mem_cocycles₁_iff
groupCohomology.coboundariesToCocycles₁
groupCohomology.H1π
```

for a `Rep`.  Nevertheless, a project-local predicate `IsAddCocycle` and an existential definition of `IsCoboundary` may be simpler initially.  The proof above uses no quotient and no topology.  It can later be wrapped as injectivity on `H¹`.

# 5. From a coboundary Kummer cocycle to an actual rational half

Let `ks` be a separable closure, let `G = Aut(ks/k)`, and let `Jks` be the geometric Jacobian with its Galois action.  For `D : J(k)`, choose a geometric half `Q : J(ks)` satisfying

```text
2Q = D.
```

Define the Kummer cocycle

```text
cD(σ) = σQ - Q.
```

Then `cD(σ) ∈ J[2]` and `cD` is a one-cocycle.

If the previous section gives `t : J[2]` such that

```text
cD(σ) = σt - t,
```

then

```text
σ(Q-t) = Q-t
```

for every `σ`.  Hence `Q-t` is rational, and

```text
2(Q-t) = 2Q - 2t = D.
```

This is the halving theorem.  Notice that it constructs the rational half conceptually, but it does not compute its Mumford coefficients.

The corresponding generic lemma is tiny once the geometric types exist:

```lean
theorem two_divisible_of_kummer_cocycle_isCoboundary
    (D : Jk)
    (Q : Jks)
    (hQ : 2 • Q = baseChange D)
    (t : J2)
    (ht : ∀ σ : G,
      σ • Q - Q = σ • (t : Jks) - (t : Jks)) :
    ∃ D' : Jk, D = 2 • D' := by
  let Q' : Jks := Q - t
  have hfixed : ∀ σ, σ • Q' = Q' := by ...
  obtain ⟨D', rfl⟩ := fixed_points_are_rational Q' hfixed
  refine ⟨D', ?_⟩
  ...
```

The genuinely geometric inputs are:

1. multiplication by `2` is surjective on `J(ks)`;
2. fixed geometric points descend to `J(k)`;
3. `J[2]` embeds into `J(ks)`.

For characteristic zero these are standard facts about abelian varieties, but they are not currently a one-line Mathlib API for a custom genus-two Jacobian.  They should be isolated in a small `KummerData` interface rather than reproved inside the `x-T` file.

# 6. The one geometric comparison theorem that is still required

The explicit map uses the rational function family

```text
x - T ∈ L(C)×,
```

where `T` is the class of the polynomial variable in `L=k[T]/(f)`.

For a root `ω` and its Weierstrass point `Wω=(ω,0)`,

\[
\operatorname{div}(x-\omega)
  = 2W_\omega-\infty^+-\infty^- .                  \tag{2}
\]

The common pole divisor in `(2)` is why the even-degree target has a scalar quotient.

For a degree-zero divisor `D` disjoint from the branch points and the two points at infinity, define

```text
(x-T)(D) ∈ L×
```

by normed evaluation on closed points.  Changing `D` by a principal divisor changes this value by a square times an element of `k×`; this follows from `(2)` and Weil reciprocity.  Hence evaluation induces

```text
xTheta : J(k) → L×/(L×² k×).
```

The required comparison theorem is only the following implication.

```lean
/-- Minimal explicit-to-cohomological bridge. -/
theorem xTheta_trivial_implies_alpha_kummer_isCoboundary
    (D : Jk)
    (hD : IsFakeTrivial (xThetaRaw D)) :
    ∃ e : RootSigns Ω, ∀ σ : G,
      alpha (kummerCocycle D σ) = σ • e - e
```

Once this is available, Sections 3--5 finish the proof.

A stronger and conceptually cleaner version defines the cohomological fake map first and proves equality with divisor evaluation:

```lean
noncomputable def fakeCohomologicalClass : Jk → FakeH1 :=
  alphaH1 (kummerClass ...)

noncomputable def xThetaClass : Jk → FakeSquareClass L k := ...

lemma xTheta_eq_fakeCohomologicalClass (D : Jk) :
  xThetaClass D = explicitRealization (fakeCohomologicalClass D) := ...
```

This is the specialization of Bruin--Poonen--Stoll, Proposition 6.10 and Corollary 6.11.  It is the right theorem to generalize later, but the one-way implication above is enough for `X_1(18)`.

## 6.1 Proof structure of the comparison

A Lean proof can be organized as follows.

1. Represent `D` by a good degree-zero divisor.
2. Choose a geometric half `Q` and a good divisor representing it.
3. Choose a rational function `h` satisfying
   ```text
   div(h) = 2Q - D
   ```
   in divisor notation.
4. Evaluate the family `(x-T)` on this divisor identity.
5. Use Weil reciprocity to commute evaluation of `(x-T)` and `h`.
6. Use `(2)` to identify the remaining evaluations at the branch points.
7. Choose square roots over `ks`; their Galois ratios form a root-sign cocycle.
8. Check coordinatewise that this cocycle is the image under `alpha` of
   ```text
   σQ - Q ∈ J[2].
   ```
9. Scalar contributions from `∞⁺+∞⁻` disappear in `L×/(L×²k×)`.

Steps 4--8 are the only place where divisor geometry, the Weil pairing, and the computational `x-T` expression meet.

# 7. Why explicit Mumford halving is not the clean route

For a good reduced Mumford representative `(u,v)` in the odd-degree case, the familiar computational formula is

```text
xTheta([u,v]) = [(-1)^deg(u) u(T)].
```

In the present scalar quotient the sign is irrelevant.  For an even-degree curve, all Jacobian classes require a balanced representation, typically `(u,v,n)` with an additional infinity component.  The target quotient hides the scalar contribution of `n`, so the same `u(T)` formula survives, but proving that fact still requires the balanced divisor theory.

Suppose

```text
u(T) = q β²
```

in `L`, with `q∈k×`.  It is tempting to interpolate `β` and directly manufacture a Mumford pair for a half.  This is possible algorithmically, but it is not a short proof:

- `β` is an element of the six-dimensional étale algebra, not a polynomial square root in `k[x]`;
- interpolation must be reconciled with reduction modulo `f`;
- one must recover both `u'` and `v'` for the half;
- degree drops and common factors create exceptional branches;
- the two infinity points introduce the balanced integer coordinate;
- proving that the constructed geometric half descends to `k` recreates the cocycle argument;
- proving that doubling the result returns the original class requires a complete verified Cantor composition/reduction implementation.

Thus an explicit square-root extraction does not eliminate the geometry.  It moves the geometry into a longer collection of polynomial identities and exceptional cases.

Bruin--Stoll's two-cover machinery is excellent for computing coverings, but for the implication `δ(D)=1 → D∈2J(k)`, the Bruin--Poonen--Stoll cohomological comparison plus the odd-partition criterion is substantially easier to formalize.

# 9. Do not reduce this sextic to an odd-degree model

An odd-degree hyperelliptic model over `k` has a rational ramified point at infinity.  Conversely, moving a branch point to infinity turns an even-degree equation into an odd-degree equation.  Thus the useful reduction requires a `k`-rational Weierstrass point, equivalently a rational root of `f` in this model.

For `f18`, the rational-root test leaves only `±1`, and

```text
f18(1)=33,
f18(-1)=1.
```

So there is no rational branch point.

The two rational points at infinity on the monic sextic are **unramified**.  Choosing one as a base point for the Abel--Jacobi map does not produce an odd-degree hyperelliptic equation.

Base extension does not simplify the proof:

- over `Q(sqrt(-2))`, the sextic becomes two cubics but still has no distinguished root;
- adjoining a root of one cubic gives an odd-degree chart only after a degree-three extension of the quadratic field;
- descent back across the quadratic extension is precisely where the even-degree fake kernel lives;
- restricting a 2-cohomology class across an even-degree extension is not automatically injective.

The conjugate cubic factorization should therefore be used directly as the invariant odd partition, not as a preliminary step toward an odd-degree model.

# 10. The fixed-curve shortcut and the role of the Selmer computation

There are three different statements that are easy to conflate.

## 10.1 Actual 2-Selmer group is trivial

If one has already proved

```text
Sel²(J) = 0
```

where `Sel²(J)` is the genuine subgroup of `H¹(Q,J[2])`, then the Kummer map

```text
J(Q)/2J(Q) ↪ Sel²(J)
```

finishes immediately.  No fake descent comparison is required.

## 10.2 Fake 2-Selmer group is trivial

Usually the finite computation proves only

```text
Sel_fake = {1} ⊂ L×/(L×²Q×).
```

Then one must know that

```text
δ̄ : J(Q)/2J(Q) → Sel_fake
```

is injective.  For a general even-degree sextic this is false.  For `f18`, the invariant `3+3` partition proves it.

## 10.3 Knowledge of `J[2](Q)`

The group `J[2](Q)` by itself does not control the fake kernel.  The obstruction is the cokernel of the norm/parity map on Galois invariants of the root-sign module.  The `3+3` partition kills that obstruction even though an odd block is not itself an element of `J[2]`.

Thus the smallest theorem needed after the finite fake-Selmer computation is exactly

```lean
theorem x1n18_fake_descent_injective :
    Function.Injective xThetaBar
```

or, avoiding the quotient,

```lean
theorem x1n18_xTheta_trivial_imp_two_divisible
    (D : J18Q)
    (hD : IsFakeTrivial (xThetaRaw D)) :
    ∃ D' : J18Q, D = 2 • D'
```

The proof should be only

```text
explicit x-T trivial
    ⇒ alpha(Kummer cocycle) is a coboundary       [comparison theorem]
    ⇒ Kummer cocycle is a coboundary              [odd-partition lemma]
    ⇒ D has a rational half.                       [Kummer lemma]
```

   Rational-root theorem reduces to `±1`; `norm_num` proves the two evaluations above.

   In `AdjoinRoot (X^2+2)`, prove `s^2=-2`.

5. **Conjugation**

6. **Factorization**
   One `ring` proof after rewriting `s²=-2`.

7. **Coprime blocks**
   Derive from the factorization and separability, or compute the gcd of the two cubics over the quadratic algebra.
