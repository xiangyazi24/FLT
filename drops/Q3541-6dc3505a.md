# Q3541 route audit: real-torsion bound

## Verdict

The `theta` construction is not logically sacred, but some analytic seam identifying the identity-component/kernel torsion with circle torsion is still the shortest non-circular Lean route under the stated assumptions. I would not try to prove `card_E_R_torsion_le` from a general compact/real Lie/topological-group theorem unless you first build a packaged topological/Lie group structure on the real point type and prove the real locus component classification. That is more work than the elliptic-integral seam.

The important shortcut is that the circle torsion part is already mostly in current Mathlib: `AddCircle.card_torsion_le_of_isSMulRegular` gives an `encard ≤ n` theorem, and `AddCircle.finite_torsion` gives finiteness for positive `n`. So S4-S8 should only prove an injective additive hom from the real identity component/kernel into an `AddCircle`; do not reprove circle torsion from representatives unless your pinned Mathlib is older.

## A. Can existing general Mathlib avoid `theta`?

No, not with only the algebraic point group plus some component machinery. A general theorem about compact abelian Lie groups would require, before it can even be applied:

* a topology on `(E⁄ℝ).Point`, not just on affine charts;
* continuity of the group law and inverse at all exceptional/projective cases;
* compactness of the real projective locus;
* identification of the identity component as a one-dimensional compact connected abelian Lie group;
* a proof that the component quotient has cardinal at most `2` and agrees with `componentBitHom`.

Those prerequisites are essentially the same analytic/topological work as the elliptic-integral route, plus a larger API surface. The existing `AddCircle` torsion theorem is useful only after you have mapped the kernel into a circle. Therefore: keep `theta`, or replace it by the direct seam theorem “kernel `n`-torsion has cardinal at most `n`”. For maintainability, expose both layers: analytic `theta` theorem, then a pure cardinal theorem deriving kernel torsion.

## C. S9 audit

The proposed S9 lemma is mathematically sufficient. No surjectivity of `component : G →+ ZMod 2` is needed. The required hypotheses are exactly:

1. `G` is an additive group, preferably `[AddCommGroup G]` for the elliptic-curve context;
2. `component` is additive, so translation from a fiber to the zero fiber preserves `n`-torsion;
3. the zero-fiber torsion set is finite and has `ncard ≤ n`.

The clean Lean proof path is direct fiber counting, not quotient/subgroup cardinality formulas. Define

```lean
import Mathlib

def torsionFiber {G : Type*} [AddCommGroup G]
    (component : G →+ ZMod 2) (n : ℕ) (c : ZMod 2) : Set G :=
  {x | n • x = 0 ∧ component x = c}
```

Then prove:

* `{x | n • x = 0} = ⋃ c : ZMod 2, torsionFiber component n c`;
* if `torsionFiber component n c` is nonempty with witness `y`, the map `x ↦ x - y` injects that fiber into `torsionFiber component n 0`;
* empty fibers have `ncard = 0`;
* sum the fiber bounds over `Fintype (ZMod 2)`, whose cardinal is `2`.

This avoids constructing quotient groups, avoids proving finite torsion subgroups first, and works even if `component` is the zero map.

## E. Hidden analytic assumptions to lock down

* The kernel of `componentBitHom` must be the identity component containing `0`, not merely the set selected by an inequality on `x`. In the three-real-root case, be explicit about which root/component is the unbounded component containing infinity.
* For a point `(e, 0)`, the chosen root `e` and the assigned circle coordinate must match the component convention. Usually the endpoint on the identity component maps to the half-period, while `0`/infinity maps to `0` modulo the full period.
* The `sqrt` branch cannot define a global differential by itself. On the lower branch the invariant differential changes sign through `y`; define the coordinate piecewise so that it is continuous on the real component and lands in `AddCircle`, not in bare `ℝ`.
* Endpoint integrability is real work: near a simple root the integrand has an integrable `1 / sqrt` singularity; near infinity it decays like `x^(-3/2)`. These convergence lemmas should be separate from additivity.
* Additivity is the hard theorem. Monotonicity/injectivity of the integral coordinate does not imply `theta (P + Q) = theta P + theta Q`; prove additivity modulo the period, including tangent, vertical-line, inverse, `0`, and branch-cut cases.
* Injectivity must be modulo exactly the full period `2*T`. Prove no unintended identifications between the two real branches except the intended endpoint/infinity identifications.
* Keep `hn : 0 < n` throughout. The `n = 0` torsion set is the whole real point group, so any finite-cardinality statement would be false.
* The `u = 1` variable change need only be injective for the final cardinal bound, but it must be an additive hom and preserve zero/nsmul. An equivalence is nicer but unnecessary.
