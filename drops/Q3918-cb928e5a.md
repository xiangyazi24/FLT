# Q3918 — Injectivity proof for the `ZMod 2 × ZMod 10` coprod map

The clean way to avoid the brittle `ha1` branch is: after representing the first coordinate as `(a : ZMod 2)` for `a : ℤ`, prove the dichotomy by introducing a named local variable `za : ZMod 2` and running `fin_cases za`.  This avoids asking `simp_all` to solve the coercion/case split directly.

The proof below assumes your already-proved theorem is in scope:

```lean
-- theorem eq_five_nsmul_of_order_two_mem_zmultiples
--     {η Q : H} (hη : addOrderOf η = 2) (hQ : addOrderOf Q = 10)
--     (hmem : η ∈ AddSubgroup.zmultiples Q) : η = 5 • Q
```

## Generic injectivity theorem for a coprod

This version is usually the most convenient: it only assumes the two cyclic factor maps evaluate on integer casts as expected.

```lean
import Mathlib

noncomputable section

open Function

variable {H : Type*} [AddCommGroup H]

/-- Injectivity of the coprod map once the two cyclic factor maps evaluate as
`z ↦ z • η` and `z ↦ z • Q` on integer representatives. -/
theorem coprod_zmod_two_ten_injective
    {η Q : H}
    (hη : addOrderOf η = 2)
    (hQ : addOrderOf Q = 10)
    (hindep : η ≠ 5 • Q)
    (gη : ZMod 2 →+ H)
    (gQ : ZMod 10 →+ H)
    (hgη : ∀ z : ℤ, gη (z : ZMod 2) = z • η)
    (hgQ : ∀ z : ℤ, gQ (z : ZMod 10) = z • Q) :
    Function.Injective (gη.coprod gQ) := by
  rw [injective_iff_map_eq_zero]
  rintro ⟨a0, b0⟩ hker

  -- Choose integer representatives for both `ZMod` coordinates.
  obtain ⟨a, rfl⟩ := ZMod.intCast_surjective a0
  obtain ⟨b, rfl⟩ := ZMod.intCast_surjective b0

  -- Evaluate the coprod on those representatives.
  have hker' : (a • η + b • Q : H) = 0 := by
    simpa [AddMonoidHom.coprod_apply, hgη a, hgQ b] using hker

  by_cases ha0 : (a : ZMod 2) = 0
  · -- First coordinate zero: the kernel relation reduces to `b • Q = 0`.
    have haη : a • η = 0 := by
      have h := congrArg gη ha0
      simpa [hgη a] using h

    have hbQ : b • Q = 0 := by
      simpa [haη] using hker'

    -- Convert `b • Q = 0` to `(b : ZMod 10) = 0`.
    have hbdiv' : ((addOrderOf Q : ℕ) : ℤ) ∣ b := by
      rw [addOrderOf_dvd_iff_zsmul_eq_zero]
      exact hbQ

    have hbdiv : (10 : ℤ) ∣ b := by
      simpa [hQ] using hbdiv'

    have hb0 : (b : ZMod 10) = 0 := by
      exact (ZMod.intCast_zmod_eq_zero_iff_dvd b 10).mpr hbdiv

    exact Prod.ext ha0 hb0

  · -- First coordinate nonzero in `ZMod 2`, hence it is `1`.
    have ha1 : (a : ZMod 2) = 1 := by
      have hcases : (a : ZMod 2) = 0 ∨ (a : ZMod 2) = 1 := by
        let za : ZMod 2 := a
        have hza : (a : ZMod 2) = za := rfl
        fin_cases za
        · exact Or.inl hza
        · exact Or.inr hza
      exact hcases.resolve_left ha0

    have haη : a • η = η := by
      have h1 : gη (1 : ZMod 2) = η := by
        simpa using hgη (1 : ℤ)
      have h := congrArg gη ha1
      simpa [hgη a, h1] using h

    have hrel : η + b • Q = 0 := by
      simpa [haη] using hker'

    -- From `η + b • Q = 0`, get `η = (-b) • Q`, so `η ∈ ⟨Q⟩`.
    have hmem : η ∈ AddSubgroup.zmultiples Q := by
      rw [AddSubgroup.mem_zmultiples_iff]
      refine ⟨-b, ?_⟩
      simpa [neg_zsmul] using (eq_neg_of_add_eq_zero_left hrel).symm

    exact (hindep (eq_five_nsmul_of_order_two_mem_zmultiples hη hQ hmem)).elim
```

## If your map is a named `f`

If your local file has a named hom

```lean
f : ZMod 2 × ZMod 10 →+ H
```

and a proof that it is the coprod of the two cyclic maps, use this wrapper.

```lean
theorem named_coprod_zmod_two_ten_injective
    {η Q : H}
    (hη : addOrderOf η = 2)
    (hQ : addOrderOf Q = 10)
    (hindep : η ≠ 5 • Q)
    (f : ZMod 2 × ZMod 10 →+ H)
    (gη : ZMod 2 →+ H)
    (gQ : ZMod 10 →+ H)
    (hf : f = gη.coprod gQ)
    (hgη : ∀ z : ℤ, gη (z : ZMod 2) = z • η)
    (hgQ : ∀ z : ℤ, gQ (z : ZMod 10) = z • Q) :
    Function.Injective f := by
  simpa [hf] using
    (coprod_zmod_two_ten_injective hη hQ hindep gη gQ hgη hgQ)
```

## The exact `ha1` tactic sequence

This is the replacement for the fragile branch:

```lean
have ha1 : (a : ZMod 2) = 1 := by
  have hcases : (a : ZMod 2) = 0 ∨ (a : ZMod 2) = 1 := by
    let za : ZMod 2 := a
    have hza : (a : ZMod 2) = za := rfl
    fin_cases za
    · exact Or.inl hza
    · exact Or.inr hza
  exact hcases.resolve_left ha0
```

Then convert `a • η` to `η` by applying `gη` to that equality:

```lean
have haη : a • η = η := by
  have h1 : gη (1 : ZMod 2) = η := by
    simpa using hgη (1 : ℤ)
  have h := congrArg gη ha1
  simpa [hgη a, h1] using h
```

## Getting `hgη` and `hgQ` from `ZMod.lift`

For maps built using `ZMod.lift`, prove the two evaluation hypotheses once and then pass them into the theorem above.  The shape is:

```lean
have hgη : ∀ z : ℤ, gη (z : ZMod 2) = z • η := by
  intro z
  -- Replace `gη_def` by your definition of the `ZMod.lift` map.
  simp [gη_def]

have hgQ : ∀ z : ℤ, gQ (z : ZMod 10) = z • Q := by
  intro z
  -- Replace `gQ_def` by your definition of the `ZMod.lift` map.
  simp [gQ_def]
```

The reason this works is that `ZMod.lift_coe` is a `[simp]` theorem, so once your `ℤ →+ H` source hom is unfolded, Lean sees exactly `z • η` or `z • Q`.
