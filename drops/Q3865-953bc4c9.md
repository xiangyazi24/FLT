## The proposed shortcut fails

Write

```text

```

Then

```text
w^2 = p(p+2q)(p-q) / q^3.
```

It is true that each of

```text
p,
p+2q,
p-q
```

is coprime to `q`.  Therefore the denominator `q^3` of the right hand side is already in lowest terms.  Since this rational number is a square, `q^3` must be a square.

But this implies only that `q` is a square, not that `q=1`.  If `q=B^2`, then `q^3=B^6` is a square.  This is exactly the usual square-denominator phenomenon for rational points on elliptic curves.

So the correct normalization is

```text
u = A/B^2,
w = C/B^3,
gcd(A,B)=1,
```

and the cleared equation is

```text
C^2 = A(A+2B^2)(A-B^2).
```

This is where the real descent begins; the proof does not reduce to integral `u`.

## The factorization is also not coprime enough

For the normalized equation

```text

```

```text

gcd(A, A+2B^2) divides 2,
gcd(A+2B^2, A-B^2) divides 3.
```

Thus their product being a square does not imply that each factor is an individual signed square.  Squareclasses involving `2` and `3` remain, so the finite squareclass set is

```text
{±1, ±2, ±3, ±6}.
```

That is precisely the 2-descent obstruction computation.
