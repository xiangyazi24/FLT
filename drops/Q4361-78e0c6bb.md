# X₁(18): the proposed finite twist-support argument does not work

## Executive verdict

The claimed a-priori restriction

```text
q ∈ {±1, ±2, ±3, ±6}
```

does **not** follow from good reduction outside `{2,3}`, the factorization `f=g·ḡ`, or class number one of `K=Q(√-2)`.

The precise calculation is:

```text
homogeneous factor G(A,D) = ± Z² in K,

but

g(A/D) = G(A,D)/D³ = ± D · (Z/D²)².
```

Thus the affine quadratic-twist parameter is

```text
q ≡ ±D  in Q×/Q×²,
```

where `D` is the denominator of `x=A/D`. A good prime `p` may divide `D` to odd order; the corresponding rational point simply reduces to a point at infinity (a cusp) modulo `p`. Good reduction does not make the affine modular function `x` integral, and it does not force `g(x)` to be a local square.

There is an explicit local counterexample at **every odd good prime**: for any `p ≠ 2,3`, the choice `x=1/p` extends to a point of `C(Q_p)`, while `v_p(g(x))=-3`, so the local squareclass contains `p`.

Therefore Route A is **not** reduced to finitely many rational twists by the proposed argument. The actual global rational points may still all have integral `x`—indeed they do—but proving that is essentially part of the rational-point problem, not a consequence of good reduction.

There is also a correction to the proposed rank table. Since `-2=(√-2)²` is a square in `K`, rational twists satisfy

```text
E^(q) ≅_K E^(-2q).
```

Hence the known rank-one `q=-1` twist is K-isomorphic to the `q=2` twist. So `q=-1` is not literally the only positive-rank entry in the eight-element list.

# 1. Homogeneous setup

Put

```text
r² = -2,
K = Q(r),
λ = 1-r.
```

The genus-two curve is

```text
C : y² = f(x),

f(x)=x⁶+4x⁵+10x⁴+10x³+5x²+2x+1.
```

Over `K`,

```text
g(x)  = x³+2λx²+λ²x-1,
ḡ(x) = x³+2λ̄x²+λ̄²x-1,
f(x)  = g(x)ḡ(x).
```

Write a rational point in primitive weighted coordinates as

```text
x=A/D,
y=B/D³,
gcd(A,D)=1.
```

Define the homogeneous cubic factors

```text
G(A,D)  = A³+2λA²D+λ²AD²-D³,
Ḡ(A,D) = A³+2λ̄A²D+λ̄²AD²-D³.
```

Then

```text
G(A,D)Ḡ(A,D)=B².                         (1)
```

The homogeneous sextic is

```text
F(A,D)=A⁶+4A⁵D+10A⁴D²+10A³D³+5A²D⁴+2AD⁵+D⁶.
```

Thus `(1)` is exactly `F(A,D)=B²`.

---

# 2. What the ideal factorization really proves

The resultant of `g` and `ḡ` is supported only above `2` (equivalently, its norm is a power of `2`). For a primitive pair `(A,D)`, any common prime ideal divisor of `G(A,D)` and `Ḡ(A,D)` therefore lies above `2`.

Let `𝔭` be a prime ideal of `O_K` not above `2`. From `(1)`:

- `𝔭` cannot divide both factors;
- the sum of their valuations is even;
- hence `v_𝔭(G(A,D))` is even.

At the unique ramified prime `𝔭₂=(r)` above `2`, conjugation fixes the prime. Since

```text
G·Ḡ = B²
```

and a rational integer has even `𝔭₂`-valuation, one also gets

```text
v_𝔭₂(G) = v_𝔭₂(Ḡ) ∈ 2Z.
```

Therefore every ideal valuation of `(G)` is even:

```text
(G)=𝔞².
```

The class number of `K=Q(√-2)` is one, so `𝔞=(Z)` is principal. The unit group is `{±1}`. Consequently

```text
G(A,D)=ε Z²,   ε∈{+1,-1}.                 (2)
```

This is the correct, strong conclusion of the coprimality/class-number argument.

Notice that `3` does not enter this conclusion at all: the common-factor resultant is supported above `2`, not above `{2,3}`.

---

# 3. Dehomogenization reintroduces the denominator

The affine value is

```text
g(A/D)=G(A,D)/D³.
```

Using `(2)`,

```text
g(A/D)
 = ε Z²/D³
 = ε D · (Z/D²)².                         (3)
```

Thus, for the affine twist convention

```text
E^(q) : q z² = g(x),
```

the point gives

```text
q ≡ εD mod Q×².                           (4)
```

In particular, for every rational prime `p`,

```text
v_p(q) ≡ v_p(D) mod 2.
```

The ideal argument proves that the **homogeneous numerator** `G(A,D)` has only the unit squareclass `±1`. It does not prove that the **affine value** `g(A/D)` is supported at bad primes. The two squareclasses differ by `D`.

This is the exact conflation in the proposed finite-list argument:

```text
homogeneous descent class: [G(A,D)] ∈ {+1,-1};

affine twist class:        [g(A/D)] = [±D].
```

Only the second one is the twist parameter of the fixed affine elliptic curve `z²=g(x)`.

---

# 4. Good reduction does not bound denominators

A smooth proper curve with good reduction over `Z_p` has a reduction map

```text
C(Q_p) → C(F_p).
```

It does **not** follow that an arbitrary chosen rational function on `C` takes an integral value. If that function has a pole at a point of the special fiber, a `Q_p`-point reducing to that point has negative valuation.

Here the function `x` has poles at the two points at infinity. When `p|D`, the point `(A/D,B/D³)` reduces to one of those points at infinity. This is perfectly compatible with good reduction.

The phrase “the local point is in the connected component” does not fix the issue:

- connected components and formal kernels concern a fixed elliptic curve/Néron model;
- before choosing a square root of `q`, the point lies on the `q`-twist, not on `E_+`;
- using connectedness of `E_+` to prove that `q` is a square assumes the desired identification and is circular.

# 5. Explicit local counterexample at every good odd prime

Let `p` be any odd prime, in particular any `p∉{2,3}`. Take

```text
A=1,
D=p,
x=1/p.
```

Then

```text
F(1,p)
 =1+4p+10p²+10p³+5p⁴+2p⁵+p⁶
 ≡1 mod p.
```

Because `p` is odd, Hensel's lemma applied to

```text
T²-F(1,p)
```

at `T=1` gives `B_p∈Z_p` with

```text
B_p²=F(1,p).
```

Therefore

```text
(x,y)=(1/p, B_p/p³) ∈ C(Q_p).             (5)
```

At every prime `𝔭|p` of `K`,

```text
G(1,p) ≡1 mod 𝔭,
```

so `G(1,p)` is a unit and

```text
v_𝔭(g(1/p))=v_𝔭(G(1,p)/p³)=-3.
```

Hence `g(1/p)` is not a local square, and its squareclass has odd `p`-valuation.

This shows concretely:

> Good reduction at `p` does not exclude `p` from the affine twist parameter.

It does not produce a global rational point with denominator `p`; it proves that **no local-good-reduction argument of the proposed form can give the desired global denominator bound**.

# 6. Which primes can divide the affine twist parameter?

For an actual global rational point written primitively as above, formula `(4)` gives the complete answer:

```text
p divides q to odd order
⇔
v_p(D) is odd.
```

Thus, from the stated factorization data alone, **any rational prime** can occur. Primes outside `{2,3}` are not eliminated.

The statement

```text
q is supported on {2,3}
```

would require an additional global theorem such as

```text
v_p(D) is even for every p∉{2,3}.
```

No such theorem follows from good reduction. Proving it for this curve would be a substantial integral/denominator theorem and, in the present setting, is essentially another form of the rational-point problem.

A posteriori, once one knows that all rational points are the six cusps, the affine `x`-values are `0,-1` (plus infinity), so the observed twists are only `-1` and `+1`. That cannot be used as the a-priori reduction.

# 7. Correction to the eight-twist rank table

Over `K`, two rational twist parameters define isomorphic curves whenever their quotient is a square in `K`.

For a rational number `a`, if

```text
a=(u+vr)² ∈ Q,
```

then the `r`-coefficient `2uv` vanishes. Hence either `v=0`, giving a rational square, or `u=0`, giving `a=-2v²`. Therefore

```text
Q× ∩ K×² = Q×² · < -2 >.
```

So rational squareclasses are identified by

```text
q ~ -2q.
```

For the proposed list:

| parameters over Q | one K-twist class |
|---|---|
| `1, -2` | `[1]` |
| `-1, 2` | `[-1]` |
| `3, -6` | `[3]` |
| `-3, 6` | `[-3]` |

The known computations therefore imply at least

| q | rank over K | reason |
|---:|---:|---|
| `1` | `0` | established for `E_+` |
| `-2` | `0` | K-isomorphic to `q=1` |
| `-1` | `1` | established for `E_-` |
| `2` | `1` | K-isomorphic to `q=-1` |

Thus the literal claim

```text
q=-1 is the only positive-rank twist among the eight q's
```

is false: `q=2` is the same K-isomorphism class and has the same rank.

I did not find a checked public rank certificate in the cited data for the remaining two K-isomorphism classes `[3]` and `[-3]`, so I do **not** assert numerical ranks for `q=3,-6,-3,6` here. They are finite CAS computations, but they are non-load-bearing: even if both classes had rank zero, the affine denominator produces infinitely many other rational twist classes.

A reproducible Magma check is:

```magma
K<r> := QuadraticField(-2);
lam := 1-r;
E := EllipticCurve([K | 0, -lam, 0, 0, -1]);

for q in [1,-1,3,-3] do
    Eq := QuadraticTwist(E, K!q);
    q, RankBounds(Eq), TorsionSubgroup(Eq);
end for;
```

The four values suffice because multiplying by `-2` does not change the K-isomorphism class. A bankable table should record exact equal rank bounds, not only analytic ranks or a point search.

# 8. Why the proposed elliptic-Chabauty conclusion does not follow

The desired conclusion was:

```text
C(Q)
  maps to finitely many rank-zero twists
  plus one rank-one twist,
therefore use elliptic Chabauty on the rank-one case.
```

The first arrow is missing. Formula `(4)` gives an a-priori family

```text
q ≡ ±D mod squares,
```

with no finite restriction on the denominator squareclass. Therefore one has not reduced to finitely many Mordell-Weil groups.

Elliptic Chabauty is excellent **after** a finite descent list is proved. It cannot by itself replace the missing finite-support theorem.

# 9. What a correct finite Route A would require

There are three logically valid ways to make an elliptic-cover route finite.

## Route A1: full two-cover descent on the genus-two curve

Use the usual finite `S`-unit/Selmer computation for the genus-two Jacobian or its two-covers. Here the relevant finite set `S` comes from the discriminant/resultant and includes the bad primes. This controls divisor/Kummer classes in the descent algebra.

Crucially, this finite Selmer class is **not** the same as the affine denominator twist `q=±D`.

## Route A2: prove a separate denominator theorem

Prove directly that

```text
v_p(D) is even outside a finite set S.
```

Only after such a theorem may one replace `q` by a finite list. Good reduction is insufficient; the proof would need genuine global arithmetic (for example, an integral-point theorem, a carefully chosen modular unit with controlled divisor, or an equivalent descent).

## Route A3: construct finitely many genuine covers

Instead of dehomogenizing prematurely, retain the complete two-cover data and produce a finite set of genus-one torsors from the Selmer computation. Determine their K-points with the rational-coordinate condition. This is the standard way the factorization `f=g ḡ` becomes a finite algorithm.

# 10. Lean-formalizable core of the correction

The obstruction itself is very small to formalize.

```lean
-- Homogeneous cubic over K.
def G (A D : ℚ) : K :=
  A^3 + 2*λ*A^2*D + λ^2*A*D^2 - D^3

-- Affine evaluation identity.
theorem g_div_identity (A D : ℚ) (hD : D ≠ 0) :
    g (A / D) = G A D / D^3 := by
  field_simp [G, g, hD]
  ring

-- The key dehomogenization calculation.
theorem affine_twist_of_homogeneous_square
    (A D Z : ℚ) (ε : ℚ)
    (hD : D ≠ 0)
    (hG : G A D = ε * Z^2) :
    g (A / D) = ε * D * (Z / D^2)^2 := by
  rw [g_div_identity A D hD, hG]
  field_simp [hD]
  ring
```

The local counterexample reduces to Hensel's lemma for a unit congruent to one modulo an odd prime and the valuation computation

```text
v_p(G(1,p)/p³)=-3.
```

The twist-equivalence correction is the explicit change of variables induced by `r²=-2`.

# Final answer to the three questions

1. **No:** the affine twist parameter is not a-priori supported on `{2,3}`. The ideal argument proves `G(A,D)=±Z²`; after dehomogenization the parameter is `q≡±D`, so any prime occurring oddly in the denominator can occur. Good reduction does not exclude it.

2. The eight rational parameters represent only four K-isomorphism classes. The verified ranks force

```text
rank(q=1)=rank(q=-2)=0,
rank(q=-1)=rank(q=2)=1.
```

The ranks of the `[3]` and `[-3]` classes require a separate certified computation. In particular, `q=-1` is not the only positive-rank entry in the literal eight-element table.

3. **No:** one cannot conclude that `C(Q)` maps into seven rank-zero twists plus a single rank-one twist. The finite twist list has not been proved and the proposed local proof is false. Route A becomes finite only after a genuine finite Selmer/two-cover computation or an independent global denominator theorem.
