# Q3935: cyclic order 14 Kubert bridge

## Answer

No.  The standard order-14 Kubert curve

\[
E_{14}: y^2 + xy + y = x^3 - x
\]

is **not** birationally equivalent over `ℚ` to

\[
E': Y^2 = X^3 + X^2 - 2X = X(X+2)(X-1).
\]

So there is no explicit birational map `(u,w) ↦ (U,W)` to construct.  This is not merely a failure of completing the square; the two smooth projective curves have different `j`-invariants.

## Invariant computation

For a Weierstrass equation

\[
y^2 + a_1xy + a_3y = x^3 + a_2x^2 + a_4x + a_6,
\]

use

\[
\begin{aligned}
b_2 &= a_1^2 + 4a_2,\\
b_4 &= 2a_4 + a_1a_3,\\
b_6 &= a_3^2 + 4a_6,\\
b_8 &= a_1^2a_6 + 4a_2a_6 - a_1a_3a_4 + a_2a_3^2 - a_4^2,\\
c_4 &= b_2^2 - 24b_4,\\
\Delta &= -b_2^2b_8 - 8b_4^3 - 27b_6^2 + 9b_2b_4b_6,\\
j &= c_4^3 / \Delta.
\end{aligned}
\]

For the standard curve

\[
E_{14}: y^2 + xy + y = x^3 - x,
\]

we have

\[
(a_1,a_2,a_3,a_4,a_6)=(1,0,1,-1,0).
\]

Thus

\[
b_2=1,\qquad b_4=-1,\qquad b_6=1,\qquad b_8=0,
\]

so

\[
c_4=25,\qquad \Delta=-28,\qquad j(E_{14})=\frac{25^3}{-28}=-\frac{15625}{28}.
\]

For the project curve

\[
E': Y^2 = X^3 + X^2 - 2X,
\]

we have

\[
(a_1,a_2,a_3,a_4,a_6)=(0,1,0,-2,0).
\]

Thus

\[
b_2=4,\qquad b_4=-4,\qquad b_6=0,\qquad b_8=-4,
\]

so

\[
c_4=112,\qquad \Delta=576,\qquad j(E')=\frac{112^3}{576}=\frac{21952}{9}.
\]

These are unequal:

\[
-\frac{15625}{28} \ne \frac{21952}{9}.
\]

Therefore the two curves are not isomorphic over `\overline{ℚ}`, hence not birational over `ℚ`.

## Why this rules out every rational substitution

Both affine equations are nonsingular and have smooth projective completions of genus one with a rational point at infinity.  A birational equivalence between the affine curves would identify their function fields, hence would extend to an isomorphism between the smooth projective completions.  Since both completions are elliptic curves, after translating the image of the identity point, such a curve isomorphism gives an elliptic-curve isomorphism.  In particular the `j`-invariant must agree.

The `j`-invariants do not agree, so no rational functions

\[
U = U(u,w),\qquad W = W(u,w)
\]

can give a birational map from

\[
w^2+uw+w=u^3-u
\]

to

\[
W^2=U^3+U^2-2U.
\]

Consequently, a substitution check of the requested kind cannot succeed: there is no map whose substitution into

\[
W^2 = U^3 + U^2 - 2U
\]

recovers

\[
w^2+uw+w=u^3-u.
\]

## Sage verification

```sage
from sage.all import EllipticCurve, QQ

# Standard order-14 Kubert/X_1(14) model:
#   y^2 + x*y + y = x^3 - x
E14 = EllipticCurve(QQ, [1, 0, 1, -1, 0])

# Project model:
#   Y^2 = X^3 + X^2 - 2*X
Eproj = EllipticCurve(QQ, [0, 1, 0, -2, 0])

assert E14.c4() == 25
assert E14.discriminant() == -28
assert E14.j_invariant() == QQ(-15625) / 28

assert Eproj.c4() == 112
assert Eproj.discriminant() == 576
assert Eproj.j_invariant() == QQ(21952) / 9

assert E14.j_invariant() != Eproj.j_invariant()
print("not birational")
```

## Consequence for `cyclic_order_14_kubert_bridge`

The theorem cannot be proved by transporting a rational point from the standard Kubert model

\[
w^2+uw+w=u^3-u
\]

to the project model

\[
w^2=u^3+u^2-2u
\]

through a birational change of variables, because no such birational change exists.  If the Lean project expects this bridge, then either the target curve in `CyclicOrder14KubertBridge` is not intended to be a mere alternative model of the standard order-14 obstruction curve, or the target equation is likely a mismatch/typo relative to the standard Kubert model.

The completed-square form of the standard model is

\[
(2w+u+1)^2 = 4u^3 + u^2 + 2u + 1,
\]

and that curve has the same `j`-invariant as the standard model, namely `-15625/28`.  The curve

\[
w^2 = u^3 + u^2 - 2u = u(u+2)(u-1)
\]

has `j = 21952/9` instead.
