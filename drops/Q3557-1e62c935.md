# Q3557: near-root integrability API for `rightIntegrand`

## Focused route

Use the already-checked strict lower bound

```lean
(shortCubicDeriv A B e / 2) * (t - e) < shortCubic A B t
```

on a smaller interval `(e, e + δ)`, then compare by negative real powers. This avoids direct algebra with inverse square roots:

```lean
rightIntegrand A B t
  = (shortCubic A B t) ^ (-(1 / 2 : ℝ))
  ≤ ((shortCubicDeriv A B e / 2) * (t - e)) ^ (-(1 / 2 : ℝ))
  = (shortCubicDeriv A B e / 2) ^ (-(1 / 2 : ℝ)) * (t - e) ^ (-(1 / 2 : ℝ)).
```

The finite-endpoint singularity is handled by

```lean
intervalIntegral.intervalIntegrable_rpow'
IntervalIntegrable.comp_sub_right
intervalIntegrable_iff_integrableOn_Ioo_of_le
```

not by an improper-integral-at-filter theorem.

## Helper lemmas to add

```lean
import Mathlib.Analysis.SpecialFunctions.ImproperIntegrals
import FLT.Assumptions.MazurProof.RealTopologyS4

noncomputable section
open Set MeasureTheory
open scoped Topology

namespace MazurProof.RealTopology

/-- Bridge `sqrt` to `rpow`. Reuse this also for tail estimates if it is not already in S4. -/
lemma sqrt_eq_rpow_half {x : ℝ} (hx : 0 ≤ x) :
    √x = x ^ ((1 : ℝ) / 2) := by
  rw [Real.sqrt_eq_iff_mul_self_eq hx (Real.rpow_nonneg hx _)]
  calc
    x = x ^ (1 : ℝ) := by simp
    _ = x ^ ((1 : ℝ) / 2 + (1 : ℝ) / 2) := by norm_num
    _ = x ^ ((1 : ℝ) / 2) * x ^ ((1 : ℝ) / 2) := by
      rw [Real.rpow_add' hx]
      norm_num

lemma inv_sqrt_eq_rpow_neg_half {x : ℝ} (hx : 0 ≤ x) :
    (√x)⁻¹ = x ^ (-(1 / 2 : ℝ)) := by
  rw [sqrt_eq_rpow_half hx]
  exact (Real.rpow_neg hx (1 / 2 : ℝ)).symm

/-- The model singularity at the left endpoint is integrable on a finite interval. -/
lemma integrableOn_Ioo_sub_rpow_neg_half {e δ : ℝ} (hδ : 0 < δ) :
    IntegrableOn (fun t : ℝ => (t - e) ^ (-(1 / 2 : ℝ))) (Ioo e (e + δ)) := by
  have hbase :
      IntervalIntegrable (fun x : ℝ => x ^ (-(1 / 2 : ℝ))) volume 0 δ :=
    intervalIntegral.intervalIntegrable_rpow'
      (by norm_num : -1 < (-(1 / 2 : ℝ)))
  have hshift :
      IntervalIntegrable (fun t : ℝ => (t - e) ^ (-(1 / 2 : ℝ))) volume (0 + e) (δ + e) := by
    simpa using hbase.comp_sub_right e
  have hshift' :
      IntervalIntegrable (fun t : ℝ => (t - e) ^ (-(1 / 2 : ℝ))) volume e (e + δ) := by
    simpa [zero_add, add_comm, add_left_comm, add_assoc] using hshift
  exact (intervalIntegrable_iff_integrableOn_Ioo_of_le
    (show e ≤ e + δ by linarith)).mp hshift'

end MazurProof.RealTopology
```

If `rw [Real.rpow_add' hx]` does not fill its side condition in your build, use the explicit version:

```lean
rw [Real.rpow_add' hx (by norm_num : (1 : ℝ) / 2 + (1 : ℝ) / 2 ≠ 0)]
```

## Pointwise comparison lemma

This is worth adding before the existential integrability theorem; it isolates all order/rpow work.

```lean
import Mathlib.Analysis.SpecialFunctions.ImproperIntegrals
import FLT.Assumptions.MazurProof.RealTopologyS4

noncomputable section
open Set MeasureTheory
open scoped Topology

namespace MazurProof.RealTopology

lemma rightIntegrand_le_root_model_near
    {A B e δ0 t : ℝ}
    (hderiv : 0 < shortCubicDeriv A B e)
    (hnear : ∀ ⦃u : ℝ⦄, e < u → u < e + δ0 →
      (shortCubicDeriv A B e / 2) * (u - e) < shortCubic A B u)
    (ht_left : e < t) (ht_right : t < e + δ0) :
    rightIntegrand A B t ≤
      (shortCubicDeriv A B e / 2) ^ (-(1 / 2 : ℝ)) *
        (t - e) ^ (-(1 / 2 : ℝ)) := by
  let c : ℝ := shortCubicDeriv A B e / 2
  have hcpos : 0 < c := by
    dsimp [c]
    exact div_pos hderiv (by norm_num)
  have hxpos : 0 < t - e := sub_pos.mpr ht_left
  have hlinpos : 0 < c * (t - e) := mul_pos hcpos hxpos
  have hlin_lt : c * (t - e) < shortCubic A B t := by
    dsimp [c]
    exact hnear ht_left ht_right
  have hshortpos : 0 < shortCubic A B t := hlinpos.trans hlin_lt
  calc
    rightIntegrand A B t
        = (shortCubic A B t) ^ (-(1 / 2 : ℝ)) := by
            unfold rightIntegrand
            rw [inv_sqrt_eq_rpow_neg_half hshortpos.le]
    _ ≤ (c * (t - e)) ^ (-(1 / 2 : ℝ)) := by
            exact Real.rpow_le_rpow_of_nonpos hlinpos
              (le_of_lt hlin_lt)
              (by norm_num : (-(1 / 2 : ℝ)) ≤ 0)
    _ = c ^ (-(1 / 2 : ℝ)) * (t - e) ^ (-(1 / 2 : ℝ)) := by
            rw [Real.mul_rpow hcpos.le hxpos.le]

end MazurProof.RealTopology
```

The theorem name `Real.rpow_le_rpow_of_nonpos` is the key API: its hypotheses should line up as “positive lower base”, “lower base ≤ upper base”, and “exponent ≤ 0”.

## Final near-root theorem

```lean
import Mathlib.Analysis.SpecialFunctions.ImproperIntegrals
import FLT.Assumptions.MazurProof.RealTopologyS4

noncomputable section
open Set MeasureTheory
open scoped Topology

namespace MazurProof.RealTopology

theorem rightIntegrand_integrableOn_near_root
    {A B e : ℝ}
    (hroot : shortCubic A B e = 0)
    (hderiv : 0 < shortCubicDeriv A B e) :
    ∃ δ > 0, IntegrableOn (rightIntegrand A B) (Ioo e (e + δ)) := by
  classical
  rcases exists_shortCubic_lower_bound_near_root
      (A := A) (B := B) (e := e) hroot hderiv with
    ⟨δ0, hδ0, hnear⟩
  let δ : ℝ := min δ0 1
  have hδ : 0 < δ := by
    dsimp [δ]
    exact lt_min hδ0 zero_lt_one
  refine ⟨δ, hδ, ?_⟩

  let c : ℝ := shortCubicDeriv A B e / 2
  have hcpos : 0 < c := by
    dsimp [c]
    exact div_pos hderiv (by norm_num)

  have hmodel :
      IntegrableOn
        (fun t : ℝ => c ^ (-(1 / 2 : ℝ)) * (t - e) ^ (-(1 / 2 : ℝ)))
        (Ioo e (e + δ)) := by
    exact (integrableOn_Ioo_sub_rpow_neg_half (e := e) hδ).const_mul _

  refine hmodel.mono' ?hmeas ?hbound
  · -- This should close because `shortCubic`, `sqrt`, and inversion are measurable.
    -- If `fun_prop` does not close it, use the existing
    -- `rightIntegrand_aestronglyMeasurable_restrict_Ioi` plus restrict-monotonicity.
    unfold rightIntegrand
    fun_prop
  · filter_upwards [ae_restrict_mem measurableSet_Ioo] with t ht
    have ht_left : e < t := ht.1
    have ht_delta : t < e + δ := ht.2
    have hδ_le_δ0 : δ ≤ δ0 := by
      dsimp [δ]
      exact min_le_left _ _
    have ht_right0 : t < e + δ0 := by linarith

    have hle := rightIntegrand_le_root_model_near
      (A := A) (B := B) (e := e) (δ0 := δ0) (t := t)
      hderiv hnear ht_left ht_right0

    let c : ℝ := shortCubicDeriv A B e / 2
    have hcpos : 0 < c := by
      dsimp [c]
      exact div_pos hderiv (by norm_num)
    have hxpos : 0 < t - e := sub_pos.mpr ht_left
    have hri_nonneg : 0 ≤ rightIntegrand A B t := by
      unfold rightIntegrand
      exact inv_nonneg.mpr (Real.sqrt_nonneg _)
    have hmodel_nonneg :
        0 ≤ c ^ (-(1 / 2 : ℝ)) * (t - e) ^ (-(1 / 2 : ℝ)) := by
      exact mul_nonneg (Real.rpow_nonneg hcpos.le _) (Real.rpow_nonneg hxpos.le _)
    simpa [Real.norm_eq_abs, abs_of_nonneg hri_nonneg, abs_of_nonneg hmodel_nonneg, c]
      using hle

end MazurProof.RealTopology
```

## If the measurability subgoal does not close

Try this named lemma; it avoids depending on the Ioi-specific existing lemma signature.

```lean
lemma rightIntegrand_aestronglyMeasurable_restrict_Ioo (A B a b : ℝ) :
    AEStronglyMeasurable (rightIntegrand A B) (volume.restrict (Ioo a b)) := by
  unfold rightIntegrand
  fun_prop
```

Then replace `?hmeas` with:

```lean
exact rightIntegrand_aestronglyMeasurable_restrict_Ioo A B e (e + δ)
```

If `fun_prop` still fails, grep/type-search in this order:

```lean
#check Real.continuous_sqrt
#check Continuous.comp
#check Continuous.inv₀
#check Continuous.aestronglyMeasurable
#check AEStronglyMeasurable.restrict
#check AEStronglyMeasurable.mono_measure
```

The fallback proof is to show `Continuous (fun x => (√(shortCubic A B x))⁻¹)` by composing polynomial continuity, `Real.continuous_sqrt`, and continuous inversion, then use `.aestronglyMeasurable` and restrict it to `Ioo`.

## If the shifted rpow model does not elaborate

The exact API names to search are:

```lean
#check intervalIntegral.intervalIntegrable_rpow'
#check integrableOn_Ioo_rpow_iff
#check IntervalIntegrable.comp_sub_right
#check intervalIntegrable_iff_integrableOn_Ioo_of_le

```

A robust replacement for `integrableOn_Ioo_sub_rpow_neg_half` is to prove interval integrability first:

```lean
have hbase : IntervalIntegrable (fun x : ℝ => x ^ (-(1 / 2 : ℝ))) volume 0 δ :=
  intervalIntegral.intervalIntegrable_rpow' (by norm_num : -1 < (-(1 / 2 : ℝ)))
have hshift := hbase.comp_sub_right e
```

then `simpa [zero_add, add_comm, add_left_comm, add_assoc]` to get endpoints `e` and `e + δ`, and finally apply

```lean
(intervalIntegrable_iff_integrableOn_Ioo_of_le (show e ≤ e + δ by linarith)).mp hshift
```
