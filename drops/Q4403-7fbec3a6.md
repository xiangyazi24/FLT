# N18 Route C, Block 6: from the annihilator to no rational 18-torsion

## Executive verdict

The endgame is constructive and does not need Faltings, Mordell–Weil finite generation, or abstract modular-stack machinery.

The correct chain is:

```text
[126] J_1(18)(Q) = 0
  + prime-to-p good-reduction injectivity at p=5 and p=13
  + #J(F_5)=42, #J(F_13)=189
  + an explicit rational class delta of order 21
        => J_1(18)(Q) = <delta> ~= Z/21Z;

J(Q)=<delta>
  + injective Abel–Jacobi map C(Q) -> J(Q)
  + the certified 21-entry reduced generalized-Mumford table
  + uniqueness of reduced representatives
        => C(Q) consists of exactly six points;

all six points are on the boundary of the Tate-normal-form chart
        => all six are cusps;

an elliptic curve over Q with a point of exact order 18
  -> a nonexceptional rational point on the explicit X_1(18) model
        => contradiction.
```

The two important corrections are:

1. **Bounded exponent alone does not imply finiteness for an abstract group.** An infinite direct sum of copies of `Z/126Z` is a counterexample. Here finiteness comes from injective reduction into a finite Jacobian at a good prime.
2. Merely knowing that `C(Q)` is finite does not identify its points. The effective enumeration uses the already-built finite Mumford table, not Faltings.

The smallest formal route in this repository is the direct Tate-normal-form bridge. The current tree contains torsion-group definitions in `FLT/EllipticCurve/Torsion.lean`, but it does not contain a general `X_1(N)` moduli interpretation or a theorem named `HasRationalPointOfOrder`. Building the abstract moduli problem would be far larger than the fixed algebraic bridge below.

# 2. Why `[126]J(Q)=0` gives a finite group here

## 2.1 Rank zero is not the formal input

In conventional arithmetic geometry one says:

```text
Mordell–Weil theorem + rank J(Q)=0 => J(Q) is finite.
```

That uses finite generation. Route C deliberately avoids this. Its actual input is stronger:

```lean
h126 : forall D : JQ, 126 • D = 0
```

where `JQ` is the fixed `Pic^0(C)(Q)` implementation.

This still does not imply finiteness in pure group theory. Add one fixed good-reduction injection.

## 2.2 Abstract prime-to-p reduction lemma

The reusable group layer should be:

```lean
structure PrimeToPReductionData
    (G R : Type*) [AddCommGroup G] [AddCommGroup R]
    (N p : Nat) where
  red : G ->+ R
  coprime : Nat.Coprime N p
  kernel_no_N_torsion :
    forall z : red.ker, N • z = 0 -> z = 0
```

Then:

```lean
theorem PrimeToPReductionData.injective
    {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    {N p : Nat}
    (D : PrimeToPReductionData G R N p)
    (hN : forall x : G, N • x = 0) :
    Function.Injective D.red := by
  intro x y hxy
  have hk : x - y ∈ D.red.ker := by
    simp [AddMonoidHom.mem_ker, hxy]
  let z : D.red.ker := ⟨x-y, hk⟩
  have hzN : N • z = 0 := by
    apply Subtype.ext
    simp [z, hN]
  have hz := D.kernel_no_N_torsion z hzN
  simpa [z] using congrArg Subtype.val hz
```

If `R` is finite, this installs `Finite G` by `Finite.of_injective`.

The arithmetic proof of `kernel_no_N_torsion` is the standard good-reduction formal-neighborhood lemma. For a smooth group scheme over a DVR of residue characteristic `p`, the reduction kernel is pro-`p`; multiplication by a number coprime to `p` is an automorphism on its formal completion. For a fixed implementation, it is enough to prove

```text
[N](z_1,z_2)=N*(z_1,z_2)+terms of total degree >=2
```

and use that `N` is a local unit. This is easier than the Block-5 `[3]` growth theorem: no iteration is needed.

# 3. The Abel–Jacobi injection

Choose `infMinus` as base point and define

```text
AJ(P)=[P-infMinus].
```

## 3.1 Exact statement

```lean
noncomputable def abelJacobi18 : C18PointQ -> J18Q

theorem abelJacobi18_injective :
    Function.Injective abelJacobi18
```

## 3.2 Fixed genus-two proof

If

```text
[P-infMinus]=[Q-infMinus],
```

then `P-Q` is principal. If `P != Q`, a function with divisor `P-Q` has one simple pole and therefore defines a degree-one map

```text
C -> P^1.
```

A smooth projective curve admitting such a map is rational, contradicting `genus(C)=2`.

The minimal new divisor lemma can be stated without general Abel varieties:

```lean
theorem point_sub_point_not_principal
    {P Q : C18PointQ}
    (hPQ : P ≠ Q) :
    ¬ IsPrincipal (pointDivisor P - pointDivisor Q) := by
  intro h
  obtain ⟨g, hg⟩ := h
  have hpole : poleDegree g = 1 := by
    -- read from hg
  have hdeg : functionFieldMapDegree g = 1 := hpole
  have hrat : curveGenus C18 = 0 := genus_zero_of_degree_one_function hdeg
  norm_num [C18_genus] at hrat
```

Equivalently, prove the fixed Riemann–Roch fact `ell(P)=1` for every rational point `P` on this genus-two curve. Either formulation is independent of Mordell–Weil finite generation.

Finiteness now follows already from

```text
C(Q) injects into the finite 21-element group J(Q).
```

But this only gives `#C(Q) <= 21`; it does not identify the points.

# 4. Effective enumeration with the 21-entry Mumford table

## 4.1 The required uniqueness theorem

Use the generalized even-degree Mumford convention from Block 3. A reduced triple `(u,v,nInf)` represents

```text
D_aff(u,v)-deg(u)*infMinus+nInf*(infPlus-infMinus),
```

with

```text
u monic,
u | f-v^2,
deg(v)<deg(u),
nInf>=0,
deg(u)+nInf<=2.
```

The one semantic theorem needed here is:

```lean
theorem reducedMumford_unique
    {D1 D2 : ReducedMumford18}
    (h : mumfordClass D1 = mumfordClass D2) :
    D1 = D2
```

This is a fixed genus-two reduced-divisor uniqueness theorem. It is preferable to a Mordell–Weil sieve: once it is available, rational-point enumeration is six table comparisons.

## 4.2 Point representatives

The Abel–Jacobi images have the following canonical reduced triples:

```text
AJ(infMinus) = (1,0,0),
AJ(infPlus)  = (1,0,1),
AJ((x,y))    = (X-x, y, 0)        for an affine rational point.
```

The certified `delta` table contains 21 distinct reduced entries. The only entries of the form required above are

```text
0*delta  = (1,0,0)                 = AJ(infMinus),
1*delta  = (1,0,1)                 = AJ(infPlus),
3*delta  = (X,1,0)                 = AJ((0,1)),
9*delta  = (X+1,-1,0)              = AJ((-1,-1)),
13*delta = (X+1,1,0)               = AJ((-1,1)),
19*delta = (X,-1,0)                = AJ((0,-1)).
```

All other table entries either have affine degree `2` or have `nInf=1` together with affine degree `1`; they cannot equal the reduced representative of a single affine point.

## 4.3 Lean theorem

```lean
theorem C18_rational_points
    (P : C18PointQ) :
    P = infMinus ∨
    P = infPlus ∨
    P = affinePoint 0 1 ∨
    P = affinePoint 0 (-1) ∨
    P = affinePoint (-1) 1 ∨
    P = affinePoint (-1) (-1) := by
  have hcyc : ∃ k : Fin 21,
      abelJacobi18 P = k.val • delta := by
    -- J(Q)=<delta>
  obtain ⟨k,hk⟩ := hcyc
  have hred := reducedMumford_unique
      (pointMumfordReduced P)
      (torsionRepReduced k)
      (by simpa [mumfordClass_point] using hk)
  fin_cases k <;>
    simp [pointMumfordReduced, torsionRepReduced,
      D0,D1,D2,D3,D4,D5,D6,D7,D8,D9,D10,
      D11,D12,D13,D14,D15,D16,D17,D18,D19,D20] at hred ⊢
```

The `fin_cases` branches reduce to equality of rational polynomial coefficients. This is the complete constructive enumeration.

# 5. An optimized affine model and the cusp locus

```text
Copt : v^2+(u^3-2u^2+3u+1)v+2u=0.
```

# 6. The concrete Tate-normal-form chart

## 6.1 Tate normal form

For `b,c ∈ Q`, define

```text
E(b,c): y^2+(1-c)xy-by=x^3-bx^2,
P0=(0,0).
```

Its discriminant is

```text
Delta(b,c)=
 b^3*(16b^2-8bc^2-20bc+b+c(c-1)^3).
```

Define

```lean
def Tate18 (b c : Q) : WeierstrassCurve Q :=
  ⟨1-c, -b, -b, 0, 0⟩

def TateNonsingular (b c : Q) : Prop :=
  b ≠ 0 ∧
  16*b^2-8*b*c^2-20*b*c+b+c*(c-1)^3 ≠ 0
```

The multiples needed to create the raw equation begin

```text
2P0=(b,bc),
3P0=(c,b-c).
```

## 6.2 Tate normalization theorem

The fixed theorem needed from an arbitrary rational elliptic curve is:

```lean
structure TateNormalFormDatum
    (E : WeierstrassCurve Q) [E.IsElliptic]
    (P : (E/Q).Point) where
  b c : Q
  nonsingular : TateNonsingular b c
  pointEquiv : (E/Q).Point ≃+ ((Tate18 b c)/Q).Point
  maps_point : pointEquiv P = tateOrigin b c

theorem tateNormalForm_of_exactOrder18
    (E : WeierstrassCurve Q) [E.IsElliptic]
    (P : (E/Q).Point)
    (hP : addOrderOf P = 18) :
    TateNormalFormDatum E P
```

This is the standard Tate-normal-form theorem for a point of order greater than `3`. The proof is a finite sequence of admissible Weierstrass changes of variables: translate `P` to `(0,0)`, use its tangent to eliminate `a4`, and rescale so that `a2=a3=-b`. Exact order `18` supplies every denominator nonvanishing condition.

Mathlib has curve-level `WeierstrassCurve.VariableChange`; the repository still needs the corresponding point-level `AddEquiv`, preserving the group law. This is reusable for all composite-order seams.

## 6.3 Raw variables

On the open set relevant to exact order `18`, define

```text
r=b/c,
s=c^2/(b-c).
```

Conversely,

```text
c=s(r-1),
b=r*s(r-1).
```

Exact order `18` implies

```text
b != 0,
c != 0,
b != c,
```

since `c=0` would force order dividing `4`, while `b=c` gives `2P0=-3P0` and hence order dividing `5`.

## 6.4 The raw `X_1(18)` equation

Set

```text
F18(r,s)=
  r^4*s^3-6*r^4*s^2+9*r^4*s-r^4
 +r^3*s^5-7*r^3*s^4+20*r^3*s^3-19*r^3*s^2-8*r^3*s+r^3
 +r^2*s^4-11*r^2*s^3+28*r^2*s^2
 +r*s^4-5*r*s^3-8*r*s^2
 +s^4+s^3+s^2.
```

Sutherland’s raw-form computation gives:

```lean
theorem rawEquation_of_tate_exactOrder18
    {b c : Q}
    (hns : TateNonsingular b c)
    (hord : addOrderOf (tateOrigin b c) = 18) :
    F18 (b/c) (c^2/(b-c)) = 0 := by
  -- From 18P=0, 10P=-8P and hence x(10P)=x(8P).
  -- Expand the fixed group-law recurrences for x(nP).
  -- `field_simp` using the nonvanishing consequences of exact order.
  -- The remaining numerator is the displayed F18 times factors
  -- corresponding to lower-order/cuspidal cases; exact order excludes them.
  ring_nf
```

This proof is large as an expanded expression but conceptually contains no arithmetic geometry.

# 7. Explicit birational coordinates between the raw and optimized models

## 7.1 Optimized point to Tate parameters

For an affine point `(u,v)` on `Copt`, put

```text
Nr=u^2-u*v-3u+1,
Dr=(u-1)^2*(u*v+1),

Ns=u^2-2u-v,
Ds=u^2-u*v-3u-v^2-2v,

r=Nr/Dr,
```

The source table has a missing opening parenthesis in the printed `s` row; the intended and algebraically verified expression is the one displayed above.

Then

```text
b=r*s*(r-1),
```

This answers the explicit-map question: the map exists over `Q` and is a composition of rational functions with fully displayed coefficients.

# 8. Why the six rational points are cusps

Define the affine noncuspidal chart by the conditions needed to produce a nonsingular Tate curve:

```lean
def OptNonCusp (u v : Q) : Prop :=
  CoptEq u v ∧
  Dr u v ≠ 0 ∧
  Ds u v ≠ 0 ∧
  let r := optR u v
  let s := optS u v
  TateNonsingular (r*s*(r-1)) (s*(r-1))
```

Evaluate it on the four affine rational points:

```text
(0,0):
  Ds=0;

(0,-1):
  r=1, s=1, hence b=c=0 and Delta=0;

(1,-1):
  Dr=0;

(1,-2):
  Dr=0.
```

The two points at infinity lie outside the affine Tate chart. Therefore every rational point is a cusp.

Lean:

```lean
theorem known_affine_points_not_noncusp :
    ¬ OptNonCusp 0 0 ∧
    ¬ OptNonCusp 0 (-1) ∧
    ¬ OptNonCusp 1 (-1) ∧
    ¬ OptNonCusp 1 (-2) := by
  norm_num [OptNonCusp, optR, optS, Dr, Ds,
    TateNonsingular, tateDiscriminant]

theorem Copt_no_rational_noncusp
    {u v : Q}
    (hC : CoptEq u v) :
    ¬ OptNonCusp u v := by
  have hp := C18_rational_points
      (optToSimplifiedPoint u v hC)
  rcases hp with h | h | h | h | h | h
  · -- infinity impossible since the constructed point is affine
    contradiction
  · contradiction
  · subst u; subst v; exact known_affine_points_not_noncusp.1
  · ...
```

# 9. Abstract modular interpretation, if desired

Mathematically, for `N>=4`, the open modular curve `Y_1(N)` is a fine moduli scheme over `Q` for elliptic curves equipped with a point of exact order `N`. A precise statement uses isomorphism classes:

```lean
structure PointedEllipticCurve (K : Type*) [Field K] (N : Nat) where
  E : WeierstrassCurve K
  isElliptic : E.IsElliptic
  P : (E/K).Point
  exactOrder : addOrderOf P = N

abbrev PointedEllipticCurveModIso K N :=
  Quotient (PointedEllipticCurveIsoSetoid K N)

noncomputable def X1OpenModuliEquiv :
  NonCuspRationalPoints X1_18 ≃ PointedEllipticCurveModIso Q 18
```

The only direction required for Mazur is

```lean
theorem noncuspPoint_of_exactOrder18
    (E : WeierstrassCurve Q) [E.IsElliptic]
    (P : (E/Q).Point)
    (hP : addOrderOf P = 18) :
    ∃ Q : X1_18.RationalPoint, ¬ IsCusp Q
```

Together with

```lean
theorem X1_18_rationalPoint_isCusp
    (Q : X1_18.RationalPoint) : IsCusp Q
```

this immediately gives the target.

However, this abstract route requires moduli schemes, generalized elliptic curves at the compactification, and identification of the explicit sextic with the coarse/fine modular curve. None of that currently exists in Mathlib or this repository. The fixed Tate route proves exactly the necessary forward implication with rational-function identities and is therefore much smaller.

```lean
  have hopt : CoptEq u v := raw_to_opt hr hr1 hF
  have hopen : OptNonCusp u v := by
    exact raw_to_opt_noncusp D.nonsingular hP hr hr1 hF

  exact Copt_no_rational_noncusp hopt hopen
```
