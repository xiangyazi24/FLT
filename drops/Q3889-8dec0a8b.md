# `addOrderOf_nsmul'` signature and proof

Mathlib has the multiplicative theorem

```lean
theorem orderOf_pow' (h : n ≠ 0) :
    orderOf (x ^ n) = orderOf x / Nat.gcd (orderOf x) n
```

in `Mathlib/GroupTheory/OrderOfElement.lean`; it is tagged with `@[to_additive]`, so the additive generated theorem is:

```lean
theorem addOrderOf_nsmul' (x : A) (h : n ≠ 0) :
    addOrderOf (n • x) = addOrderOf x / Nat.gcd (addOrderOf x) n
```

The argument order is the one you expected:

```lean
addOrderOf_nsmul' P (show (10 : ℕ) ≠ 0 by norm_num)
```

`norm_num` reduces both:

```lean
Nat.gcd 20 10 = 10
20 / 10 = 2
```

Complete working proof:

```lean
import Mathlib

namespace MazurProof

example {G : Type*} [AddCommGroup G] {P : G} (hP : addOrderOf P = 20) :
    addOrderOf (10 • P) = 2 := by
  rw [addOrderOf_nsmul' P (by norm_num : (10 : ℕ) ≠ 0), hP]
  norm_num

end MazurProof
```
