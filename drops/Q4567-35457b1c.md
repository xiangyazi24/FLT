# R2 audit: the pointwise nonsquare interface is overstrong

## Verdict

The proposed pointwise theorem

```lean
∀ P, ¬ LutzNagellBranch P → ¬ IsSquare K (delta P)
```

is **not** a standard output of classical 2-descent. For an elliptic curve

\[
E:\quad y^2=f(x),
\]

with `f` an irreducible cubic and `K = ℚ(θ)`, the standard Kummer map satisfies

\[
\kappa(P)=[x(P)-\theta]\in K^\times/K^{\times 2},
\qquad
\ker \kappa=2E(\mathbf Q).
\]

Thus

\[
\delta(P)\text{ is a square in }K
\quad\Longleftrightarrow\quad
P\in 2E(\mathbf Q).
\]

Every doubled point has square `delta`. Consequently, if a non-torsion point existed, infinitely many doubled non-torsion points would exist, and all but finitely many would lie outside the finite Lutz–Nagell candidate set. The proposed pointwise assertion would therefore rule out positive rank by itself.

For the specific curve

\[
E:\quad \eta^2=\xi^3-432\xi+8208,
\]

proving the pointwise assertion is already at least as strong as proving the rank-zero/finiteness core. It is not a local ideal-parity lemma, and it makes the downstream nonsquare-unit contradiction logically unnecessary.

Billing–Mahler do **not** use such a pointwise assertion. They invoke Billing's 1937 Satz 1 in the global existential form:

\[
\text{if ordinary rational points exist, then some rational point has the nonsquare-unit class.}
\]

That is a selection theorem about a suitable non-double point, not a statement about every non-Lutz point.

# 1. Exact Kummer meaning of `delta`

Let

\[
f(T)=T^3-432T+8208,
\qquad f(\theta)=0,
\qquad K=\mathbf Q(\theta).
\]

Write a rational affine point primitively as

\[
P=\left(\frac{x}{z^2},\frac{y}{z^3}\right),
\qquad x,y,z\in\mathbf Z,\quad z>0,\quad \gcd(x,z)=1.
\]

Define

\[
\delta(P)=x-\theta z^2.
\]

Since

\[
\frac{x}{z^2}-\theta=\frac{\delta(P)}{z^2}
\]

and `z²` is already a square in `K`, `delta(P)` and `x(P)-θ` represent the same element of `Kˣ/Kˣ²`.

Because `f` is irreducible over `ℚ`, the curve has no nonzero rational 2-torsion:

\[
E(\mathbf Q)[2]=0.
\]

The standard 2-descent map therefore has the clean exactness statement

\[
\boxed{
\delta(P)\in K^{\times 2}
\iff
\exists Q\in E(\mathbf Q),\; P=2Q.
}
\tag{1}
\]

A suitable Lean-facing interface is:

```lean
/-- The primitive denominator does not change the Kummer squareclass. -/
theorem delta_square_iff_x_sub_theta_square
    (P : PrimitiveAffinePoint E) :
    (∃ b : K, delta P = b ^ 2) ↔
      ∃ b : K, xCoord P - theta = b ^ 2

/-- Exactness of the concrete 2-Kummer map. -/
theorem delta_square_iff_two_mul
    (P : PrimitiveAffinePoint E) :
    (∃ b : K, delta P = b ^ 2) ↔
      ∃ Q : E.Point, 2 • Q = P.toPoint
```

The second theorem is global Kummer exactness. Ideal factorization alone proves neither direction involving `2 • Q`.

# 2. Direct calculation: every double has square `delta`

The easy implication in (1) is a single tangent-line identity and is completely elementary.

Let

\[
Q=(r,s)\in E(\mathbf Q),\qquad s\ne0.
\]

The assumption `s ≠ 0` is automatic for a nonzero rational point because `f` is irreducible and hence there is no rational 2-torsion. Put

\[
m=\frac{f'(r)}{2s}=\frac{3r^2-432}{2s},
\qquad
\ell(T)=s+m(T-r),
\]

and let

\[
r_2=m^2-2r
\]

be the `x`-coordinate of `2Q`. The tangent intersects the cubic at `Q` with multiplicity two and at the point whose `x`-coordinate is `r₂`, so the following polynomial identity holds:

\[
\boxed{
\ell(T)^2-f(T)=-(T-r)^2(T-r_2).
}
\tag{2}
\]

This can be proved by `field_simp` followed by `ring`, using only `s²=f(r)`.

Evaluate (2) at `T=θ`. Since `f(θ)=0`,

\[
\ell(\theta)^2
=-(\theta-r)^2(\theta-r_2)
=(r-\theta)^2(r_2-\theta).
\]

Therefore

\[
\boxed{
r_2-\theta
=\left(\frac{\ell(\theta)}{r-\theta}\right)^2.
}
\tag{3}
\]

If `2Q` has primitive coordinates `(x/z²,y/z³)`, multiplying (3) by `z²` gives

\[
\boxed{
\delta(2Q)=x-\theta z^2
=\left(\frac{z\ell(\theta)}{r-\theta}\right)^2.
}
\tag{4}
\]

Thus `delta(2Q)` is a square in `K` for every affine double. This is the exact direct-coordinate obstruction to the proposed pointwise nonsquare theorem.

A Lean certificate can be isolated as:

```lean
lemma tangent_factor_identity
    {r s : ℚ} (hQ : s ^ 2 = f.eval r) :
    let m  := (3 * r ^ 2 - 432) / (2 * s)
    let r₂ := m ^ 2 - 2 * r
    let ell := fun T : K => s + m * (T - r)
    ell theta ^ 2 = (r - theta) ^ 2 * (r₂ - theta) := by
  dsimp
  field_simp
  -- rewrite `theta_cubic` and `hQ`
  ring
```

No ideal theory, class group, or rank theorem is used in this direction.

# 3. An explicit counterexample on a positive-rank curve

The failure is not merely hypothetical as a general 2-descent principle. Consider

\[
E_1:\quad y^2=x^3-2,
\qquad K_1=\mathbf Q(\sqrt[3]{2}).
\]

The cubic is irreducible. The point

\[
Q=(3,5)
\]

is non-torsion: the integral Lutz–Nagell criterion would require `25` to divide the discriminant magnitude `1728`, which it does not.

Doubling gives

\[
2Q=\left(\frac{129}{100},-\frac{383}{1000}\right).
\]

This point is nonintegral, hence outside the integral Lutz–Nagell branch. Nevertheless, writing `θ³=2`, its primitive Kummer numerator is

\[
\delta(2Q)=129-100\theta,
\]

and one has the exact identity

\[
\boxed{
129-100\theta
=\left(\frac{27\theta-31}{3-\theta}\right)^2.
}
\]

Indeed, after multiplying by `(3-θ)²`, both sides become

\[
729\theta^2-1674\theta+961.
\]

So “non-Lutz implies nonsquare Kummer class” is false as a general classical-descent statement even under irreducibility of the cubic.

For the particular rank-zero curve in the question, the assertion may be extensionally true because there are no non-Lutz points. That does not make it an admissible intermediate descent lemma: proving it already proves the hard global conclusion.

# 4. Rigorous implication: the pointwise theorem already proves finiteness

Let `L(P)` be the proposed Lutz–Nagell branch. For the current curve it is a finite predicate:

```text
z = 1, and y = 0 or y² divides 1496537856.
```

There are finitely many possible integers `y`, and for each one the cubic equation has at most three possible integers `x`. Hence

\[
S_L:=\{P\in E(\mathbf Q):L(P)\}
\]

is finite.

Assume the target pointwise statement

\[
\forall P,\quad \neg L(P)\Longrightarrow \delta(P)\notin K^{\times2}.
\tag{5}
\]

Its contrapositive is

\[
\delta(P)\in K^{\times2}\Longrightarrow L(P).
\tag{6}
\]

For every `Q`, equation (4) gives `delta(2Q)` square. Therefore

\[
2E(\mathbf Q)\subseteq S_L.
\tag{7}
\]

The right side is finite. Since `E(ℚ)[2]=0`, multiplication by two is injective:

\[
2P=2Q\Longrightarrow 2(P-Q)=0\Longrightarrow P=Q.
\]

Thus the map

\[
E(\mathbf Q)\hookrightarrow S_L,
\qquad Q\longmapsto2Q,
\]

is injective, and `E(ℚ)` is finite.

This proof uses no Mordell–Weil finite-generation theorem. It shows directly that (5) already proves the rank-zero/finiteness core.

Moreover, once `E(ℚ)` is finite, multiplication by two is an injective self-map of a finite set and hence is surjective. Consequently

\[
E(\mathbf Q)=2E(\mathbf Q)\subseteq S_L.
\]

So the pointwise nonsquare assertion alone already implies that **every rational point lies in the finite Lutz branch**. The later contradiction of the nonsquare-unit branch is then redundant.

Conversely, if `E(ℚ)` is finite, every rational point is torsion, and Nagell's theorem puts every affine point in the Lutz–Nagell candidate set. Hence (5) is vacuous. Under the stated irreducibility and Nagell hypotheses, the pointwise interface is therefore essentially equivalent to the desired “all points are exceptional” conclusion.

A useful abstract Lean theorem exposing this circularity is:

```lean
theorem finite_of_nonLutz_implies_kummer_nonsquare
    (lutz : G → Prop)
    (hlutz : Set.Finite {P | lutz P})
    (double : G → G)
    (hdouble_injective : Function.Injective double)
    (kummerSquare : G → Prop)
    (hdouble_square : ∀ Q, kummerSquare (double Q))
    (hpointwise : ∀ P, ¬ lutz P → ¬ kummerSquare P) :
    Finite G := by
  have hrange : Set.range double ⊆ {P | lutz P} := by
    rintro P ⟨Q, rfl⟩
    by_contra h
    exact hpointwise _ h (hdouble_square Q)
  exact Finite.of_injective double
    (Set.Finite.to_subtype (hlutz.mono hrange))
```

The exact packaging may differ, but the mathematical implication cannot be avoided.

# 5. What the local ideal-square calculation really gives

The prime-ideal parity argument can validly prove, pointwise, that

\[
(\delta(P))=\mathfrak a^2.
\tag{8}
\]

Class number one then gives

\[
\delta(P)=u\beta^2
\]

for some unit `u`. After positivity and the explicit unit-squareclass calculation, there are two possible classes:

\[
\boxed{
\delta(P)=\beta^2
\quad\text{or}\quad
\delta(P)=\varepsilon\beta^2,
}
\tag{9}
\]

where, in the notation used in the N11 development, `ε` is the positive nonsquare unit.

This is the correct pointwise output of the ideal descent. It does not permit one to delete the first branch.

The two branches have exact group-theoretic meanings:

\[
\delta(P)=\beta^2
\iff P\in2E(\mathbf Q),
\]

while

\[
\delta(P)=\varepsilon\beta^2
\]

is the nontrivial Kummer coset. Local valuation calculations determine that the image lies in the two-element set `{1,[ε]}`; they do not determine which element corresponds to an arbitrary point.

Therefore the strongest valid pointwise interface is:

```lean
theorem delta_ideal_square
    (P : PrimitiveAffinePoint E) (hP : P.y ≠ 0) :
    ∃ I : Ideal OK, Ideal.span {delta P} = I ^ 2

theorem delta_unit_squareclass_dichotomy
    (P : PrimitiveAffinePoint E) (hP : P.y ≠ 0) :
    (∃ b : OK, delta P = b ^ 2) ∨
    (∃ b : OK, delta P = epsilon * b ^ 2)

theorem delta_square_iff_two_mul
    (P : PrimitiveAffinePoint E) :
    (∃ b : K, delta P = b ^ 2) ↔
    ∃ Q : E.Point, 2 • Q = P.toPoint
```

These three statements are noncircular and faithfully separate local ideal arithmetic from global Mordell–Weil information.

# 6. What Billing–Mahler actually invokes

The relevant source is:

G. Billing and K. Mahler, *On Exceptional Points on Cubic Curves*, J. London Math. Soc. 15 (1940), especially pp. 42–43. A scan is available at:

<https://carmamaths.org/resources/mahler/docs/067.pdf>

On p. 42, after writing a rational point as `(x/z²,y/z³)`, Billing–Mahler cite Billing 1937, Satz 1. Their statement has two parts:

1. the rank of the curve is at most two;
2. **if ordinary rational points exist**, then there exist integers `x,z` satisfying
   \[
   x-\theta z^2=\eta\alpha^2,
   \]
   where `η` is a positive unit that is not a unit square.

The wording is explicitly existential. The paper says, in part, “if the curve has ordinary rational points ... there must exist rational integers `x,z`”. It does not say that every ordinary point, every nonintegral point, or every point outside Nagell's finite candidate set has the nonsquare unit class.

Billing–Mahler then derive a contradiction from that one selected nonsquare-unit equation. Only **after** concluding on p. 42 that no ordinary rational points exist do they turn, on p. 43, to Nagell's theorem and enumerate the exceptional points.

Thus the logical order in the paper is:

```text
existence of an ordinary point
  → existence of a selected nonsquare Kummer-class point
  → congruence contradiction
  → no ordinary points
  → Nagell finite enumeration of exceptional points.
```

It is not:

```text
arbitrary non-Nagell point
  → that same point has nonsquare Kummer class.
```

The 1940 article does not reproduce the proof of Billing's 1937 Satz 1. Therefore a formalization should not silently strengthen the cited existential theorem into a universal pointwise theorem. The exact 1940 citation supports only the existential selector.

# 7. The missing global selection theorem

To pass from “there exists an ordinary point” to “there exists a point in the nontrivial Kummer class,” one must select an ordinary point that is **not divisible by two**.

That is the missing global ingredient.

## 7.1 Finite-generation route

If one uses Mordell–Weil finite generation, write

\[
E(\mathbf Q)\cong\mathbf Z^r\oplus T.
\]

If an ordinary point exists, then `r>0`, so

\[
E(\mathbf Q)/2E(\mathbf Q)\ne0.
\]

Choose a nonzero coset representative `P`. Then `P∉2E(ℚ)`, so its Kummer class is nontrivial. Since the local descent has already restricted the possible positive unit classes to `{1,[ε]}`, one obtains

\[
\delta(P)=\varepsilon\beta^2.
\]

This proves the existential theorem used by Billing–Mahler, but not the pointwise theorem.

## 7.2 Height/minimality route

Without explicitly invoking a finitely generated group decomposition, choose an ordinary point of minimal positive canonical height, or use an explicit denominator-minimal descent representative. If `P=2Q`, then

\[
\widehat h(P)=4\widehat h(Q),
\]

so `Q` is ordinary and has smaller positive height, a contradiction. Therefore the selected `P` is not a double and has nontrivial Kummer class.

This route requires a genuine global theorem ensuring that a minimal positive-height point exists—typically Northcott finiteness or an explicit denominator descent. It cannot be replaced by prime-ideal parity.

## 7.3 MW-finite-generation-free separatedness route

There is also a clean selection argument using no finite-generation theorem. Assume the global group is 2-adically separated:

\[
\left(\forall n,\;\exists Q_n,\;2^nQ_n=P\right)\Longrightarrow P=O.
\tag{10}
\]

Let `P₀` be ordinary. By (10), some `n` has no `2^n`-preimage of `P₀`. Choose the least such `n`. Then `n≥1`, and minimality gives a point `P` with

\[
2^{n-1}P=P_0.
\]

The point `P` is ordinary. It is not a double, since `P=2R` would imply

\[
2^nR=P_0,
\]

contradicting the definition of `n`. Hence `κ(P)≠1`, and the two-class unit dichotomy forces

\[
\delta(P)=\varepsilon\beta^2.
\]

This is the precise MW-FG-free replacement for Billing's selector. It still requires a genuine separatedness theorem; it is not a finite ideal-factorization calculation.

A Lean-shaped statement is:

```lean
def InfinitelyTwoDivisible (P : E.Point) : Prop :=
  ∀ n : ℕ, ∃ Q : E.Point, (2 ^ n) • Q = P

def Ordinary (P : E.Point) : Prop :=
  ¬ IsOfFinAddOrder P

theorem exists_ordinary_nondouble
    (hsep : ∀ P : E.Point, InfinitelyTwoDivisible P → P = 0)
    (hOrd : ∃ P : E.Point, Ordinary P) :
    ∃ P : E.Point,
      Ordinary P ∧ ¬ ∃ Q : E.Point, 2 • Q = P

theorem exists_nonsquare_unit_witness_of_ordinary
    (hsep : ∀ P : E.Point, InfinitelyTwoDivisible P → P = 0)
    (hOrd : ∃ P : E.Point, Ordinary P) :
    ∃ P : PrimitiveAffinePoint E, ∃ b : OK,
      Ordinary P.toPoint ∧ delta P = epsilon * b ^ 2
```

The second theorem is obtained by composing:

```text
exists_ordinary_nondouble
+ delta_square_iff_two_mul
+ delta_unit_squareclass_dichotomy.
```

That is the faithful formal version of the Billing–Mahler step.

# 8. Recommended replacement interface

Do not expose the overstrong theorem

```lean
theorem nonLutz_implies_delta_nonsquare
    (P : PrimitiveAffinePoint E)
    (hP : ¬ LutzNagellBranch P) :
    ¬ ∃ b : K, delta P = b ^ 2
```

as a descent lemma. It is already a disguised finiteness theorem.

Use the following dependency split instead.

```lean
/-- Local/global ideal arithmetic; valid for every primitive affine point. -/
theorem delta_ideal_square ...

/-- Class number one plus units; valid pointwise, with both branches retained. -/
theorem delta_unit_squareclass_dichotomy ...

/-- Genuine Kummer exactness. -/
theorem delta_square_iff_two_mul ...

/-- Global selector: an ordinary point yields some non-double ordinary point. -/
theorem exists_ordinary_nondouble ...

/-- Billing-style existential nonsquare-unit witness. -/
theorem ordinary_exists_implies_epsilon_witness ...

/-- The explicit congruence calculation excludes that witness. -/
theorem no_epsilon_witness ...

/-- Therefore all rational points are exceptional/torsion. -/
theorem no_ordinary_points ...

/-- Nagell plus finite checking gives the complete rational-point list. -/
theorem rational_points_exhaustive ...
```

This order is noncircular and matches the cited source.

# Final audit conclusion

The current pointwise nonsquare target is overstrong.

- Classical 2-descent gives `delta(P)` square **exactly for doubles**.
- A hypothetical positive-rank point produces infinitely many doubled points with square `delta`; some necessarily lie outside any finite Lutz–Nagell candidate set.
- Therefore “every non-Lutz point has nonsquare `delta`” already proves `E(ℚ)` finite in the irreducible-cubic setting.
- Billing–Mahler invoke an **existential selection theorem**: if ordinary points exist, some selected ordinary point has the nonsquare-unit class.
- The missing theorem is a global nondivisibility selector, proved by finite generation, height minimality, explicit denominator descent, or 2-adic separatedness—not by local ideal-square parity.

The correct formal interface must retain the square branch pointwise and move the nonsquare conclusion into an existential theorem quantified over a specially selected ordinary point.
