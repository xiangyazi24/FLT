# Descent for `w^2 = u^3 + u^2 - 2u`

## Bottom line

Let

```text
E : w^2 = u^3 + u^2 - 2u = u(u+2)(u-1).
```

The affine rational points are exactly

```text
(-2,0), (0,0), (1,0).
```

Together with the point at infinity, this is

```text
E(ℚ) = E(ℚ)[2] ≃ (ℤ/2ℤ)^2.
```

The curve is **not** `14a1`.  In Cremona/LMFDB notation it is the curve with coefficients

```text
[a1,a2,a3,a4,a6] = [0,1,0,-2,0]
```

at conductor `96`, class `A`, number `1`: Cremona `96A1`, LMFDB `96.a1`.  John Cremona's `ecdata` table lists this row as conductor `96`, class `A`, number `1`, rank `0`, torsion size `4`.

The cleanest hand proof is a **2-isogeny descent**, not the full three-coordinate 2-descent.  It proves the same rank-zero conclusion with two quartic Selmer computations of size `8` rather than a full `64`-class full-2-descent enumeration.

---

## 1. The curve and its 2-isogenous curve

Write

```text
E : y^2 = x^3 + x^2 - 2x.
```

This has rational 2-torsion

```text
O,  T0=(0,0),  T1=(1,0),  T_{-2}=(-2,0).
```

Use the 2-isogeny with kernel `⟨T0⟩`.  For a curve

```text
y^2 = x^3 + a x^2 + b x,
```

the 2-isogenous curve is

```text
E' : y^2 = x^3 - 2a x^2 + (a^2 - 4b)x.
```

Here `a=1`, `b=-2`, hence

```text
E' : y^2 = x^3 - 2x^2 + 9x = x(x^2 - 2x + 9).
```

The usual descent maps are:

```text
α : E(ℚ)  → ℚ*/ℚ*²,
α(O)=1,
α((0,0))=b=-2,
α((x,y))=x mod squares       if x≠0;

β : E'(ℚ) → ℚ*/ℚ*²,
β(O)=1,
β((0,0))=b'=9≡1,
β((x,y))=x mod squares       if x≠0.
```

The relevant bad squareclasses are supported only at

```text
S = {∞,2,3},
ℚ(S,2) = {±1, ±2, ±3, ±6}.
```

This is because

```text
b=-2,
a^2-4b=9,
b'=9,
a'^2-4b'=-32.
```

## 2. First isogeny descent on `E`

For a squareclass `d ∈ ℚ(S,2)`, the homogeneous quartic is

```text
C_d : d W^2 = d^2 U^4 + d U^2 V^2 - 2 V^4.
```

Equivalently, if `x=d(U/V)^2`, this is the condition that the right side of

```text
y^2 = x(x^2+x-2)
```

be a square after removing the forced square factor.

### Locally soluble classes

The two soluble classes are:

```text
d = 1      : U=1, V=0, W=±1;
d = -2     : U=0, V=1, W=±1.
```

So

```text
{1,-2} ⊆ Sel^{φ}(E/ℚ).
```

The other six classes are locally insoluble by very small congruence checks.

### Local obstruction table for `C_d`

Use primitive integral representatives `U,V,W` in the quartic equation.

| `d` | obstruction | check |
|---:|---|---|
| `-1` | no `ℚ₂` point | The equation becomes `W² = -U⁴ + U²V² + 2V⁴`. If `V` is even then `U` is odd and `W²≡7 mod 8`; if `V` is odd and `U` is even then `W²≡2 mod 8`; if both are odd then again `W²≡2 mod 8`. |
| `2` | no `ℚ₂` point | Dividing by `2` gives `W² = 2U⁴ + U²V² - V⁴`. If `V` is even then `U` is odd and `W²≡2 mod 8`; if `V` is odd and `U` is even then `W²≡7 mod 8`; if both are odd then `W²≡2 mod 8`. |
| `3` | no `ℚ₃` point | Modulo `3` forces `3∣V`; primitiveness gives `3∤U`. Then the right side has `v₃=2`, while the left side has `v₃=1+2v₃(W)`, impossible. |
| `-3` | no `ℚ₃` point | Same valuation argument as for `d=3`. |
| `6` | no `ℚ₃` point | Same valuation argument: modulo `3` forces `3∣V`, then right side has `v₃=2`, left side has odd `3`-adic valuation. |
| `-6` | no `ℚ₃` point | Same valuation argument. |

Therefore

```text
Sel^{φ}(E/ℚ) = {1, -2},
#Sel^{φ}(E/ℚ) = 2.
```

## 3. Dual isogeny descent on `E'`

For

```text
E' : y^2 = x^3 - 2x^2 + 9x,
```

the dual quartics are

```text
C'_d : d W^2 = d^2 U^4 - 2d U^2 V^2 + 9 V^4,
```

again with `d ∈ {±1,±2,±3,±6}`.

### Locally soluble classes

The soluble classes are:

```text
d = 1      : U=1, V=0, W=±1;
d = 3      : U=1, V=1, W=±2,
             since 3·(±2)^2 = 9 - 6 + 9 = 12.
```

The class `d=3` is represented by the rational point `(3,±6)` on `E'`.

### Local obstruction table for `C'_d`

| `d` | obstruction | check |
|---:|---|---|
| `-1` | no real point | The left side is nonpositive while `d²U⁴ - 2dU²V² + 9V⁴ = U⁴+2U²V²+9V⁴` is positive unless `U=V=0`. |
| `-2` | no real point | Same sign obstruction. |
| `-3` | no real point | Same sign obstruction. |
| `-6` | no real point | Same sign obstruction. |
| `2` | no `ℚ₂` point | Modulo `2` forces `V` even. Then primitiveness gives `U` odd. The right side has `v₂=2`, while the left side has `v₂=1+2v₂(W)`, impossible. |
| `6` | no `ℚ₂` point | Divide by `3`: `2W² = 12U⁴ - 4U²V² + 3V⁴`. Modulo `4` forces `V` even. Then `U` is odd and the right side has `v₂=2`, while the left side has odd `2`-adic valuation. |

Therefore

```text
Sel^{φ̂}(E'/ℚ) = {1, 3},
#Sel^{φ̂}(E'/ℚ) = 2.
```

## 4. Rank consequence

The standard 2-isogeny descent inequality gives

```text
dim_{𝔽₂} E(ℚ)/2E(ℚ)
  ≤ dim Sel^{φ}(E/ℚ) + dim Sel^{φ̂}(E'/ℚ)
  = 1 + 1 = 2.
```

Since `E` has full rational 2-torsion, the full 2-Selmer computation is equivalently saying that the only locally soluble full 2-covering classes are the four classes coming from `E[2]`:

```text
O             ↦ (1,1,1),
(-2,0)        ↦ (6,-2,-3),
(0,0)         ↦ (2,-2,-1),
(1,0)         ↦ (3,1,3),
```

where the full-descent map is

```text
P=(x,y) ↦ (x+2, x, x-1) ∈ ker((ℚ*/ℚ*²)^3 → ℚ*/ℚ*²),
```

with the standard special values at the 2-torsion points.

Thus

```text
#Sel₂(E/ℚ) = 4 = #E[2](ℚ),
```

and the Mordell-Weil rank is `0`.

So yes: showing that the 2-Selmer group has order `4`, equal to the rational 2-torsion, is enough to prove rank zero.  For the final statement “only the three affine 2-torsion points,” also record that there is no additional rational torsion.

## 5. Excluding odd and higher 2-power torsion

The rank-zero descent shows every rational point is torsion, but one still has to rule out torsion beyond `E[2]`.

Use good reduction at `5` and `7`.

### Count modulo `5`

For `E : y^2=x(x+2)(x-1)` over `𝔽₅`, the only affine solutions occur at the three roots

```text
x = -2, 0, 1,
```

so

```text
#E(𝔽₅) = 4.
```

### Count modulo `7`

A direct count gives

```text
#E(𝔽₇) = 12.
```

For example, the number of affine points by `x=0,1,2,3,4,5,6` is

```text
1, 1, 2, 2, 2, 1, 2,
```

and adding the point at infinity gives `12`.

Since both `5` and `7` are primes of good reduction, rational torsion injects prime-to-`p` into the reduction modulo `p`.  Combining `p=5` and `p=7`, every rational torsion order divides

```text
gcd(#E(𝔽₅), #E(𝔽₇)) = gcd(4,12) = 4.
```

The curve already has four rational 2-torsion points, hence

```text
E(ℚ)_tors = E[2](ℚ) = {O, (-2,0), (0,0), (1,0)}.
```

Since the rank is `0`, this is the whole Mordell-Weil group.

## 6. Final rational-point theorem

Therefore the projective rational points are

```text
O, (-2,0), (0,0), (1,0),
```

and the affine rational solutions of

```text
w^2 = u^3 + u^2 - 2u
```

are exactly

```text
(u,w) = (-2,0), (0,0), (1,0).
```

Equivalently, the only rational `u`-coordinates are

```text
u ∈ {-2,0,1},
```

and in all three cases `w=0`.

## 8. Minimal proof script as a formal certificate

For the descent certificate, the actual mathematical payload is the following finite list.

### First isogeny certificate

```text
C_d : dW² = d²U⁴ + dU²V² - 2V⁴.

Soluble:
  d=1   via (U,V,W)=(1,0,1),
  d=-2  via (U,V,W)=(0,1,1).

Insoluble:
  d=-1,2     over ℚ₂, by mod 8;
  d=±3,±6    over ℚ₃, by valuation after mod 3 forces 3∣V.
```

### Dual isogeny certificate

```text
C'_d : dW² = d²U⁴ - 2dU²V² + 9V⁴.

Soluble:
  d=1   via (U,V,W)=(1,0,1),
  d=3   via (U,V,W)=(1,1,2).

Insoluble:
  d<0       over ℝ, by sign;
  d=2       over ℚ₂, because mod 2 forces V even and valuations contradict;
  d=6       over ℚ₂, after dividing by 3, mod 4 forces V even and valuations contradict.
```

This is the compact descent computation I would formalize.
