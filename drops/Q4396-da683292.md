# Recommended architecture: an oriented fractional-ideal class group

## Executive decision

Do **not** prove associativity by expanding Cantor composition and reduction on triples. Also do **not** use the ordinary class group of

\[
A=K[x,y]/(y^2-f(x))
\]

as the semantic target without modification: this affine ring removes **both** points at infinity and therefore forgets the class

\[
\eta_\infty=[\infty_+-\infty_-].
\]

The smallest robust architecture is a third option, combining the best parts of (a) and (b):

1. Use the explicit two-infinity affine coordinate ring `A`, represented as an `AdjoinRoot`, because this is where Mumford ideals and Cantor arithmetic are simplest.
2. Define a custom **oriented fractional-ideal class group**
   \[
   \widetilde{\mathrm{Cl}}_+(A)
   =
   \frac{\operatorname{InvFrac}(A)\times\mathbf Z}
        {\{((\alpha),\operatorname{ord}_{\infty_+}(\alpha)):\alpha\in K(C)^\times\}}.
   \]
   This is canonically `Pic^0(C)` after choosing `∞₋` as base point.
3. Map a balanced Mumford triple `(u,v,nInf)` to
   \[
   \bigl[I(u,v),\,nInf-1\bigr],
   \qquad
   I(u,v)=\langle u(x),y-v(x)\rangle.
   \]
4. Prove that each Cantor composition/reduction step preserves this semantic class by explicit ideal identities and explicit valuations at `∞₊`.
5. Prove that balanced reduced triples map **injectively** into the oriented class group and that every semantic class has a balanced reduced representative.
6. Define the executable addition on triples by `normalize (composeSemi D₁ D₂)`. Associativity is then one line after applying injectivity and using associativity in the quotient group.

This is exactly the architecture used in spirit by Mathlib's elliptic affine-point implementation: it maps explicit coordinates into a class group, proves the map injective, and inherits the group laws rather than proving associativity from the coordinate formulas.

The conclusion is:

> **Use explicit Mumford algorithms for computation, but use an oriented fractional-ideal quotient as the proof semantics.** The hard theorem becomes existence and uniqueness of the balanced normal form, not associativity.

# 1. Why the three candidate architectures differ

## 1.1 Option (a): build divisors and principal divisors directly

This is conceptually perfect:

```text
Div⁰(C) / Prin(C)
```

has its abelian-group structure for free, and Cantor reduction can be proved to compute its canonical representatives.

It is not the smallest Lean route from current Mathlib. A direct implementation needs at least:

- closed points or Galois-stable effective divisors;
- a divisor group;
- degree;
- the divisor of a rational function;
- principal divisors;
- enough valuation theory at every point;
- proofs that the relevant divisor formulas are principal;
- then the quotient.

Mathlib currently has useful function-field, valuation, ideal, and class-group components, but not a ready algebraic-curve `Div`, `Prin`, or `Pic⁰` package. Building this semantically general layer would duplicate a large part of what invertible fractional ideals already provide on the affine open.

**Verdict:** mathematically clean, but larger than necessary for one fixed curve.

## 1.2 Naive option (b): use `ClassGroup A`

This is very close, but it is the wrong group. Put

\[
U=C\setminus\{\infty_+,\infty_-\},
\qquad A=\Gamma(U,\mathcal O_U).
\]

There is an exact sequence

\[
\mathbf Z\infty_+\oplus\mathbf Z\infty_-
\longrightarrow \operatorname{Pic}(C)
\longrightarrow \operatorname{Pic}(U)
\longrightarrow 0.
\]

Since `A` is affine and smooth,

\[
\operatorname{Pic}(U)\simeq \operatorname{Cl}(A).
\]

Choose `∞₋` to split degree:

\[
\operatorname{Pic}(C)\simeq
\operatorname{Pic}^0(C)\oplus\mathbf Z.
\]

Under this splitting,

\[
[\infty_-]\mapsto(0,1),
\qquad
[\infty_+]\mapsto(\eta_\infty,1),
\qquad
\eta_\infty=[\infty_+-\infty_-].
\]

Therefore

\[
\boxed{
\operatorname{Cl}(A)
\simeq
\operatorname{Pic}^0(C)/\langle\eta_\infty\rangle.
}
\]

The ordinary affine class group loses precisely the information carried by `nInf`. For example, the balanced identity `(1,0,1)` and the triple representing `∞₊-∞₋` have the same affine ideal, namely the unit ideal, but are not generally the same class in `Pic⁰`.

**Verdict:** excellent for the affine component, but insufficient without an infinity orientation.

## 1.3 Recommended option (c): oriented ideals

Keep the convenient ring `A`, but add one integer before quotienting by principal ideals. This restores exactly the missing infinity class and no more.

This is smaller than a full divisor theory and fits Mathlib's existing `FractionalIdeal`/`QuotientGroup` APIs.

# 2. The semantic group in exact form

Let

```text
A  := K[x,y]/(y²-f(x)),
F  := Frac(A) = K(C),
IF := (FractionalIdeal A⁰ F)ˣ.
```

Here `IF` is the commutative group of invertible fractional ideals. Define the valuation homomorphism at the chosen infinity:

```lean
ordPlus : Fˣ →* Multiplicative ℤ
```

and the principal oriented homomorphism

```lean
principalOriented : Fˣ →* IF × Multiplicative ℤ
principalOriented α :=
  (toPrincipalIdeal A F α, ordPlus α)
```

Then define

```lean
abbrev OrientedPicMul :=
  (IF × Multiplicative ℤ) ⧸ principalOriented.range

abbrev N18Pic0Ideal := Additive OrientedPicMul
```

The range is normal automatically because the ambient group is commutative. The quotient therefore supplies all group axioms immediately.

A Lean-shaped declaration is:

```lean
abbrev InvFrac (K : Type*) [Field K] :=
  (FractionalIdeal (N18AffineRing K)⁰ (N18FunctionField K))ˣ

abbrev OrientedFrac (K : Type*) [Field K] :=
  InvFrac K × Multiplicative ℤ

noncomputable def principalOriented
    (K : Type*) [Field K] :
    (N18FunctionField K)ˣ →* OrientedFrac K :=
  (toPrincipalIdeal (N18AffineRing K) (N18FunctionField K)).prod
    (ordPlus K)

abbrev N18Pic0Ideal (K : Type*) [Field K] :=
  Additive
    (OrientedFrac K ⧸ (principalOriented K).range)
```

The semantic layer may be noncomputable. The algorithm on Mumford triples remains executable. This separation is desirable: quotient groups and chosen inverses are proof devices, while polynomial gcd, exact division, and normalization remain computable.

## 2.1 Why this quotient is `Pic⁰`

An invertible fractional ideal represents a divisor on the affine open `U`. If `D_U` is that affine divisor and `n : ℤ`, send the pair to

\[
D_U+n\infty_+
-(\deg D_U+n)\infty_-.
\]

This has degree zero. For a rational function `α`, the pair

\[
((\alpha),\operatorname{ord}_{\infty_+}\alpha)
\]

maps to the full principal divisor of `α`, because the coefficient at `∞₋` is forced by the degree-zero identity for principal divisors. Hence quotienting by the image gives `Pic⁰(C)`.

For the Lean development, it is not necessary to formalize this as a general theorem about projective curves before using the group. One can take `N18Pic0Ideal` as the semantic definition and prove directly that balanced Mumford representatives are equivalent to it. That equivalence is the fixed-curve version of the preceding divisor argument.

# 3. Coordinate ring and Mathlib reuse

## 3.1 Explicit affine ring

Use an `AdjoinRoot` presentation, just as the elliptic affine-point file does:

```lean
open Polynomial

-- Outer variable is Y; coefficients lie in K[X].
def curvePoly (K : Type*) [Field K] : K[X][X] :=
  X ^ 2 - C (n18F K)

abbrev N18AffineRing (K : Type*) [Field K] :=
  AdjoinRoot (curvePoly K)

abbrev N18FunctionField (K : Type*) [Field K] :=
  FractionRing (N18AffineRing K)
```

The ring is free of rank two over `K[X]`, with basis `{1,y}`. The needed API already exists around:

```lean
AdjoinRoot.mk
AdjoinRoot.root
AdjoinRoot.powerBasis'
AdjoinRoot.mk_eq_mk
AdjoinRoot.isDomain_of_prime
```

The elliptic implementation proves analogous basis, multiplication, domain, and injectivity results in `WeierstrassCurve.Affine.CoordinateRing`; the genus-two version is the same rank-two algebra with a degree-six `f` instead of a cubic.

## 3.2 Domain proof

For `K=ℚ` and for the explicit cubic field `L`, characteristic is zero and `f` is squarefree. Thus `Y²-f` is irreducible over `K(X)` and the coordinate ring is a domain.

The clean proof pattern is the elliptic one:

1. map coefficients from `K[X]` into `K(X)`;
2. prove the quadratic polynomial over `K(X)` irreducible because `f` is not a square;
3. obtain a domain for the `AdjoinRoot` over `K(X)`;
4. prove the coefficient-extension map from the original coordinate ring is injective;
5. transport `IsDomain` back.

Do this parametrically for characteristic zero if convenient, or prove it once for `ℚ` and once after base change to `L`.

# 4. Mumford ideals and the balanced class map

For a pair `(u,v)`, define

\[
I(u,v)=\langle u(x),y-v(x)\rangle\subset A.
\]

In Lean:

```lean
noncomputable def CClass (u : K[X]) : N18AffineRing K := ...
noncomputable def YSubClass (v : K[X]) : N18AffineRing K := ...

noncomputable def mumfordIdeal (u v : K[X]) : Ideal (N18AffineRing K) :=
  Ideal.span {CClass u, YSubClass v}
```

The semantic map for a balanced triple `D=(u,v,nInf)` is

\[
\boxed{
\operatorname{classOf}(D)=
[I(u,v),\;nInf-1].
}
\]

The shift by `-1` is forced by the balanced divisor convention

\[
D(u,v,n)=D_{\rm aff}(u,v)
+n\infty_+ +(2-r-n)\infty_-
-(\infty_++\infty_-),
\qquad r=\deg u.
\]

Thus the coefficient of `∞₊` is `n-1`.

A Lean-shaped definition is:

```lean
noncomputable def classOf (D : N18Mumford K) : N18Pic0Ideal K :=
  Additive.ofMul <|
    QuotientGroup.mk' _
      (mumfordIdealUnit D,
       Multiplicative.ofAdd ((D.nInf : ℤ) - 1))
```

## 4.1 No global Dedekind instance is required here

Mathlib's `ClassGroup R` is defined for an arbitrary domain as invertible fractional ideals modulo principal ideals. It does **not** require `[IsDedekindDomain R]`.

That is important. Instead of first proving every nonzero ideal of `A` invertible, construct the unit corresponding to each Mumford ideal explicitly. The key identity is

\[
\boxed{
I(u,v)I(u,-v)=(u).
}
\]

The squarefreeness of `f`, together with `u\mid f-v²`, supplies the local coprimality needed for this equality. Therefore an explicit inverse is

\[
I(u,v)^{-1}=u^{-1}I(u,-v).
\]

This directly constructs

```lean
mumfordIdealUnit D : InvFrac K
```

without an `IsDedekindDomain` instance.

# 5. Cantor composition becomes an ideal identity

Let `D₁=(u₁,v₁,n₁)` and `D₂=(u₂,v₂,n₂)`. Let

\[
d=\gcd(u_1,u_2,v_1+v_2),
\qquad \delta=\deg d.
\]

The standard extended-gcd formula constructs a semi-reduced pair `(u₀,v₀)` with

\[
u_0=\frac{u_1u_2}{d^2}.
\]

The semantic theorem to prove is not a statement about associativity. It is the ideal equality

\[
\boxed{
I(u_1,v_1)I(u_2,v_2)=(d)I(u_0,v_0).
}
\tag{COMPOSE}
\]

This is a finite generator calculation in the rank-two coordinate ring. Extended-gcd certificates supply the reverse ideal containment; polynomial exact-division lemmas supply all denominator-free equalities.

Since `d` is monic of degree `δ`,

\[
\operatorname{ord}_{\infty_+}(d(x))=-\delta.
\]

In the oriented quotient, the principal pair `((d),-δ)` vanishes. If `m_i=n_i-1`, equation `(COMPOSE)` gives

\[
[I_1,m_1]+[I_2,m_2]
=[I_0,m_1+m_2+\delta].
\]

Consequently the raw infinity counter must be

\[
\boxed{n_0=n_1+n_2+\delta-1,}
\]

which is exactly the balanced Cantor formula.

The central Lean lemma should be split in two:

```lean
lemma compose_ideal_identity
    (D₁ D₂ : N18Mumford K) :
    mumfordIdealUnit D₁ * mumfordIdealUnit D₂ =
      toPrincipalIdeal _ _ (composeGCDUnit D₁ D₂) *
        mumfordIdealUnit (composeSemi D₁ D₂) := by
  ...

lemma classOf_composeSemi
    (D₁ D₂ : N18Mumford K) :
    classOfSemi (composeSemi D₁ D₂) =
      classOf D₁ + classOf D₂ := by
  -- quotient relation + ordPlus of a monic polynomial
  ...
```

Only the first lemma contains substantial polynomial/ideal arithmetic.

# 6. Reduction becomes multiplication by one principal function

Suppose a semi-reduced pair has `(u,v,n)`. Choose the adjusted polynomial `vTilde` used by the even-degree reduction branch and put

\[
u'=(f-v_{\rm Tilde}^2)/u,
\qquad
v'\equiv-v_{\rm Tilde}\pmod{u'}.
\]

Define

\[
\alpha=\frac{y-v_{\rm Tilde}}{u'}\in K(C)^\times.
\]

The exact ideal identity is

\[
\boxed{
I(u,v)=(\alpha)I(u',v').
}
\tag{REDUCE}
\]

Let `p₊(vTilde)` denote the pole order of `y-vTilde` at `∞₊`. Since `u'` is monic of degree `r'`,

\[
\operatorname{ord}_{\infty_+}(\alpha)
=-p_+(v_{\rm Tilde})+r'.
\]

Therefore the oriented counter changes by

\[
\boxed{
n'=n+p_+(v_{\rm Tilde})-r'.
}
\]

Again, the algorithmic update is not guessed and associativity is irrelevant: it is forced by one principal-pair relation in the quotient.

Lean decomposition:

```lean
lemma reduce_ideal_identity
    (D : N18SemiMumford K) :
    semiIdealUnit D =
      toPrincipalIdeal _ _ (reducePrincipal D) *
        semiIdealUnit (reduceStep D) := by
  ...

lemma ordPlus_reducePrincipal (D : N18SemiMumford K) :
    ordPlus (reducePrincipal D) =
      Multiplicative.ofAdd
        (-(polePlus D.vTilde) + (D.uPrime.natDegree : ℤ)) := by
  ...

lemma classOf_reduceStep (D : N18SemiMumford K) :
    classOfSemi (reduceStep D) = classOfSemi D := by
  ...
```

This architecture isolates the two difficult components cleanly:

- ring/ideal equality;
- infinity valuation.

# 7. Balancing at infinity is also principal ideal arithmetic

For this fixed curve put

\[
A_\infty(x)=x^3+2x^2+3x-1.
\]

The crucial identity is

\[
\boxed{f(x)-A_\infty(x)^2=8x.}
\]

Thus

\[
(y-A_\infty)(y+A_\infty)=8x.
\]

With the chosen labels,

\[
\operatorname{div}(y-A_\infty)
=(0,-1)+2\infty_+-3\infty_-,
\]

\[
\operatorname{div}(y+A_\infty)
=(0,1)+2\infty_--3\infty_+.
\]

In oriented-ideal notation these say that the following semi-representatives are zero:

```text
Zminus = (X, -1,  3)
Zplus  = (X,  1, -2)
```

Indeed:

- `I(X,-1)` together with orientation `3-1=2` is the principal pair of `y-A∞`;
- `I(X,1)` together with orientation `-2-1=-3` is the principal pair of `y+A∞`.

These are exactly the certificates used to move an out-of-range infinity counter back into the balanced interval. Their correctness proofs are short quotient calculations after two ideal identities and two `ordPlus` computations.

# 8. Hyperelliptic negation is immediate in this model

For the present equation `y²=f(x)`, the involution sends `(x,y)` to `(x,-y)`. On balanced triples:

\[
\boxed{
(u,v,n)
\longmapsto
(u,-v\bmod u,\;2-\deg u-n).
}
\]

The affine ideals satisfy

\[
I(u,v)I(u,-v)=(u),
\]

and the two orientation integers add to

\[
(n-1)+(2-r-n-1)=-r
=\operatorname{ord}_{\infty_+}(u(x)).
\]

Hence their product is the principal oriented pair of `u`, and therefore

```lean
lemma classOf_hyperelliptic (D : N18Mumford K) :
    classOf (hyperelliptic D) = -classOf D := by
  ...
```

This is preferable to running Cantor composition on `D` and its inverse and normalizing every branch.

# 9. The true crux: existence and uniqueness of balanced representatives

Once the semantic quotient is in place, the hard theorem is no longer associativity. It is the canonical-representative theorem:

```lean
theorem every_class_has_balanced_rep
    (c : N18Pic0Ideal K) :
    ∃ D : N18Mumford K, classOf D = c

 theorem classOf_injective :
    Function.Injective (classOf : N18Mumford K → N18Pic0Ideal K)
```

Equivalently, package them as:

```lean
noncomputable def mumfordEquivPic0 :
    N18Mumford K ≃ N18Pic0Ideal K
```

## 9.1 Existence

A practical fixed-curve proof can be phrased entirely in ideal language:

1. clear denominators of an oriented fractional ideal;
2. use the free rank-two `K[X]` basis `{1,y}` to put the resulting lattice into a two-generator normal form;
3. extract a monic `u` and a reduced `v` with ideal `⟨u,y-v⟩`;
4. apply complement reduction until `deg u≤2`;
5. use the two principal balancing elements `y±A∞` to put the orientation counter in
   \[
   0\le nInf\le2-\deg u.
   \]

Because genus is fixed at two, all degree branches are bounded and explicit. A general Riemann–Roch theorem is unnecessary.

## 9.2 Uniqueness

Suppose two balanced triples have equal semantic class. Then there is `α∈K(C)ˣ` such that

```text
I(D₁) = (α) I(D₂)
```

and their orientation difference equals `ordPlus α`.

Write `α` in the quadratic function field as

\[
\alpha=(p(x)+q(x)y)/r(x).
\]

The ideal inclusions bound the finite zeros and poles, while the orientation equality bounds the pole at `∞₊`; total degree bounds the other infinity. Since both reduced affine degrees are at most two, explicit degree estimates force either:

- `α` is constant, giving identical ideals and identical counters; or
- one of the forbidden conjugate-pair/nonreduced branches occurs.

The most stable implementation uses the rank-two algebra norm

\[
N(p+qy)=p^2-q^2f
\]

plus the `∞₊`-adapted decomposition

\[
p+qy=(p+qA_\infty)+q(y-A_\infty).
\]

This handles the only leading-term cancellation that ordinary polynomial degree misses. It is the genus-two analogue of Mathlib's elliptic proof using degree of the coordinate-ring norm, but with the infinity orientation retaining the extra bit.

This injectivity theorem is likely the single longest conceptual proof in the module. It is still much smaller and more maintainable than a branchwise associativity proof.

# 10. Associativity after injectivity

Define the executable operation:

```lean
def add (D₁ D₂ : N18Mumford K) : N18Mumford K :=
  normalize (composeSemi D₁ D₂)
```

Prove only its semantic correctness:

```lean
lemma classOf_add (D₁ D₂ : N18Mumford K) :
    classOf (add D₁ D₂) = classOf D₁ + classOf D₂ := by
  rw [add, normalize_sound, classOf_composeSemi]
```

Then associativity is inherited:

```lean
lemma add_assoc (D₁ D₂ D₃ : N18Mumford K) :
    add (add D₁ D₂) D₃ = add D₁ (add D₂ D₃) := by
  apply classOf_injective
  simp only [classOf_add, add_assoc]
```

Commutativity and inverse laws are identical:

```lean
lemma add_comm (D₁ D₂ : N18Mumford K) :
    add D₁ D₂ = add D₂ D₁ := by
  apply classOf_injective
  simp [classOf_add, add_comm]

lemma neg_add_cancel (D : N18Mumford K) :
    add (neg D) D = zero := by
  apply classOf_injective
  simp [classOf_add, classOf_neg, classOf_zero]
```

Thus the `AddCommGroup` instance is routine once the class map is injective.

A Gröbner or `ring` certificate is appropriate for the local ideal-generator identities. It is **not** an appropriate proof of associativity, because associativity crosses gcd choices, exact divisions, normalization recursion, and exceptional infinity branches.

# 11. Is the affine coordinate ring Dedekind?

## 11.1 Mathematical answer

Yes. If `char K≠2` and `f` is squarefree, then

\[
A=K[x,y]/(y^2-f(x))
\]

is the coordinate ring of a smooth affine curve. The Jacobian criterion says a singular point would satisfy

```text
y = 0,
f(x) = 0,
f'(x) = 0,
```

contradicting squarefreeness. A smooth affine curve over a field has a regular one-dimensional noetherian coordinate ring, hence a Dedekind domain.

## 11.2 Lean answer

Proving this exact `IsDedekindDomain A` instance is optional and is not currently a one-line consequence of a ready smooth-curve API for this `AdjoinRoot` presentation.

Mathlib does provide:

```lean
IsIntegralClosure.isDedekindDomain
integralClosure.isDedekindDomain
```

in `Mathlib/RingTheory/DedekindDomain/IntegralClosure.lean`. Therefore one can define the maximal order as the integral closure of `K[X]` in `K(C)` and obtain the Dedekind instance from finite separability.

But identifying the explicit ring `K[x,y]/(y²-f)` with that integral closure is itself a maximal-order/integral-closedness proof. For squarefree `f` it is true, but formalizing it is not free.

The recommended route avoids making this a prerequisite:

- `ClassGroup` in pinned Mathlib only assumes `[IsDomain R]`;
- its objects are **invertible** fractional ideals;
- construct every Mumford ideal as an invertible unit explicitly using its conjugate ideal.

A Dedekind instance may later be useful for convenience—especially `FractionalIdeal.mk0`, arbitrary ideal inverses, and surjectivity statements—but it should not block the group-law construction.

# 12. The one-point affine-ring alternative

There is a mathematically elegant alternative that fixes the infinity issue at the ring level.

Let

\[
B=\Gamma(C\setminus\{\infty_-\},\mathcal O_C).
\]

Then

\[
\boxed{\operatorname{Cl}(B)\simeq\operatorname{Pic}^0(C)}
\]

because quotienting `Pic(C)` by the single rational point `∞₋` kills only the degree summand.

For this curve, put

\[
A_\infty(x)=x^3+2x^2+3x-1,
\qquad
t=y-A_\infty(x).
\]

The divisor formula

\[
\operatorname{div}(t)=(0,-1)+2\infty_+-3\infty_-
\]

shows that `t` has its only pole at `∞₋`, of order three. Consequently `B` is the integral closure of `K[t]` in `K(C)`. Since `K[t]` is a PID/Dedekind domain and `K(C)/K(t)` is finite separable of degree three, Mathlib's integral-closure theorem supplies a Dedekind domain.

This looks ideal abstractly, but it is not the smallest route for the **balanced Mumford algorithm**:

- `x` and `y` are not both regular at `∞₊`, which now lies inside the affine open;
- the simple ideals `⟨u(x),y-v(x)⟩` no longer live in an immediately explicit two-generator coordinate ring without clearing poles;
- one needs an explicit `K[t]`-basis or a presentation using functions of pole orders `3,4,5`, for example `t`, `xt`, and `x²t`;
- all Cantor formulas then have to be translated into that presentation;
- exceptional fibers at `∞₊` become part of every ideal formula rather than one orientation integer.

Thus the one-point integral-closure ring is attractive if the entire algorithm is redesigned as one-point ideal reduction. It is not shorter if the desired executable representation remains the balanced `(u,v,nInf)` model.

**Recommendation:** use the one-point ring only as an optional semantic cross-check, not as the primary implementation.

With disciplined reuse of the elliptic coordinate-ring/class-group patterns, the likely target is approximately **5,000–7,000 lines**, not 9,000+.

The N18-specific two pushforwards, pullbacks, and trace identities remain a separate approximately **1,500–3,000-line** layer, depending on how much resultant/interpolation infrastructure already exists.

Alternative costs:

- full divisor/principal-divisor theory from scratch: roughly `8,000–14,000` lines before push-pull;
- one-point integral-closure class group plus an explicit basis and translation from balanced triples: roughly `5,500–9,000` lines;
- brute-force group laws on triples with direct associativity: not recommended, difficult to estimate, and likely less maintainable than either route.

# Final recommendation

Build the module around the following theorem chain:

```lean
-- Semantic class in an already associative quotient group.
classOf : N18Mumford K → N18Pic0Ideal K

-- Local algorithm certificates.
classOf_composeSemi
classOf_reduceStep
normalize_sound

-- Canonical normal form.
classOf_injective
every_class_has_balanced_rep

-- Executable law.
classOf_add

-- Group axioms inherited from the target.
instance : AddCommGroup (N18Mumford K)
```

The dominant proof obligation is:

```lean
theorem balanced_representative_unique
```

or equivalently `classOf_injective`, together with the existence theorem. It is **not** `add_assoc`.

The ordinary affine class group is a crucial tool but not the final target. The exact repair is the one-integer orientation at `∞₊`, quotienting principal pairs by their `∞₊` valuation. That correction makes the balanced counter mathematically transparent, turns every Cantor counter update into a principal-ideal valuation identity, and lets Mathlib's quotient-group machinery carry all associativity and commutativity obligations.
