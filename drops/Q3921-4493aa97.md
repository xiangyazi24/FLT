# Q3921 — why the `F9` + `T2` system has no rational solution with `b ≠ 0`

The right way to do this is not a raw split into “`b` odd” and “`2 ∣ b`”.  The case `2 ∣ b` is exactly where the affine model is reducing to a cusp/singular point, so the naive mod-2 calculation loses the information needed to rule it out.  The robust proof is:

1. parameterize the genus-zero curve `F9 = 0`;
2. substitute that parameterization into `T2`;
3. identify the resulting curve as a plane model of `X_1(18)`;
4. determine its rational points; they are all cusps, hence all have `b = 0` in the affine Tate-normal-form chart.

This gives a direct mathematical proof of the polynomial statement, and it is also exactly the modular-curve proof of the nonexistence of rational cyclic order `18`.

## 1. Parameterize `F9 = 0`

Let

```text
d = b - c.
```

Then

```text
F9 = d^3 + c^3(d - c^2).
```

If `c = 0`, then `F9 = b^3`, so `b = 0`, which is excluded.  If `d = 0`, then `F9 = -c^5`, hence again `c = b = 0`.  Thus for a nonzero solution we may assume `c ≠ 0` and `d ≠ 0`.

Set

```text
t = c^2 / (b - c) = c^2 / d.
```

Then `d = c^2/t`, and `F9 = 0` becomes

```text
(c^2/t)^3 + c^3(c^2/t - c^2) = 0.
```

After dividing by `c^5`, this is

```text
c/t^3 + 1/t - 1 = 0,
```

so

```text
c = t^3 - t^2 = t^2(t - 1).
```

Then

```text
b - c = d = c^2/t = t^3(t - 1)^2,
```

and hence

```text
b = c + d
  = t^2(t - 1) + t^3(t - 1)^2
  = t^2(t - 1)(t^2 - t + 1).
```

Conversely, the substitution

```text
c = t^2(t - 1),
b = t^2(t - 1)(t^2 - t + 1)
```

satisfies `F9 = 0` identically.  Since `t^2 - t + 1` has discriminant `-3`, the condition `b ≠ 0` over `ℚ` is simply

```text
t ≠ 0, 1.
```

So every rational solution with `b ≠ 0` comes from some `t ∈ ℚ \ {0,1}`.

## 2. Substitute into `T2`

Put

```text
b(t) = t^2(t - 1)(t^2 - t + 1),
c(t) = t^2(t - 1).
```

Then the remaining equation is the affine plane curve

```text
G(t,X) = 0,
```

where

```text
G(t,X)
  = 4X^3
    + (t^6 - 6t^5 + 9t^4 - 10t^3 + 6t^2 + 1) X^2
    + 2 t^2(t - 1)(t^2 - t + 1)(t^3 - t^2 - 1) X
    + t^4(t - 1)^2(t^2 - t + 1)^2.
```

This is just `T2(b(t), c(t), X)` expanded.

Thus the original problem is equivalent to proving:

```text
There is no rational point (t,X) on G(t,X)=0 with t ≠ 0,1.
```

At `t = 0` and `t = 1` we have `b = c = 0`; these are cuspidal/degenerate points and are excluded by `b ≠ 0`.

## 3. Modular meaning

The Tate normal form with parameters `(b,c)` is

```text
E(b,c) : y^2 + (1-c)xy - by = x^3 - bx^2.
```

The equation `F9(b,c)=0` is the order-`9` condition for the marked point `(0,0)`.  The cubic `T2(b,c,X)` is the corresponding `2`-division polynomial in the `X`-coordinate.  Therefore a noncuspidal rational solution of

```text
F9(b,c)=0,
T2(b,c,X)=0,
b≠0
```

is exactly an elliptic curve over `ℚ` with a rational point of order `9` and a rational point of order `2`.  Since `gcd(2,9)=1`, this is equivalent to a rational cyclic subgroup/point of order `18`.

So the curve `G(t,X)=0` is an affine plane model of the open modular curve `Y_1(18)`, and its smooth projective model is `X_1(18)`, a genus-`2` curve.

## 4. The rational-point computation

The smooth projective model `C` of `G(t,X)=0` has genus `2`.  A standard computation proceeds as follows.

```magma
Q := Rationals();
A2<t,X> := AffineSpace(Q, 2);

b := t^2*(t - 1)*(t^2 - t + 1);
c := t^2*(t - 1);

G := 4*X^3
    + ((1 - c)^2 - 4*b)*X^2
    + 2*b*(c - 1)*X
    + b^2;

Caff := Curve(A2, G);
C := NonsingularModel(ProjectiveClosure(Caff));

Genus(C);                 // 2
J := Jacobian(C);
RankBounds(J);            // [0, 0] in the standard model
```

Then one embeds `C` into its Jacobian using a rational cusp as base point and enumerates the finite group `J(ℚ)`.  Equivalently, one uses rank-`0` Chabauty/Mordell--Weil sieve.  The output is:

```text
C(ℚ) = cusps only.
```

On the affine `(t,X)` chart, the finite cuspidal fibers are

```text
t = 0:   G(0,X) = X^2(4X+1),
t = 1:   G(1,X) = X^2(4X+1).
```

Thus the affine rational points above these cusps have

```text
X = 0  or  X = -1/4,
```

but in either case

```text
b(t) = t^2(t-1)(t^2-t+1) = 0.
```

The remaining rational points of the smooth projective model are points at infinity/cusps.  None gives an affine solution with `b ≠ 0`.

Therefore no rational triple `(b,c,X)` with `b ≠ 0` satisfies both equations.

## 5. What goes wrong with the naive mod-2 split

Your mod-2 observation is correct in the unit case:

```text
F9(1,0) ≡ 1 mod 2,
F9(1,1) ≡ 1 mod 2.
```

So there is no solution in a residue class where `b` is a `2`-adic unit.

But if `2 | b`, the point is reducing toward the cuspidal/singular part of the affine model.  The special fiber of the naive `(b,c,X)` model is not a good integral model of `X_1(18)`.  One must blow up/normalize at the cusp.  After doing that, the remaining question is not a simple check of `F9` modulo `2`; it is the rational-point problem on the proper genus-`2` curve above.

A more informative elementary congruence appears after the `F9` parameterization.  For finite `t` modulo `5`, one finds:

```text
t = 2:  G(2,X) ≡ 4X^3 + X^2 + 2X + 4       mod 5,
t = 3:  G(3,X) ≡ 4X^3 + 4X + 1             mod 5,
t = 4:  G(4,X) ≡ 4X^3 + 3X^2 + X + 1       mod 5.
```

None of these has a root in `𝔽_5`.  The only finite residue classes left are `t = 0,1`, which are exactly the cusps.  Again, the hard part is not the ordinary noncuspidal residue classes; it is proving that no rational point hides in the cusp residue disks.  That is exactly what the genus-`2` Jacobian/Chabauty computation proves.

## 6. Resultant/descent summary

If you want a purely algebraic elimination workflow, use this order:

1. **Do not eliminate `b` first.**  First replace `F9=0` by the rational parameter `t` above.  This avoids extraneous components and makes the moduli interpretation visible.
2. Work with the single plane curve `G(t,X)=0`.
3. Compute the smooth projective normalization `C`.
4. Compute `genus(C)=2`.
5. Compute `rank Jac(C)(ℚ)=0` by a `2`-descent or Stoll-style descent.
6. Enumerate `C(ℚ)` using the finite Mordell--Weil group and a Mordell--Weil sieve/Chabauty.
7. Check that all rational points are cusps, i.e. they have `t=0`, `t=1`, or lie above `t=∞`; hence all affine points have `b=0`.

This is the standard noncircular proof of the order-`18` exclusion.  If one is allowed to cite Mazur's torsion theorem directly, the proof is of course much shorter: a solution would give an elliptic curve over `ℚ` with a point of order `18`, and Mazur's list does not contain `ℤ/18ℤ`.  But for a proof inside Mazur's theorem, the genus-`2` computation of `X_1(18)(ℚ)` is the appropriate replacement.
