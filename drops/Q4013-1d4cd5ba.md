# Q4013: the eta covering error

The error is that the coefficient condition

```text
delta*w^2 = X - beta
```

was treated as the whole covering.  It is not.  For the model coming from 11a3 there is also a scalar/norm condition, because the cubic is not literally `Y^2 = f(X)` after the substitution `X = 2*x`.

## 1. The normalization issue

For

```text
E : y^2 + y = x^3 - x^2,
z = 2*y + 1,
X = 2*x,
f(X) = X^3 - 2*X^2 + 2,
```

we have

```text
z^2 = 4*x^3 - 4*x^2 + 1
    = (X^3 - 2*X^2 + 2)/2
    = f(X)/2.
```

So the actual affine equation is

```text
f(X) = 2*z^2,
```

not

```text
f(X) = z^2.
```

Since

```text
Norm_K/Q(X - beta) = f(X),
```

a descent representative satisfying

```text
delta*w^2 = X - beta
```

must satisfy the additional norm-squareclass condition

```text
Norm(delta) * Norm(w)^2 = 2*z^2.
```

Equivalently,

```text
Norm(delta) is 2 in Q*/Q*^2.
```

This is the missing condition.

Thus the old `square rational norm` target was the wrong target.  For this normalization, the target norm class is `2`, not `1`.

## 2. Sign correction for eta

There is also a small sign issue:

```text
eta = 1 - beta
```

has

```text
Norm(eta) = Norm(1 - beta) = f(1) = 1.
```

By contrast,

```text
Norm(beta - 1) = -f(1) = -1.
```

So the statement `eta = 1-beta, Norm(eta) = -1` has the sign reversed.

## 3. Re-deriving the eta coefficient equations

Write

```text
w = a + b*beta + c*beta^2,
w^2 = s0 + s1*beta + s2*beta^2,
```

with

```text
s0 = a^2 - 4*b*c - 4*c^2,
s1 = 2*a*b - 2*c^2,
s2 = b^2 + 2*a*c + 4*b*c + 4*c^2.
```

For

```text
eta = 1 - beta,
```

multiplication gives

```text
eta*w^2
  = (s0 + 2*s2)
    + (s1 - s0)*beta
    + (-s1 - s2)*beta^2.
```

To have

```text
eta*w^2 = X - beta,
```

the coefficient equations are

```text
-s1 - s2 = 0,
s1 - s0 = -1,
X = s0 + 2*s2.
```

Equivalently,

```text
s1 + s2 = 0,
s1 - s0 = -1.
```

Expanding:

```text
b^2 + 2*a*b + 2*a*c + 4*b*c + 2*c^2 = 0,
-a^2 + 2*a*b + 4*b*c + 2*c^2 = -1.
```

Subtracting the second equation from the first gives

```text
a^2 + 2*a*c + b^2 = 1.
```

But this last equation is only a consequence of the two coefficient equations.  It is not equivalent to them.

That said, the trivial solution

```text
a = 1,
b = 0,
c = 0
```

actually satisfies the full two coefficient equations, because then

```text
w = 1,
eta*w^2 = 1 - beta = X - beta
```

with

```text
X = 1.
```

So the coefficient part alone really is soluble.

## 4. Where eta fails

It fails at the missing norm/scalar condition.

For `a=1,b=0,c=0`, the coefficient equation gives

```text
X = 1,
X - beta = 1 - beta.
```

Taking norms gives

```text
Norm(1 - beta) = f(1) = 1.
```

But a point on the actual curve must satisfy

```text
f(X) = 2*z^2.
```

At `X = 1`, this demands

```text
1 = 2*z^2.
```

This has no solution over `Q_2`, because the 2-adic valuation of the right side is odd, while a square has even valuation.  It also has no solution over `Q_11`, because `2` is not a square modulo `11`:

```text
{nonzero squares mod 11} = {1,3,4,5,9},
2 notin {1,3,4,5,9}.
```

So if you keep `eta = 1-beta` as a candidate despite its wrong norm class, its local failure is already visible in the norm condition:

```text
Norm(eta) = 1 is not 2 in Q_2*/Q_2*2.
```

Equivalently, the full eta covering includes an extra scalar equation

```text
Norm(eta) * Norm(w)^2 = 2*z^2.
```

Since `Norm(eta)=1`, this says

```text
Norm(w)^2 = 2*z^2,
```

which is impossible over `Q_2` for nonzero `w,z` by valuation parity.

## 5. Correct candidate coset

Because the correct norm target is `2`, the candidates are not

```text
{1, eta, pi, eta*pi}.
```

Those are the norm-`1` classes.  The correct norm-`2` coset is obtained by multiplying by any class of norm `2`.  Since

```text
Norm(beta) = -2,
Norm(-1) = -1,
Norm(-beta) = 2,
```

one convenient representative is `-beta`.  Thus the corrected candidate coset is

```text
{-beta,
 -beta*eta,
 -beta*pi,
 -beta*eta*pi}
```

where

```text
eta = 1 - beta,
pi  = beta^2 + beta + 3.
```

Equivalently, the old norm-one kernel still matters, but it acts by multiplication on the norm-two coset.

## 6. What to formalize in Lean

Do not formalize the eta obstruction as a failure of the coefficient equations.  That is false: `w=1, X=1` solves them.

Formalize the full covering as something like:

```lean
structure CoverPoint (delta : K) where
  a b c X z : Q
  coeff_beta2 : coeff2 (delta * sq a b c) = 0
  coeff_beta1 : coeff1 (delta * sq a b c) = -1
  coeff_beta0 : coeff0 (delta * sq a b c) = X
  norm_eq : norm delta * normSq a b c = 2 * z^2
```

or, equivalently, replace `norm_eq` by the curve equation

```text
f(X) = 2*z^2.
```

Then the eta fake solution is killed immediately:

```text
X = 1,
f(1) = 1,
1 = 2*z^2 impossible over Q_2.
```

For a kernel-checkable local obstruction at `Q_2`, the finite statement is simply valuation parity, or modulo powers of 2:

```text
no z in Q_2 satisfies 1 = 2*z^2.
```

For a residue-only certificate after clearing denominators, this can be reduced to the elementary fact that `v_2(2*z^2)` is odd while `v_2(1)` is zero.

## Bottom line

The eta coefficient equation was not the correct full covering.  The missing condition is the norm/scalar condition coming from

```text
f(X) = 2*z^2,
```

not `f(X)=z^2`.  Under the coefficient equation alone, `eta=1-beta` has the genuine trivial solution `w=1, X=1`.  It fails only after imposing the required norm condition, and it fails locally at `Q_2` by valuation parity.  More structurally, `eta` is in the norm-one kernel, while the actual 11a3 descent for this normalization needs the norm-two coset

```text
-beta * {1, eta, pi, eta*pi}.
```
