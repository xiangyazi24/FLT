# Route-selection memo for closing `ThetaCandidateAdditive`

## Verdict

The right bridge is **not** “`AddCircle` is discrete” and not merely “locally constant on a dense open set”.  The right bridge is:

```text
finite bad set + local constancy on the punctured complement
+ continuity/removable limits at the bad points
⇒ locally constant on all of `Set.Ioi e`.
```

Then your existing S9 theorem applies:

```text
IsLocallyConstantOn F (Set.Ioi e)
+ Tendsto F atTop (𝓝 0)
⇒ F ≡ 0 on Set.Ioi e.
```

The cleanest final decomposition is:

1. prove the fixed-`Q` theorem for the **upper branch** `U x = (x, +sqrt(f x))`, `x>e`;
2. deduce the lower branch from the upper branch by negation, using the already checked `theta(-P)=-theta(P)`;
3. get the root point `(e,0)` by taking `x → e+` in the upper-branch theorem;
4. handle `O` directly;
5. use branch reduction for arbitrary `P` in the identity component.

This avoids duplicating the entire S8→S9 glue for both input signs.  S8 already has all four input/output sign local lemmas, but the global glue only needs to be written once for upper input if lower input is obtained by negation and the fixed point is allowed to be arbitrary `Q`.

## (a) S8→S9 bridge

### Recommended lemma shape

For fixed affine `Q=(a,b)` and upper input branch, define

```text
F_Q(x) = theta(U(x)+Q) - theta(U(x)) - theta(Q),   x ∈ Set.Ioi e.
```

For `Q=O`, skip everything and prove directly.  For affine `Q`, use a finite bad set

```text
Bad_Q = {a if a>e}
      ∪ {x0 if U(x0) = root - Q and e < x0}.
```

The point `a` covers both the tangent point `U(a)=Q` when `Q` is upper and the vertical point `U(a)=-Q` when `Q` is lower.  The second point is the unique preimage of the output root.  Duplicates are harmless; in the case `2Q=root`, the tangent point and the output-root point coincide.

For `Q=root=(e,0)`, `a=e` is not in `Set.Ioi e`, and `root-Q=O`, so there is no interior bad point on the upper branch.

The bridge should be packaged as a topological lemma over `ℝ`, not as elliptic-curve algebra:

Mathematically, the local bad-point argument is:

```text
Let r ∈ Bad_Q ∩ (e,∞).
Choose ε>0 with (r-ε,r+ε) containing no other bad point.
S8 gives F=c_left  on (r-ε,r), if this interval is nonempty.
S8 gives F=c_right on (r,r+ε).
Continuity of F at r gives
  c_left = F(r) = c_right
by uniqueness of one-sided limits in the Hausdorff space AddCircle(2T).
Therefore F is locally constant at r.
```

So the theorem you need is local, not a global sorted-partition theorem.  A finite set is used only to isolate bad points and to choose clean punctured neighborhoods.

### Important correction to the proposed “continuity by rational extension” claim

The statement “`chordX` and `chordY` are rational functions, so they extend continuously past the bad points” is only partly true.

* At a **regular output-root point**, yes: if `x0≠a`, the rational chord formulas are continuous and the output tends to `(e,0)`.  The branch sign may flip, but `theta` is continuous there because `sigma(x)→T` as `x→e+` and `-T=T` in `AddCircle(2*T)`.
* At a **tangent point**, the secant slope has a removable singularity.  You need the derivative of the branch `sqrt(f x)` to identify the limiting tangent slope.  The raw expression `(sqrt(f x)-b)/(x-a)` does not extend by `ring_nf`; it extends by the checked derivative of the branch.
* At a **vertical point** `U(a)=-Q`, the affine output does not extend to a finite affine point.  In fact `chordX→∞`.  What extends continuously is `theta(U(x)+Q)`, because `U(x)+Q→O` in the elliptic-curve topology and `theta→0` along both branches at infinity.

Thus the safe Lean target is not “`chordX/chordY` are globally continuous”.  It is:

```text
ContinuousAt F_Q r
```

for each bad coordinate `r`, proved by the appropriate removable-limit lemma.

### Dense-open warning

Continuity plus local constancy on a dense open subset is not, by itself, a robust principle.  It becomes valid here because the complement is **finite**.  If the bad set were Cantor-like, a continuous function could be locally constant on the dense open complement and still not be constant globally.  For Lean, use the finite-isolated-points argument above.

## Clean-point local constancy obligations

On a clean interval `I ⊆ Set.Ioi e \ Bad_Q`, S8 applies after proving:

```text
x-a ≠ 0,
U(x)+Q is not O,
U(x)+Q is not root,
U(x)+Q lies in the identity component,
therefore its affine x-coordinate satisfies x3>e,
and its output branch sign is constant on I.
```

The output sign constancy is a small but essential real-topology lemma.  Use:

```text
x ↦ chordY A x (sqrt(f x)) a b
```

is continuous on `I`.  If it changed sign, IVT would give a zero.  An identity-component affine point with `y=0` is the root, which is excluded by `Bad_Q`.  Therefore the sign is constant.

This is where the component-closure fact is needed: `U(x)+Q` must remain in the identity component, otherwise `y=0` could be another real two-torsion point on another component.

## (b) AtTop asymptotics for `Q=(a,b)`

Assume first that `Q` is non-root affine in the identity component, so

```text
a>e,
b ≠ 0,
b^2 = f(a),
f(x)=x^3 + A*x^2 + B*x.
```

Use the S7 convention

```text
m      = chordM x y a b = (y-b)/(x-a),
x3     = chordX A x y a b = m^2 - A - x - a,
y3     = chordY A x y a b = -(y + m*(x3-x)).
```

For either branch `y=±sqrt(f(x))`, as `x→∞`,

```text
y/(x-a)^2 → 0,
y/(x-a)^3 → 0,
f(x)/(x-a)^3 → 1,
m/(x-a) → 0,
m^2/(x-a) → 1.
```

The following exact identities are the ones to add as algebra lemmas.  They are designed for `field_simp` followed by `ring_nf` using

```text
hy : y^2 = shortCubic A B x
hQ : b^2 = shortCubic A B a
hD : x-a ≠ 0.
```

```lean
import FLT.Assumptions.MazurProof.RealTopologyS7

namespace FLT.Assumptions.MazurProof

/-!
Algebra lemmas to prove in Lean; statements are schematic because namespaces and
existing theorem names may differ.

1. Tail x-coordinate identity:

  chordX A x y a b - a
    = shortCubicDeriv A B a / (x-a)
      - 2*b * chordM x y a b / (x-a)

Equivalent denominator-cleared form:

  (chordX A x y a b - a) * (x-a)^2
    = shortCubicDeriv A B a * (x-a) - 2*b*(y-b)

Expanded version:

  (chordX A x y a b - a) * (x-a)^2
    = (B + 2*A*a + 3*a^2)*x + (B*a - a^3) - 2*b*y

2. Tail y-coordinate identity:

  chordY A x y a b - b
    = 2*b*((chordM x y a b)^2/(x-a) - 1)
      - shortCubicDeriv A B a * chordM x y a b/(x-a)

3. Slope-square identity:

  (chordM x y a b)^2/(x-a)
    = (shortCubic A B x + shortCubic A B a - 2*b*y)/(x-a)^3

4. Trivial slope-over-denominator identity:

  chordM x y a b/(x-a) = (y-b)/(x-a)^2
-/

end FLT.Assumptions.MazurProof
```

Consequences:

```text
chordX A x y a b → a,
chordY A x y a b → b.
```

Since `b≠0`, eventually `chordY` has the sign of `b`.  Hence the output branch is eventually the branch of `Q`, and

```text
theta(U(x)+Q) → theta(Q).
```

Together with `theta(U(x))→0`, this gives

```text
F_Q(x) → theta(Q)-0-theta(Q)=0.
```

For the lower branch the same asymptotics hold, with `y=-sqrt(f(x))`; `chordY→b` is still true.  If you use negation to deduce the lower branch, you do not need to formalize the lower AtTop argument separately.

### Root fixed point `Q=(e,0)`

For `Q=root`, use special identities instead of the generic `a>e`, `b≠0` asymptotics.  Let

```text
C = shortCubicDeriv A B e = f'(e) > 0,
d = x-e,
y^2=f(x),
f(e)=0.
```

Then for `d≠0`,

```text
chordX A x y e 0 - e = C/(x-e),
chordY A x y e 0     = - y*C/(x-e)^2.
```

Thus for upper input `y>0` and `x>e`,

```text
chordX → e from the right,
chordY < 0 eventually, in fact for all x>e,
theta(U(x)+root) → theta(root)=T.
```

Since `theta(U(x))→0`, the defect again tends to zero:

```text
F_root(x) → theta(root)-0-theta(root)=0.
```

These two root formulas should also be proved with `field_simp`/`ring_nf`, using `shortCubic A B e = 0` and `hy : y^2 = shortCubic A B x`.

## (c) Degenerate `Q`: uniform or case-by-case?

Use a **small top-level case split** and keep the rest uniform.

### `Q=O`

Direct:

```text
theta(P+O)=theta(P),
theta(O)=0.
```

No S8/S9, no chord calculus.

### `Q=root=(e,0)`

Separate this from non-root affine `Q`, because `a=e` and `b=0`, so the generic atTop argument through `sigma(a)` is not available.  The root formulas above give the entire upper-branch S9 proof, and `root+root=O` follows from

```text
T+T = 0 in AddCircle(2*T).
```

### Non-root affine `Q`

Do **not** split further for `2Q=root`, tangent-to-root, or vertical points.  These are exactly collisions inside `Bad_Q`.

* If `Q` is upper, `x=a` is the tangent point `U(a)=Q`.
* If `Q` is lower, `x=a` is the vertical point `U(a)=-Q`.
* If `2Q=root`, then the tangent point is also the output-root bad point.

All are handled by the same finite-bad-set bridge.  Duplicates in `Finset` are harmless.  This is less work than a large degeneracy tree.

One caveat: in the identity component, a non-root affine point has `b≠0`; hence `2Q=O` cannot occur for non-root `Q`.  If your point type still sees other real two-torsion points, exclude them by the component-kernel hypothesis and the branch-reduction theorem.

## (d) Minimal-work decomposition to close `ThetaCandidateAdditive`

### Step 1: Upper-branch fixed-`Q` theorem

Target:

```text
∀ Q in component kernel,
∀ x>e,
theta(U(x)+Q) = theta(U(x)) + theta(Q).
```

Proof:

* `Q=O`: direct.
* `Q=root`: root chord identities, S8 clean local constancy on all `Set.Ioi e`, S9 atTop limit zero.
* `Q` non-root affine: finite bad set, S8 on clean punctured neighborhoods, continuity/removable limits at bad points, S9 atTop limit zero.

This theorem should be stated as the fixed-`Q` defect vanishing:

```text
F_Q(x)=0
```

because S8/S9 already work with the defect.

### Step 2: Lower branch from negation

Let `L(x)=-U(x)`.  Apply the upper-branch theorem to the fixed point `-Q`:

```text
theta(U(x)+(-Q)) = theta(U(x)) + theta(-Q).
```

Negate both sides and use `theta(-R)=-theta(R)`:

```text
theta(-(U(x)+(-Q))) = -theta(U(x)) - theta(-Q).
```

Since the group is abelian,

```text
-(U(x)+(-Q)) = -U(x)+Q = L(x)+Q,
-theta(U(x)) = theta(L(x)),
-theta(-Q) = theta(Q).
```

So

```text
theta(L(x)+Q)=theta(L(x))+theta(Q).
```

This is usually less Lean work than duplicating the bad-set bridge for lower input.

### Step 3: Root input by `x→e+`

Take the upper-branch theorem

```text
theta(U(x)+Q)=theta(U(x))+theta(Q)
```

and pass to the limit as `x→e+`:

```text
U(x) → root,
theta(U(x)) → theta(root),
theta(U(x)+Q) → theta(root+Q).
```

The root-limit facts in S4/S6 should supply the theta limits.  This proves

```text
theta(root+Q)=theta(root)+theta(Q).
```

This avoids a direct case split on `root+Q`.

### Step 4: Infinity input

Direct:

```text
theta(O+Q)=theta(Q)=0+theta(Q).
```

### Step 5: General `P`

Use branch reduction for the identity component:

```text
P=O
or P=root
or P=U(x), x>e
or P=L(x), x>e.
```

Apply Steps 1--4.

## Concrete dependency DAG

### A. Algebra and asymptotic lemmas

**A1. Generic tail algebra for non-root affine `Q`.**

Proof idea: unfold `chordM`, `chordX`, `chordY`, `shortCubic`, `shortCubicDeriv`; use `field_simp [hD]`; replace `y^2` by `shortCubic A B x` and `b^2` by `shortCubic A B a`; finish with `ring_nf`.

Outputs:

```text
chordX - a = f'(a)/(x-a) - 2*b*m/(x-a),
chordY - b = 2*b*(m^2/(x-a)-1) - f'(a)*m/(x-a).
```

**A2. Polynomial/sqrt growth at infinity.**

Needed limits:

```text
f(x)/(x-a)^3 → 1,
sqrt(f(x))/(x-a)^2 → 0,
sqrt(f(x))/(x-a)^3 → 0.
```

Then derive

```text
m/(x-a) → 0,
m^2/(x-a) → 1,
chordX → a,
chordY → b.
```

**A3. Root fixed-point algebra.**

```text
chordX A x y e 0 - e = f'(e)/(x-e),
chordY A x y e 0 = -y*f'(e)/(x-e)^2.
```

**A4. AtTop defect limit.**

For non-root `Q`, use A1/A2 and continuity of `sigma` at `a>e`.

For root `Q`, use A3 and `sigma(x)→T` as `x→e+`.

Conclusion:

```text
Tendsto F_Q atTop (𝓝 0).
```

### B. Bad-set and clean-interval lemmas

**B1. Bad set finite.**

Use group cancellation, not polynomial solving:

```text
U(x)+Q=O    ↔ U(x)=-Q,
U(x)+Q=root ↔ U(x)=root-Q.
```

For upper input, each right-branch affine point has unique `x`, so there is at most one point of each type.

**B2. Clean output branch.**

On a connected clean interval, output is neither `O` nor root.  Since it is in the identity component, branch reduction gives either upper output or lower output with `x3>e`.

**B3. Output sign constancy.**

The output `y3(x)` is continuous on a clean interval.  If signs changed, IVT gives `y3=0`, hence output root in the identity component, contradicting cleanness.

**B4. S8 local constancy on clean neighborhoods.**

Apply the appropriate one of the two upper-input S8 lemmas depending on the constant output sign.

### C. Bad-point continuity/removable limits

**C1. Regular output-root point.**

If `U(x0)+Q=root` and `x0≠a`, rational chord continuity gives output tending to root; S4/S6 root theta limits give `ContinuousAt F_Q x0`.

**C2. Tangent point.**

If `U(a)=Q`, use the checked branch derivative to show the secant slope tends to the tangent slope `f'(a)/(2*b)`, hence the chord output tends to the tangent sum `2Q`.  Then theta continuity at `2Q` gives `ContinuousAt F_Q a`.  If `2Q=root`, this uses the root theta limit.

**C3. Vertical point.**

If `U(a)=-Q`, then `m→∞`, `chordX→∞`, and theta of the output tends to `0` independent of output sign.  Therefore `F_Q(x)→theta(O)-theta(-Q)-theta(Q)=0`, using negation compatibility.

**C4. Bad-point local constancy.**

At each isolated bad point, combine punctured one-sided S8 constants with C1/C2/C3 and `tendsto_nhds_unique` in `AddCircle(2*T)`.

### D. Global branch and final theorem

**D1. Upper branch is locally constant on all `Set.Ioi e`.**

From B4 and C4.

**D2. Upper branch defect vanishes.**

Apply S9 with D1 and A4.

**D3. Lower branch.**

Deduce by negation from D2 applied to `-Q`.

**D4. Root and `O` inputs.**

Root from `x→e+`; `O` direct.

**D5. Global `ThetaCandidateAdditive`.**

Branch-reduce `P` and apply D2--D4.

## Adversarial checklist

1. **Do not use discreteness.**  `AddCircle(2*T)` is not discrete.  S9 needs connectedness plus local constancy plus a limit, not discreteness.

2. **Do not rely on dense-open local constancy without finiteness.**  The finite bad set is what lets continuity force adjacent constants to agree.

3. **Vertical points are not ordinary rational continuations.**  `chordX→∞`, not a finite value.  The continuation is only after applying `theta`.

4. **Tangent points require derivative input.**  The removable slope limit is exactly where the checked branch derivative should be used.

5. **`chordX→a` is insufficient at infinity.**  You also need `chordY→b` or an equivalent eventual-output-branch lemma.  Otherwise the output could limit to `Q` or `-Q` at the same `x`-coordinate.

6. **Root continuity depends on `sigma→T` at `e+`.**  You list this as checked in S4; it is essential for both output-root bad points and root input.

7. **Component closure under addition is load-bearing.**  It excludes other real two-torsion roots when `y3=0` and justifies `x3>e` after branch reduction.

8. **Treat `2Q=root` as a collision, not a new case.**  It is the tangent bad point coinciding with the output-root bad point.

9. **Use upper-branch theorem plus negation for lower branch.**  This is the shortest final route, provided the upper theorem is stated for arbitrary fixed `Q` and the component is closed under negation.
