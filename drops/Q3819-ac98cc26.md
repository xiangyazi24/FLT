# Q3819: route review for `ThetaCandidateAdditive`

## Executive verdict

I mostly agree with the advisor's six-layer plan, but with three important corrections:

1. The atTop formula in Layer 2 is correct only for the convention
   `f(x)=x^3 + A*x + B` and `chordX = λ^2 - x - a`.  Your Lean development uses
   `shortCubic A B x = x^3 + A*x^2 + B*x` and
   `chordX = λ^2 - A - x - a`, so the displayed numerator changes.
2. The tangent case is not something S7 local chord calculus needs to “cover” for S8; S8 deliberately excludes `x=a`.  Tangency is a **seam-limit** obligation, proved with the derivative/slope-quotient theorem.
3. “Continuous + locally constant on dense open” is not a safe black-box route.  It is viable only with the finite-bad-set hypothesis.  Without finiteness it is false in this generality, as the Cantor-function pattern shows: continuous, locally constant on a dense open complement, but not globally constant.

The minimal final route is still:

```text
upper input branch for arbitrary fixed Q
→ lower input branch by negation
→ root input by the fixed-root theorem plus commutativity, or by x→e+
→ O input directly
→ branch reduction for arbitrary P.
```

## Review of the advisor's layers

### Layer 0: prerequisites

**Agree, with clarification.**

Component closure under addition is load-bearing.  It is what lets you say that if the output affine `y3` vanishes, then the output is the identity-component root `(e,0)`, not some other real two-torsion point on another component.  It also justifies output branch reduction and `x3>e` for non-root affine outputs.

I would phrase the tangent prerequisite differently.  You do not need S7's derivative-zero chord calculus to include the tangent point, because the local constancy lemmas are correctly stated away from `x=a`.  What you need is a separate tangent seam lemma:

```text
x → a, P(x) → Q on the same branch
⇒ P(x)+Q → Q+Q.
```

That seam uses the derivative of the branch, not the S8 local derivative-zero theorem.

### Layer 1: bridge lemma

**Agree.**

The correct bridge is:

```text
F : ℝ → X, X Hausdorff,
F locally constant on clean punctured neighborhoods away from a finite set S,
and F has matching one-sided/removable limits at each s ∈ S,
⇒ F is locally constant on all of Set.Ioi e.
```

For Lean, I would avoid a fully general sorted-finset interval decomposition unless you already have one.  At each `s ∈ S`, choose a small interval avoiding the rest of `S`; S8 gives constants on the punctured left and right pieces; continuity or explicit `Tendsto` at `s` identifies both constants with `F s`.

### Layer 2: atTop anchor

**Mostly agree, but fix the convention and finish the y-coordinate.**

For the short model in the new subquestion,

```text
f(x)=x^3 + A*x + B,
λ=(sqrt(f(x))-b)/(x-a),
chordX=λ^2-x-a,
```

the advisor's numerator is correct:

```text
(chordX - a) * (x-a)^2
  = (3*a^2 + A)*x - 2*b*sqrt(f(x)) + (2*B + A*a - a^3).
```

This gives `chordX → a`.  But `chordX → a` is not enough; you also need the output point tends to `Q`, not `-Q`.  The useful second asymptotic is

```text
λ * (chordX - a) → -2*b,
```

because the chord formula gives the exact identity

```text
y3 = -(sqrt(f(x)) + λ*(chordX-x))
   = -b - λ*(chordX-a),
```

hence

```text
y3 → b.
```

So the atTop anchor is genuinely:

```text
P(x)+Q → Q,
theta(P(x)) → 0,
theta(P(x)+Q) → theta(Q),
therefore defect → 0.
```

For your Lean convention

```text
shortCubic A B x = x^3 + A*x^2 + B*x,
chordX A x y a b = λ^2 - A - x - a,
```

the numerator is instead

```text
(chordX A x y a b - a) * (x-a)^2
  = (3*a^2 + 2*A*a + B)*x + (B*a - a^3) - 2*b*y.
```

Equivalently,

```text
(chordX A x y a b - a) * (x-a)^2
  = shortCubicDeriv A B a * (x-a) - 2*b*(y-b).
```

This is usually the most Lean-friendly statement.

### Layer 3: group-theoretic bad set

**Agree.**

For the upper input branch `U(x)`, define the bad coordinates group-theoretically:

```text
Bad_Q = {x | U(x)=Q}
      ∪ {x | U(x)=-Q}
      ∪ {x | U(x)+Q=root}.
```

Each set is subsingleton because the upper branch parameterization is injective.  This avoids polynomial root counting and avoids square-root squaring artifacts.

For affine non-root `Q=(a,b)`, exactly one of `U(a)=Q` or `U(a)=-Q` occurs.  If `Q` is the root `(e,0)`, then `a=e` is not in `Set.Ioi e`, and `root-Q=O`, so the root case has no interior bad point for the upper branch.

### Layer 4: seam-limit lemmas

**Agree.**

The three seam lemmas are exactly the right finite list:

```text
vertical:      U(a)=-Q,  U(x)+Q → O;
doubling:      U(a)= Q,  U(x)+Q → Q+Q;
output-root:   U(x0)+Q=root, U(x)+Q → root.
```

The `2Q=root` subcase should be treated as a collision of the doubling seam with the output-root seam, not as a new global case.  The tangent seam then lands at the root, and theta-continuity at the root uses `sigma(x) → T` as `x → e+` and `-T=T` in `AddCircle (2*T)`.

### Layer 5: affine Q assembly

**Agree, with the root separated.**

For non-root affine `Q`, use the finite-bad-set bridge and the atTop anchor.  For `Q=root`, use the root-specific chord identities and no bad set.  For `Q=O`, do not invoke chord calculus.

### Layer 6: algebra lift

**Partly agree.**

The lower-input case can be obtained cleanly by negation from the upper-input theorem, provided the upper theorem is proved for arbitrary fixed `Q`.

If `L(x)=-U(x)`, apply the upper theorem to fixed `-Q`:

```text
theta(U(x)+(-Q)) = theta(U(x)) + theta(-Q).
```

Negating and using commutativity gives

```text
theta(L(x)+Q)=theta(L(x))+theta(Q).
```

So I disagree with any claim that the lower branch needs its own global atTop anchor.  S8 still needs the upper-input/output-sign alternatives, but not a second global lower-input glue proof.

For the root input, commutativity is enough if you already proved the fixed-root theorem for branch inputs:

```text
theta(Q+root)=theta(Q)+theta(root)
⇒ theta(root+Q)=theta(root)+theta(Q).
```

Alternatively, take the limit of the upper-input theorem as `x→e+`.  Both routes require the checked root limit `sigma→T` somewhere.

## What they missed

1. **Convention mismatch.**  Your checked Lean files use `x^3 + A*x^2 + B*x`, not `x^3 + A*x + B`; all tail identities and tangent slopes must match this.
2. **`chordX→a` is insufficient.**  You must also prove `chordY→b`, or equivalently `λ*(chordX-a)→-2b`, to identify the output as tending to `Q` rather than `-Q`.
3. **Global continuity is not free.**  At vertical seams, `chordX→∞`; there is no finite rational extension of the affine coordinates.  Only `theta(P(x)+Q)` has a removable limit.
4. **Tangent seams need slope-quotient formalization.**  The raw quotient `(u(x)-u(a))/(x-a)` is `0/0`; use `HasDerivAt` to get its punctured-neighborhood limit.
5. **Output sign constancy is a separate lemma.**  On a clean interval, prove `y3` cannot change sign by IVT; otherwise `y3=0`, and component closure forces the output root, contradicting cleanness.
6. **`AddCircle` is not discrete.**  The bridge uses Hausdorff uniqueness of limits, not discreteness.
7. **The root fixed point has a special atTop anchor.**  Since `b=0` and `a=e`, the generic `sigma(chordX)→sigma(a)` argument does not apply.  Use
   `chordX-e=f'(e)/(x-e)` and `chordY=-y*f'(e)/(x-e)^2`.

## (a) Correct atTop asymptotic for `chordX`

For the subquestion's convention,

```text
f(x)=x^3 + A*x + B,
b^2=f(a),
y=sqrt(f(x)),
λ=(y-b)/(x-a),
chordX=λ^2-x-a.
```

Then

```text
chordX - a
  = ((y-b)^2)/(x-a)^2 - x - 2*a
  = (y^2 - 2*b*y + b^2 - (x+2*a)*(x-a)^2)/(x-a)^2.
```

Since

```text
(x+2*a)*(x-a)^2 = x^3 - 3*a^2*x + 2*a^3,
y^2=x^3+A*x+B,
b^2=a^3+A*a+B,
```

we get the exact identity

```text
(chordX - a) * (x-a)^2
  = (3*a^2 + A)*x - 2*b*y + (2*B + A*a - a^3).
```

Because `y=sqrt(f(x)) ~ x^(3/2)`,

```text
chordX - a
  = -2*b / sqrt(x) + (3*a^2 + A)/x + o(1/x),
```

so

```text
chordX → a.
```

The naive computation missed the second term in

```text
f(x)/(x-a)^2 = x + 2*a + O(1/x),
```

not merely `x+o(1)`.  Thus

```text
λ^2 = x + 2*a - 2*b/sqrt(x) + O(1/x),
chordX = λ^2 - x - a = a - 2*b/sqrt(x) + O(1/x).
```

For the actual Lean convention,

```text
f(x)=x^3 + A*x^2 + B*x,
chordX=λ^2-A-x-a,
```

the corresponding exact identity is

```text
(chordX - a) * (x-a)^2
  = (3*a^2 + 2*A*a + B)*x + (B*a - a^3) - 2*b*y.
```

So again `chordX→a`.

To identify the y-coordinate, use the exact identity

```text
y3 = -b - λ*(chordX-a),
```

and prove

```text
λ*(chordX-a) → -2*b.
```

Then `y3→b`.

## (b) Is the global-continuity approach viable?

Yes as an **organization**, no as a shortcut.

It is viable to prove:

```text
ContinuousOn F_Q (Set.Ioi e)
```

for the actual defect function

```text
F_Q(x)=theta(U(x)+Q)-theta(U(x))-theta(Q),
```

and then combine it with S8 local constancy on the finite clean complement.  The output branch sign flip at `x3=e` is not a genuine discontinuity in `AddCircle`, because

```text
sigma(x3) → T,
mk(-T) = mk(T) in AddCircle (2*T).
```

But proving this continuity contains exactly the seam work:

```text
regular output-root seam: rational chord continuity + sigma→T;
tangent seam: slope quotient tends to tangent slope;
vertical seam: chordX→∞ and theta output →0.
```

So the global-continuity theorem is a good wrapper if it lets S9 consume a cleaner hypothesis, but it does not remove the hard parts.

Also, avoid stating the bridge as merely:

```text
continuous + locally constant on a dense open set ⇒ constant.
```

That is false without stronger hypotheses.  The correct theorem for this situation is:

```text
I is an interval / preconnected,
S is finite,
F is continuous on I,
F is locally constant on I \ S,
⇒ F is locally constant on I.
```

or the more local version:

```text
finite isolated bad points + matching removable limits ⇒ local constancy everywhere.
```

This finite-complement version is the one worth proving in Lean.

Now prove by continuity of algebraic operations:


as `t→a` within the punctured neighborhood.  Separately connect `(x2,y2)` to the actual group-theoretic doubling point `Q+Q`, either by an existing affine doubling formula theorem or by a local lemma that the tangent formula is the curve addition formula at `Q`.
