# Minimal axiom-free rank-zero architecture for the order-3 curve

## Executive verdict

The shortest correct route is the one proposed in the question, with one important correction:

1. prove the two explicit descent-image statements;
2. deduce the weak decomposition
   \[
   P=T_i+3Q,
   \qquad T_i\in\{O,T,-T\};

3. combine it with fixed-curve \(3\)-adic formal-kernel separatedness;
4. conclude \(3P=O\) for every rational point;
5. enumerate rational \(3\)-torsion by the factored \(3\)-division polynomial.

No finite-generation theorem, Mordell--Weil rank API, canonical height, or BSD input is needed.

# 3. The exact Eisenstein-integer implementation

## 3.1 Do not use `Zsqrtd (-3)` as the coefficient ring

The ring needed is the maximal order

\[
\mathcal O=\mathbf Z[\rho],
\qquad \rho=\frac{1+q}{2},
\qquad \rho^2=\rho-1.
\]

The subring \(\mathbf Z[q]\) has index \(2\) and is not the full ring of integers.  Using `Zsqrtd (-3)` and silently assuming it is a UFD would be an error.

The smallest local implementation is a pair type.

```lean
@[ext]
structure Eis where
  re : ℤ
  im : ℤ
```

Interpret `⟨a,b⟩` as \(a+b\rho\).  Define

```lean
(a,b) + (c,d) = (a+c, b+d)
(a,b) * (c,d) = (a*c - b*d, a*d + b*c + b*d)
conj (a,b) = (a+b, -b)
rho = (0,1)
sqrtNegThree = 2*rho - 1 = (-1,2)
norm (a,b) = a^2 + a*b + b^2
```

The basic certificates are all `ext <;> ring`:

```lean
lemma rho_sq : rho^2 = rho - 1
lemma rho_cube : rho^3 = -1
lemma sqrtNegThree_sq : sqrtNegThree^2 = -3
lemma mul_conj (z : Eis) : z * conj z = (norm z : Eis)
lemma norm_mul (x y : Eis) : norm (x*y) = norm x * norm y
```

## 3.2 Euclidean-domain instance

Use `norm` as the Euclidean function.  For \(a/b\), multiply by \(\bar b/N(b)\), round the two coefficients in the basis \(1,\rho\) to nearest integers, and call the rounded element \(q\).  If the two coefficient errors are \(u,v\in[-1/2,1/2]\), then

\[
u^2+uv+v^2\le \frac34<1.
\]

Consequently

\[
N(a-bq)<N(b).
\]

This is enough to install

```lean
EuclideanDomain Eis
PrincipalIdealDomain Eis
UniqueFactorizationMonoid Eis
```

The inequality proof is a fixed quadratic calculation.  There is no need for algebraic-number-field or ideal-class infrastructure.

## 3.3 Units modulo cubes

An element is a unit exactly when its norm is \(1\).  Solving

\[
a^2+ab+b^2=1
\]

gives

\[
\mathcal O^\times=\{\pm1,\pm\rho,\pm\rho^2\}.
\]

Since \(\rho^3=-1\), the quotient of the unit group by cubes has three elements:

\[
\boxed{1,\rho,\rho^2}.
\]

The Lean output should be the following, not merely a cardinality statement.

```lean
lemma unit_mod_cube (u : Eisˣ) :
    (∃ v : Eisˣ, u = v^3) ∨
    (∃ v : Eisˣ, u = rhoUnit * v^3) ∨
    (∃ v : Eisˣ, u = rhoUnit^2 * v^3)
```

A convenient proof first shows the six-coordinate classification by `norm_num`, `omega`, and `nlinarith`, and then checks the six cases.

# 4. The reusable UFD cube-extraction lemma

This is the compact general lemma that isolates all factorization bookkeeping.

```lean
/-- If `A * conj A` is a cube and no non-self-conjugate
irreducible occurs in both `A` and `conj A`, then `A` is a unit
multiplied by a cube. -/
theorem unit_mul_cube_of_mul_conj_cube
    {R : Type*}
    [CommRing R] [IsDomain R] [UniqueFactorizationMonoid R]
    (conj : R ≃+* R)
    (conj_involutive : Function.Involutive conj)
    {A M : R}
    (hA : A ≠ 0)
    (hcube : A * conj A = M^3)
    (hsep : ∀ pi : R,
      Irreducible pi →
      ¬ Associated pi (conj pi) →
      ¬ (pi ∣ A ∧ conj pi ∣ A)) :
    ∃ eps : Rˣ, ∃ B : R,
      A = (eps : R) * B^3
```

### Proof by factorization exponents

Fix an irreducible \(\pi\) occurring in \(A\), and let \(e_\pi\) denote its exponent.

- If \(\pi\sim\bar\pi\), its exponent in \(A\bar A\) is \(2e_\pi\).  Since \(A\bar A\) is a cube, \(3\mid2e_\pi\), hence \(3\mid e_\pi\).
- If \(\pi\not\sim\bar\pi\), `hsep` says \(\bar\pi\nmid A\).  Thus its exponent in \(A\bar A\) is exactly \(e_\pi\), so again \(3\mid e_\pi\).

Every nonunit factor exponent in \(A\) is divisible by \(3\).  Extract the cube from `Associates.factorization`; the remaining associate is a unit.

For Lean, it is cleaner to split this into two declarations:

```lean
lemma factorization_mod_three_eq_zero ... :
    (Associates.factorization (Associates.mk A) (Associates.mk pi)) % 3 = 0

lemma exists_unit_mul_cube_of_factorization_mod_three ... :
    ∃ eps : Rˣ, ∃ B : R, A = eps * B^3
```

The first declaration is the only place where conjugate factors are compared.

# 5. Clearing denominators on `ED`

For an affine rational point \((s,t)\), first prove the standard denominator-shape lemma.

```lean
lemma ED_clear_denominators
    (s t : ℚ)
    (h : t^2 = s^3 - 3*(12*s + 1500)^2) :
    ∃ (m n : ℤ) (d : ℕ),
      0 < d ∧
      Int.gcd m (d : ℤ) = 1 ∧
      s = m / (d : ℚ)^2 ∧
      t = n / (d : ℚ)^3 ∧
      n^2 = m^3 - 3*(d : ℤ)^2 *
        (12*m + 1500*(d : ℤ)^2)^2
```

The proof is short and elementary.  Write \(s=m/b\) in lowest terms.  Then

\[
t^2=
\frac{m^3-3b(12m+1500b)^2}{b^3}.
\]

The numerator is coprime to \(b\), because modulo every prime dividing \(b\) it is congruent to \(m^3\).  Hence the reduced denominator of the square \(t^2\) is \(b^3\).  It must be a square, so \(b=d^2\); then the denominator of \(t\) is \(d^3\).

Define

\[
C=d(12m+1500d^2),
\qquad
A=n-Cq\in\mathcal O.
\]

In pair coordinates,

```lean
def edA (m n d : ℤ) : Eis :=
  (n : Eis) - sqrtNegThree * (d * (12*m + 1500*d^2) : ℤ)
```

The curve equation gives

\[
A\bar A=n^2+3C^2=m^3.
\]

```lean
lemma edA_mul_conj
    (hcurve : n^2 = m^3 - 3*d^2*(12*m+1500*d^2)^2) :
    edA m n d * conj (edA m n d) = (m : Eis)^3 := by
  ext <;> simp [edA, Eis.norm]
  ring_nf at hcurve ⊢
  nlinarith
```

# 6. The specialized no-common-split-factor lemma

This is the only curve-specific UFD support argument needed for `ED`.

```lean
lemma edA_no_common_nonsymmetric_factor
    (m n d : ℤ)
    (hd : 0 < d)
    (hmd : Int.gcd m d = 1)
    (hcurve : n^2 = m^3 - 3*d^2*(12*m+1500*d^2)^2)
    {pi : Eis}
    (hpi : Irreducible pi)
    (hnself : ¬ Associated pi (conj pi)) :
    ¬ (pi ∣ edA m n d ∧ conj pi ∣ edA m n d)
```

### Exact proof

Assume both divisibilities.  Conjugating the second one shows that \(\pi\mid\bar A\).  Hence

\[
\pi\mid A+\bar A=2n,
\qquad
\pi\mid A-\bar A=-2Cq.
\]

The elements \(2\), \(q\), and \(5\) are irreducible and associated to their own conjugates:

- \(N(q)=3\), so \(q\) is irreducible;
- \(N(2)=4\), and a nontrivial factorization would require an element of norm \(2\);
- \(N(5)=25\), and a nontrivial factorization would require an element of norm \(5\);
- but \(a^2+ab+b^2\pmod 3\) is only \(0\) or \(1\), so norms \(2\) and \(5\) are impossible.

Thus `hnself` implies \(\pi\nmid2\) and \(\pi\nmid q\).  Since irreducibles are prime in the UFD,

\[
\pi\mid n,\qquad \pi\mid C.
\]

Also \(\pi\mid A\bar A=m^3\), hence \(\pi\mid m\).  If \(\pi\mid d\), the Bézout identity coming from `Int.gcd m d = 1` would give \(\pi\mid1\); therefore \(\pi\nmid d\).  From

\[
C=d(12m+1500d^2)
\]

one obtains

\[
\pi\mid12m+1500d^2,
\]

and since \(\pi\mid m\) and \(\pi\nmid d\),

\[
\pi\mid1500=2^2\cdot3\cdot5^3.
\]

Hence \(\pi\) is associated to \(2\), \(q\), or \(5\), contradicting `hnself`.

This proof avoids a general theorem classifying split rational primes.  It is substantially shorter in Lean than ideal factorization or quadratic reciprocity.

Combining Sections 4--6 gives

```lean
lemma edA_unit_mul_cube ... :
    ∃ eps : Eisˣ, ∃ B : Eis,
      edA m n d = (eps : Eis) * B^3
```

and the unit classification gives the exact output needed by the descent:

```lean
lemma edA_three_cubeclasses ... :
    (∃ B : Eis, edA m n d = B^3) ∨
    (∃ B : Eis, edA m n d = rho * B^3) ∨
    (∃ B : Eis, edA m n d = rho^2 * B^3)
```

Since the denominator \(d^3\) is itself a cube, these are exactly the three possible classes of `alphaED`.

# 7. The two correct mod-27 covering cubics

For a curve

\[
y^2=x^3+D(ax+b)^2
\]

and a parameter \(v=v_1+v_2\sqrt D\), with

\[
N(v)=v_1^2-Dv_2^2,
\]

the fixed homogeneous cubic used here is

\[
\begin{aligned}
0={}&2v_2X^3+2Dv_1Y^3+rac{2b}{N(v)}Z^3
 +6v_1X^2Y+6Dv_2XY^2\\
&+2aX^2Z-2aD Y^2Z.
\end{aligned}
\tag{*}

For `ED`, \(D=-3,a=12,b=1500\).

- With \(v=\rho=(1+q)/2\), equation `(*)` is `Gρ`.
- With \(v=\rho^2=(-1+q)/2\), equation `(*)` is `Gρ²`.

The only direction required in Lean is

```lean

      Int.gcd (Int.gcd X Y) Z = 1 ∧

lemma alphaED_rho_sq_gives_cubic
    (Q : EDPoint)

      G_rho_sq X Y Z = 0
```

Write the cube root in the basis \(1,q\), use `field_simp`, and prove `(*)` by `ring`.  Clear a common rational denominator and divide the integer triple by its gcd; homogeneity preserves the equation.

## 7.1 Shortest finite certificate

Define reduction from `ZMod 27` to `ZMod 3`.

```lean
abbrev Z3 := ZMod 3
abbrev Z27 := ZMod 27

def divBy3_27 (x : Z27) : Prop :=
  ZMod.castHom (by norm_num : 3 ∣ 27) Z3 x = 0
```

Then use exactly two finite checks.

```lean
lemma G_rho_mod27 :
    ∀ X Y Z : Z27,
      G_rho X Y Z = 0 →
      divBy3_27 X ∧ divBy3_27 Y ∧ divBy3_27 Z := by
  native_decide

lemma G_rho_sq_mod27 :
    ∀ X Y Z : Z27,
      G_rho_sq X Y Z = 0 →
      divBy3_27 X ∧ divBy3_27 Y ∧ divBy3_27 Z := by
  native_decide
```

There are only \(27^3=19683\) triples in each check.  This is smaller and more robust than managing substitutions in the final proof.

If a transparent arithmetic proof is preferred, both checks have the same three steps:

1. modulo \(3\), \(3\mid X\);
2. after \(X=3U\), division by \(3\) gives
   \[
   Y\equiv Z\pmod3
   \quad\text{for }G_\rho,
   \qquad
   Y\equiv-Z\pmod3
   \quad\text{for }G_{\rho^2};
   \]
3. substitute \(Y=Z+3V\) or \(Y=-Z+3V\), divide by \(9\), and reduce modulo \(3\).  In both cases the surviving term is
   \[
   341Z^3\equiv2Z^3\pmod3,
   \]
   so \(3\mid Z\), and hence \(3\mid Y\).

Thus every integral solution is divisible by \(3\) in all coordinates, contradicting primitivity.

The conclusion is


with no Selmer-group or rank object ever defined.

# 10. The two elementary lift lemmas

## 10.1 Lift from trivial `alphaES`

The formula supplied in the question is sufficient.

If

\[
r^3=y-(4x+28),
\]

put

\[
s=\frac{3000r}{3x-3r^2-8r},
\qquad
 t=9sr+12s+4500.
\]

Then prove by `field_simp` and `ring` that `(s,t)` lies on `ED` and

\[
\psi(s,t)=(x,y).
\]

The denominator proof is short and should be retained explicitly.  Put \(u=x/r\).  If \(r\ne0\) and

\[
3x-3r^2-8r=0,
\]

then \(u-r=8/3\).  From

\[
(y-(4x+28))(y+(4x+28))=x^3
\]

one obtains

\[
u^3-r^3=8ru+56.
\]

Dividing by \(u-r=8/3\) gives

\[
u^2+ur+r^2=3ur+21,
\]

hence

\[
(u-r)^2=21,
\]

contradicting \((u-r)^2=64/9\).  If \(r=0\), the point is \(T\), whose special descent class is \(49\), not \(1\).  Thus the denominator is nonzero in the only branch where the formula is used.

## 10.2 Lift from trivial `alphaED`

Do not build a general cohomological kernel theorem.  Prove only

```lean
theorem alphaED_trivial_lift (Q : EDPoint)
    (h : CubeEqK (alphaED Q) 1) :
    ∃ P : ESPoint, phi P = Q
```

as a fixed algebraic reconstruction.

The cubeclass-\(1\) principal homogeneous cubic is obtained from `(*)` with \(v=1\):

\[
\boxed{
C_1(X,Y,Z)=X^2Y-Y^3+4X^2Z+12Y^2Z+500Z^3=0.
}
\]

A cube root of `alphaED Q` supplies a rational point on \(C_1\).  Define once the explicit birational map

\[
C_1\dashrightarrow E_S
\]

and check

\[
\phi\circ\operatorname{lift}_{C_1}=\operatorname{cover}_{C_1}
\]

by `field_simp; ring`.  Only the denominators and the point at infinity require separate cases.  This fixed implication is much smaller than formalizing a generic theorem `ker alpha = image isogeny`.

This lemma is unavoidable: triviality of the dual image alone does not turn `Q` into a `phi`-preimage.

# 11. Weak three-descent

Let

\[
H=\{O,T,-T\}.
\]

For \(P\in E_S(\mathbf Q)\), select \(T_i\in H\) whose `alphaES` class equals that of \(P\).  Since `alphaESClass` is a homomorphism,

\[
\alpha_S(P-T_i)=1.
\]

The first lift lemma gives

\[
P-T_i=\psi(Q)
\]

for some \(Q\in E_D(\mathbf Q)\).  The dual-image theorem gives

\[
\alpha_D(Q)=1,
\]

and the second lift lemma gives \(Q=\phi(R)\).  Therefore

\[
P=T_i+\psi\phi(R)=T_i+3R.
\]

This proves `weak_three_descent` without any finite-generation assumption.

The group-theoretic iteration should be separated into a generic file.

```lean
structure WeakThreeSplit (A : Type*) [AddCommGroup A] where
  H : AddSubgroup A
  kill_H : ∀ h : H, 3 • (h : A) = 0
  split : ∀ P : A, ∃ h : H, ∃ Q : A,
    P = (h : A) + 3 • Q

lemma WeakThreeSplit.iterate
    (D : WeakThreeSplit A) (P : A) (n : ℕ) :
    ∃ Q : A,
      3 • P = (3^(n+1) : ℕ) • Q
```

At the successor step, split the current `Q`; the torsion term is killed because its coefficient is already divisible by \(3\).

# 12. Fixed \(3\)-adic separatedness

Because the reduction group has exponent \(3\),

\[
3P\in\ker\big(E_0(\mathbf Q_3)\to E_0(\mathbf F_3)\big)
\]

for every rational point \(P\).

Use the local parameter

\[
\tau(P)=-\frac{x(P)}{y(P)}
\]

on the formal kernel, with `tau O = 0`.  The only fixed-curve local input needed is

```lean
structure ThreeAdicFormalKernel
    (A B : Type*) [AddCommGroup A] [AddCommGroup B]
    (red : A →+ B) where
  tau : red.ker → ℚ
  tau_eq_zero_iff : ∀ P, tau P = 0 ↔ P = 0
  tau_positive : ∀ {P}, P ≠ 0 →
    1 ≤ padicValRat 3 (tau P)
  triple_growth : ∀ {P},
    P ≠ 0 → 3 • P ≠ 0 →
    padicValRat 3 (tau P) + 1 ≤
      padicValRat 3 (tau (3 • P))
```

For this model, obtain `triple_growth` directly from the projective tripling formulas.  After substituting the curve equation, put the parameter formula in the form

\[
\tau(3P)=
\frac{3\tau(P)+\tau(P)^2 A(P)}{1+\tau(P)B(P)},
\]

where \(A(P)\) and \(B(P)\) are \(3\)-integral on the reduction kernel.  The denominator is a \(3\)-adic unit; every numerator term has valuation at least \(v_3(\tau(P))+1\).  Exact equality is unnecessary.

The abstract separatedness proof is then fewer than one hundred lines:

```lean
theorem eq_zero_of_infinitely_three_divisible
    (F : ThreeAdicFormalKernel A B red)
    {P : red.ker}
    (hdiv : ∀ n : ℕ, ∃ Q : red.ker,
      (3^n : ℕ) • Q = P) :
    P = 0
```

Assume \(P\ne0\).  Every intermediate point in a division chain is nonzero, since its final multiple is \(P\).  Repeated `triple_growth` gives

\[
n+1\le v_3(\tau(P))
\]

for every \(n\), a contradiction.

The fact that Mathlib defines `padicValRat 3 0 = 0` causes no problem: split the case `P = 0` first and apply valuation lemmas only to nonzero intermediate points.

## Applying separatedness

From `WeakThreeSplit.iterate`, for every \(n\ge1\) choose \(Q_n\) with

\[
3P=3^{n+1}Q_n.
\]

Set

\[
R_n=3Q_n.
\]

Because the reduced group has exponent \(3\), every \(R_n\) lies in the formal kernel, and

\[
3^nR_n=3P.
\]

Thus \(3P\) is infinitely \(3\)-divisible **inside the formal kernel**.  Separatedness yields

\[
\boxed{3P=O}
\]

for every rational point \(P\).

# 13. Final rational \(3\)-torsion enumeration

On \(E_0\), the \(3\)-division polynomial is

\[
\begin{aligned}
\psi_3(X)
 &=3X^4+b_2X^3+3b_4X^2+3b_6X+b_8\\
 &=X(3X^3+16X^2+84X+147)\\
 &=\boxed{X(3X+7)(X^2+3X+21)}.
\end{aligned}
\]

This factorization is preferable to a generic rational-root theorem.

If \(P\ne O\) and \(3P=O\), then `psi3 X = 0`.

- The factor \(X^2+3X+21\) never vanishes over \(\mathbf Q\), since
  \[
  4(X^2+3X+21)=(2X+3)^2+75>0.
  \]
- If \(3X+7=0\), then \(X=-7/3\).  Substitution into the curve equation gives
  \[
  Y^2-\frac73Y+\frac{343}{27}=0,
  \]
  equivalently
  \[
  (18Y-21)^2+3675=0,
  \]
  impossible over \(\mathbf Q\).
- Hence \(X=0\), and the curve equation becomes
  \[
  Y(Y+7)=0.
  \]

Therefore

\[
E_0(\mathbf Q)=\{O,(0,0),(0,-7)\}.
\]

Applying the inverse coordinate change gives

\[
\boxed{
E(\mathbf Q)=\{O,(1,3),(1,-4)\}.
}
\]

One small audit point: the cubic factor of `psi3` **does** have the rational root \(-7/3\); it factors as shown above.  What fails at that \(X\)-coordinate is the existence of a rational \(Y\).  A proof claiming that the cubic factor has no rational root would be incorrect.
