# The canonical balanced-Mumford theorem for the fixed N18 curve

## Executive answer

The right foundational theorem is a **bijection theorem**, not an associativity theorem:

```lean
classOf : N18Mumford K → N18OrientedClass K

 theorem classOf_bijective : Function.Bijective (classOf (K := K))
```

or, equivalently,

```lean
theorem existsUnique_balancedRep
    (c : N18OrientedClass K) :
    ∃! D : N18Mumford K, classOf D = c
```

Once this is proved, Cantor addition inherits associativity from the already associative quotient group. The executable algorithm only has to satisfy

```lean
classOf (cantorAdd D₁ D₂) = classOf D₁ + classOf D₂.
```

The inverse construction has three stages:

1. clear the denominator of an invertible fractional ideal;
2. put the resulting integral ideal into the **fixed rank-two Mumford basis**
   \(\langle u(x),y-v(x)\rangle\);
3. perform the already-certified complement reduction and infinity balancing until
   \(\deg u\le 2\) and \(0\le n_\infty\le 2-\deg u\).

The fixed-rank ideal normal form is much more elementary than a general Hermite-normal-form development. It comes from the two coefficient projections in the basis \(1,y\).

The uniqueness proof should be isolated as the following rigidity lemma:

```lean
theorem principal_between_balanced_reduced_imp_eq
    {D₁ D₂ : N18Mumford K} {α : N18FunctionField Kˣ}
    (hIdeal :
      mumfordIdealUnit D₁ *
          toPrincipalIdeal (N18AffineRing K) (N18FunctionField K) α =
        mumfordIdealUnit D₂)
    (hInf :
      Multiplicative.ofAdd ((D₁.nInf : ℤ) - 1) * ordPlus α =
        Multiplicative.ofAdd ((D₂.nInf : ℤ) - 1)) :
    D₁ = D₂
```

This is the single genuinely geometric statement. It is the fixed-curve, degree-two form of uniqueness of a reduced divisor.

A crucial correction is:

> `deg u ≤ 2` by itself is not enough. One also needs the Mumford semireduced condition—equivalently that the affine effective divisor contains no hyperelliptic-conjugate pair—and the balanced infinity condition. Otherwise all divisors `P + h(P)` represent the canonical class.

For the structure below, semireducedness is encoded by the ideal form `⟨u,y-v⟩`, the canonical remainder condition, and the smooth squarefree curve relation.

```lean
structure N18Mumford where
```

```lean
structure N18SemiMumford where
```

# 2. The oriented ideal class group

Let

```lean
abbrev InvFrac (K : Type*) [Field K] :=
  (FractionalIdeal (N18AffineRing K)⁰ (N18FunctionField K))ˣ

abbrev OrientedRaw (K : Type*) [Field K] :=
  InvFrac K × Multiplicative ℤ
```

The chosen infinity valuation is

```lean
noncomputable def ordPlus :
    (N18FunctionField K)ˣ →* Multiplicative ℤ
```

normalized so that, for a nonzero monic polynomial `a`,

```lean
ordPlus (algebraMap _ _ a) = Multiplicative.ofAdd (-(a.natDegree : ℤ)).
```

Define

```lean
noncomputable def principalOriented :
    (N18FunctionField K)ˣ →* OrientedRaw K :=
  (toPrincipalIdeal (N18AffineRing K) (N18FunctionField K)).prod
    (ordPlus K)

abbrev N18OrientedClass (K : Type*) [Field K] :=
  Additive
    (OrientedRaw K ⧸ (principalOriented K).range)
```

The ambient raw group is commutative, so `principalOriented.range` is normal and the quotient supplies all group axioms. This is the project-local semantic model of `Pic⁰(C)`.

For

\[
I(u,v)=\langle u(x),y-v(x)\rangle\subset A,
\]

define

```lean
noncomputable def classOf (D : N18Mumford K) :
    N18OrientedClass K :=
  Additive.ofMul <|
    QuotientGroup.mk' _
      (mumfordIdealUnit D,
       Multiplicative.ofAdd ((D.nInf : ℤ) - 1))
```

The shift `nInf - 1` is forced by the divisor convention

\[
D(u,v,n)=D_{\rm aff}(u,v)
+n\infty_+ +(2-\deg u-n)\infty_-
-(\infty_++\infty_-).
\]

The useful equality eliminator is:

```lean
theorem classOf_eq_iff (D₁ D₂ : N18Mumford K) :
    classOf D₁ = classOf D₂ ↔
      ∃ α : (N18FunctionField K)ˣ,
        mumfordIdealUnit D₁ *

            mumfordIdealUnit D₂ ∧
        Multiplicative.ofAdd ((D₁.nInf : ℤ) - 1) * ordPlus α =
          Multiplicative.ofAdd ((D₂.nInf : ℤ) - 1) := by
  -- `QuotientGroup.mk'_eq_mk'`, followed by unpacking membership in
```

This lemma converts quotient equality into exactly the two hypotheses consumed by the rigidity theorem.

# 3. Precise canonical-representative theorem

The main proposition should be stated in all of the following equivalent forms. The first is best for users, the second and third are best for implementation.

## 3.1 Existence and uniqueness

```lean
theorem existsUnique_balancedRep
    (c : N18OrientedClass K) :
    ∃! D : N18Mumford K, classOf D = c
```

An elaboration-stable version is:

```lean
theorem balancedRep_exists_unique
    (c : N18OrientedClass K) :
    ∃ D : N18Mumford K,
      classOf D = c ∧
      ∀ E : N18Mumford K, classOf E = c → E = D
```

## 3.2 Bijectivity

```lean
theorem classOf_injective :
    Function.Injective (classOf (K := K))

theorem classOf_surjective :
    Function.Surjective (classOf (K := K))

theorem classOf_bijective :
    Function.Bijective (classOf (K := K)) :=
  ⟨classOf_injective, classOf_surjective⟩
```

## 3.3 Equivalence

```lean
noncomputable def mumfordEquivOriented :
    N18Mumford K ≃ N18OrientedClass K :=
  Equiv.ofBijective classOf classOf_bijective
```

After Cantor addition has been defined and proved compatible with `classOf`, this upgrades to an additive equivalence.

# 4. Invertibility of a Mumford ideal

The ideal is

```lean
noncomputable def mumfordIdeal (u v : K[X]) :
    Ideal (N18AffineRing K) :=
  Ideal.span {
    algebraMap K[X] (N18AffineRing K) u,
    y K - algebraMap K[X] (N18AffineRing K) v
  }
```

Let

\[
w=(f-v^2)/u.
\]

The key Bezout statement is

\[
(u,\,2v,\,w)=1.
\]

Indeed, if an irreducible polynomial `p` divided all three, then `p ∣ v` because `2` is a unit, and

\[
p^2\mid u w=f-v^2,
\qquad p^2\mid v^2,
\]

so `p² ∣ f`, contradicting `Squarefree f`.

Using this Bezout certificate, prove the exact ideal identity

\[
\boxed{I(u,v)I(u,-v)=(u).}
\]

The product is generated by

```text
u²,
 u(y-v),
 u(y+v),
 (y-v)(y+v)=u w.
```

After factoring out `u`, the Bezout relation in `u,2v,w` shows that the remaining ideal is `⊤`.

The corresponding Lean lemmas should be:

```lean
lemma mumford_bezout (D : N18SemiMumford K) :
    IsCoprime D.u
      (Polynomial.gcd (2 * D.v) ((n18F K - D.v^2) / D.u))

lemma mumfordIdeal_mul_conj (D : N18SemiMumford K) :
    (mumfordIdeal D.u D.v : FractionalIdeal _ _) *
        (mumfordIdeal D.u (-D.v) : FractionalIdeal _ _) =
      FractionalIdeal.spanSingleton _
        (algebraMap (N18AffineRing K) (N18FunctionField K)
          (algebraMap K[X] (N18AffineRing K) D.u))
```

Then define the unit explicitly:

```lean
noncomputable def mumfordIdealUnit (D : N18SemiMumford K) : InvFrac K :=
  Units.mkOfMulEqOne
    (mumfordIdeal D.u D.v : FractionalIdeal _ _)
    (FractionalIdeal.spanSingleton _
        (algebraMap _ _ (algebraMap _ _ D.u))⁻¹ *
      (mumfordIdeal D.u (-D.v) : FractionalIdeal _ _))
    -- product equals one
    ...
```

A global `IsDedekindDomain` instance is therefore not needed merely to put a Mumford ideal in `(FractionalIdeal ...)ˣ`.

# 5. Existence: extracting a Mumford basis from an arbitrary ideal

This is the most useful concrete part of the architecture. It avoids a general Hermite-normal-form implementation.

Let

```text
R = K[X],
A = R ⊕ R y.
```

Take a nonzero integral ideal `J : Ideal A`. Define two ideals of the PID `R`:

```lean
/-- All possible `y`-coefficients of elements of `J`. -/
def yCoeffIdeal (J : Ideal A) : Ideal R :=
  J.toSubmodule.map coeffY

/-- The elements of `R` whose images lie in `J`. -/
def basePartIdeal (J : Ideal A) : Ideal R :=
  J.comap (algebraMap R A)
```

Choose their principal generators:

```lean
c := Submodule.IsPrincipal.generator (yCoeffIdeal J)
a := Submodule.IsPrincipal.generator (basePartIdeal J)
```

Both are nonzero.

- `basePartIdeal J ≠ ⊥`: choose `0 ≠ z=p+qy ∈ J`; then
  \(z\bar z=p^2-q^2f\) is a nonzero element of `J ∩ R`.
- `yCoeffIdeal J ≠ ⊥`: either some element already has nonzero `y`-coefficient, or a nonzero `a∈J∩R` gives `a y∈J` with `y`-coefficient `a`.

By `generator_mem` and `Submodule.mem_map`, choose

\[
z=b+c y\in J.
\]

Then

\[
\boxed{J=R a+R(b+c y).}
\]

To prove the reverse inclusion, take `p+q y∈J`. Since `q` belongs to the coefficient ideal `(c)`, write `q=sc`; then

\[
(p+qy)-s(b+cy)=p-sb∈J∩R=(a).
\]

Now use stability under multiplication by `y`:

1. `a∈J`, hence `a y∈J`; its `y`-coefficient is `a`, so `c ∣ a`.
2. `b+c y∈J`, hence
   \[
   y(b+c y)=cf+b y∈J;
   \]
   its `y`-coefficient is `b`, so `c ∣ b`.

Write

\[
a=c u,
\qquad b=c b_0.
\]

Multiplying the fractional ideal by `c⁻¹` gives

\[
\boxed{c^{-1}J=\langle u,y+b_0\rangle.}
\]

Set `v=-b₀`. Since `y-v` belongs to this ideal,

\[
(f-v^2)=(y-v)(y+v)
\]

belongs to its intersection with `R`, which is `(u)`. Thus

\[
u∣f-v^2.
\]

Finally:

- replace `u` by its monic associate;
- replace `v` by `v % u`.

This yields a semi-Mumford pair.

The core theorem should be:

```lean
theorem integralIdeal_exists_mumfordBasis
    (J : Ideal (N18AffineRing K))
    (hJ : J ≠ ⊥)
    (hunit : IsUnit (J : FractionalIdeal _ (N18FunctionField K))) :
    ∃ (c : K[X]) (hc : c ≠ 0) (S : N18SemiMumford K),
      FractionalIdeal.spanSingleton _
          (algebraMap _ _ (algebraMap _ _ c))⁻¹ *
        (J : FractionalIdeal _ _) =
      (mumfordIdeal S.u S.v : FractionalIdeal _ _)
```

The assumption `hunit` is not actually needed for the two-generator algebra calculation; it is present because every raw object in `InvFrac K` supplies it and because later class-group code uses units.

## 5.1 Clearing a fractional denominator

For `I : InvFrac K`, use the exact pinned-Mathlib theorem

```lean
FractionalIdeal.den_mul_self_eq_num'
```

which states, in fractional-ideal form,

```lean
spanSingleton _ (algebraMap _ _ I.1.den) * I.1 = I.1.num.
```

Thus every raw oriented pair is equivalent, after multiplying by a principal oriented pair, to a nonzero integral ideal plus an updated infinity integer.

A useful combined theorem is:

```lean
theorem raw_exists_semiMumford
    (z : OrientedRaw K) :
    ∃ α : (N18FunctionField K)ˣ,
      ∃ S : N18SemiMumford K,
        z * principalOriented K α = rawOfSemi S
```

This theorem is proved by:

1. `den_mul_self_eq_num'`;
2. `integralIdeal_exists_mumfordBasis`;
3. one quotient calculation for the orientation.

## 5.2 Reduction to degree at most two

Apply the already-certified complement step

\[
u'=(f-\widetilde v^2)/u,
\qquad v'\equiv-\widetilde v\pmod {u'}.
\]

For `deg u ≥ 4`, the degree drops by at least two. For `deg u = 3`, choose the cubic leading coefficient of `ṽ` to be `+1` or `-1` so that the leading degree-six term cancels; then `deg u' ≤ 2`.

The semantic certificate is the principal ideal identity

\[
I(u,v)=(\alpha)I(u',v'),
\qquad
\alpha=(y-\widetilde v)/u'.
\]

Together with the proved `ordPlus α`, this gives

```lean
classOfSemi (reduceStep S) = classOfSemi S.
```

## 5.3 Balancing the infinity integer

Use

\[
A_\infty=x^3+2x^2+3x-1,
\qquad f-A_\infty^2=8x.
\]

The two fixed principal functions `y-A∞` and `y+A∞` give the zero-class semi-representatives

```text
(X,-1, 3),
(X, 1,-2).
```

Repeated baby steps move the integer into

\[
0≤n_\infty≤2-\deg u.
\]

The normalizer theorem is:

```lean
noncomputable def normalize :
    N18SemiMumford K → N18Mumford K

 theorem normalize_sound (S : N18SemiMumford K) :
    classOf (normalize S) = classOfSemi S
```

Combining quotient induction, `raw_exists_semiMumford`, and `normalize_sound` proves `classOf_surjective`.

# 6. Uniqueness: the exact reduced-divisor rigidity theorem

Suppose `D₁,D₂` have the same oriented class. By `classOf_eq_iff`, choose `α` satisfying

\[
I(D_1)(\alpha)=I(D_2)
\]

and the matching infinity valuation equation.

Let

\[
E(D)=D_{\rm aff}(u,v)
+n\infty_+ +(2-\deg u-n)\infty_-.
\]

It is an effective divisor of degree two and

\[
[D]=[E(D)-(\infty_++\infty_-)].
\]

The ideal and infinity equations say exactly

\[
\operatorname{div}(\alpha)+E(D_1)=E(D_2).
\]

Thus the pole divisor of `α` is bounded by the reduced effective divisor `E(D₁)` of degree two.

## 6.1 Why `deg u ≤ 2` is not the whole argument

On a genus-two hyperelliptic curve, an effective degree-two divisor `E` has a moving linear system precisely when it is a hyperelliptic fiber:

\[
E=P+h(P).
\]

All such fibers are linearly equivalent to the canonical divisor

\[
K_C=\infty_++\infty_-.
\]

Therefore:

- if `E` contains no conjugate pair and is not `∞₊+∞₋`, then `L(E)=K`, so every function with poles bounded by `E` is constant;
- the sole canonical reduced representative is the chosen infinity fiber, corresponding to `(1,0,1)`.

The Mumford graph condition `y=v(x)` is what excludes an affine pair `P+h(P)`: a single residue value `v mod u` chooses one branch over every finite `x`-coordinate. This semireduced fact should be an explicit lemma, not left implicit in prose.

## 6.2 Avoiding a general Riemann–Roch development

Mathlib does not provide the required algebraic-curve Riemann–Roch theorem. Prove only the fixed degree-two statement:

```lean
theorem n18_smallPole_rigidity
    (D : N18Mumford K)
    {α : N18FunctionField K}
    (hα : α ≠ 0)
    (hpoles : PolesBoundedByMumford α D) :
    (∃ c : K, α = algebraMap K _ c) ∨
      (D = zeroMumford ∧ α ∈ KspanOneX)
```

Here `PolesBoundedByMumford` need not be a general divisor predicate. It can be defined by:

- the finite ideal inclusion derived from `(α)I(D₁)=I(D₂)`;
- the single `ordPlus` inequality;
- the forced `ordMinus` inequality obtained from total degree or the conjugate norm.

The proof is explicit. Write

\[
α=(p(x)+q(x)y)/r(x).
\]

Use

\[
N(p+qy)=p^2-q^2f
\]

and the infinity-adapted decomposition

\[
p+qy=(p+qA_\infty)+q(y-A_\infty).
\]

The second formula handles the only possible leading-term cancellation at `∞₊`; its conjugate handles `∞₋`. The two-pole bound forces `q=0`. Then `α∈K(x)`, and a rational function of `x` inducing at most two poles on `C` has degree at most one in `x`, hence is a Möbius transform of `x`. Its fibers are hyperelliptic fibers. Semireducedness rules this out unless the representative is `(1,0,1)`.

This specialized lemma is the fixed-curve replacement for the general statement that a genus-two curve has a unique `g¹₂`.

## 6.3 Finishing uniqueness

If `α` is constant, its infinity valuation is zero and its principal fractional ideal is a scalar unit. Therefore

```text
I(u₁,v₁)=I(u₂,v₂),
nInf₁=nInf₂.
```

Recover the polynomials from the ideal by two exact lemmas.

First, define the quotient evaluation

```lean
def mumfordEval (D : N18SemiMumford K) :
    N18AffineRing K →+* K[X] ⧸ Ideal.span {D.u}
```

sending

```text
x ↦ x mod u,
y ↦ v mod u.
```

The relation `u ∣ f-v²` makes this well-defined. Prove

```lean
lemma ker_mumfordEval (D : N18SemiMumford K) :
    RingHom.ker (mumfordEval D) = mumfordIdeal D.u D.v
```

and hence

```lean
lemma mumfordIdeal_comap_base (D : N18SemiMumford K) :
    (mumfordIdeal D.u D.v).comap (algebraMap K[X] (N18AffineRing K)) =
      Ideal.span {D.u}
```

Equal ideals therefore give `(u₁)=(u₂)`. Since both polynomials are monic,

```text
u₁=u₂.
```

With the common `u`, equality of kernels gives

```text
u ∣ v₁-v₂.
```

Both `v₁` and `v₂` are canonical remainders modulo `u`, so

```text
v₁=v₂.
```

The orientation equation gives `nInf₁=nInf₂`, and structure extensionality finishes.

The final rigidity theorem is therefore:

```lean
theorem principal_between_balanced_reduced_imp_eq
    {D₁ D₂ : N18Mumford K} {α : N18FunctionField Kˣ}
    (hIdeal :
      mumfordIdealUnit D₁ * toPrincipalIdeal _ _ α =
        mumfordIdealUnit D₂)
    (hInf :
      Multiplicative.ofAdd ((D₁.nInf : ℤ) - 1) * ordPlus α =
        Multiplicative.ofAdd ((D₂.nInf : ℤ) - 1)) :
    D₁ = D₂
```

Then `classOf_injective` is short:

```lean
theorem classOf_injective : Function.Injective (classOf (K := K)) := by
  intro D₁ D₂ h
  obtain ⟨α, hIdeal, hInf⟩ := (classOf_eq_iff D₁ D₂).mp h
  exact principal_between_balanced_reduced_imp_eq hIdeal hInf
```

# 8. Is the affine coordinate ring Dedekind?

## 8.1 Mathematical answer: yes

For `char K ≠ 2` and squarefree `f`,

\[
A=K[x,y]/(y^2-f)
\]

is a smooth affine curve ring, hence a one-dimensional noetherian integrally closed domain: a Dedekind domain.

Equivalently, `A` is the integral closure of `K[x]` in `K(C)`.

A direct local proof is particularly simple:

- away from primes dividing `f`, the quadratic algebra is étale;
- if `p ∣ f`, squarefreeness gives `f=p·u` with `u` a unit in `K[x]_(p)`;
- in the local extension, `y` is a uniformizer because `y²=p·u`;
- hence every height-one localization is a DVR.

The discriminant of the basis `{1,y}` is `4f`. Since `2` is a unit and `f` is squarefree, the order has squarefree discriminant and is maximal. Its conductor in the integral closure is therefore the unit ideal.

## 8.2 What Mathlib supplies

From `Mathlib/RingTheory/DedekindDomain/IntegralClosure.lean`:

```lean
IsIntegralClosure.isDedekindDomain
integralClosure.isDedekindDomain
```

They show that the integral closure of a Dedekind domain in a finite separable extension is Dedekind.

Thus one possible implementation is:

```lean
abbrev O := integralClosure K[X] (N18FunctionField K)

instance : IsDedekindDomain O :=
  integralClosure.isDedekindDomain K[X] (FractionRing K[X]) _
```

with the appropriate finite-dimensional and separability instances.

However, the remaining theorem

```lean
N18AffineRing K ≃ₐ[K[X]] O
```

is exactly the proof that the explicit quadratic order is integrally closed. Mathlib does not currently turn `Squarefree f` into this equivalence automatically.

## 8.3 Do not silently replace `A` by the integral closure

If `A` were a nonmaximal order and `O` its integral closure, extension and contraction of ideals would only behave cleanly away from the conductor

\[
\mathfrak f=\{z∈O:zO⊆A\}.
\]

The class group of `O` would not be the same as the invertible-ideal class group of `A`; one would need the ring-class correction and coprimality to `𝔣`.

For this curve the conductor is `⊤`, but proving that is equivalent to proving `A=O`. Therefore the two honest choices are:

1. **Recommended for the initial module:** work directly with invertible fractional ideals of `A`, prove each Mumford ideal invertible explicitly, and use the fact that every raw object already has type `InvFrac K`.
2. Prove once that `A` is the integral closure, install `IsDedekindDomain A`, and then use `FractionalIdeal.mk0` and `ClassGroup.mk0_surjective`.

Introducing `O` without proving `A ≃ O` does not save work and complicates every Mumford ideal with extension/contraction and conductor conditions.

```text
19. cantorAdd and classOf_cantorAdd
20. AddCommGroup inherited through classOf_injective
```

The group law is then routine:

```lean
lemma cantorAdd_assoc (D₁ D₂ D₃ : N18Mumford K) :
    cantorAdd (cantorAdd D₁ D₂) D₃ =
      cantorAdd D₁ (cantorAdd D₂ D₃) := by
  apply classOf_injective
  simp only [classOf_cantorAdd, add_assoc]
```

No branch of Cantor composition appears in this proof.

# 10. Scope of the hard theorem

Assuming the coordinate ring, infinity valuation, and reduction-step correctness are already available, a realistic breakdown for `Canonical.lean` is:

| Part | Estimated Lean lines |
|---|---:|
| coefficient-ideal two-generator normal form | 300–550 |
| raw oriented class to semi-Mumford form | 150–300 |
| surjectivity through normalization | 100–200 |
| fixed two-pole/small-function rigidity | 450–850 |
| recovery of `u`, `v`, and `nInf` | 180–350 |
| quotient and bijection glue | 100–200 |
| **Total** | **1,280–2,450** |

The conceptual bottleneck is `n18_smallPole_rigidity`, not ideal multiplication and not associativity.

# Final recommendation

Use the oriented invertible-fractional-ideal quotient as the semantic group. Prove a custom rank-two ideal normal form using the coefficient projections in the basis `{1,y}`; this gives the inverse direction far more directly than generic Smith normal form. Prove uniqueness through one fixed degree-two pole-rigidity lemma, then recover the canonical polynomials from the kernel of `mumfordEval`.

This gives the exact theorem chain needed for a maintainable implementation:

```lean
classOf_surjective
classOf_injective
existsUnique_balancedRep
mumfordEquivOriented
classOf_cantorAdd
```

and makes all group axioms consequences of the quotient group rather than new arithmetic identities.
