# 1. The degree-six algebra is one field

Let `theta` denote the image of `T` in

```text
L = Q[T] / (f(T)).
```

## 1.1 Factorization over `Q(sqrt(-2))`

Put

```text
q^2 = -2,
K0  = Q(q),
pi  = 1 + q,
piBar = 1 - q,
pi*piBar = 3.
```

Define

```text
A(T) = T^3 + 2*T^2 - T - 1,
B(T) = 2*T^2 + 2*T.
```

A direct identity is

```text
f(T) = A(T)^2 + 2*B(T)^2
     = (A(T) + q*B(T)) * (A(T) - q*B(T)).
```

Thus over `K0`,

```text
g(T) = T^3 + (2+2*q)*T^2 + (-1+2*q)*T - 1
     = T^3 + 2*pi*T^2 + pi^2*T - 1,
```

and `f = g * conjugate(g)`.

This is **not** a factorization over `Q`; `L` is not a product algebra.

## 1.2 Irreducibility

After translating `T = U+1`,

```text
g(U+1)
  = U^3 + (5+2*q)*U^2 + 6*(1+q)*U + (1+4*q)
  = U^3 + pi*(3-q)*U^2 + 2*pi^2*piBar*U + pi*(3+q).
```

This is `pi`-Eisenstein in `Z[q][U]`: the three nonleading coefficients are divisible by `pi`, and the constant coefficient is not divisible by `pi^2`.  Hence `g` is irreducible over `K0`.

Moreover, in `L`,

```text
q = -(theta^3 + 2*theta^2 - theta - 1) / (2*theta*(theta+1)).
```

The denominator is nonzero because `f(0)=f(-1)=1`.  Therefore `Q(theta)` contains `K0`; since `g` is cubic over `K0`,

```text
[L : Q] = 6,
```

and `f` is irreducible over `Q`.

## 1.3 A much cleaner integral presentation

Introduce `r` by

```text
r^3 + (1+q)*r + 1 = 0,
theta = r^2.
```

Then `g(theta)=0`, since

```text
r^6 + 2*pi*r^4 + pi^2*r^2 - 1 = 0.
```

Conversely,

```text
r = -(theta^3 + 2*theta^2 + 3*theta + 1) / (2*(theta+1)).
```

Hence

```text
L = Q(q,r),       q^2=-2,       r^3+(1+q)*r+1=0,       theta=r^2.
```

## 1.4 Ring of integers and discriminants

The quadratic ring is

```text

Disc(K0) = -8.
```

The relative cubic polynomial

```text
R^3 + pi*R + 1
```

has discriminant

```text

```

At `pi`, the translated polynomial for `gamma=r+1`,

```text

```

is Eisenstein.  Away from `pi`, its discriminant is a unit.  Therefore


Two integral bases are



# 3. The even-degree 2-descent map

Let

```text
H = { alpha in L^*/(L^*^2 * Q^*) : Norm_L/Q(alpha) is a square in Q^* }.
```

The norm condition is well-defined modulo `Q^*`, because a rational scalar has sixth-power norm.

For a degree-zero divisor whose finite support avoids the Weierstrass points,

```text
D = sum_i P_i - m*P,
P_i=(x_i,y_i),
```

define

```text
delta(D) = [ product_i (x_i - theta) ] in H.
```

Indeed,

```text
Norm_L/Q(x_i-theta)=f(x_i)=y_i^2.
```

For a monic Mumford pair `(u,v)`, with `u(X)=product_i (X-x_i)`, this is

```text
delta(u,v) = [(-1)^(deg u) * u(theta)].
```

The sign is irrelevant after quotienting by `Q^*`.  Divisors meeting a branch point or infinity are handled by the usual moving lemma/resultant regularization; no extra instance-specific value is needed.

## 3.1 Why the fake target is injective in this instance

For an even sextic there can, in general, be a true/fake kernel.  Here it is killed by an explicit rational sign class.

Over `Q(q)`, the six roots split into the three roots of `g` and the three roots of `conjugate(g)`.  Give the first block sign `+1` and the second block sign `-1`.  Galois conjugation swaps the blocks, changing the sign vector by the diagonal sign, so its class is rational in

```text
(Res_{L/Q} mu_2)/mu_2.
```

Its norm is `(-1)^3=-1`.  Thus the norm map on rational points in the exact sequence

```text
1 -> J[2] -> (Res mu_2)/mu_2 -> mu_2 -> 1
```

is surjective.  The associated cohomology sequence gives an injection

```text
H^1(Q,J[2]) -> H^1(Q,(Res mu_2)/mu_2),
```

which is the fake descent target above.  Therefore a trivial fake 2-Selmer set implies a trivial true `Sel_2(J/Q)` in this fixed instance.

Also, `J[2](Q)=0`.  Indeed, rational 2-torsion is an even subset of the six roots modulo complement.  Irreducibility makes the root action transitive.  If a Galois element sent such a subset to its complement, the subset would have size `3`, contradicting evenness; hence it would be genuinely stable, and transitivity leaves only the empty/full class.

```lean
  lambdaCandidates :
    map lambda globalCandidates = ![0,a,a+a^2,a^2]
  localKummerGenerators : Fin 2 -> J(Q_2)
  localCongruence1 : E1 = 1+q^3*(1-r^2-r^3) [MOD q^4]
  localCongruence3 : E3 = 1-q^2*r+q^3*(1-r^3) [MOD q^4]
  localMuIndependent : LinearIndependent F2 ![a+a^2,a^2]

  -- true/fake injection
  oddCubicPartition : RationalNormMinusOneSignClass

  -- torsion and cusps

```

A practical proof order is:

1. define the quotient algebra by `q^2+2` and `r^3+(1+q)r+1`;
2. check all polynomial identities and the two changes of generators;
3. prove the integral-basis and discriminant statements;
4. prove the three ideal factorizations and the Minkowski finite norm check;
5. verify the three residue characters and perform the `F_2` linear algebra;
6. derive the four global candidates;
7. work in the finite quotient `O_F/(q^4)` and verify `lambda`/`mu` by `ring` plus `native_decide` in `F_8`;
8. invoke the local index formula to identify the full local Kummer image;
9. invoke Bruin--Stoll and the explicit odd-cubic sign partition to conclude true `Sel_2=0`;
10. check the small divisor identities and the sixteen continued-fraction rows.

The only infinite-looking computations have thereby been replaced by:

```text
2 local Kummer generators,
3 candidate obstructions,

```
