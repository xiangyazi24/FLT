# Lean-friendly S8b/S9 plan for global `ThetaCandidateAdditive`

The shortest route I would take is not to build a sorted finite partition of `(e,∞)`.  Instead:

1. make the upper/lower branch defect functions on the subtype `Set.Ioi e`;
2. prove they are locally constant on the whole subtype by a reusable finite-bad-set removal lemma;
3. identify the global constant by the `x → ∞` limit, where both affine branches tend to the group identity;
4. reduce arbitrary `P,Q : ComponentKer` by the branch constructors/reduction lemmas already in S6.

This keeps S9 mostly topological glue and avoids turning the zeroes of `chordY`/`chordX-e` into a hand-ordered interval list.

The code snippets below use the existing names from S5-S8.  I write the import as `RealTopologyS8`; if these files are under an FLT namespace path, only the import line should be adjusted.  The `sorry`s are placeholders in theorem skeletons, not proposed permanent axioms.

## 2. Branch cases and constants

Prove branch pairs in this order.

1. `Q = 0` and `Q = rootKerPoint`: use the S6 zero-left/right lemmas and the root branch formula/reduction.  If the root case is not already a simp lemma, add it before the topology.
2. Opposite branches first:
   * `upperRight + lowerRight`
   * `lowerRight + upperRight`

   These are the safest because the point `x=a` is the vertical/additive-inverse point.  The value at `x=a` is handled directly by the negation lemmas plus zero-left/right; the two punctured sides are handled by the S8 local lemmas and the vertical asymptotics below.
3. Same branches:
   * `upperRight + upperRight`
   * `lowerRight + lowerRight`

   Do not prove a tangent doubling formula first unless it is already cheap.  Use `continuous_upperDefectFn`/`continuous_lowerDefectFn` and the finite-bad-set removal lemma to pass through the tangent point.  The global constant is still determined by the `x → ∞` endpoint.
4. Arbitrary fixed `Q`: reduce `Q` by `componentKer_eq_rootKerPoint_of_some_x_eq_root`, `componentKer_eq_upperRightKerPoint_of_some_nonneg`, and `componentKer_eq_lowerRightKerPoint_of_some_neg`.
5. Arbitrary `P,Q`: reduce `P` by the same branch cases, then call the upper/lower arbitrary-`Q` theorems.

Use `x → ∞`, not `x → e+`, as the primary basepoint constant.  Both upper and lower affine branches tend to the group identity at infinity, so the defect tends to `thetaDefect 0 Q = 0`.  This determines the unique constant after local constancy on `Set.Ioi e` is known.

## 7. Likely Lean/mathlib pitfalls

* **`AddCircle` and uniqueness of limits.**  Any use of `tendsto_nhds_unique` needs a `T2Space` instance for the target.  If typeclass search stalls for `AddCircle thetaPeriod`, explicitly provide the nonzero/positive period fact from S6, for example `thetaPeriod_ne_zero` or `thetaPeriod_pos`.

* **Do not extensionalize `AddCircle` too early.**  For final additivity, prove `thetaDefect P Q = 0` in `AddCircle thetaPeriod`; only then unfold `thetaDefect`.  Avoid manually choosing representatives unless a branch formula lemma already does it.

* **Use subtype branch functions to avoid proof irrelevance.**  Prefer `upperDefectFn Q : Set.Ioi e → _` to raw functions with an explicit `hx : e < x`.  When you must compare `upperRightKerPoint x hx₁` and `upperRightKerPoint x hx₂`, add a simp lemma using proof irrelevance:

  ```lean
  @[simp] theorem upperRightKerPoint_proof_irrel {x : ℝ} (hx₁ hx₂ : e < x) :
      upperRightKerPoint x hx₁ = upperRightKerPoint x hx₂ := by
    congr
    exact Subsingleton.elim hx₁ hx₂
  ```

  Add the lower analogue.

* **`Point.some` proof irrelevance.**  If the `ComponentKer` constructor stores a `Point.some` proof that the point lies on the curve, Lean may not close goals by `rfl`.  Add `@[simp]` lemmas that normalize the x-coordinate/y-coordinate of each branch constructor and avoid rewriting through the proof field directly.

* **Intervals in the subtype.**  Mathlib lemmas such as `isOpen_Ioo` and `isPreconnected_Ioo` are for subsets of `ℝ`.  In subtype goals use preimages under `Subtype.val`, or define `IooInRay`.  The `Convex.isPreconnected` route is often more robust than guessing lemma names.

* **`𝓝[>] a` and `𝓝[<] a`.**  These are notation for `nhdsWithin` on `Ioi a`/`Iio a`.  For one-sided vertical asymptotics, remember to prove the side also lies in `Set.Ioi e`; this is where `ha : e < a` and a small-radius lemma are used.

* **Local-constant-to-global transport.**  Do not prove separate lemmas for every interval between bad points.  Prove `IsLocallyConstant` on all of `Set.Ioi e` once, then use preconnectedness of the open ray.  This makes the branch-pair zero theorems almost one-liners.

* **Root vs group zero.**  Keep `rootKerPoint` and `(0 : ComponentKer)` distinct in theorem names unless the existing development has already identified them.  The atTop constant uses the group zero; the near-`e` optional lemmas use `rootKerPoint`.

* **Bad set finiteness.**  Avoid polynomial root counting.  Use group cancellation: `P + Q = rootKerPoint` has at most one solution `P` on each branch because addition by `Q` is injective and the branch constructor is injective.  Use S7 only to bridge `chordX=e`/`chordY=0` to that group-law statement.
