# Square-denominator normalization for `w^2 = u^3 + a*u^2 + b*u`

## Correction

The statement is false for arbitrary rational coefficients `a b : ℚ`.

Counterexample:

```text
a = 0,
b = 7/4,
u = 1/2,
w = 1.
```

Then

```text
1 = (1/2)^3 + (7/4)*(1/2),
```

so `(u,w)` is a rational point on `w^2 = u^3 + b*u`.  But `u=1/2` cannot be written as `A/B^2` with `A B : ℤ`, `B>0`, and `gcd(A,B)=1`, because such a fraction has square reduced denominator, while `1/2` has reduced denominator `2`.

The standard square-denominator lemma is correct for an **integral monic model**:

```lean
(a b : ℤ)
w^2 = u^3 + (a : ℚ)*u^2 + (b : ℚ)*u
```

or after making an integral change of variables.  If `a,b` are merely rational, primes from their denominators can occur in the denominator of `u`.

## Proof plan

Let

```lean
p : ℤ := u.num
q : ℕ := u.den
```

Then Mathlib gives:

```lean
have hqpos : 0 < q := u.den_pos
have hcop : Nat.Coprime p.natAbs q := u.reduced
have hu : u = (p : ℚ) / (q : ℚ) := by
  simpa using (Rat.num_div_den u).symm
```

Substituting `u=p/q` into the integral equation gives

```text
w^2 = N / q^3,
N = p * (p^2 + a*p*q + b*q^2).
```

The first arithmetic helper should prove:

```lean
lemma cubic_numerator_coprime_den
    (a b p : ℤ) {q : ℕ}
    (hcop : Nat.Coprime p.natAbs q) :
    Nat.Coprime
      (p * (p ^ 2 + a * p * (q : ℤ) + b * (q : ℤ) ^ 2)).natAbs
      q
```

Reason: the second factor is congruent to `p^2` modulo `q`; since `p` is coprime to `q`, so is `p^2`, and hence so is the product.

Because `N` is coprime to `q`, the fraction `N/q^3` is already reduced, so the denominator of `w^2` is `q^3`.  Since `w^2` is a square rational, `Rat.isSquare_iff` gives that `q^3` is a square natural number.

The second helper should prove:

```lean
lemma nat_isSquare_of_isSquare_cube {q : ℕ} :
    IsSquare (q ^ 3) → IsSquare q
```

Best proof: use `Nat.factorization`.  If `q^3` is a square, every prime exponent `3*v_p(q)` is even.  Since `gcd(2,3)=1`, every `v_p(q)` is even, so `q` is a square.  The file `Mathlib/Data/Nat/Factorization/Root.lean` can help through `Nat.floorRoot`.

Then choose `B : ℕ` with `q = B^2`, set `A := p`, and coerce `B` to an integer.  The coprimality condition follows from `u.reduced`: if `A` is coprime to `B^2`, it is coprime to `B`.

Finally, because

```text
w^2 = A*(A^2 + a*A*B^2 + b*B^4) / B^6,
```

the same denominator argument gives an integer `C` with

```text
w = C / B^3.
```

After substituting these definitions, the cleared equation is exactly

```text
C^2 = A * (A^2 + a*A*B^2 + b*B^4).
```

In Lean the last line should be a `field_simp` followed by `ring_nf`.

## For the N=14 curve

For

```text
w^2 = u^3 + u^2 - 2u
```

take `a=1`, `b=-2`.  The integral equation becomes

```text
C^2 = A * (A^2 + A*B^2 - 2*B^4)
    = A * (A + 2*B^2) * (A - B^2).
```

This is the right starting point for the N=14 squareclass/descent proof.
