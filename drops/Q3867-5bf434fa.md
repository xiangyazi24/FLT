# Order 20 and 24: what is actually “free”?

## Bottom line

A rational point of order `20` on `E/ℚ` does **not** give `ℤ/2 × ℤ/10 ⊆ E(ℚ)` by group theory on the same curve.  The point `2P` has order `10`, but its unique nonzero `2`-torsion multiple is

```text
5*(2P) = 10P,
```

so `10P` is already inside the cyclic subgroup generated by `2P`.  The same issue occurs for order `24`: `2P` has order `12`, and `6*(2P)=12P`.

What is true, and is exactly the useful “free” reduction, is:

```text
P ∈ E(ℚ), order(P)=20
  ⇒ for E' = E / ⟨10P⟩, E'(ℚ) contains ℤ/2 × ℤ/10.

P ∈ E(ℚ), order(P)=24
  ⇒ for E' = E / ⟨12P⟩, E'(ℚ) contains ℤ/2 × ℤ/12.
```

So the Vélu/2-isogeny quotient trick is the simplest route **given that `no_Z2_cross_Z10` and `no_Z2_cross_Z12` are already proved**.  A direct same-curve group-theory proof cannot work: the abstract cyclic groups `C20` and `C24` satisfy the elementary torsion-structure constraints but do not contain `C2 × C10` or `C2 × C12`.

You do not need full general Vélu machinery.  The narrow formal interface needed is just the quotient by a rational order-`2` point and its dual kernel.  It can later be implemented by the explicit 2-isogeny formula after moving the rational 2-torsion point to `(0,0)` on a model

```text
E : y^2 = x^3 + a*x^2 + b*x,
E' : y^2 = x^3 - 2*a*x^2 + (a^2 - 4*b)*x,
φ(x,y) = (y^2/x^2, y*(b - x^2)/x^2)
```

with the usual special values at `O` and `(0,0)`.

## Mathematical verification of the quotient argument

### Order 20

Let `P ∈ E(ℚ)` have order `20`, and set

```text
Q = 10P.
```

Then `Q` is a rational point of order `2`.  Let

```text
φ : E → E' = E / ⟨Q⟩
```

be the rational degree-`2` quotient isogeny.

The image `A = φ(P)` has order exactly `10`.  Indeed,

```text
10A = φ(10P) = φ(Q) = 0.
```

If `5A = 0`, then `φ(5P)=0`, so `5P ∈ ker φ = {0,Q}`.  But `5P` has order `4`, while `0` has order `1` and `Q` has order `2`.  This is impossible.  Similarly, `A ≠ 0` and `2A ≠ 0`.  Hence `A` has order `10`.

Now let `η` be the nonzero point in the kernel of the dual isogeny

```text
φ̂ : E' → E.
```

The point `η` is rational and has order `2`.  It is the nonzero element of `φ(E[2])`, equivalently the kernel generator of the dual isogeny.

The only nonzero order-`2` point inside the cyclic subgroup `⟨A⟩` is `5A = φ(5P)`.  We must show

```text
η ≠ 5A.
```

Choose `T ∈ E[2]` with `φ(T)=η` and `T ∉ {0,Q}`.  If `η = 5A`, then

```text
φ(T) = φ(5P),
```

so

```text
T - 5P ∈ ker φ = {0,Q}.
```

Thus either `T = 5P` or `T = 5P + Q = 15P`.  Both `5P` and `15P` have order `4`, whereas `T` has order at most `2`.  Contradiction.

Therefore `η` is an independent rational `2`-torsion point on `E'`, and

```text
⟨η, A⟩ ≅ ℤ/2 × ℤ/10 ⊆ E'(ℚ).
```

This contradicts the already proved `no_Z2_cross_Z10`.

### Order 24

The proof is identical.  If `P` has order `24`, put

```text
Q = 12P,
φ : E → E' = E / ⟨Q⟩,
A = φ(P).
```

Then `A` has order `12`.  The dual-kernel generator `η ∈ E'(ℚ)[2]` is independent from the unique order-`2` point in `⟨A⟩`, namely

```text
6A = φ(6P).
```

If `η = 6A`, choose `T ∈ E[2] \ {0,Q}` with `φ(T)=η`.  Then `T-6P ∈ {0,Q}`, so `T=6P` or `T=18P`.  But `6P` and `18P` both have order `4`, contradiction.  Hence

```text
ℤ/2 × ℤ/12 ⊆ E'(ℚ),
```

contradicting the already proved `no_Z2_cross_Z12`.

## What to formalize first

Do not try to prove the final exclusions directly from the structure theorem for `E(ℚ)_tors`.  That structure theorem allows a cyclic group of order `20` or `24`.  The missing ingredient is geometric: quotient by the rational order-`2` subgroup.

The cleanest formal plan is to add one narrow API theorem for rational 2-isogeny quotients, then make `20` and `24` very short corollaries of the noncyclic exclusions.

## Lean scaffolding: curve-level file

This is the intended statement file.  The names of the existing noncyclic predicates may need to be adjusted to the project’s actual `TorsionDefs` API, but the shape should stay this small.

```lean
import FLT.Assumptions.MazurProof.TorsionDefs

namespace MazurProof

open scoped WeierstrassCurve.Affine

/-- Minimal data needed from quotienting an elliptic curve by a rational point of
order `2`.  This is deliberately weaker than a full Vélu API.

In the eventual proof, construct this from the explicit degree-2 isogeny formula
rather than assuming it globally. -/
structure RationalTwoQuotient
    (E : WeierstrassCurve ℚ) [E.IsElliptic]
    (Q : (E⁄ℚ).Point) where
  E' : WeierstrassCurve ℚ
  instE' : E'.IsElliptic
  phi : (E⁄ℚ).Point →+ (letI := instE'; (E'⁄ℚ).Point)
  dualKerGen : letI := instE'; (E'⁄ℚ).Point
  dualKerGen_order : letI := instE'; addOrderOf dualKerGen = 2
  ker_phi : ∀ R : (E⁄ℚ).Point, phi R = 0 ↔ R = 0 ∨ R = Q
  dualKerGen_lift_two_torsion :
    ∃ T : (E⁄ℚ).Point,
      addOrderOf T = 2 ∧ T ≠ 0 ∧ T ≠ Q ∧ phi T = dualKerGen

/-- Construction theorem for the narrow 2-isogeny quotient API.

This is the only geometric theorem needed for the “free” composite exclusions.
It can be proved later from the explicit model
`y^2 = x^3 + a*x^2 + b*x` and its 2-isogenous curve. -/
theorem exists_rationalTwoQuotient
    (E : WeierstrassCurve ℚ) [E.IsElliptic]
    {Q : (E⁄ℚ).Point} (hQ : addOrderOf Q = 2) :
    RationalTwoQuotient E Q := by
  sorry

/-- Group-theory bridge for the order-20 argument after applying the degree-2
quotient by `Q = 10 • P`. -/
theorem quotient_of_order20_has_Z2_cross_Z10

    {P : (E⁄ℚ).Point} (hP : addOrderOf P = 20) :
    ∃ (E' : WeierstrassCurve ℚ), ∃ (_ : E'.IsElliptic),
      HasRationalTorsionSubgroup E' 2 10 := by
  classical
  let Q : (E⁄ℚ).Point := 10 • P
  have hQ : addOrderOf Q = 2 := by
    -- `addOrderOf_nsmul`: order of `10 • P` is `20 / gcd 20 10 = 2`.
    sorry
  let D := exists_rationalTwoQuotient E hQ
  refine ⟨D.E', D.instE', ?_⟩
  letI := D.instE'
  let A : (D.E'⁄ℚ).Point := D.phi P
  let eta : (D.E'⁄ℚ).Point := D.dualKerGen
  have hA : addOrderOf A = 10 := by
    -- Kernel intersection with `⟨P⟩` is exactly `{0, 10 • P}`.
    -- Equivalently: `10 • A = 0`, while `A`, `2 • A`, and `5 • A` are nonzero.
    sorry
  have heta : addOrderOf eta = 2 := D.dualKerGen_order
  have hind : eta ≠ 5 • A := by
    rcases D.dualKerGen_lift_two_torsion with ⟨T, hT, hT0, hTQ, hTeta⟩
    intro h
    have hker : D.phi (T - 5 • P) = 0 := by
      -- `D.phi T = eta = 5 • D.phi P = D.phi (5 • P)`.
      sorry
    rcases (D.ker_phi (T - 5 • P)).1 hker with hzero | hq
    · -- `T = 5 • P`, but `5 • P` has order `4`, while `T` has order `2`.
      sorry
    · -- `T = 15 • P`, again order `4`, contradiction.
      sorry
  -- Convert `A` of order 10 plus independent `eta` of order 2 into the project’s
  -- predicate for `ℤ/2 × ℤ/10` rational torsion.
  exact hasRationalTorsionSubgroup_two_cross_of_order_and_independent
    E' eta A heta hA hind

quotient by `Q = 12 • P`. -/

    {P : (E⁄ℚ).Point} (hP : addOrderOf P = 24) :
    ∃ (E' : WeierstrassCurve ℚ), ∃ (_ : E'.IsElliptic),
      HasRationalTorsionSubgroup E' 2 12 := by
  classical
  let Q : (E⁄ℚ).Point := 12 • P
  have hQ : addOrderOf Q = 2 := by
    -- `addOrderOf_nsmul`: order of `12 • P` is `24 / gcd 24 12 = 2`.
    sorry
  let D := exists_rationalTwoQuotient E hQ
  refine ⟨D.E', D.instE', ?_⟩
  letI := D.instE'
  let A : (D.E'⁄ℚ).Point := D.phi P
  let eta : (D.E'⁄ℚ).Point := D.dualKerGen
  have hA : addOrderOf A = 12 := by
    -- Kernel intersection with `⟨P⟩` is exactly `{0, 12 • P}`.
```

## Why the same-curve group-theory shortcut cannot be repaired

From `P` of order `20`, the subgroup generated by `2P` and `10P` is just

```text
⟨2P,10P⟩ = ⟨2P⟩ ≅ ℤ/10,
```

because `10P = 5*(2P)`.  Similarly,

```text
⟨2P,12P⟩ = ⟨2P⟩ ≅ ℤ/12
```

for order `24`.

The structure theorem

```text
E(ℚ)_tors ≅ ℤ/m₁ × ℤ/m₂,  m₁ | m₂,  m₁ ≤ 2
```

also does not exclude `m₂=20` or `m₂=24`; it permits cyclic groups `ℤ/20` and `ℤ/24`.  The real-torsion bound gives `m₁≤2`, but no upper bound on `m₂` strong enough to rule these out.

Thus the quotient-isogeny trick is not just a convenience: it supplies the missing independent rational `2`-torsion point on a different rational elliptic curve.  If full Vélu feels too heavy, implement only the explicit rational 2-isogeny formula.  That should make `n=20` and `n=24` short corollaries of the already checked `Z/2 × Z/10` and `Z/2 × Z/12` exclusions.
