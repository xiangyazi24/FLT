# Additive order lemmas for a rational two-isogeny quotient

The exact Mathlib theorem you asked about is the additive version generated from `orderOf_pow'`:

```lean
#check addOrderOf_nsmul'
-- addOrderOf_nsmul' (x : A) (h : n ≠ 0) :
--   addOrderOf (n • x) = addOrderOf x / Nat.gcd (addOrderOf x) n
```

For proving the image orders below, the cleanest theorem is usually:

```lean
#check addOrderOf_eq_of_nsmul_and_div_prime_nsmul
```

It proves `addOrderOf x = n` from `n • x = 0` plus nonvanishing of `(n / p) • x` for every prime `p ∣ n`.

Here is a complete Lean file with the four requested lemmas.

private lemma image_five_nsmul_ne_zero_of_order_20

    {P : G} (hP : addOrderOf P = 20)
    (D : RationalTwoIsogenyData (G := G) (H := H) (10 • P)) :
    5 • D.phi P ≠ 0 := by

    simpa using h5
