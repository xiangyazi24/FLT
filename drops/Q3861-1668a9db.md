## Q1. The minimal composite set

Let

```text
B = {14, 15, 16, 18, 20, 21, 24, 25, 27, 35, 49}.
```

The intended theorem is:

```text
If n > 12 and every prime divisor of n is in {2,3,5,7},
then some d ∈ B divides n.
```

This is true.

Equivalently, `B` is the set of divisibility-minimal integers `n>12` whose prime divisors are all in `{2,3,5,7}`.  Each listed number has all proper divisors at most `12`:

```text
14 = 2*7       proper divisors 1,2,7
15 = 3*5       proper divisors 1,3,5
16 = 2^4       proper divisors 1,2,4,8
18 = 2*3^2     proper divisors 1,2,3,6,9
20 = 2^2*5     proper divisors 1,2,4,5,10
21 = 3*7       proper divisors 1,3,7
24 = 2^3*3     proper divisors 1,2,3,4,6,8,12
25 = 5^2       proper divisors 1,5
27 = 3^3       proper divisors 1,3,9
35 = 5*7       proper divisors 1,5,7
49 = 7^2       proper divisors 1,7
```

No element of `B` divides another element of `B`, so none is redundant for a pure divisor-antichain reduction.

### Completeness proof

Write

```text
n = 2^a * 3^b * 5^c * 7^d.
```

If `d ≥ 2`, then `49 ∣ n`.

If `d = 1`, then:

* if `a ≥ 1`, then `14 ∣ n`;
* if `b ≥ 1`, then `21 ∣ n`;
* if `c ≥ 1`, then `35 ∣ n`;
* if `a=b=c=0`, then `n=7≤12`.

So after excluding divisors `14`, `21`, `35`, `49`, we may assume `d=0`.

If `c ≥ 2`, then `25 ∣ n`.

If `c = 1`, then:

* if `b ≥ 1`, then `15 ∣ n`;
* if `a ≥ 2`, then `20 ∣ n`;
* if `a≤1` and `b=0`, then `n` is `5` or `10`, hence `≤12`.

So after excluding `15`, `20`, `25`, we may assume `c=0`.

Now `n=2^a*3^b`.  If `b ≥ 3`, then `27 ∣ n`.  If `b = 2` and `a ≥ 1`, then `18 ∣ n`.  If `b = 1` and `a ≥ 3`, then `24 ∣ n`.  If `a ≥ 4`, then `16 ∣ n`.  The remaining cases are all at most `12`:

```text
2^a              with a≤3 gives 1,2,4,8;
3*2^a            with a≤2 gives 3,6,12;
9                gives 9.
```

Therefore every `{2,3,5,7}`-smooth `n>12` is divisible by an element of `B`.

## Q2. The hard composite cases `25`, `27`, `35`, `49`

### Q2(a). Can `p^2 | n` be excluded by Galois representations or formal groups?

Not by a simple argument that is currently available from your infrastructure.

A rational point of order `p^2` gives a rational point of order `p`, namely `pP`.  Equivalently, it gives a Galois-stable cyclic subgroup of order `p^2`, hence a mod-`p^2` representation with a fixed vector.  Reducing mod `p`, this only says there is rational `p`-torsion, which is allowed for `p=5` and `p=7`.

Formal groups and good reduction do not give a uniform contradiction either.  At a good prime `ℓ≠p`, rational `p^2`-torsion injects into `E(𝔽_ℓ)`, so `p^2 ∣ #E(𝔽_ℓ)` for every good `ℓ`.  But for a varying curve `E/ℚ`, you cannot choose a fixed small good `ℓ` that forces a contradiction: the discriminant can be divisible by any prescribed finite set of primes.

At the prime `p` itself, good ordinary/supersingular/multiplicative cases require local analysis, and bad reduction at `p` is possible.  Turning this into a global exclusion is essentially a modular-curve argument for `X_1(p^2)`, or a closely related local-global descent.

So for `25` and `49`, the formalization-friendly route is likely:

```text
Tate/Kubert normal form for rational p-torsion
+ condition that the p-torsion point is divisible by p over ℚ
+ explicit obstruction curve / rational-point certificate.
```

This may avoid writing a general `X_1(p^2)` theory, but it is still the `X_1(p^2)(ℚ)` computation in explicit coordinates.

### Q2(b). Can `35=5*7` be excluded without computing `X_1(35)`?

A point of order `35` is equivalent to simultaneous rational `5`-torsion and rational `7`-torsion: if `P` has order `35`, then `7P` has order `5` and `5P` has order `7`; conversely, rational points of coprime orders `5` and `7` add to a rational point of order `35`.

This lets you use a fiber-product formulation:

```text
X_1(35) = X_1(5) ×_{j-line} X_1(7).
```

Since `X_1(5)` and `X_1(7)` are genus-zero and have Kubert parameterizations, a formalization-friendly proof can be:

```text
write j_5(t) and j_7(u);
solve j_5(t)=j_7(u);
show all rational solutions are cuspidal/degenerate.
```

This may be much more convenient than building abstract modular curves, but it is not conceptually a different theorem.  It is the rational-point computation on `X_1(35)` through a concrete model.

### Q2(c). Is there a uniform bound theorem with `B≤12` simpler than Mazur?

No.  A uniform theorem over `ℚ` saying

```text
no rational torsion point of order n > 12
```

is already the cyclic part of Mazur’s theorem.  Merel gives uniform boundedness over number fields, but the explicit bounds are not the exact bound `12` and the proof is much heavier than the local Kubert computations you are doing.  Parent/Kamienny-style explicit bounds are also deep modular-curve/formal-immersion theorems; they are not a shortcut to a self-contained `B≤12` proof.

A weaker uniform theorem can be useful for reducing an infinite tail, but if it has `B>12`, you still need to handle many intermediate orders.  A theorem with `B≤12` is essentially the desired theorem.

### Q2(d). Can `|E(ℝ)[n]|≤2n` plus `m₁≤2` exclude any of these composites?

No, not for cyclic orders.

If `E(ℚ)` has a rational point of order `n`, then the cyclic subgroup it generates has size `n`.  The real theorem gives only

```text
n ≤ |E(ℝ)[n]| ≤ 2n,
```

which is always compatible.

The theorem `m₁≤2` excludes large full two-dimensional rational torsion, not large cyclic torsion.  Every forbidden composite in `B` could occur as the order of a cyclic subgroup without contradicting `m₁≤2` or the real `n`-torsion bound.  The real topology remains essential for the noncyclic/product side, but it does not replace the cyclic modular-curve exclusions.

## Q3. Prime exclusions

### Q3(a). Can Tate normal form + division polynomials handle `p=11`?

Yes, `p=11` is the most plausible next explicit target.

The recommended route is not to expand the raw `ψ₁₁` polynomial in a general Weierstrass model.  Use Tate normal form with the marked point `P=(0,0)`:

```text
E_{b,c}: y^2 + (1-c)xy - by = x^3 - bx^2,
P=(0,0).
```

Then impose the condition that `P` has exact order `11` by computing multiples of `P` in the Tate normal form.  Kubert’s recurrences are much smaller than a raw division-polynomial expansion and should produce an explicit genus-one model for `X_1(11)`.

The expected proof shape is:

```text
HasRationalPointOfOrder E 11
⇒ after Tate normal form, a rational point on an explicit model of X_1(11)
⇒ rational point on the elliptic curve model of X_1(11)
⇒ that rational point is a cusp
⇒ contradiction with noncuspidality.
```

The hard sublemma is the rational-point computation on the genus-one curve.  For `X_1(11)`, this is still feasible: its rational points are finite and cuspidal.  A formal proof may use a `5`-isogeny descent, a hand-built descent certificate, or an already verified finite point list for the specific curve.  This is a real new ingredient compared with the `N=10,12` genus-zero obstruction style, but it is much smaller than the full prime theorem.

A good minimum interface is:

```lean
import Mathlib.AlgebraicGeometry.EllipticCurve.Weierstrass

namespace FLT

/-- Explicit Tate-normal-form bridge for order 11. -/
axiom order11_to_X1_11_non_cusp
    (E : WeierstrassCurve ℚ) [E.IsElliptic]
    (h : HasRationalPointOfOrder E 11) :
    ∃ P : X1_11_RatPoint, X1_11_NonCusp P

/-- Certified rational-point computation on the chosen model of `X_1(11)`. -/
axiom X1_11_rational_points_are_cusps
    (P : X1_11_RatPoint) :
    X1_11_Cusp P

theorem no_rational_point_order_11
    (E : WeierstrassCurve ℚ) [E.IsElliptic] :
    ¬ HasRationalPointOfOrder E 11 := by
  intro h
  rcases order11_to_X1_11_non_cusp E h with ⟨P, hnon⟩
  exact hnon.not_cusp (X1_11_rational_points_are_cusps P)

end FLT
```

Then discharge the two axioms separately.  The second one is where descent belongs.

### Q3(b). For `p=13`, can one avoid Chabauty?

You can avoid formalizing a **general Chabauty theory** by using a certificate-style rational-point proof for the particular genus-two curve `X_1(13)`.  But you cannot avoid a genus-two rational-point computation altogether.

The Tate-normal-form route gives an explicit model of `X_1(13)`, but this curve has genus `2`.  Proving that its rational points are only cusps typically requires one of:

```text
Chabauty + Mordell-Weil information on the Jacobian;
Mordell-Weil sieve / two-cover descent;
an explicit map to auxiliary elliptic curves plus descent certificates;
a precomputed finite rational-point certificate checked by local obstructions and polynomial identities.
```

For Lean, the most practical approach is probably not “build Chabauty” but rather:

```text
define a concrete hyperelliptic/plane model of X_1(13);
state a finite rational-point certificate for that model;
prove the certificate by elementary local obstruction and descent sublemmas if possible;
connect the certificate to Tate normal form.
```

This still represents the rational-point computation on `X_1(13)`.  If the question is whether there is a genus-zero-style parametrization like `N=10,12`, the answer is no.

### Q3(c). Is handling primes `{11,13,17,19}` enough?

Only if you also have a separate theorem excluding all primes `p≥23`.

Without such a theorem, the set of primes to exclude is infinite:

```text
11, 13, 17, 19, 23, 29, 31, 37, ...
```

A rational point of prime order `p` gives a rational cyclic `p`-isogeny, so one possible reduction is to use a rational-isogeny theorem.  But that theorem is also deep.  For example, Mazur’s rational-isogeny theorem would reduce possible prime isogeny degrees to a finite list, and then rational `p`-torsion would require checking only the prime degrees in that list.  But importing or proving that theorem is not easier than the prime-torsion theorem in this project context.

So the honest options are:

```text
1. Prove/assume no prime torsion p≥11 directly.
2. Prove/assume a tail theorem no prime torsion p≥23, then handle 11,13,17,19.
3. Prove/assume a stronger theorem such as Parent/Kamienny/Mazur prime bound, then handle the remaining small primes.
```

The finite set `{11,13,17,19}` is not sufficient by itself.

### Q3(d). Simplest self-contained proof for `p≥23` without Eisenstein ideals?

There is no simple self-contained proof from the tools listed in the project.

The elementary-looking approaches fail for uniform reasons:

* **Reduction modulo small primes:** no fixed small prime is guaranteed to be good for an arbitrary curve.
* **Real topology:** cyclic `p`-torsion is compatible with `|E(ℝ)[p]|≤2p`.
* **Weil pairing:** excludes full rational `p`-torsion, not one rational point of order `p`.
* **Galois representation reducibility:** rational `p`-torsion gives a reducible representation, but reducible mod-`p` representations occur for rational isogenies; excluding them uniformly is itself Mazur/isogeny-level mathematics.

Mazur’s original proof of the prime torsion theorem uses modular curves and formal immersion/Eisenstein-ideal machinery.  Later uniform boundedness approaches, such as Merel/Parent/Kamienny-style results, replace that with other deep modular-curve machinery.  They are not formalization shortcuts if the goal is a self-contained Lean proof.

For this project, the cleanest dependency boundary remains:

```lean
axiom mazur_prime_torsion_bound
    (E : WeierstrassCurve ℚ) [E.IsElliptic] {p : ℕ}
    (hp : Nat.Prime p)
    (hord : HasRationalPointOfOrder E p) :
    p ∈ ({2, 3, 5, 7} : Finset ℕ)
```

or, if you want finer future work items:

```lean
axiom no_order_11 : ...
axiom no_order_13 : ...
axiom no_order_17 : ...
axiom no_order_19 : ...
axiom no_prime_order_ge_23 : ...
```

The last axiom is the deep tail theorem.

### 2. Keep prime and composite inputs separate

Use:

```lean

    (E : WeierstrassCurve ℚ) [E.IsElliptic] {n : ℕ}
```

Then prove the current `mazur_cyclic_order_bound` from these two axioms.  This exposes exactly what remains after prime torsion and prevents accidental circularity.

### 3. Attack composites in increasing complexity

Suggested order:

```text
14, 15, 16, 18, 20, 21, 24  -- likely Tate/Kubert explicit obstruction curves;
25, 27, 35, 49              -- higher-genus or fiber-product computations.
```

`35` may be a good test for the fiber-product style because `X_1(5)` and `X_1(7)` both have genus-zero parameterizations.

### 4. Attack primes separately

Start with `11`.  It is the smallest genuinely new modular curve and should validate the Tate-normal-form-to-genus-one-certificate pipeline.  Do not start with `p≥23`; that is the deep tail.

## Bottom line

Your composite list is exactly the right antichain.  Excluding those 11 composite orders plus the prime torsion theorem suffices for the full pointwise cyclic order bound.

For `25`, `27`, `35`, and `49`, there is no hidden shortcut from the real-topology or Weil-pairing side.  The formalization-friendly path is explicit modular-curve computation in Tate/Kubert coordinates, packaged as rational-point certificates.

For primes, `p=11` is feasible as the next explicit case; `p=13` is a genus-two rational-point computation; and `p≥17` requires a genuine prime-tail theorem unless you are prepared for infinitely many modular-curve computations.
