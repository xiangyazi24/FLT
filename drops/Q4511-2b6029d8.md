# N18 Block 5: strict 3-adic formal-kernel filtration and the [21]-annihilator

## Executive verdict

The Block-5 argument is correct, with two important corrections.

1. The reduction of the good E₀-model at π = a − 1 is supersingular in characteristic 3. Its reduced multiplication series has height 2, so modulo π its first nonzero term is in degree 3² = 9, not degree 3. There is no load-bearing z³ term.
2. The nonarchimedean triangle inequality gives a lower bound

$$
v([3]z) ≥ min(3 + v(z), 2v(z)),
$$

not equality in general. Cancellation may make the valuation larger.

Neither correction hurts the proof. The universal formal-group identity

$$
[3](T) = 3T + T² A(T),   A(T) ∈ 𝒪_K[[T]],
$$

already gives, for nonzero z in the maximal ideal with [3]z ≠ 0,

```text
v([3]z)
  = v(3z + z² A(z))
  ≥ min(v(3z), v(z² A(z)))
  ≥ min(3 + v(z), 2v(z))
  ≥ v(z) + 1.
```

This is the entire local estimate. It proves that the reduction kernel has no nonzero element divisible by 3ⁿ for every n. Combined with

```text
E₀(L) = H₃ + 3 E₀(L),          3 H₃ = 0,
7 · E₀(𝔽₃) = 0,
```

it gives

```text
21 · E₀(L) = 0
```

without Mordell-Weil finite generation.

The generic filtration and annihilator code below was compiled against the repository's pinned Lean/Mathlib environment; validation ended with `EXIT_STATUS=0`. The remaining curve-specific work is exactly the adapter from the explicit good Weierstrass model to its formal parameter and additive valuation. Current Mathlib has a generic `FormalGroup`, but no `WeierstrassCurve.formalGroup` or ready reduction-kernel/formal-parameter equivalence, so that adapter must be project-local.

# 1. Local arithmetic and the good model

Set

```text
L = ℚ(a),       a³ = 3a + 1,
π = a − 1,
K = L_π,
𝒪 = 𝒪_K,
k = 𝒪/(π) = 𝔽₃.
```

Substituting a = π + 1 into a³ − 3a − 1 = 0 gives

```text
π³ + 3π² − 3 = 0,
3(1 − π²) = π³.
```

Since 1 − π² is congruent to 1 modulo π, it is a unit of 𝒪. With additive normalization v(π) = 1,

```text
v(3) = 3.
```

Use the integral model already identified in Block 5:

```text
Y² + (a²+a−1)XY + (a²−2)Y
  = X³ + (−a²+a+2)X²
      + (13a²+2a−44)X − 22a²−3a+88.
```

Its discriminant is −8, a π-adic unit, so it has good reduction. Reducing at π gives

```text
y² + xy − y = x³ − x² + x
```

over 𝔽₃. Its rational point group has exactly seven elements, so every reduced rational point is killed by 7.

**Codomain correction.** For the annihilator proof, reduction must have codomain the rational residue group:

```lean
redLocal : E0KPoint →+ E0ReductionF3Point
```

or its pullback to E₀(L). Do not use E₀(𝔽̄₃) as the codomain of the exponent-7 statement: the algebraic-closure point group is not killed by 7. The image of a K-rational integral point lies in E₀(𝔽₃), so the smaller codomain is the correct one.

# 2. The elliptic formal group and [3]-series

For a good integral Weierstrass equation

```text
y² + a₁xy + a₃y = x³ + a₂x² + a₄x + a₆,
```

use the standard parameter at the identity

```text
t = −x/y.
```

A concrete construction introduces w = −1/y, so x = t/w and y = −1/w. The series w(t) is the unique element of t³𝒪[[t]] satisfying

```text
w = t³ + a₁tw + a₂t²w + a₃w² + a₄tw² + a₆w³.
```

Transporting the elliptic group law through t gives a commutative one-dimensional formal group law

```text
F(T₁,T₂) = T₁ + T₂ + terms of total degree at least 2.
```

Define its n-series recursively:

```text
[0](T) = 0,
[n+1](T) = F([n](T), T).
```

## 2.1 Linear coefficient and the quadratic remainder

Induction on n, using F(X,Y) = X + Y plus terms of total degree at least 2, gives

```text
[n](T) = nT + O(T²).
```

Thus [3](T) has constant coefficient 0 and linear coefficient 3. Therefore [3](T) − 3T has zero coefficients in degrees 0 and 1 and is divisible by T². There is a unique integral series A(T) with

```text
[3](T) = 3T + T² A(T).
```

A direct Lean quotient definition is coefficient shifting:

```lean
noncomputable def threeRemainderQuotient
    (threeSeries : O⟦X⟧) : O⟦X⟧ :=
  PowerSeries.mk fun n ↦
    PowerSeries.coeff (n + 2)
      (threeSeries - PowerSeries.C (3 : O) * PowerSeries.X)
```

After proving the constant and linear coefficients, the identity

```lean
threeSeries =
  PowerSeries.C (3 : O) * PowerSeries.X +
    PowerSeries.X ^ 2 * threeRemainderQuotient threeSeries
```

is coefficient extensionality, splitting the index into 0, 1, and n + 2. Exact syntax around `PowerSeries.mk` may be adapted to the project's formal-series wrapper, but no elliptic arithmetic remains in this factorization.

## 2.2 Supersingular refinement, not needed

The reduced curve has

```text
#E(𝔽₃) = 7,
trace(Frob₃) = 3 + 1 − 7 = −3,
```

so it is supersingular. Its formal group has height 2 and modulo π:

```text
[3](T) = u T⁹ + higher terms,       u ≠ 0.
```

This stronger statement implies that the coefficients of degrees 2 through 8 in the integral [3]-series lie in the maximal ideal. It is useful for sharper ramification estimates, but it should not be the basic Block-5 proof. The universal factorization `3T + T²A(T)` is enough.

# 3. Evaluation in the formal kernel

Let

```text
E₁(K) = ker(E₀(K) → E₀(𝔽₃)).
```

Good reduction identifies E₁(K) with the maximal ideal equipped with the formal group law. The project-facing interface should be:

```lean
formalParam : E1K ≃+ FormalMaxIdealPoint e0FormalGroup
```

with underlying coordinate P ↦ t(P), and therefore

```lean
formalParam (n • P) = n • formalParam P.
```

After unfolding formal multiplication,

```lean
t ((3 : ℕ) • P) =
  PowerSeries.eval₂ (algebraMap O K) (t P) e0ThreeSeries.
```

For nonzero P in the formal kernel, put

```text
z = t(P),
r = v(z).
```

Then z belongs to the maximal ideal, so r ≥ 1. Completeness of 𝒪 makes evaluation of every integral power series at z well-defined, and A(z) belongs to 𝒪, so v(A(z)) ≥ 0.

If 3 • P ≠ 0, then [3](z) ≠ 0 and

```text
v(t(3 • P))
  = v(3z + z²A(z))
  ≥ min(v(3) + v(z), 2v(z) + v(A(z)))
  ≥ min(3 + r, 2r).
```

For r ≥ 1,

```text
3 + r ≥ r + 1,
2r ≥ r + 1.
```

Hence

```text
v(t(3 • P)) ≥ v(t(P)) + 1.
```

### Lean valuation-order warning

Mathlib's `Valuation K ℤᵐ⁰` is multiplicative, and its order looks reversed relative to the usual additive order of vanishing. Do not formulate strictness directly in that order unless every conversion is explicit. Expose a natural-valued additive level

```lean
localFormalLevel : E1K → ℕ
```

with `localFormalLevel P = vπ(t(P))` for P ≠ 0. An equally robust implementation defines

```text
F_r = {P | t(P) ∈ maximalIdeal^r}
```

and proves `[3](F_r) ⊆ F_(r+1)` for r ≥ 1.

# 4. Exact strict-filtration interface

The identifier `StrictNSmulFiltration` is not currently landed on `scratch`. This definition is sufficient and avoids assigning an infinite natural level to zero:

```lean
/-- A strict `m`-divisibility filtration on an additive subgroup.
Strictness is required only when the `m`-multiple is nonzero. -/
structure StrictNSmulFiltration
    {G : Type*} [AddCommGroup G] (H : AddSubgroup G) (m : ℕ) where
  level : H → ℕ
  strict : ∀ x : H, m • x ≠ 0 → level x < level (m • x)
```

Package the curve-specific estimate in this minimal data structure:

```lean
structure FormalKernelThreeData
    {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
    (red : G →+ Q) where
  level : red.ker → ℕ
  level_pos : ∀ P : red.ker, P ≠ 0 → 1 ≤ level P
  three_bound : ∀ P : red.ker, (3 : ℕ) • P ≠ 0 →
    min (3 + level P) (2 * level P) ≤ level ((3 : ℕ) • P)
```

The numerical step and strict-filtration constructor are fully elementary:

```lean
lemma min_three_add_two_mul_ge_succ {r : ℕ} (hr : 1 ≤ r) :
    r + 1 ≤ min (3 + r) (2 * r) := by
  omega

namespace FormalKernelThreeData

variable {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
variable {red : G →+ Q}

/-- The valuation estimate builds the strict `3`-filtration. -/
def strictNSmulFiltration (D : FormalKernelThreeData red) :
    StrictNSmulFiltration red.ker 3 where
  level := D.level
  strict := by
    intro P h3P
    have hP : P ≠ 0 := by
      intro hP0
      apply h3P
      rw [hP0, nsmul_zero]
    have hmin := min_three_add_two_mul_ge_succ (D.level_pos P hP)
    have hbound := D.three_bound P h3P
    omega

end FormalKernelThreeData
```

For the global L-rational group define

```lean
loc : E0LPoint →+ E0KPoint
redGlobal : E0LPoint →+ E0ReductionF3Point := redLocal.comp loc
```

and pull the local level back along `loc`. Injectivity of L ↪ K gives injectivity of `loc`, so `3 • P ≠ 0` globally implies `3 • loc P ≠ 0` locally.

A project-facing adapter has this shape:

```lean
noncomputable def e0GlobalFormalKernelThreeData :
    FormalKernelThreeData redGlobal where
  level := fun P ↦
    localFormalLevel
      ⟨loc P.1, by simpa [redGlobal] using P.2⟩
  level_pos := by
    intro P hP
    apply localFormalLevel_pos
    intro hloc
    apply hP
    apply Subtype.ext
    exact loc_injective hloc
  three_bound := by
    intro P h3P
    let Ploc : redLocal.ker :=
      ⟨loc P.1, by simpa [redGlobal] using P.2⟩
    have h3Ploc : (3 : ℕ) • Ploc ≠ 0 := by
      intro hzero
      apply h3P
      apply Subtype.ext
      apply loc_injective
      simpa [Ploc] using congrArg Subtype.val hzero
    simpa [Ploc, localFormalLevel, map_nsmul] using
      local_three_level_bound Ploc h3Ploc

noncomputable def e0StrictThree :
    StrictNSmulFiltration redGlobal.ker 3 :=
  e0GlobalFormalKernelThreeData.strictNSmulFiltration
```

The identifiers for the concrete local point types are the only parts to adapt.

# 5. No nonzero infinitely 3-divisible point

If x = mⁿ • y ≠ 0, none of the intermediate multiples can be zero. Repeated strictness gives

```text
level(y) + n ≤ level(x).
```

Taking n = level(x) + 1 is impossible. The following proof compiled unchanged:

```lean
namespace StrictNSmulFiltration

variable {G : Type*} [AddCommGroup G]
variable {H : AddSubgroup G} {m : ℕ}

lemma level_add_le_of_eq_pow_nsmul
    (F : StrictNSmulFiltration H m)
    {n : ℕ} {x y : H} (hx : x ≠ 0) (hxy : x = (m ^ n) • y) :
    F.level y + n ≤ F.level x := by
  induction n generalizing x with
  | zero =>
      simpa [hxy]
  | succ n ih =>
      let z : H := (m ^ n) • y
      have hxz : x = m • z := by
        calc
          x = (m ^ (n + 1)) • y := hxy
          _ = (m ^ n * m) • y := by rw [pow_succ]
          _ = (m * m ^ n) • y := by rw [Nat.mul_comm]
          _ = m • ((m ^ n) • y) := by rw [smul_smul]
          _ = m • z := rfl
      have hz : z ≠ 0 := by
        intro hz0
        apply hx
        rw [hxz, hz0, nsmul_zero]
      have hi : F.level y + n ≤ F.level z := ih hz rfl
      have hmz : m • z ≠ 0 := by
        intro hmz0
        exact hx (hxz.trans hmz0)
      have hs : F.level z < F.level x := by
        simpa [hxz] using F.strict z hmz
      omega

/-- A nonzero element cannot be divisible by every power of `m`. -/
theorem eq_zero_of_infinitely_divisible
    (F : StrictNSmulFiltration H m) (x : H)
    (hdiv : ∀ n : ℕ, ∃ y : H, x = (m ^ n) • y) :
    x = 0 := by
  by_contra hx
  obtain ⟨y, hy⟩ := hdiv (F.level x + 1)
  have hle := F.level_add_le_of_eq_pow_nsmul hx hy
  omega

end StrictNSmulFiltration
```

# 6. The visible order-3 point

Let T be the known point of exact order 3. Its reduction satisfies

```text
3 · red(T) = red(3T) = 0,
7 · red(T) = 0.
```

Since 3 and 7 are coprime, `red(T) = 0`. Thus T lies in the formal kernel. Also `[3]T = O`, so in extended valuation notation

```text
v(t([3]T)) = v(0) = ∞ > v(t(T)).
```

Our structure asks for strictness only when `3 • P ≠ 0`, so no artificial natural level for infinity is needed.

**Do not claim that strictness proves T is not once 3-divisible.** If T = 3Q, strictness merely gives `level Q < level T`, which is not a contradiction. What strictness proves, and what the annihilator argument needs, is that no nonzero formal-kernel point is divisible by every power 3ⁿ.

# 7. The [21]-annihilator

Define weak descent abstractly:

```lean
structure WeakDescent
    {G : Type*} [AddCommGroup G] (m : ℕ) (T : AddSubgroup G) : Prop where
  decompose : ∀ x : G, ∃ t : T, ∃ y : G, x = (t : G) + m • y
```

Assume

```text
hweak : WeakDescent 3 H₃,
hH₃   : ∀ t : H₃, 3 • t = 0,
hred  : ∀ q : E0ReductionF3Point, 7 • q = 0.
```

Recursive weak descent gives, for every n, a point yₙ with

```text
21x = 3ⁿ · (21yₙ).
```

Indeed, multiplying `x = t + 3y` by 21 kills t because `21t = 7(3t) = 0`. Also

```text
red(21yₙ) = 3 · (7 · red(yₙ)) = 0,
```

so every `21yₙ` belongs to the reduction kernel. Thus `21x` is infinitely 3-divisible inside the formal kernel and must be zero.

The following complete generic proof compiled with `EXIT_STATUS=0`:

```lean
namespace WeakDescent

variable {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
variable {T : AddSubgroup G}

lemma twentyOne_smul_torsion_zero
    (hT : ∀ t : T, (3 : ℕ) • (t : G) = 0) (t : T) :
    (21 : ℕ) • (t : G) = 0 := by
  calc
    (21 : ℕ) • (t : G) = (7 : ℕ) • ((3 : ℕ) • (t : G)) := by
      norm_num [smul_smul]
    _ = 0 := by rw [hT t, nsmul_zero]

lemma twentyOne_smul_three_pow_divisible
    (hweak : WeakDescent 3 T)
    (hT : ∀ t : T, (3 : ℕ) • (t : G) = 0)
    (n : ℕ) (x : G) :
    ∃ y : G, (21 : ℕ) • x = (3 ^ n) • ((21 : ℕ) • y) := by
  induction n with
  | zero =>
      exact ⟨x, by simp⟩
  | succ n ih =>
      obtain ⟨y, hy⟩ := ih
      obtain ⟨t, z, hz⟩ := hweak.decompose y
      refine ⟨z, ?_⟩
      have h21t : (21 : ℕ) • (t : G) = 0 :=
        twentyOne_smul_torsion_zero hT t
      have hinner : (21 : ℕ) • ((t : G) + (3 : ℕ) • z) =
          (3 : ℕ) • ((21 : ℕ) • z) := by
        rw [nsmul_add, h21t, zero_add]
        simp [smul_smul, Nat.mul_comm]
      calc
        (21 : ℕ) • x = (3 ^ n) • ((21 : ℕ) • y) := hy
        _ = (3 ^ n) • ((21 : ℕ) • ((t : G) + (3 : ℕ) • z)) := by rw [hz]
        _ = (3 ^ n) • ((3 : ℕ) • ((21 : ℕ) • z)) := by rw [hinner]
        _ = (3 ^ n * 3) • ((21 : ℕ) • z) := by rw [smul_smul]
        _ = (3 ^ (n + 1)) • ((21 : ℕ) • z) := by rw [pow_succ]

lemma twentyOne_smul_mem_ker
    (red : G →+ Q) (hred : ∀ q : Q, (7 : ℕ) • q = 0) (x : G) :
    red ((21 : ℕ) • x) = 0 := by
  rw [map_nsmul]
  calc
    (21 : ℕ) • red x = (3 : ℕ) • ((7 : ℕ) • red x) := by
      norm_num [smul_smul]
    _ = 0 := by rw [hred (red x), nsmul_zero]

/-- Weak 3-descent modulo 3-torsion, exponent 7 on the reduction,
and a strict 3-filtration on the reduction kernel imply exponent 21. -/
theorem twentyOne_annihilator
    (red : G →+ Q)
    (hweak : WeakDescent 3 T)
    (hT : ∀ t : T, (3 : ℕ) • (t : G) = 0)
    (hred : ∀ q : Q, (7 : ℕ) • q = 0)
    (F : StrictNSmulFiltration red.ker 3) :
    ∀ x : G, (21 : ℕ) • x = 0 := by
  intro x
  let X : red.ker :=
    ⟨(21 : ℕ) • x, twentyOne_smul_mem_ker red hred x⟩
  have hdiv : ∀ n : ℕ, ∃ Y : red.ker, X = (3 ^ n) • Y := by
    intro n
    obtain ⟨y, hy⟩ :=
      twentyOne_smul_three_pow_divisible hweak hT n x
    let Y : red.ker :=
      ⟨(21 : ℕ) • y, twentyOne_smul_mem_ker red hred y⟩
    refine ⟨Y, ?_⟩
    apply Subtype.ext
    exact hy
  have hX : X = 0 := F.eq_zero_of_infinitely_divisible X hdiv
  exact congrArg Subtype.val hX

end WeakDescent
```

```text

    ↓
π = a−1, vπ(3) = 3, residue field 𝔽₃
    ↓
```

This closes the intended Block-5 seam. The supersingular height-2 refinement is compatible with the proof but unnecessary; the universal quadratic remainder is the cleanest and shortest Lean route.
