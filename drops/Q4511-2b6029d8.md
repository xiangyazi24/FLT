# N18 Block 5: the actual strict 3-adic formal-kernel proof

## Verdict

The Block-5 conclusion is correct:

```text
weak 3-descent + exponent 7 on reduction + separated 3-adic formal kernel
  ==>  [21] E0(L) = 0.
```

Two formulas in the question must, however, be corrected before they can be formalized.

1. The reduction of the good model at `pi = a - 1` is **supersingular** in characteristic `3`. Therefore the reduced formal `[3]`-series has height `2` and begins in degree `3^2 = 9`, not degree `3`. There is no unit `z^3` Frobenius term for this curve.
2. The nonarchimedean triangle inequality gives

   ```text
   v([3](z)) >= min (3 + v(z)) (3 * v(z)),
   ```

   not equality in general. Cancellation can increase the valuation; the point `T` itself is the decisive example, because `[3]T = O` and hence the left side is infinity.

The useful integral shape is

```text
[3](Z) = 3 Z + 3 b Z^2 + Z^3 B(Z),       b in O, B(Z) in O[[Z]],
```

where for the elliptic formal parameter `Z = -X/Y` one has `b = -a1`. This shape gives exactly the requested strict inequality. It also proves the extra fact omitted from the earlier draft: every nonzero `3`-torsion point in the formal kernel has level exactly `1`. Consequently the visible point `T` is not once `3`-divisible.

The pure group-theoretic Lean code below has no `sorry`. The only project-local infrastructure required to instantiate it is the standard good-reduction/formal-parameter bridge, which current Mathlib does not construct for a `WeierstrassCurve`.

# 1. The local field and the good model

Let

```text
L  = Q(a),          a^3 = 3a + 1,
pi = a - 1,
K  = L_pi,
O  = O_K,
k  = O/(pi) = F_3.
```

Putting `a = pi + 1` in `a^3 - 3a - 1 = 0` gives

```text
pi^3 + 3 pi^2 - 3 = 0,
3 (1 - pi^2) = pi^3.
```

Because `1 - pi^2` is congruent to `1` modulo `pi`, it is a unit. For the additive normalization `v(pi) = 1`,

```text
v(3) = 3.
```

Use the integral Weierstrass model

```text
Y^2 + A1 X Y + A3 Y
  = X^3 + A2 X^2 + A4 X + A6,
```

with

```text
A1 =  a^2 + a - 1,
A2 = -a^2 + a + 2,
A3 =  a^2 - 2,
A4 = 13a^2 + 2a - 44,
A6 = -22a^2 - 3a + 88.
```

Its discriminant is `-8` times a `pi`-adic unit; equivalently its reduction has nonzero discriminant. Reducing `a` to `1` gives

```text
y^2 + x y - y = x^3 - x^2 + x                         (Ebar)
```

over `F_3`.

The affine points are

```text
x = 0 : y = 0, 1,
x = 1 : y = 1, 2,
x = 2 : y = 0, 2,
```

and there is the point at infinity. Hence

```text
# Ebar(F_3) = 7,
7 * Q = O for every Q in Ebar(F_3).
```

The trace of Frobenius is

```text
3 + 1 - 7 = -3,
```

so the reduction is supersingular.

For the global proof, reduction may be written either as

```lean
redGlobal : E0LPoint ->+ EbarF3Point
```

or as a map to a larger special-fibre point type together with the pointwise statement

```lean
hred7 : forall P : E0LPoint, (7 : Nat) • redGlobal P = 0.
```

The second formulation is more robust. One must not assert that every point of `Ebar(Fbar_3)` is killed by `7`; only the reductions of `L`-rational points land in the rational seven-element group.

# 2. The elliptic formal group

For a good integral equation

```text
y^2 + a1 x y + a3 y = x^3 + a2 x^2 + a4 x + a6,
```

use the standard parameter at the identity

```text
Z = -x/y.
```

Introduce

```text
W = -1/y,
```

so that

```text
x = Z/W,
y = -1/W.
```

Substitution in the Weierstrass equation gives the exact fixed-point equation

```text
W = Z^3 + a1 Z W + a2 Z^2 W + a3 W^2
          + a4 Z W^2 + a6 W^3.                         (W)
```

There is a unique solution

```text
W(Z) in Z^3 O[[Z]].
```

The chord-and-tangent law, transported through `Z = -x/y`, gives a commutative one-dimensional formal group law

```text
F(X,Y) in O[[X,Y]].
```

Its first terms are

```text
F(X,Y)
  = X + Y - a1 X Y
      - a2 (X^2 Y + X Y^2)
      + terms of total degree at least 4.               (Fjet)
```

Only the quadratic term is needed below. Put

```text
b = coeff_(X Y)(F) = -a1.
```

Define the multiplication series recursively by

```text
[0](Z)     = 0,
[n+1](Z)   = F([n](Z), Z).
```

From

```text
F(X,Y) = X + Y + b X Y + terms of total degree at least 3
```

one gets

```text
[2](Z) = 2 Z + b Z^2 + Z^3 C2(Z),
```

and then

```text
[3](Z) = F([2](Z), Z)
       = 3 Z + 3 b Z^2 + Z^3 B(Z)                       (3shape)
```

for a unique integral series `B(Z) in O[[Z]]`. For the elliptic law, `b = -A1`, so

```text
[3](Z) = 3 Z - 3 A1 Z^2 + Z^3 B(Z).
```

This is the correct load-bearing series identity.

## 2.1 Coefficient proof of `(3shape)`

The proof is finite. If

```text
F(X,Y) = X + Y + bXY + R3(X,Y),
```

where every monomial in `R3` has total degree at least `3`, then

```text
[2](Z) = 2Z + bZ^2 + O(Z^3).
```

Therefore

```text
F([2](Z),Z)
 = [2](Z) + Z + b[2](Z)Z + O(Z^3)
 = 3Z + bZ^2 + 2bZ^2 + O(Z^3)
 = 3Z + 3bZ^2 + O(Z^3).
```

Thus the residual series has coefficients `0` in degrees `0`, `1`, and `2`, and is divisible by `Z^3`. In Lean, define the quotient by coefficient shifting:

```lean
noncomputable def shiftThree (S : O⟦X⟧) : O⟦X⟧ :=
  PowerSeries.mk fun n => PowerSeries.coeff (n + 3) S
```

and prove by coefficient extensionality that, whenever the first three coefficients of `S` vanish,

```lean
S = PowerSeries.X ^ 3 * shiftThree S.
```

Applying this to

```text
S = [3](Z) - 3Z - 3bZ^2
```

gives `(3shape)`.

## 2.2 The cubic coefficient and the supersingular correction

Keeping one more degree in `(Fjet)` gives the standard initial expansion

```text
[3](Z)
  = 3Z - 3a1 Z^2 + (a1^2 - 8a2) Z^3 + O(Z^4).
```

For the good model,

```text
A1^2 - 8A2 = 10a^2 - 3a - 13.
```

With `a = 1 + pi`, this is

```text
-6 + 17pi + 10pi^2.
```

Since `v(-6) = 3`, it is congruent to `17pi`, hence to `2pi`, modulo `pi^2`. Thus its valuation is exactly `1`; in particular it is not a unit.

More conceptually, the reduced curve is supersingular, so its formal group has height `2` and

```text
[3](Z) mod pi = u Z^9 + higher terms,       u in k^*.
```

The degree-`3` Frobenius term belongs to the ordinary height-`1` case. It is false for this curve and is not needed for strictness.

# 3. Evaluation on the formal kernel

Let

```text
E1(K) = ker(E0(K) -> Ebar(F_3)).
```

Good reduction identifies `E1(K)` with the maximal ideal `m_K` equipped with the formal group law. The project-local interface needed by Lean is:

```lean
formalParam : redLocal.ker -> K
formalParam_zero_iff : formalParam P = 0 <-> P = 0
formalParam_mem_maximal : P != 0 -> 1 <= ordPi (formalParam P)
formalParam_three :
  formalParam ((3 : Nat) • P) = evalThreeSeries (formalParam P)
```

For nonzero `P`, write

```text
z = formalParam P,
r = v(z) >= 1.
```

Evaluate `(3shape)`:

```text
[3](z) = 3z + 3b z^2 + z^3 B(z).
```

Because `b` and every coefficient of `B` are integral and `z` is topologically nilpotent,

```text
B(z) in O,
v(B(z)) >= 0.
```

The three summands therefore satisfy

```text
v(3z)          = 3 + r,
v(3b z^2)      >= 3 + 2r,
v(z^3 B(z))    >= 3r.
```

Consequently

```text
v([3](z))
  >= min (3 + r) (3 + 2r) (3r)
   = min (3 + r) (3r).                                  (VAL)
```

This is exactly why the higher terms cannot lower the valuation: all terms of degree at least `3` have been packaged into `z^3 B(z)`, and integral evaluation makes that whole tail have valuation at least `3r`. The only quadratic term has an extra factor `3`.

For `r >= 1`,

```text
3 + r > r,
3r > r.
```

Hence

```text
v([3](z)) > v(z)
```

whenever `[3](z) != 0`; if `[3](z) = 0`, then the extended valuation is infinity and the same strict inequality holds.

The equality claimed in the question is not valid. If `r = 1`, the lowest valuations can tie and cancellation can occur. The point `T` gives total cancellation.

## 3.1 A useful stronger statement for `r >= 2`

If `r >= 2`, then

```text
3 + r < 3 + 2r,
3 + r < 3r.
```

Thus `3z` is the unique term of least valuation, so

```text
[3](z) != 0,
v([3](z)) = 3 + r.                                  (EXACT-DEEP)
```

It follows immediately that every nonzero `3`-torsion point in the formal kernel has level exactly `1`: its level is at least `1`, and level at least `2` would contradict `(EXACT-DEEP)`.

# 4. `StrictNSmulFiltration red.ker 3`

Zero has infinite formal valuation, so it is cleaner to store a natural-valued level and require strictness only when the multiple is nonzero.

```lean
import Mathlib

set_option autoImplicit false

namespace N18Block5

/-- A natural-valued strict filtration for multiplication by `m` on `H`.
The level assigned to zero is irrelevant; strictness is requested only when
`m • x` is nonzero. -/
structure StrictNSmulFiltration
    {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (m : Nat) where
  level : H -> Nat
  strict : forall x : H, m • x != 0 -> level x < level (m • x)

/-- The exact local output consumed by the generic Block-5 proof. -/
structure FormalKernelThreeData
    {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
    (red : G ->+ Q) where
  level : red.ker -> Nat
  level_pos : forall P : red.ker, P != 0 -> 1 <= level P
  three_bound : forall P : red.ker, (3 : Nat) • P != 0 ->
    min (3 + level P) (3 * level P) <= level ((3 : Nat) • P)

lemma lt_min_three_add_three_mul {r : Nat} (hr : 1 <= r) :
    r < min (3 + r) (3 * r) := by
  omega

namespace FormalKernelThreeData

variable {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
variable {red : G ->+ Q}

/-- The valuation estimate `(VAL)` gives the required strict filtration. -/
def strictNSmulFiltration (D : FormalKernelThreeData red) :
    StrictNSmulFiltration red.ker 3 where
  level := D.level
  strict := by
    intro P h3P
    have hP : P != 0 := by
      intro hP0
      apply h3P
      rw [hP0, nsmul_zero]
    exact lt_of_lt_of_le
      (lt_min_three_add_three_mul (D.level_pos P hP))
      (D.three_bound P h3P)

end FormalKernelThreeData
```

For the curve, define

```lean
localFormalLevel : redLocal.ker -> Nat
```

by

```text
localFormalLevel(0) = 0,
localFormalLevel(P) = v_pi(formalParam(P)) for P != 0.
```

Then `(VAL)` proves

```lean

  (3 : Nat) • P != 0 ->
  min (3 + localFormalLevel P) (3 * localFormalLevel P)
```

For global `L`-points, let

The embedding `L -> K` makes `loc` injective. Pull the local level back along `loc`; injectivity ensures that a nonzero global `3`-multiple remains nonzero locally. Thus:

# 5. No nonzero infinitely `3`-divisible formal-kernel point

Repeated strictness is enough; no finite-generation theorem is used.

```lean
namespace StrictNSmulFiltration

variable {G : Type*} [AddCommGroup G]
variable {H : AddSubgroup G} {m : Nat}

lemma level_add_le_of_eq_pow_nsmul
    (F : StrictNSmulFiltration H m)
    {n : Nat} {x y : H} (hx : x != 0)
    (hxy : x = (m ^ n) • y) :
    F.level y + n <= F.level x := by
  induction n generalizing x with
  | zero =>
      simpa [hxy]
  | succ n ih =>
      let z : H := (m ^ n) • y
      have hxz : x = m • z := by
        calc
          x = (m ^ (n + 1)) • y := hxy
          _ = (m ^ n * m) • y := by rw [pow_succ]
          _ = (m * m ^ n) • y := by rw [Nat.mul_comm]
          _ = m • ((m ^ n) • y) := by rw [smul_smul]
          _ = m • z := rfl
      have hz : z != 0 := by
        intro hz0
        apply hx
        rw [hxz, hz0, nsmul_zero]
      have hi : F.level y + n <= F.level z := ih hz rfl
      have hmz : m • z != 0 := by
        intro hmz0
        exact hx (hxz.trans hmz0)
      have hs : F.level z < F.level x := by
        simpa [hxz] using F.strict z hmz
      omega

/-- A nonzero element cannot be divisible by every power of `m`. -/
theorem eq_zero_of_infinitely_divisible
    (F : StrictNSmulFiltration H m) (x : H)
    (hdiv : forall n : Nat, exists y : H, x = (m ^ n) • y) :
    x = 0 := by
  by_contra hx
  obtain ⟨y, hy⟩ := hdiv (F.level x + 1)
  have hle := F.level_add_le_of_eq_pow_nsmul hx hy
  omega

end StrictNSmulFiltration
```

The proof is elementary. If

```text
x = 3^n y != 0,
```

none of the intermediate multiples can vanish, so there are `n` strict level increases. Taking `n > level(x)` is impossible.

# 6. The visible order-3 point `T`

Let

```text
T = (1,0),
3T = O,
T != O.
```

## 6.1 `T` lies in the formal kernel

Reduction is a homomorphism, so

```text
3 red(T) = red(3T) = O.
```

Every reduced rational point is killed by `7`. Since `3` and `7` are coprime,

```text
red(T) = O.
```

Thus `T` belongs to `red.ker`.

A reusable Lean lemma is:

```lean
lemma eq_zero_of_coprime_nsmul_eq_zero
    {A : Type*} [AddCommGroup A]
    {m n : Nat} (hmn : m.Coprime n) {x : A}
    (hm : m • x = 0) (hn : n • x = 0) : x = 0 := by
  have hom : addOrderOf x ∣ m :=
    addOrderOf_dvd_iff_nsmul_eq_zero.mpr hm
  have hon : addOrderOf x ∣ n :=
    addOrderOf_dvd_iff_nsmul_eq_zero.mpr hn
  have hog : addOrderOf x ∣ Nat.gcd m n :=
    Nat.dvd_gcd hom hon
  rw [hmn.gcd_eq_one] at hog
  exact AddMonoid.addOrderOf_eq_one_iff.mp (Nat.dvd_one.mp hog)
```

## 6.2 The formal level of `T` is exactly `1`

Because `T` is a nonzero formal-kernel point,

```text
1 <= level(T).
```

If `level(T) >= 2`, `(EXACT-DEEP)` says `[3](formalParam T)` is nonzero. This contradicts `3T = O`. Hence

```text
level(T) = 1.                                           (TLEVEL)
```

In extended valuation notation,

```text
v(formalParam(3T)) = v(0) = infinity > 1 = v(formalParam(T)).
```

Thus `T` is perfectly consistent with the strict filtration; it is precisely the cancellation case where the lower bound is strict by an infinite amount.

## 6.3 `T` is not `3`-divisible

Suppose

```text
T = 3Q.
```

Then

```text
3 red(Q) = red(T) = O,
7 red(Q) = O.
```

Coprimality again gives `red(Q) = O`, so `Q` lies in the formal kernel. Also `Q != O`, and strictness applied to `3Q = T != O` gives

```text
level(Q) < level(T) = 1.
```

But every nonzero formal-kernel point has level at least `1`, contradiction. Therefore

```text
not exists Q, T = 3Q.
```

This is the missing argument needed to justify the sentence “`T` is 3-torsion but not 3-divisible.” Strictness alone does not prove it until `(TLEVEL)` has been established.

# 7. Weak descent implies the `[21]` annihilator

Package the weak-descent output as follows.

```lean
/-- `G = T + mG`, with `T` represented by a subgroup. -/
structure WeakDescent
    {G : Type*} [AddCommGroup G]
    (m : Nat) (Tsub : AddSubgroup G) : Prop where
  decompose : forall x : G,
    exists t : Tsub, exists y : G, x = (t : G) + m • y
```

Assume

```text
hweak : WeakDescent 3 H3,
hH3   : forall t : H3, 3 • (t : G) = 0,
hred7 : forall x : G, 7 • red x = 0,
F     : StrictNSmulFiltration red.ker 3.
```

Iterating weak descent gives, for every `n`, a point `y_n` such that

```text
21x = 3^n (21 y_n).                                    (DIV)
```

Indeed, if `y = t + 3z`, then

```text
21y = 21t + 63z = 0 + 3(21z),
```

because `3t = 0`.

Moreover

```text
red(21 y_n) = 3 (7 red(y_n)) = 0,
```

so `21 y_n` lies in the formal kernel. Hence `21x` is infinitely `3`-divisible **inside the formal kernel**, and Section 5 forces `21x = 0`.

Here is the complete Lean proof.

```lean
namespace WeakDescent

variable {G Q : Type*} [AddCommGroup G] [AddCommGroup Q]
variable {Tsub : AddSubgroup G}

lemma twentyOne_smul_torsion_zero
    (hT : forall t : Tsub, (3 : Nat) • (t : G) = 0)
    (t : Tsub) :
    (21 : Nat) • (t : G) = 0 := by
  calc
    (21 : Nat) • (t : G) = (7 : Nat) • ((3 : Nat) • (t : G)) := by
      norm_num [smul_smul]
    _ = 0 := by rw [hT t, nsmul_zero]

lemma twentyOne_smul_three_pow_divisible
    (hweak : WeakDescent 3 Tsub)
    (hT : forall t : Tsub, (3 : Nat) • (t : G) = 0)
    (n : Nat) (x : G) :
    exists y : G, (21 : Nat) • x = (3 ^ n) • ((21 : Nat) • y) := by
  induction n with
  | zero =>
      exact ⟨x, by simp⟩
  | succ n ih =>
      obtain ⟨y, hy⟩ := ih
      obtain ⟨t, z, hz⟩ := hweak.decompose y
      refine ⟨z, ?_⟩
      have h21t : (21 : Nat) • (t : G) = 0 :=
        twentyOne_smul_torsion_zero hT t
      have hinner :
          (21 : Nat) • ((t : G) + (3 : Nat) • z) =
            (3 : Nat) • ((21 : Nat) • z) := by
        rw [nsmul_add, h21t, zero_add]
        simp [smul_smul, Nat.mul_comm]
      calc
        (21 : Nat) • x = (3 ^ n) • ((21 : Nat) • y) := hy
        _ = (3 ^ n) • ((21 : Nat) • ((t : G) + (3 : Nat) • z)) := by
          rw [hz]
        _ = (3 ^ n) • ((3 : Nat) • ((21 : Nat) • z)) := by
          rw [hinner]
        _ = (3 ^ n * 3) • ((21 : Nat) • z) := by
          rw [smul_smul]
        _ = (3 ^ (n + 1)) • ((21 : Nat) • z) := by
          rw [pow_succ]

lemma twentyOne_smul_mem_ker
    (red : G ->+ Q)
    (hred7 : forall x : G, (7 : Nat) • red x = 0)
    (x : G) :
    red ((21 : Nat) • x) = 0 := by
  rw [map_nsmul]
  calc
    (21 : Nat) • red x = (3 : Nat) • ((7 : Nat) • red x) := by
      norm_num [smul_smul]
    _ = 0 := by rw [hred7 x, nsmul_zero]

/-- Weak 3-descent modulo 3-torsion, exponent 7 on rational reduction,
and strict separatedness of the formal kernel imply exponent 21. -/
theorem twentyOne_annihilator
    (red : G ->+ Q)
    (hweak : WeakDescent 3 Tsub)
    (hT : forall t : Tsub, (3 : Nat) • (t : G) = 0)
    (hred7 : forall x : G, (7 : Nat) • red x = 0)
    (F : StrictNSmulFiltration red.ker 3) :
    forall x : G, (21 : Nat) • x = 0 := by
  intro x
  let X : red.ker :=
    ⟨(21 : Nat) • x, twentyOne_smul_mem_ker red hred7 x⟩
  have hdiv : forall n : Nat, exists Y : red.ker, X = (3 ^ n) • Y := by
    intro n
    obtain ⟨y, hy⟩ :=
      twentyOne_smul_three_pow_divisible hweak hT n x
    let Y : red.ker :=
      ⟨(21 : Nat) • y, twentyOne_smul_mem_ker red hred7 y⟩
    refine ⟨Y, ?_⟩
    apply Subtype.ext
    exact hy
  have hX : X = 0 := F.eq_zero_of_infinitely_divisible X hdiv
  exact congrArg Subtype.val hX

end WeakDescent

end N18Block5
```
