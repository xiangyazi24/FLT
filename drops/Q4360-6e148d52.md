# 4. Cyclic base-change factorization

Let `f0` be the rational newform `162.2.a.c` attached to `E0`. Let `chi` be the primitive cubic character modulo `9` with `chi(2)=zeta_3`.

The two nontrivial twists are

```text
f1=f0 tensor chi,
f2=f0 tensor chi^2=conjugate(f1).
```

They have order-three nebentypus and together form the degree-two newform orbit

```text
18.2.c.a.
```

The modular abelian variety attached to this orbit is the genus-two Jacobian

```text
A_{18.2.c.a} = J_1(18)
```

up to `Q`-isogeny.

## 4.1 These twists are not elliptic curves over Q

Because `chi` takes values in `Q(zeta_3)` and is not quadratic, `f1` and `f2` do not individually correspond to elliptic curves over `Q`. They are conjugate coefficient-field embeddings of one GL2-type abelian surface.

So the correct replacement for a table of “two twist curves” is

| character | modular object | analytic rank |
|---|---|---:|
| `1` | elliptic curve `E0`, newform `162.2.a.c` | `0` |
| `chi` | one embedding of newform `18.2.c.a` | `0` |
| `chi^2` | conjugate embedding of `18.2.c.a` | `0` |

The last two rows together constitute `J_1(18)`, not two rational elliptic curves.

## 4.2 Representation-theoretic isogenies

For every prime `ell`, Artin formalism gives

```text
V_ell(Res_{L/Q} E0)
 = V_ell(E0) tensor Ind_{G_L}^{G_Q}(1)
 = V_ell(E0)
   + V_ell(E0) tensor chi
   + V_ell(E0) tensor chi^2.
```

The last two summands are the Tate module of `J_1(18)`. Faltings' isogeny theorem therefore gives

```text
Res_{L/Q}(E0) ~_Q E0 x J_1(18).
```

After restriction to `G_L`, both characters become trivial, so

```text
V_ell(J_1(18))|_{G_L}
 = V_ell(E0)|_{G_L} + V_ell(E0)|_{G_L},
```

hence

```text
J_1(18)_L ~_L E0_L^2.
```

This is the correct splitting field statement. It is unrelated to the dead `Q(sqrt(-2))` factorization shortcut.

Artin formalism gives

```text
L(E0/L,s)

  L(f0 tensor chi,s)
  L(f0 tensor chi^2,s)
```

The stored special values are

```text

 =1.6839691374503703985195213019...,

L(E0/L,1)
 =0.29236646593300151539140377191827674932... .
```

Both are nonzero. Therefore

```text
L(J_1(18),1)
 =L(E0/L,1)/L(E0/Q,1)
 approximately 0.1736174728093068
```

is nonzero. Since the two twist values are complex conjugates,

```text
L(J_1(18),1)
 = |L(f0 tensor chi,1)|^2.
```

Thus each nontrivial twist has analytic order of vanishing `0`, and

```text
ord_{s=1} L(E0/L,s)=0.
```

## Turning analytic rank zero into algebraic rank zero

This step is not parity. Root number `+1` proves only that the analytic rank is even and cannot distinguish `0` from `2`.

Instead use the standard analytic-rank-zero theorem for modular abelian varieties, supplied by Euler-system results such as Kato's theorem. Nonvanishing of the relevant modular `L`-values implies

```text
rank E0(Q)=0,
rank J_1(18)(Q)=0.
```

Then the isogeny

```text
Res_{L/Q}(E0) ~ E0 x J_1(18)
```

gives

```text
rank E0(L)
 =rank E0(Q)+rank J_1(18)(Q)
 =0.
```

This is genuinely independent of the explicit `3`-isogeny descent. It is not elementary, and it is not currently a short Lean/Mathlib route, but it is a mathematically rigorous second method once the modular analytic-rank-zero theorem is admitted.

# 6. Root number and parity are not decisive

The ECNF local-data line records local root number `-1` at the unique prime above `2`.

There are three real places, each contributing `-1`, so the global sign is

```text
w(E0/L)=(-1)^3*(-1)=+1.
```

Hence parity predicts

```text
rank E0(L) is even.
```

This is consistent with rank `0`, but by itself permits ranks `2,4,...`. Root number is therefore only a consistency check, not the requested rank certificate.

# 7. What a full 2-descent over L would look like

Completing the square in the rational model gives

```text
Y=2y+x+1,
Y^2=4x^3-3x^2-18x+21.
```

Put

```text
h(X)=4X^3-3X^2-18X+21.
```

Its discriminant is

```text
Disc(h)=-10368=-2^7*3^4.
```

Since `E0(L)_tors` has odd order, `E0(L)[2]=0`; hence `h` has no root in `L` and is irreducible as a cubic over `L`.

A full `2`-descent therefore uses the cubic extension

```text
M=L[theta]/(h(theta)),
```

which has degree

```text
[M:Q]=9.
```

The Kummer map has the usual form

```text
E0(L)/2E0(L)
 -> ker(
      Norm_{M/L}: M^x/M^{x2} -> L^x/L^{x2}
    ),
P=(x,y) |-> [x-theta].
```

The only rational primes that can enter the unramified-outside-`S` bound are `2` and `3`, but the certificate still needs

```text
- the ring of integers and class group of the degree-9 field M;
- primes of M over 2 and 3;
- an S-unit basis modulo squares;
- local Kummer images at all places over 2 and 3 and at infinity;
- a finite F2 linear-algebra intersection proving Sel_2=0.
```

The ECNF exact rank computation shows that such a bound closes, but its raw database files do not publish this local matrix.

This route is therefore a valid algebraic alternative, but not automatically a smaller Lean build than the original fixed genus-two descent, whose etale algebra has degree `6` over `Q`.

# 8. Final implication for N18

Assume the following two checked ingredients:

```text
(A)  J_1(18)_L ~ E0_L^2;
(B)  rank E0(L)=0.
```

Then

```text
rank J_1(18)(L)=2*rank E0(L)=0.
```

The natural inclusion

```text
J_1(18)(Q) -> J_1(18)(L)
```

is injective, so

```text
rank J_1(18)(Q)=0.
```

No `2`-adic separatedness argument is needed after this point. Reduction at `5` and `7`, together with the explicit class of order `21`, then pins

```text
J_1(18)(Q) = Z/21Z.
```

Thus the logic is airtight **provided** either:

```text
- the exact ECNF algebraic rank certificate [0,0] is accepted, or
- the analytic nonvanishing plus the modular analytic-rank-zero theorem is accepted, or
- a new explicit 2-descent certificate over L is formalized.
```

For an axiom-free elementary Lean development, the first two are not presently internal Mathlib proofs. The third is possible but involves a degree-nine descent field. Therefore this is an excellent independent cross-check and may support a modular/analytic formalization strategy, but it does not automatically replace the fixed genus-two descent in the current elementary Lean plan.
