# Lean-oriented proof skeleton for `hasDerivAt_chordX_signed`

Use the slope convention already checked in `RealTopologyS7.lean`:

```lean
chordM x y a b := (y - b) / (x - a)
chordX A x y a b := (chordM x y a b) ^ 2 - A - x - a
chordY A x y a b := -(y + chordM x y a b * (chordX A x y a b - x))
```

This is the line-through-`P` convention with

```text
m = (y - b)/(x - a),
x3 = m^2 - A - x - a,
y3 = -(y + m*(x3 - x)).
```

With this convention, the derivative of `m(t) = (u t - b)/(t - a)` at `x` is

```text
dm = (du * (x - a) - (y - b)) / (x - a)^2,
du = shortCubicDeriv A B x / (2*y),
```

and the derivative of `chordX` is `2 * chordM x y a b * dm - 1`. The checked algebra theorem then rewrites exactly to `chordY A x y a b / y`.

## Paste-first proof

This version avoids differentiating a `pow` directly: it differentiates `m*m`, then converts to `m^2` with `ring`. Put this after `chord_deriv_identity_algebra` in `RealTopologyS7.lean`, or import `RealTopologyS7` from a later file.

```lean
import Mathlib.Tactic
import FLT.Assumptions.MazurProof.RealTopologyS7

open scoped BigOperators

theorem hasDerivAt_chordX_signed
    {u : ℝ → ℝ} {A B a b x y : ℝ}
    (hQ : b ^ 2 = shortCubic A B a)
    (hy : y ^ 2 = shortCubic A B x)
    (hy0 : y ≠ 0)
    (hD : x - a ≠ 0)
    (huval : u x = y)
    (hu : HasDerivAt u (shortCubicDeriv A B x / (2 * y)) x) :
    HasDerivAt
      (fun t : ℝ => chordX A t (u t) a b)
      (chordY A x y a b / y)
      x := by
  let du : ℝ := shortCubicDeriv A B x / (2 * y)
  let dm : ℝ := (du * (x - a) - (y - b)) / (x - a) ^ 2

  have hu' : HasDerivAt u du x := by
    simpa [du] using hu

  have hconstb : HasDerivAt (fun _ : ℝ => b) 0 x := by
    simpa using (hasDerivAt_const (x := x) (c := b))
  have hnum : HasDerivAt (fun t : ℝ => u t - b) du x := by
    simpa using (hu'.sub hconstb)

  have hid : HasDerivAt (fun t : ℝ => t) (1 : ℝ) x := by
    simpa using (hasDerivAt_id (x := x))
  have hconsta : HasDerivAt (fun _ : ℝ => a) 0 x := by
    simpa using (hasDerivAt_const (x := x) (c := a))
  have hden' : HasDerivAt (fun t : ℝ => t - a) (1 : ℝ) x := by
    simpa using (hid.sub hconsta)
  have hden_ne : (fun t : ℝ => t - a) x ≠ 0 := by
    simpa using hD

  have hm_div : HasDerivAt (fun t : ℝ => (u t - b) / (t - a))
      ((du * (x - a) - (u x - b) * (1 : ℝ)) / (x - a) ^ 2) x := by
    simpa using (hnum.div hden' hden_ne)

  have hm : HasDerivAt (fun t : ℝ => chordM t (u t) a b) dm x := by
    simpa [chordM, dm, huval] using hm_div

  have hsq_mul : HasDerivAt
      (fun t : ℝ => chordM t (u t) a b * chordM t (u t) a b)
      (dm * chordM x y a b + chordM x y a b * dm) x := by
    simpa [huval] using (hm.mul hm)

  have hsq : HasDerivAt
      (fun t : ℝ => (chordM t (u t) a b) ^ 2)
      (2 * chordM x y a b * dm) x := by
    convert hsq_mul using 1
    · funext t
      ring
    · ring

  have hconstA : HasDerivAt (fun _ : ℝ => A) 0 x := by
    simpa using (hasDerivAt_const (x := x) (c := A))

  have hx3_poly : HasDerivAt
      (fun t : ℝ => (chordM t (u t) a b) ^ 2 - A - t - a)
      (2 * chordM x y a b * dm - 1) x := by
    have h1 : HasDerivAt
        (fun t : ℝ => (chordM t (u t) a b) ^ 2 - A)
        (2 * chordM x y a b * dm - 0) x := by
      simpa using (hsq.sub hconstA)
    have h2 : HasDerivAt
        (fun t : ℝ => (chordM t (u t) a b) ^ 2 - A - t)
        ((2 * chordM x y a b * dm - 0) - 1) x := by
      simpa using (h1.sub hid)
    have h3 : HasDerivAt
        (fun t : ℝ => (chordM t (u t) a b) ^ 2 - A - t - a)
        (((2 * chordM x y a b * dm - 0) - 1) - 0) x := by
      simpa using (h2.sub hconsta)
    simpa using h3

  have hx3 : HasDerivAt
      (fun t : ℝ => chordX A t (u t) a b)
      (2 * chordM x y a b * dm - 1) x := by
    simpa [chordX] using hx3_poly

  have halg :
      2 * chordM x y a b * dm - 1 = chordY A x y a b / y := by
    simpa [du, dm] using
      (chord_deriv_identity_algebra hy hQ hy0 hD)

  simpa [halg] using hx3
```

## Algebraic interface being used

The proof has only two analytic ingredients:

```text
u'(x) = shortCubicDeriv A B x / (2*y)
((u-b)/(id-a))'(x)
  = (u'(x)*(x-a) - (u x-b)*1)/(x-a)^2
  = (du*(x-a) - (y-b))/(x-a)^2
```

and

```text
(chordX A t (u t) a b)' at x
  = 2 * chordM x y a b * dm - 1.
```

All curve-specific cancellation is isolated in your checked theorem:

```lean
chord_deriv_identity_algebra hy hQ hy0 hD
```

which rewrites

```text
2 * chordM x y a b
  * (((shortCubicDeriv A B x)/(2*y))*(x-a) - (y-b))/(x-a)^2
  - 1
```

to

```text
chordY A x y a b / y.
```

## Local exclusions for S6/S7 patching

For this nonvertical chord lemma, keep `x - a ≠ 0`. This excludes both the vertical case `P = -Q`, where the affine sum is `O`, and the tangent case `P = Q`, where the chord slope denominator changes to the tangent formula. For the theta/additivity local-constancy step, also exclude points where the image branch changes or hits a junction, especially `chordX A x y a b = e` and hence `chordY A x y a b = 0` on the root, plus any endpoint/root/O cases. Those are not failures of the differential identity; they are the finite exceptional points across which the later proof should extend local constancy by continuity of the AddCircle defect.
