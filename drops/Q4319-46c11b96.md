# Executive verdict

Option **(B) does not prove rank zero**.  Reduction at any finite collection of good primes bounds only the rational torsion subgroup.  The kernels of

```text
J(Q) → J(F_p)
```

can contain non-torsion points, and 2-adic separatedness rules out only a point which is divisible by every power of `2` in the formal kernel.  It does not make an arbitrary rational point infinitely 2-divisible.

The finite-field orders for the Jacobian of

```text
C : y^2 = x^6 + 4*x^5 + 10*x^4 + 10*x^3 + 5*x^2 + 2*x + 1
```

are

```text
#J(F_5)  =  21
#J(F_7)  =  63
#J(F_11) =  84
#J(F_13) = 189
```

and hence

```text
gcd(21, 63, 84, 189) = 21.
```

The best pair for a pure torsion bound is `(5,11)`:

```text
gcd(#J(F_5), #J(F_11)) = gcd(21,84) = 21.
```

This proves `J(Q)_tors ≅ Z/21Z` once the known rational cuspidal subgroup of order `21` is constructed, but it gives no information about a possible free summand.

The **smallest correct axiom-free route** is therefore:

1. prove only the fixed-curve global statement
   ```lean
   theorem n18_two_surjective (P : JQ) : ∃ Q : JQ, P = 2 • Q
   ```
   rather than a full generic Bruin--Stoll exact sequence;
2. use the already identified 2-adic local quotient of exponent `21` and formal-kernel separatedness to prove
   ```text
   21 P = 0  for every P ∈ J(Q);
   ```
3. for the rational-point theorem, do **not** enumerate all `21` Jacobian elements: use the good prime `5`, where `#C(F_5)=6`, and show reduction on `C(Q)` is injective via Abel--Jacobi and prime-to-5 torsion reduction.

If a genuinely cohomological theorem `Sel₂(J/Q)=0` is already formalized, Step 1 follows from the ordinary Kummer injection and the explicit `x-T` descent can be omitted entirely.  If only the computed **fake** 2-Selmer group is available, some bridge is logically unavoidable.  The smallest bridge is the fixed-curve one-way implication designed in `Q4283-c51817a6.md`, using the conjugate `3+3` factorization over `Q(sqrt(-2))`; it is substantially smaller than a generic even-degree halving theorem.

# 1. Exact finite-field orders

All of `5,7,11,13` are good primes: the conductor is

```text
324 = 2^2 * 3^4,
```

so only `2` and `3` are bad.

A convenient independent audit comes from the unique two-dimensional newform orbit

```text
18.2.c.a
```

in `S_2^new(Γ_1(18))`.  Let `ω` satisfy

```text
ω^2 + ω + 1 = 0.
```

The coefficient field is `Q(ω)`.  Up to conjugating the embedded newform, its coefficient at `2` is `a_2 = ω`.

The trace form displayed for the level-18 weight-2 space gives

```text
Tr(a_2)  = -1,       Tr(a_4)  = -1,
Tr(a_5)  =  0,       Tr(a_10) =  0,
Tr(a_7)  = -2,       Tr(a_14) = -2,
Tr(a_11) =  3,       Tr(a_22) =  3,
Tr(a_13) = -2,       Tr(a_26) =  4.
```

Since the coefficients are multiplicative at coprime indices,

```text
a_(2p) = a_2 * a_p.
```

For `a=m+nω`,

```text
Tr(a)   = 2m - n,
Tr(ωa)  = -m - n,
Norm(a) = m^2 - m*n + n^2.
```

Solving the two trace equations for each prime gives, up to conjugation,

```text
p = 5:   a_5  = 0,        Norm(a_5)  = 0
p = 7:   a_7  = 2ω,       Norm(a_7)  = 4
p = 11:  a_11 = -3ω,      Norm(a_11) = 9
p = 13:  a_13 = 2ω^2,     Norm(a_13) = 4.
```

The nebentypus is the even order-three character `χ_18(7,·)`.  For each of `p=5,7,11,13`, its value is a nontrivial cube root of unity, so

```text
χ(p) + conjugate(χ(p)) = -1.
```

For a good prime, the degree-four local numerator is

```text
P_p(T)
  = Norm_Q(ω)/Q (1 - a_p*T + χ(p)*p*T^2)
  = 1 - t_p*T + c_p*T^2 - p*t_p*T^3 + p^2*T^4,
```

where

```text
t_p = Tr(a_p),
c_p = Norm(a_p) - p.
```

Thus:

```text
P_5(T)  = 1             - 5*T^2              + 25*T^4
P_7(T)  = 1 + 2*T       - 3*T^2 + 14*T^3     + 49*T^4
P_11(T) = 1 - 3*T       - 2*T^2 - 33*T^3     + 121*T^4
P_13(T) = 1 + 2*T       - 9*T^2 + 26*T^3     + 169*T^4.
```

Since `#J(F_p)=P_p(1)`, this gives

```text
#J(F_5)  = 1 - 5 + 25                         = 21
#J(F_7)  = 1 + 2 - 3 + 14 + 49                = 63
#J(F_11) = 1 - 3 - 2 - 33 + 121               = 84
#J(F_13) = 1 + 2 - 9 + 26 + 169               = 189.
```

# 2. What the two-prime reduction argument really proves

Let `T=J(Q)_tors`.  At a good prime `p`, reduction is injective on the prime-to-`p` part of `T`.  Using `p=5` and `p=11` prime by prime gives

```text
|T| divides 21.
```

Indeed:

- the `5`-primary part injects at `11`, and `5 ∤ 84`;
- the `11`-primary part injects at `5`, and `11 ∤ 21`;
- for every prime `ℓ≠5,11`, the `ℓ`-primary part injects at both primes and is bounded by the `ℓ`-part of `gcd(21,84)=21`.

The known cuspidal subgroup has order `21`, so

```text
J(Q)_tors ≅ Z/21Z.
```

This is a very cheap and useful theorem, but it is only a torsion theorem.

## Why it cannot kill a free part

A rank-one abstract countermodel is

```text
G = Z ⊕ Z/21Z.
```

There are homomorphisms from `G` to finite groups of orders `21`, `63`, `84`, and `189` whose restrictions to `Z/21Z` have all the desired reduction properties.  The infinite cyclic factor can lie in the kernels.  Thus the four finite orders are compatible with positive rank.

Likewise, 2-adic separatedness says schematically

```text
R ∈ J_1(Q_2)  and
(∀ n, ∃ S_n ∈ J_1(Q_2), 2^n S_n = R)
------------------------------------------------
R = 0.
```

It does **not** say that every point of `J(Q)` has all of these halves.  The missing premise is precisely

```text
J(Q) = 2 J(Q).
```

Therefore reduction plus separatedness, without a global 2-divisibility theorem, is logically insufficient.

# 3. The minimal local-global group argument

Let `J_1(Q_2)` denote the formal kernel.  The fixed local calculation in `Q4253-6cccc2ea.md` gives

```text
J_0(Q_2)/J_1(Q_2) ≅ Z/7Z,
J(Q_2)/J_0(Q_2)   ≅ Z/3Z,
```

and hence the abelian quotient

```text
J(Q_2)/J_1(Q_2)
```

has order and exponent `21`.

Assume only the global theorem

```lean
/-- The sole global output needed from the 2-Selmer computation. -/
theorem n18_two_surjective (P : JQ) :
    ∃ Q : JQ, P = 2 • Q
```

and the local separatedness theorem

```lean
/-- No nonzero formal-kernel point is divisible by every power of two. -/
theorem n18_formalKernel_separated
    (R : J1Q2)
    (hdiv : ∀ n : ℕ, ∃ S : J1Q2,
      (2^n : ℕ) • S = R) :
    R = 0
```

Then every rational point is killed by `21`.

## Proof

Fix `P : J(Q)`.  Iterating `n18_two_surjective`, for every `n` choose `Q_n` with

```text
2^n Q_n = P.
```

Since the local quotient has exponent `21`,

```text
R_n := 21 Q_n
```

belongs to `J_1(Q_2)`.  Moreover

```text
2^n R_n = 21 P.
```

Thus `21P`, regarded as a formal-kernel point, is divisible there by every power of two.  Separatedness gives

```text
21P=0.
```

The corresponding reusable Lean theorem should be purely group-theoretic:

```lean
structure TwoDescentSeparatedData
    (G L Q : Type*) [AddCommGroup G] [AddCommGroup L] [AddCommGroup Q] where
  loc : G →+ L
  red : L →+ Q
  quotient_exp : ∀ q : Q, 21 • q = 0
  two_surjective : ∀ P : G, ∃ R : G, P = 2 • R
  separated : ∀ x : red.ker,
    (∀ n : ℕ, ∃ y : red.ker, (2^n : ℕ) • y = x) → x = 0

lemma TwentyOneExponent.of_twoDescentSeparatedData
    (D : TwoDescentSeparatedData G L Q) :
    ∀ P : G, 21 • P = 0 := by
  -- Iterate `D.two_surjective`.
  -- Put `21 • loc(Q_n)` in `red.ker` using `D.quotient_exp`.
  -- Apply `D.separated` to `21 • loc(P)`.
  ...
```

No finite generation and no Mordell--Weil rank API appears in this argument.

# 4. An endpoint cheaper than determining all of `J(Q)`

For the N18 rational-point exclusion, after proving `21P=0` on `J(Q)`, it is unnecessary to prove or enumerate the abstract equality

```text
J(Q) = Z/21Z.
```

Use reduction modulo `5` directly on the curve.

Modulo `5`, the six smooth projective points are

```text
∞⁺, ∞⁻,
(0,1), (0,-1),
(-1,1), (-1,-1).
```

Indeed, for `x=1,2,3` the sextic value is a nonsquare modulo `5`, while at `x=0,-1` it equals `1`.  Hence

```text
#C(F_5)=6.
```

The same six points are rational over `Q`, and they are the rational cusps.

Choose `∞⁺` as basepoint and let

```text
i : C(Q) → J(Q),
P ↦ [P-∞⁺]
```

be Abel--Jacobi.  For a positive-genus smooth curve this map is injective.  Since every element of `J(Q)` is killed by `21` and `5∤21`, good reduction at `5` is injective on `J(Q)`.  Therefore reduction on `C(Q)` is injective:

- if `P,Q ∈ C(Q)` have the same reduction, then `i(P)-i(Q)` reduces to zero;
- injectivity on the prime-to-5 torsion group `J(Q)` gives `i(P)=i(Q)`;
- Abel--Jacobi injectivity gives `P=Q`.

The six rational cusps reduce to the six distinct elements of `C(F_5)`.  Hence

```text
C(Q) = {∞⁺,∞⁻,(0,±1),(-1,±1)}.
```

This endpoint is smaller than:

- computing the full group structure of `J(F_5)`;
- proving `J(Q)≅Z/21Z`;
- enumerating all twenty-one rational Jacobian classes and testing which contain an effective divisor of degree one.

For the final Mazur exclusion, this is the recommended endpoint.

# 5. Where the indispensable global 2-divisibility theorem comes from

There are two materially different meanings of the phrase “the 2-Selmer rank is zero”.

## 5.1 If the true cohomological Selmer group is already formalized

If one has a theorem

```lean
theorem n18_trueSelmer_eq_bot : Selmer2 J = ⊥
```

then the ordinary Kummer injection

```text
J(Q)/2J(Q) ↪ Sel₂(J/Q)
```

immediately gives `n18_two_surjective`.

In this situation the explicit étale algebra `L=Q[T]/(f)`, the squareclass quotient, and the theorem `ker δ=2J(Q)` are not needed at all.  The minimal global interface is only

```lean
theorem two_surjective_of_selmer_eq_bot
    (hSel : Selmer2 J = ⊥) :
    ∀ P : JQ, ∃ Q : JQ, P = 2 • Q
```

The caveat is that a database statement or an external Magma output saying “2-Selmer rank 0” is not yet such a Lean theorem.  One must still formalize how the finite certificate maps into the true cohomological Selmer group.

## 5.2 If what has been computed is the fake even-degree 2-Selmer group

Then a bridge cannot be omitted.  But a full generic Bruin--Stoll halving algorithm is unnecessary.

For this sextic, `Q4283-c51817a6.md` identifies the fixed certificate

```text
f(X) = g(X) * conjugate(g)(X)
```

over `Q(sqrt(-2))`, with two conjugate cubic factors.  The resulting Galois-stable unordered `3+3` partition has odd block size, so the fake cohomological map is injective.

The smallest theorem to build is only

```lean
/-- Fixed-curve, one-way bridge; no generic quotient exactness required. -/
theorem n18_fakeTrivial_implies_twoDivisible
    (D : JQ)
    (hD : IsFakeTrivial (xThetaRaw D)) :
    ∃ D' : JQ, D = 2 • D'
```

Together with the already finite fake-Selmer computation, this yields `n18_two_surjective`.

The `3+3` certificate removes the extra even-degree fake kernel, but it does **not** remove the one geometric comparison theorem between divisor evaluation by `x-T` and the Kummer cocycle.  That comparison is the irreducible global input.  The right economy is to prove it in only the direction displayed above and only for this curve.

# 6. Ranking by expected Lean line cost

The ranges below are engineering estimates, not formal complexity bounds.  They assume that a usable fixed genus-two Jacobian/Mumford group implementation is already present.  The 2-adic local model and Abel--Jacobi infrastructure are shared costs.

| Rank | Route | Approximate new proof burden | Verdict |
|---:|---|---:|---|
| 1 | **True Selmer zero already formal** → abstract Kummer injection → 2-adic separation → mod-5 curve injection | about `3k–6k` total including local and endpoint layers | Absolute minimum |
| 2 | **Fixed fake-Selmer bridge** from Q4283 → 2-adic separation → mod-5 curve injection | about `6k–10k` | Recommended from currently computable certificates |
| 3 | Full generic Bruin--Stoll even-degree descent, full `ker δ=2J`, local images, separation, Abel--Jacobi | about `12k–18k+` | Correct but unnecessarily general |
| — | Two good reductions + 2-adic separatedness, with no theorem `J(Q)=2J(Q)` | no finite line count: it cannot prove the result | Invalid route |
| 4 | Modular/CM decomposition of the Jacobian and a rank proof for the factors over an extension | likely at least as large as Route 3 in current Mathlib | Not recommended |

The line savings come from three restrictions:

1. expose only `∀P, ∃Q, P=2Q`, not a full Selmer exact sequence;
2. prove only the fixed one-way `x-T`/Kummer comparison if fake descent is used;
3. end with `#C(F_5)=6`, not a twenty-one-element Jacobian enumeration.

# Final answer to the design question

- The computed Jacobian orders are
  ```text
  21, 63, 84, 189
  ```
  at `p=5,7,11,13` respectively.
- Their gcd is `21`; `(5,11)` is the best two-prime pair for proving the torsion bound.
- These reductions prove `J(Q)_tors=Z/21Z`, but **cannot prove rank zero**.
- 2-adic separatedness becomes useful only after a global theorem supplies arbitrary iterated halves.
- The absolute minimal global statement is `J(Q)=2J(Q)`.
- If true `Sel₂=0` is already formal, use the ordinary Kummer injection and omit Bruin--Stoll entirely.
- If only fake Selmer data is formal, use the fixed `3+3` odd-partition bridge from Q4283; do not build a generic even-degree halving algorithm.
- After the resulting exponent-`21` theorem, finish the actual N18 point exclusion by the six-point reduction of `C` modulo `5`, which is cheaper than determining all of `J(Q)`.
